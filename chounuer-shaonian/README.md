# 丑奴儿·书博山道中壁 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《丑奴儿·书博山道中壁》（宋·辛弃疾）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**水墨夜思**赛道——全套冷银水墨色板，冷月是唯一主角。全词骨架是**今昔对照**：同一座八角层楼、同一条博山山道、同一个凭栏处，少年境稍亮稍暖（锈色霜叶是全页唯一的暖处），而今境转冷转沉，同景叠化。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"点击层楼"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：层楼今昔叠化 + 秋声四起（老者淡去、少年魂影浮显，锈赭记忆之光升起，落叶骤急、西风横流、雁阵横空，四声下行如一声轻叹 +「天凉好个秋」题字）
- 末章：全词回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#a0b4cc`（accent/按钮/边框/进度点/题字，全部银蓝水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#111826`～`#141c29`，fd 0.0048–0.0068 |
| 月 | 冷银白（ms 1.5–1.75），全页唯一主角；今境月沉云翳（mhaze 0.12）；星稀（亮度 0.38–0.5） |
| 粒子母题 | 微尘、霜晶、锈色落叶、横流西风（替代《将进酒》的金色流萤/火星） |
| 唯一暖色 | 少年境锈色霜叶（`#8a5a40`/`#54413a` 系，锈非金）与点击后升起的锈赭记忆之光——「少年」的一点余温，叠化后即冷 |

**有意的设计**：今昔两境用几乎相同的机位拍同一座楼（同景叠化）——境①少年"指月"凭栏、窗月微光稍亮；境②老者"独立"同处、雾更浓月更沉。点击后老者淡去、少年魂影在同一位置浮显，即"欲说还休"时涌上心头的那个少年。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，水墨赛道清朗男声）：

- `00.mp3` 题名（诗题自动提取："丑奴儿"）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字处理（`tts.json`，sub 非空即完全接管）：「为赋新词强说愁」之「强」读 qiǎng（勉强），替换表 `强说愁→抢说愁` 同音同调钉音；「欲说还休」之「还」按页面拼音读 hái，钉 `欲说还休→欲说孩休`。识（shí）、却（què）、好（hǎo）经核为默认读音，未钉。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：设问"'愁'可以被人看见吗？"再入境①，看少年登楼指点的意气，听"爱上层楼"的叠句回环。
2. **境①意象**：少年、层楼、霜叶三层意象逐层看——锈色霜叶是"强说愁"的那点刻意暖色；结合注释讲"强"读 qiǎng、是"勉强"之意。
3. **境②动作**：先让学生看同景转冷：雾更浓、月更沉、人更瘦。观察"一声轻叹化雾"的细节，再点击层楼看今昔叠化——问学生"楼影里浮出来的少年是谁？"
4. **主旨**：上片无愁找愁、下片愁深难言——"而今识尽"四字与"欲说还休"的两次叠句对读，体会"却道天凉好个秋"的言外之意。
5. **背景**：此词作于辛弃疾被劾落职、闲居江西带湖时期，博山在广丰西南，是他常往之地。
6. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 两境），境名逐一对齐（爱上层楼 / 却道天凉）；分境拼接与 queue.json 文本逐字一致。
- 交互境序号 `curIdx===2`（pointerdown + 空格双接线；空格首次触发交互、交互后再按才进终章，`clicked` 标志 + 1.2s 冷却门控）。
- 三层构图逐境齐备：`makeRange` 山脊背景 + `makeForeground` 前景框景（坡石/芦苇/树枝）+ 中景主体（`makeFigure` 少年/老者同位叠化、`makeCenglou` 层楼）；每帧写 opacity/intensity 均乘 fadeK，会增亮的材质初值=最大值；落叶用自定义 ShaderMaterial 显式传 vertexShader/fragmentShader。
- 校验：`node _pipeline/tools/validate.js chounuer-shaonian/index.html` → **✓ 校验全部通过**。
- 冒烟：`node chounuer-shaonian/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 两境 build/update ×400 帧 → 末境点击门控与 pointerdown → 自动游览至终章 → 键盘全路径 → 小测全流程；逐境 drawCall 代理 17/21/29，三角面 ≤0.9 万，fadeK 合规）。
