# 春夜洛城闻笛 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《春夜洛城闻笛》（唐·李白）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**水墨夜思**赛道——冷银水墨的洛城春夜，笛声是听不见却看得见的主角：它化作光缕，从谁家小楼的一点微光，散入春风、漫满全城。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"点击折柳"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：笛声化作柳丝漫卷洛城，远处故园剪影显影，"故园情"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#9fb0c9`（按钮/边框/进度点/题字，全部冷银蓝水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#111826`–`#121a27`，fd 0.0048–0.0065 |
| 月 | 冷银白（ms 1.6–1.9），全页唯一主角；境②月移向故园方向（mph 0.08 微缺） |
| 星 | 稀疏（亮度 0.45–0.5） |
| 粒子母题 | 笛声光缕、横流春风、柳絮、万户窗火（冷银）、夜雾微尘 |

**「暗」与「满」的对照**是本篇的美术题眼：境①吹笛小楼藏在城下，窗光只有一点（暗飞声）；而笛声光缕自那一点漫散开来，两层光带随风掠过高城万户的屋脊（满洛城）——无形之声被画成有形的光。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，免密钥生成）：

- `00.mp3` 标题（"春夜洛城闻笛"）
- `01–02.mp3` 两句逐境朗读
- `03.mp3` 全诗连读

多音字以页面拼音为准，`tts.json` 钉写 1 条同音同调替换：`曲中闻折柳 → 取中闻折柳`（强制"曲"读 qǔ）；"散"（sàn，散入）与"折"（zhé，折柳）语境读音明确、未钉写。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：问学生"声音看得见吗？"再入境①，对照画面找"笛声从哪里来、飘到了哪里"。
2. **境①炼字**：扣住「暗」与「满」——「暗」写笛声不知来处、悄悄入夜，「满」写它随春风无处不至；体会"以形写声"的妙处。
3. **境②典故**：讲折柳赠别习俗（「柳」谐「留」），《折杨柳》曲多写离愁；点击折柳看"笛声—柳丝—故园"的意象串联。
4. **情感**：读"何人不起故园情"的反问，讨论为什么一声笛能让全城人思乡；可结合李白客居洛城的背景。
5. **收束**：末章全诗连读一遍，再做 5 题小测（接龙 ×2、词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；诗文与 `queue.json` 口径逐字一致。
- 交互境序号 `curIdx===2`（pointerdown + 空格双接线，空格先交互、再按进终章）；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 每帧写 opacity/intensity 均乘 fadeK，材质初值=写入区间最大值；自定义光缕着色器显式双 shader、uFade 每帧同步；单境 draw call ≤27、三角面 ≤1.2 万。
- 校验：`node _pipeline/tools/validate.js index.html` → **✓ 校验全部通过**（零警告）。
- 冒烟：`node smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 逐境 build/update×400 帧 → 末境点击门控与 pointerdown → 自动游览至终章 → 小测满分全流程，多次运行稳定）。
