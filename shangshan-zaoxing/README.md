# 循文入境 · 商山早行（唐 · 温庭筠）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（首次需联网加载 Three.js，音频本地播放）。

## 四境

| 境 | 诗句 | 看点 |
|---|---|---|
| 壹 · 晨铎催行 | 晨起动征铎，客行悲故乡。 | 木架悬铎随霜风摇响，斗笠旅人拄杖背囊踏上残夜山路 |
| 贰 · 霜桥人迹 | 鸡声茅店月，人迹板桥霜。 | **标志性瞬间**：茅店上空一轮残月，鸡声化作声波涟漪荡开，板桥白霜覆面。**点击画面/空格**：霜上足迹自桥头逐个亮出 + 鸡声啼鸣 + 题字 |
| 叁 · 槲路枳花 | 槲叶落山路，枳花明驿墙。 | 槲叶纷纷落在弯弯山路上，白枳花簇拥驿墙、微光映亮（"明"字动词化的画面解释） |
| 肆 · 凫雁回塘 | 因思杜陵梦，凫雁满回塘。 | 梦中春塘暖色调，凫雁浮水、飞雁低回。**点击画面/空格**：涟漪荡开、雁群惊起——暖闹反衬岸头旅人的孤独 |

## 使用

- `← →` 或空格逐境游览；底部可切自动游览 / 自动朗读 / 注音 / 声音 / 全屏。
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置 MP3 → 系统语音。
- `audio/`：00 标题、01–04 各句、05 全诗，共 6 个 MP3（百度 TTS 生成；如需"诗朗诵"级可配 `TTS_AZURE_KEY` 重跑 gen-voice.js）。

## 教学要点

- 名句"鸡声茅店月，人迹板桥霜"：六个名词性意象纯然并列、不着动词（意象并置考点），对应第贰境画面。
- 多音字/难字注音：铎 duó、槲 hú、枳 zhǐ、凫 fú、迹 jì、驿 yì。
- "明"形容词作动词（照亮）；尾联以梦中之暖反衬旅途之孤（反衬考点）。
