# 循文入境 · 清明（唐 · 杜牧）

Three.js 沉浸式诗词课件（单文件网页，生产队列 41/72 · 烟雨江南赛道 · 清明雨巷变体）。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；朗读音频已内置在 `audio/`，无网时自动回退浏览器语音）。

## 三重意境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 雨纷纷 | 清明时节雨纷纷 | 清明烟雨湿旷野：水田田埂、时疏时密的斜雨、远处一株杏花伏笔 |
| 贰 · 欲断魂 | 路上行人欲断魂 | 泥泞长路：行人斗笠低伏、竹杖点地缓行没入雨雾，路旁野亭无处久避 |
| 叁 · 借问遥指 | 借问酒家何处有，牧童遥指杏花村 | 行人拱手问路，牧童骑牛抬臂遥指（**点击画面 / 空格：雨幕沿指向裂开、杏花村显现、题字「牧童遥指杏花村」**；再点落杏花雨） |

基调：湿冷烟雨中透出暖意——前两境全冷色，末境雨歇处一线暖光、粉白杏花与酒旗。

## 操作

- `← →` / 空格：切境；点击进度点跳境；「自动游览」默认可开，课堂无人值守展示（末境 7.5s 后自动裂开雨幕）。
- 第三境可点击画面触发互动（每 2.4 秒可重复）。
- 控制条：朗读此句 / 自动朗读 / 注音开关 / 声音开关 / 全屏。

## 配音生成

```bash
python _pipeline/tools/gen-voice-edge.py qingming
```

本诗多音字已逐字核对：**魂 hún**（欲断魂）、**酒 jiǔ**、**处 chù**（何处）、**行 xíng**（行人）、**指 zhǐ**——均为 TTS 默认正确读音，无需同音字替换表。配置 `TTS_AZURE_KEY` 环境变量可升级为 Azure 神经语音「诗朗诵」音色。

## 教学建议

- 多音字：**魂 hún**（欲断魂）、**处 chù**（何处，名词读四声）、**行 xíng**（行人）。
- 考点：「断魂」形容愁苦忧伤而非实指魂魄离散；杏花村为杏花深处有酒家的村庄（今安徽池州亦有杏花村之说）。
- 情感线：雨纷纷的湿冷 → 欲断魂的愁苦 → 遥指杏花村的暖意，可让学生对比三境画面色温体会"哀而不伤"。
