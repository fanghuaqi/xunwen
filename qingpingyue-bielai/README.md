# 清平乐·别来春半 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《清平乐·别来春半》（五代·李煜）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**水墨夜思**赛道——全套冷银水墨色板，冷月是唯一主角；**落梅白**与**春草微青**是全页仅有的两处色彩层次，无一处金色。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"点击拂梅"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：梅雪扑落又纷回，春草沿长路更行更远还生（草地逐排立起蔓向天际 + 五声琴韵 +「更行更远还生」题字）
- 末章：全词回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#a8bcd4`（accent/按钮/边框/进度点/题字，冷银水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#0f1520`→`#121a26`，fd 0.0048–0.0074（随境渐浓渐远：春半→梅乱→雁杳→草蔓） |
| 月 | 冷银白（ms 1.6–1.9），全页唯一主角；星随离愁渐稀（亮度 0.45→0.32） |
| 粒子母题 | 落梅白瓣、砌下残梅、草原微尘、横渡雁影（替代《将进酒》的金色流萤/火星） |
| 仅有的色彩层次 | 境①**落梅白**（花簇/纷瓣/积肩，`#dde6f2` 系）；境②**春草微青**（草尖 `#74927e`，低饱和青灰） |

**情感曲线**：春半（明净）→ 梅乱（纷飞）→ 雁杳（空阔）→ 草蔓（绵浓）——雾密度逐境增大、星亮度逐境降低，冷月始终是唯一光源主角。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，水墨赛道清朗男声）：

- `00.mp3` 题名（诗题自动提取："清平乐·别来春半"）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字处理（`tts.json`，sub 非空即完全接管）：「拂了一身还满」之「了」读 liǎo（完毕）、「还」读 huán（仍旧、又），「更行更远还生」之「还」读 huán——同音同调钉音（了→瞭、还→环）。砌（qì）、雁（yàn）经核为默认读音，未钉。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"别来多久了？"——"春半"既是时节也是心事（别后不觉春过半）；再入境①对照画面数一数落梅。
2. **境①动作**：让学生盯住词人的肩头看满一个 9 秒周期——积满、拂散、又落满，体会"拂了一身还满"为什么是离愁的具象（了 liǎo、还 huán 两个读音随手带过）。
3. **境②意象**：先看雁（鸿雁传书之典——雁至而书不至），再看长路与尽头那个走不到的人影，最后点击画面看春草如何"更行更远还生"。
4. **主旨**：全词以落梅、春草两个"无穷无尽"的意象写离恨——梅拂了还满是"去而复来"，草更远还生是"愈远愈深"；比较两个比喻的方向不同。
5. **收束**：末章全词连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 两境），境名逐一对齐（砌下梅雪 / 恨如春草）；分境拼接与 queue.json 文本逐字一致。
- 交互境序号 `curIdx===2`（pointerdown + 空格双接线；空格首次触发交互、交互后再按才进终章，`clicked` 标志 + 1.2s 冷却门控）。
- 三层构图逐境齐备：`makeRange` 山脊背景 + `makeForeground` 前景框景（坡石/芦苇/树枝）+ 中景主体（`makeFigure` 词人、`makeCrowd` 归人影）；每帧写 opacity 均乘 fadeK（肩头积梅初值=最大值），落梅/梅雪/春草三枚自定义着色器均显式传 vertexShader/fragmentShader，春草着色器进 `fogShaders` 同步雾。
- 校验：`node _pipeline/tools/validate.js qingpingyue-bielai/index.html` → **✓ 校验全部通过**。
- 冒烟：`node qingpingyue-bielai/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 两境 build/update ×400 帧 → 末境点击门控与 pointerdown → 自动游览至终章 → 键盘全路径 → 小测全流程；逐境 drawCall 代理 18/22/21，三角面 ≤0.9 万，fadeK 合规）。
