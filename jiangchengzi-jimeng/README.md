# 江城子·乙卯正月二十日夜记梦 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《江城子·乙卯正月二十日夜记梦》（宋·苏轼）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。悼亡词之冠，本版为**水墨夜思**赛道——全套冷银水墨色板，冷月与孤坟是底色，小轩窗的一盏暖光是全页唯一的暖色：冷暖对照，即是「生死之隔」。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境③先触发"梳妆影凝现"，再按才进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境③轻点画面：窗内梳妆影凝现、明月光柱垂照短松冈，"明月照短松冈"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#b8c4dd`（按钮/边框/进度点/题字，全部冷银水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#121926` 系，fd 0.0050–0.0060 |
| 月 | 冷银白，全场唯一主角；境③放至 ms 2.2，低悬于短松冈之上 |
| 星 | 稀疏（亮度 0.16–0.32，梦境内压至最低） |
| 粒子母题 | 茫茫横流的雾海、微尘、霜晶微闪、泪光细痕（替代《将进酒》的金色流萤/火星） |

**有意的设计**：境②"小轩窗，正梳妆"的窗纸与窗内剪影保留**暖橙**（窗纸 `#d99a55`、外辉 `#eab36a`、暖点光）——它是全页唯一的暖源，是"家"的温度；与全局冷银底形成唯一对比，让学生一眼读出"月是冷的，家是暖的"。境③梦将醒，窗内影散作微茫，点击后梳妆影**凝现**（唯一暖点最后一次亮起），随后明月光柱垂照短松冈——暖光退场，冷月收束全词。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%）：

- `00.mp3` 标题（江城子·乙卯正月二十日夜记梦）

## 教学建议

1. **导入**：从词题入手——"记梦"为什么值得专门写一首词？再入境①，看"茫茫"的雾海如何隔开两界。
2. **境①对写**：结合注释讲王弗其人与"千里孤坟"，让学生找出画面里"无处话凄凉"的空旷感。
3. **境②冷暖**：让学生在冷银画面里找出唯一的暖色——小轩窗；讨论为什么梦里还乡的第一眼是"正梳妆"这样的家常瞬间。
4. **境③留白**：点击看梳妆影凝现、明月照短松冈，讨论"相顾无言"为什么胜过千言万语；"短松冈"与"千里孤坟"遥相呼应。
5. **收束**：末章全诗连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
