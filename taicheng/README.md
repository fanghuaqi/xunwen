# 台城 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《台城》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**烟雨江南**赛道，取「台城柳堤」变体——霏霏江雨、齐整江草、烟雨中若隐若现的六朝宫阙残影，以及十里长堤上"依旧烟笼"的一行垂柳。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击烟堤"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：柳烟渐浓漫过十里长堤，六朝宫阙残影如梦散去，"烟笼十里堤"题字同现
- 末章：全诗回放、学习小测（5 题）

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 `zh-CN-XiaoxiaoNeural`，语速 −16%，烟雨婉约赛道音色）：

- `00.mp3` 标题（"台城"）
- `01.mp3` 境壹（江雨霏霏江草齐，六朝如梦鸟空啼。）
- `02.mp3` 境贰（无情最是台城柳，依旧烟笼十里堤。）
- `03.mp3` 全篇连读

多音字处理见 `tts.json`（**sub 非空即完全接管**，不再叠加脚本内置兜底表）：

- `烟笼` → `烟垄`：钉住「笼」的动词读音 **lǒng**（笼罩）。「笼」作名词（笼子）读 lóng，是本诗最易读错的字，注释与第 3 题小测同点
- 其余逐句核过：江雨霏霏、江草齐、六朝 liù cháo、鸟空啼、无情、台城柳、依旧、十里堤——无须干预

页面朗读优先级：Edge 在线自然语音现场逐句朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"如果一座都城只剩下风景，会是什么样子？"再入境壹。
2. **境壹读景**：找出四个景——雨、草、鸟、柳（后两句）；"鸟空啼"的"空"字怎么讲？（鸟不知兴亡，啼声愈清，愈显故都之空。）
3. **境贰析情**：柳本无情，诗人为何说它"最是无情"？——正因它年年如此、一如往昔，才衬得人事全非；这是以"无情"写"有情"。
4. **点击体会**：点击烟堤看柳烟漫堤、残影散尽，让学生说一句"此刻柳色为什么让人难过"。
5. **知人论世**：韦庄身处唐末乱世，凭吊六朝故都（今南京），实为伤今（六朝三百年，唐亦将尽）。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音义 ×1、典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 37 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（长堤、垂柳、诗人）都在 20–40 单位内，fd ≤ 0.0082；残柱唯一一处「每帧写 opacity」处已乘 fadeK，基座 = 运行期最大值 0.40；雨丝/柳烟/水面等着色器全部登记 `fogShaders`，穹顶/星/月 `fog:false`。
- 场景构件（冒烟实测）：卷首 14 mesh / 3 points / 12 sprite、境壹 18 mesh / 3 points / 11 sprite、境贰 21 mesh / 3 points / 12 sprite；draw call 代理值 29 / 32 / 36（≤120），三角面 ≈2.5 / 3.4 / 2.5 万（≤12 万）。
- 校验记录：
  - `node _pipeline/tools/validate.js taicheng/index.html` → **✓ 校验全部通过**
  - `node taicheng/smoke.test.js` → **SMOKE PASS**（连跑 3 次稳定）
  - `node _pipeline/accept.js taicheng` → **ACCEPT**（下见汇报）
- 实拍抽检（`_pipeline/shots.py`，输出到系统 Temp，逐张 Read 检查）。
