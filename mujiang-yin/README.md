美术赛道：夜宴金彩 · 残阳弓月变体（--gold #d9b06a，底色 #120d08；情绪从暖金到清蓝）。

## 使用
- 双击 `index.html`（首次需联网加载 Three.js）；自动朗读 + 自动游览默认开，可课堂大屏无人值守。
- `audio/00-04.mp3`：00 标题、01-03 各境、04 全诗（百度 TTS 生成；无音频时自动回退浏览器语音，Edge 下为神经语音现场朗诵）。
- 操作：← → 或空格逐境；第三境点击/空格触发"日沉月升"。

## 注音自查（多音字）
一道（yí，变调）· 铺 pū（动词）· 瑟瑟 sè · 可怜 lián（可爱）· 露 lù · 似 sì · 弓 gōng。
注：百度 TTS 无多音字上下文模型，若 01.mp3 中"铺"读音存疑，以页面注音 pū 为准（或删除 audio/ 用 Edge 神经语音回退）。

## 教学
- 考点：①"铺"字妙处（阳光低斜贴水面）；②"瑟瑟"＝青碧（未受光侧），非琴瑟；③"可怜"＝可爱；④两个比喻句"露似真珠""月似弓"（九月初三为弯月、秋夜始有露）。
- 时间线设计即诗线：前两境的"暮"与第三境的"夜"由天空/雾色逐境插值过渡。
