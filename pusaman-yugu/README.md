# 菩萨蛮·书江西造口壁 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《菩萨蛮·书江西造口壁》（宋·辛弃疾）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**水墨夜思**赛道——全套冷银水墨色板，冷月是唯一主角，江面泪光是全词之痛，末境「毕竟东流去」是全词气骨。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②先触发"冲开夹峙"，再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：雾闸散开、两岸青山向两侧让路、一线银光水路亮起、急流迸发，鹧鸪啼声与"毕竟东流去"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#8fa4c0`（queue 分配强调色；按钮/边框/进度点/题字，全部银蓝水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#131a26`，fd 0.0048–0.0062 |
| 月 | 冷银白，全页唯一主角（ms 1.65–1.85）；末境转沉：月弱、雾深、星稀 |
| 星 | 稀疏（亮度 0.36–0.50） |
| 粒子母题 | 江面泪光（冷银微点浮水）、流云横移、微尘、水雾急流（替代金色流萤/火星） |

**有意的设计**：境②"江晚正愁余"整体转沉（fd 0.0062、star 0.36、月偏弦），点击前下游被**雾闸**封住去路——"青山遮不住"先要"遮"；点击后雾闸散开、两岸崖壁让路、一线银光水路亮起、水流加急，是大势不可挡的唯一亮色，与全局冷银底形成张力。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，`gen-voice-edge.py` 生成）：

- `00.mp3` 标题（"菩萨蛮·书江西造口壁"）
- `01.mp3` 上片逐境朗读
- `02.mp3` 下片逐境朗读
- `03.mp3` 全词连读

多音字处理（`tts.json`）：「江晚正愁余」钉读 zhèng（同音同调接管）；「无数山」之「数」读 shù、「遮」zhē、「鹧鸪」zhè gū 均为默认常读，无需替换。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。如需"诗朗诵"级音色，可设 `TTS_AZURE_KEY` 后重跑 `gen-voice.js`。

## 教学建议

1. **导入**：封面设问"一条江能承载多少眼泪？"再入境①，对照"中间多少行人泪"看江面泪光。
2. **境①望断**：结合注释讲建炎年间金兵追隆祐太后至造口的史事——"行人泪"是国难之泪；西北层山遮断望眼，"可怜"二字压住全句。
3. **境②气骨**：先看被雾闸封住的江水，让学生读"青山遮不住，毕竟东流去"，再点击冲开夹峙——体会以水喻大势的手法。
4. **境②收束**：听鹧鸪四声下行啼鸣，讲"行不得也哥哥"的民间拟声如何把恢复无路的悲愤收进暮色。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境，N=queue stages=2），境名逐一对齐；诗文逐字与 queue.json 一致（西北望长安/毕竟东流去/正愁余从教材通行本）。
- 交互境序号 `curIdx===2`（pointerdown + 空格双接线，clicked 标志 + 1.2s 冷却）；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
