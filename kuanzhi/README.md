# 客至 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《客至》（唐·杜甫）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**青绿春晓**赛道——春水绕舍、群鸥花径、蓬门浊酒的浣花溪人家，是全集里最温暖亲切的页面之一。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"隔篱呼邻"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：柴门呀然内开，白发邻翁举杯穿门而入，酒盏相碰迸出暖光与"隔篱呼取尽余杯"题字
- 末章：全诗回放、学习小测（5 题）

## 朗读配音

`audio/` 内置 6 个 AI 朗读 MP3（Edge 神经语音 zh-CN-XiaoxiaoNeural，青绿赛道自动选声，免费无密钥）：

- `00.mp3` 标题（"客至"）
- `01–04.mp3` 四联逐境朗读
- `05.mp3` 全诗连读

多音字经 `tts.json` 同音同调接管（非空 sub，不叠兜底表）：舍南舍北→社南社北（舍 shè）、为君开→卫君开（为 wèi）、盘飧→盘孙（飧 sūn）、旧醅→旧胚（醅 pēi），`--dry` 逐条核对后合成。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：问学生"如果客人突然到家，你会怎么迎？"再入境①，看春水绕舍、惟有鸥鸟做客的清幽与寂静。
2. **境②对衬**："不曾缘客扫"与"今始为君开"互为映衬——让学生找画面里"为君开"的动作（主人倚门、客在花径），体会不事虚礼的真心。
3. **境③自谦**：数一数案上几碟几器，"无兼味、只旧醅"是待客从简的实话，为什么读来反而亲切？
4. **境④高潮**：点击蓬门看"隔篱呼取"，讨论"为什么可以随口喊邻居来喝酒"——宾主之欢延展到邻里之谊，人情之美尽在不言中。
5. **背景**：此诗作于上元二年（761）春杜甫定居成都草堂时，题下自注"喜崔明府相过"（明府为县令尊称）；与"黄四娘家花满蹊"同写浣花溪畔生活。
6. **收束**：末章全诗连读，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 四境），境名逐一对齐；诗文逐字同 queue.json。
- 交互境序号 `curIdx===4`（clicked 标志 + 1.2s 冷却 + 可重复触发碰杯）；进度点/按键/自动游览末境判断均以 `POEM.length=4` 对齐；全诗音频 `05.mp3`。
