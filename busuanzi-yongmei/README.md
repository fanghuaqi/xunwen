# 循文入境 · 卜算子·咏梅（陆游）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，配音在本地 `audio/`）。

## 四境

| 境 | 词句 | 画面 |
|---|---|---|
| 壹 · 驿外断桥 | 驿外断桥边，寂寞开无主。 | 荒驿驿道、溪涧断桥，一株寒梅独立桥头，落瓣稀疏；行人沿驿道远去，不曾为它停留 |
| 贰 · 风雨黄昏 | 已是黄昏独自愁，更著风和雨。 | 暮色压城，雨丝斜织、风扫荒草，梅枝在风里乱颤，驿中一点冷光，无人出来看花 |
| 叁 · 无意争春 | 无意苦争春，一任群芳妒。 | 远处群芳林与花田喧闹争春、蜂蝶往来；镜头却缓缓转开，落在近处冷清一侧的孤梅上 |
| 肆 · 零落成泥 | 零落成泥碾作尘，只有香如故。 | **标志性瞬间**：花瓣簌簌坠落、积于泥中，被石碾碾作尘点；一缕淡香雾逆风升起，被吹散又重新聚拢——香不随花灭 |

美术：宣纸留白（浅色赛道）—— 纸底 `#e9e2d0`、墨字、浓墨远山，全诗只留梅瓣的一点淡绛；
落瓣（飘坠）、雨丝（斜织）、香雾（逆风不散）三套粒子母题，与《将进酒》的夜宴金彩形成明显反差。

## 使用

- `← →` / 空格逐境游览；**第四境轻点画面或按空格**唤一阵风雨：雨骤风急、落瓣纷飞，香雾却更分明（题字「香如故」）。
- 控制条：自动游览（默认开）/ 朗读此句 / 自动朗读（默认开）/ 注音（默认开）/ 声音 / 全屏；终章附 5 题学习小测。
- 封面与终章均有「返回诗集目录」链接（`../index.html`）。
- 朗读管线：Edge「在线自然语音」→ 现场逐句朗诵；否则回退 `audio/00-05.mp3`（00 标题、01-04 各境、05 全词）。

## 课堂建议

1. **先整体自动游览一遍**（约 70 秒），让学生说出画面里"冷 → 更冷 → 转头不看热闹 → 落尽"的情绪曲线。
2. **逐字跟读**，重点正音：`著 zhuó`（更著风和雨）、`一任 yī rèn`、`碾 niǎn`、词牌 `卜算子`的「卜」读 `bǔ`。
3. **注释对照**：本词有多处考点可展开——「驿」（古代传递公文者歇宿换马之处）、「无主」（花开无人欣赏）、「著」（同"着"，遭受）、「碾作尘」（摧折之彻底）。
4. **名句品读**：末境可让学生先看图再读句，讨论"零落成泥碾作尘，只有香如故"里"香"指的是什么（梅香 / 品格 / 操守）；点击唤风雨，看香雾被吹散又自聚，体会"风雨不改"。
5. **对照阅读**：与毛泽东《卜算子·咏梅》（"反其意而用之"，梅是"傲然绽放、笑迎风雪"）对读，比较同调词中梅的形象差异，写一段 100 字短评。
