# 陇西行 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《陇西行》（唐·陈陶，《陇西行四首》其二）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**大漠金戈**赛道——但刻意避开孤城/金甲/雪弓刀/梦回连营等既有边塞构图，写的是这场悲剧的**两重时空**：境壹=暮色沙场（誓师出征→冲入胡尘），境贰=冷月寒滩（无定河边残戈锈甲 ↔ 春闺梦影）。accent=#c4823a（赭金）只落在军旗/戟锋/人物边缘光/梦烛暖光/UI 上，禁艳金。白骨意象克制写意：只做残戈、锈甲、箭镞散落寒滩，不直写尸骸。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"骨梦对切"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：春闺窗影暖光浮现，闺中人与梦里人窗前相对，冷滩与暖梦如电影交叉剪辑般缓缓明灭，"可怜无定河边骨 犹是春闺梦里人"题字同现
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：先讲题目——《陇西行》是乐府旧题，多写边塞征战；陈陶这组《陇西行四首》约作于晚唐宣宗年间，本篇为其二、也是最著名的一首。可先让学生带着"这场战争谁赢了"的问题入境。
2. **境①诗眼**：「誓」与「丧」——「誓扫」「不顾身」写尽出征的果决豪勇，「五千貂锦」愈众愈重；而五千人的性命只化成「丧胡尘」三个字。让学生注意：诗人完全不写交战过程（画面里也只给冲入尘沙），前句有多壮、后句就有多痛。
3. **境②点击后**：看重现的春闺梦影与冷滩残戈交叉明灭，讨论「犹是」二字——家里不知死讯，他仍是梦里活生生的人；「春」字愈暖，消息愈寒。
4. **写法**：诗人把「河边骨」（现实·实·冷）与「梦里人」（梦境·虚·暖）两个时空的画面剪在一起，不说破、不议论——虚实对写、以美梦写惨祸，可对照"正面描写战争惨状"的写法讨论留白的力量。
5. **常识**：「无定河」黄河支流，河道迁徙、深浅不定而得名，唐代著名边塞战场——地名本身就是命运的隐喻（"无定"的人生）。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、文学常识 ×1、名句理解/反战主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 28 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 交互境序号 `curIdx===2`（pointerdown 与空格双接线，`clicked` 标志 + 1.2s 冷却防连点；空格先交互、再按进终章）。
- fadeK 铁律：所有每帧写 opacity/intensity 的对象（残阳、梦烛点光、冷光、梦影与窗棂材质）初值=最大且逐帧乘 fadeK；军旗/无定河自写 ShaderMaterial 显式带 `uFade`；河面着色器推入 `fogShaders` 做雾同步。梦影组点击前整组 `visible=false` 硬关，杜绝任何渲染时序下的幽灵残影。
- 预算：三境 drawCall 代理 ≈ 18/26/27、三角面 ≈ 0.98/2.25/0.79 万（≤120 / ≤12 万）。
- 校验：`node _pipeline/tools/validate.js longxixing/index.html` → **✓ 校验全部通过**；`node longxixing/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 逐境 build/update×400 帧 → fadeK 合规 → 末境点击门控 → 自动游览至终章 → 小测满分）；`node _pipeline/accept.js longxixing` → **ACCEPT（2境 · 大漠金戈）**。
- 实拍：`shots.py` 封面/两境/终章逐张人工检查通过；标志性瞬间（冷月寒滩 ↔ 春闺梦影对切）经实拍迭代修掉三处穿帮（自写 ShaderMaterial 未挂 vertexShader/fragmentShader 被 three 默认红debug材质渲染成红旗与红河、军旗颜色过艳、梦影组未点击时的幽灵残影→visible 硬关）。
- 文本口径：诗文逐字为「誓扫匈奴不顾身，五千貂锦丧胡尘。可怜无定河边骨，犹是春闺梦里人。」与 queue.json 一致。
