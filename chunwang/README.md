# 春望 · 循文入境（唐 · 杜甫）

单文件沉浸式诗词课件：诗句逐境推进，Three.js 三维实景 + 逐字注音 + 释义注释 + AI 朗读 + 学习小测。
双击 `index.html` 即可打开（需联网加载 Three.js 引擎，音频为本地 MP3）。

## 四境导览

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 国破城春 | 国破山河在，城春草木深 | 断墙豁口、春草漫过废墟，远处山河依旧 |
| 贰 · 花泪鸟惊 | 感时花溅泪，恨别鸟惊心 | 花丛带露如泪、栖鸟骤然惊起（乐景写哀） |
| 叁 · 烽火家书 | 烽火连三月，家书抵万金 | 标志瞬间：远山烽燧火光连成一线，案头家书是全页唯一暖光 |
| 肆 · 白头簪影 | 白头搔更短，浑欲不胜簪 | 青灯白头；**点击画面/按空格**展开案头家书，字迹发光、暖光泛起 |

美术：水墨夜思 · 国破城春变体——全诗冷灰蓝调（bg `#0d1117`、强调 `#b0bccd`），唯一暖色给家书。

## 使用

- 「入境」后自动朗读 + 自动游览；← → / 空格逐境，Esc 停止。
- 控制条可关自动游览/自动朗读/注音/声音；第四境点击画面展开家书。
- 朗读优先级：Edge 神经语音现场朗诵 → 本地 `audio/00–05.mp3` → 系统语音。

## 朗读多音字

页面注音：溅 jiàn、搔 sāo、簪 zān、胜 shēng（旧读，按教材）。
音频生成时「不胜」替换为同音「不升」以读出 shēng（仅影响音频，不改页面文字）。

## 课堂建议

- 由景入情：先看断墙与春草的反差，再问「为什么花开反而落泪」。
- 名句精讲：烽火/家书一冷一暖的对比；尾联「搔」字细节与忧国忧己。
- 小测 5 题覆盖接龙、读音（溅/胜）、词义（抵/搔）。
