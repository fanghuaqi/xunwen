# 循文入境 · 观书有感（宋·朱熹）

「半亩方塘一鉴开，天光云影共徘徊。问渠那得清如许？为有源头活水来。」

单文件沉浸式诗词课件（Three.js r128，CDN 三路回退；音频本地）。双击 `index.html` 即可打开（首次需联网加载引擎）。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 方塘鉴开 | 半亩方塘一鉴开，天光云影共徘徊。 | 浅色宣纸全链路换肤：一方静塘平铺如镜，天上云与水面云影同步徘徊，塘心一道"鉴"环随光呼吸 |
| 贰 问渠 | 问渠那得清如许？ | 低空掠过塘面：水至清而见游鱼（背脊出水、尾随微漪） |
| 叁 源头活水 | 为有源头活水来。 | 标志瞬间：镜头循水面推向塘角石隙，一泓活水注入，涟漪带起天光云影流转（点击源头可引泉+云影流转+题字） |

## 操作

- `入境` 进入；`← →` 或空格逐境；第三境**点击画面/空格**触发源头活水
- 自动游览 / 自动朗读默认开，可作课堂大屏无人值守展示
- `朗读此句` 朗读当前句；终章可聆听全诗、做 5 题学习小测

## 朗读

- `audio/00–04.mp3`（00 标题·作者，01–03 各句，04 全诗），百度 TTS 生成，多音字已按读音替换（那 nǎ / 为 wèi）
- Edge 浏览器下优先使用"在线自然语音"现场逐句朗诵；无 MP3 时自动回退系统语音

## 教学

- 注音全句覆盖；多音字：鉴 jiàn / 徘 pái / 徊 huái / 渠 qú / 那 nǎ / 为 wèi
- 注释含考点：「渠」是代词（不是水渠）；说理诗"方塘喻心、活水喻学"
- 小测 5 题：接龙 ×2、词义 ×1、文学常识 ×1、主旨 ×1
