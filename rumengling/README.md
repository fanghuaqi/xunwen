## 三、教学建议

1. **导入（听雨）**：先只放第壹境画面与雨声，问「这场雨是大是小？」——从「疏」「骤」二字入手，
   体会「雨点不大、风却急」的夜里，词人是带着残酒沉沉睡去的。
2. **一问一答（第贰境）**：把「试问卷帘人，却道海棠依旧」读成对话。问得**小心**（试问），
   答得**随意**（却道）——对比之下，词人的惜花之心才显得深。
3. **炼字（第叁境）**：请学生先不看画面，猜「绿肥红瘦」应该看到什么；再点击卷帘验证。
   重点讲两点：① 借代——以「绿」「红」代叶与花；② 炼字——用「肥」「瘦」写叶茂花残，
   比「叶茂花残」更具情味（花如人，因人瘦而惜）。
4. **主旨**：由惜花到惜春、惜时；联系她另一首《如梦令·常记溪亭日暮》，点明「小令」篇制短小、
   同为李清照婉约词。
5. **朗读**：跟读音频，注意「卷（juǎn）」「绿（lǜ）」「应（yīng）」「否（fǒu）」四处读音。

## 五、备注

- 雨声由 WebAudio 现场合成（带通噪声，随「雨疏→雨歇」逐境减弱），非音频文件。
- 语音优先级：Edge「在线自然语音」现场逐句朗诵 → 内置 MP3 → 系统语音；切境即停。
- 若首句朗读无声，多为浏览器未授权/离线：页面会自动降级到内置 MP3。
- 自绘美术（防同质化）：雨丝着色器（点精灵内画细线，随「风」变斜）、花瓣飘落着色器、
  canvas 生成的竹帘纹理（细竹条 + 条间透光 + 编绳横档）；全境藏月（烟雨夜），
  以雾密度 0.016→0.0095 的渐变把「夜雨→帘问→雨止天明」的情绪曲线做出来。
