# 八声甘州 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《八声甘州·对潇潇暮雨洒江天》（宋·柳永）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**水墨夜思**赛道——冷银水墨、全页禁金，暮雨/霜风/寒江俱冷；残照是全页唯一锈赭低饱和暖色（同《忆秦娥》先例）。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"点击倚阑干"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：倚栏人影凝愁显形，天际归舟虚影往复愈明，"正恁凝愁"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#98aec8`（accent 取自 queue；按钮/边框/进度点/题字/人物边缘光，**全页无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#131a26` 系，fd 0.0056–0.0082（逐境渐沉，境④最浓） |
| 月 | 全隐（ms 0.001 入地下）——雨暮无月，全页唯一"天光"是境①那束锈赭残照 |
| 残照 | 锈赭低饱和（`#7a4638` 系光 + additive 光束 shader），禁金先例同《忆秦娥》 |
| 粒子母题 | 斜急暮雨、侧扫霜风（转向雾流）、褪红黯翠残屑（红衰翠减）、贴水横雾、天际归舟虚影（替代金色流萤/火星） |

**有意的设计**：①境「残照当楼」是全页唯一暖源——一束锈赭残照打在江楼之上，而天地俱冷（苏轼所谓「不减唐人高处」）；②境两层侧向雾流整体转向，把"无语东流"拍成可以看见的水流方向；境③（我望故乡·危台背影远镜）与境④（她望天际·妆楼反打）构成镜头对切，末境点击倚阑干后，倚栏人影凝愁显形、天际归舟虚影往复——两地域愁，一语双绾。

## 教学建议

1. **导入**：从"秋雨"设问——一场秋雨把世界洗成了什么颜色？再入境①对照"一番洗清秋"，看雨、风、关河如何一层层"冷"下去。
2. **境①名句**：先看画面再读"霜风凄紧，关河冷落，残照当楼"，找一找画面里唯一的暖色——为什么这点"暖"反而更冷？引苏轼「不减唐人高处」。
3. **境②练字**："红衰翠减"为何不说"花谢叶落"？让学生体会"无语东流"——江水不是不会说，是替人说。
4. **境③动作**："不忍登高临远"却为何还是登了？看背影与远到几乎看不见的村影，理解"渺邈"与自问"何事苦淹留"。
5. **境④对写**：点击倚阑干后，讨论"她眼中天际归舟"与"我眼中倚栏凝愁"的对切——从己之愁，推开写对面之愁，再合于一处（"争知我"），这是本词最见匠心的双重对照。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
