# 《春江花月夜》 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《春江花月夜》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。全诗九段并作八境，从"春江潮水连海平"一路走到"落月摇情满江树"。本页取**青绿春晓**色板做**月夜江景变体**——青玉绿的江面与远山铺满全页，一轮月白孤月是唯一主角，楼窗与归舟灯火是仅有的暖色。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进
- 控制条：上一境 / 自动游览（默认开）/ 下一境 / 朗读此句 / 自动朗读（默认开）/ 注音开关 / 声音开关 / 全屏
- 境③"皎皎孤月"轻点画面：月轮外圈荡开层层涟漪、光尘迸发，题字「孤月轮 · 清辉起」闪现
- 末境⑧"落月摇情"轻点画面：江面涟漪四起、光尘迸发，题字「落月摇情」闪现
- 末章：全诗回放（`09.mp3`）、学习小测（5 题）

## 美术方案：青绿春晓（art-direction 赛道④）

| 项 | 取值 |
|---|---|
| 底色 | `#0a1410`（与赛道④典型底色一致，作夜江深底） |
| 主色 | `#9ec9b8`（青玉绿；按钮/边框/进度点/题字） |
| 文字 | `#eef4e6`；次要 `#8fb3a2` |
| 雾 | `#0e1d16`（SK 默认），逐境 fd 0.0038–0.0072 |
| 月 | 月白偏青（`#e8eed6`），ms 1.25–2.15；境③"皎皎孤月"放大至 2.15 为全页峰值 |
| 江水 | 青玉绿水色（deep `#061619` → shallow `#1d6757`），月路金波（makeMoonPath）贯穿各境 |
| 粒子母题 | 月路波光、浪花泡沫与水面碎光（makeGlow）、春花瓣（makePetals）、横向月华流光（makeFlow）、青枫/芦苇/坡石剪影 |

**有意的设计**：全页统一青绿冷调，唯一的暖色是**人间的灯火**——明月楼的暖黄窗光（`#f2c94c`）、楼上灯与归舟灯笼点光。从境⑤"青枫浦上"起才出现暖窗，末境两条归舟各挑一盏——"不知乘月几人归"的答案就写在这几点暖光上；与全局青玉冷底形成对比，让学生一眼读出"江月是永恒冷的，人间灯火是暖的"。另：赛道④典型用法是晨景天光渐亮，本页反向用于**月夜**，天色由潮头的微亮走向末境海雾沉沉（末境 mhaze 0.50、星 0.32），是本诗专属的时间线。

## 教学建议

1. **导入**：先设问"一首写月亮的诗为什么题目里有五种景物？"再入境①，看潮水与明月一同涌起，理解"春、江、花、月、夜"五字诗题。
2. **境③宇宙意识**：点击画面荡开月轮涟漪后，齐读"江畔何人初见月？江月何年初照人？"结合注释讲闻一多"诗中的诗，顶峰上的顶峰"之评。
3. **境④哲理**：对照画面里不变的月与流走的江水，讨论"人生代代无穷已"——个人有限、人类绵延，是昂扬的哲思而非感伤。
4. **境⑤–⑦相思双线**：找出画面两侧的"扁舟子"与"明月楼"，讲"对写"手法；境⑥看月光"卷不去、拂还来"，体会把月光写成有情厮缠的痴语。
5. **境⑧收束**：点击涟漪后齐读末句"落月摇情满江树"，数一数画面里的归舟灯火，回答"不知乘月几人归"。
6. 课堂大屏可开"自动游览 + 自动朗读"（默认开启）无人值守循环展示；末章做完 5 题小测（接句 ×2、读音词义 ×1、文学常识 ×1、主旨 ×1）。
