# 宿新市徐公店 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《宿新市徐公店》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页走**青绿春晓**赛道的**菜花黄绿变体**——满目新绿，一只黄蝶是贯穿后半场的运动主角；"蝶入花丛寻不见"的菜花地，是全诗最亮的黄。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境叁为"蝶隐花丛"触发；末境再按进入终章）
- 控制条：自动游览、自动朗读（默认均开）、注音开关、声音开关、全屏
- 境叁轻点画面（或空格）：金黄花屑迸散、钟声响起，"飞入菜花无处寻"题字浮现（4 秒防连点）
- 末章：全诗回放、学习小测（5 题）

## 美术方案：青绿春晓（art-direction 赛道④）

| 项 | 取值 |
|---|---|
| 底色 | `#0a1410`（春野夜绿） |
| 主色 | `#c9c95f`（菜花黄绿：按钮/边框/进度点/题字；比赛道典型主绿 `#9fce8f` 更偏花黄） |
| 文字 | `#eef4e6`（与赛道典型一致），次要文字 `#7f9a78` |
| 雾 | `#0e1d16`，fd 0.0048–0.006 |
| 月 | 微明月（辉光 `#cfe2ff` 调），ms 1.15–1.3，作春夜高悬的一点清辉 |
| 粒子母题 | 黄绿浮尘（`#cfe8a8`）、金黄花屑迸散（`#ffe9a0`）、薄雾（`#8fb89a`） |

**变体说明**：主色取菜花黄 `#c9c95f` 而非典型主绿，辅杏 `#f2c94c` 亦未单列——因为本诗的"春色"不在桃杏，而在油菜花：境叁 320 株菜花（花头 `#d8c94a`）与黄蝶（`#e8d24a`）同色，这正是"无处寻"的画面谜底，颜色本身就是教学设计。**有意的设计**：追蝶境与花丛境之间，黄蝶始终是画面里唯一的运动焦点。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题（"宿新市徐公店。宋，杨万里。篱落疏疏一径深，树头新绿未成阴。"）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全诗连读

页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。无 tts.json 多音字副本，按页面注音提示易错点：题名"**宿**新市"读 sù（住宿义，不读 xiǔ/xiù）；"一径"之**一**页面标注原调 yī（口语句中常变调读 yí）；"未成**阴**"同"荫"，读 yīn。如需"诗朗诵"级音色，可设 `TTS_AZURE_KEY` 后重跑配音脚本。

## 教学建议

1. **导入**：问"春天在哪里？"再入境壹，对照画面找"疏疏"的篱笆与"未成阴"的新绿，理解暮春初夏的时令。
2. **境贰动词**：让学生模仿"急走"的奔跑节奏读"儿童急走追黄蝶"，讲清"走"在古文中是"跑"。
3. **境叁谜题**：先看画面再问"为什么蝴蝶飞进菜花就找不到了？"——蝶黄与花黄同色，颜色即答案；再点击看花屑迸散，读"飞入菜花无处寻"。
4. **童趣与理趣**：结合注释体会杨万里"诚斋体"的活泼——农村儿童追蝶的小事，写得有画面、有悬念。
5. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×1、词义 ×1、文学常识 ×1、画面理解 ×1、推理 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 28 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 三境，POEM 第一条含两句），境名逐一对齐。
- 交互境序号 `curIdx===3`（花深蝶隐）；进度点/按键/自动游览末境判断均以 `POEM.length=3` 对齐。
- 校验：`node _pipeline/tools/validate.js su-xinshi/index.html` → **✓ 校验全部通过**。
