# 兵车行 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《兵车行》（唐 · 杜甫，queue no.262）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**水墨夜思**赛道——但刻意避开既有水墨/战乱页的构图（不做雨前危楼眺望、不做雪原戍楼听笛、不做关外行军、不做差吏夜呼），写的是**咸阳桥头一幅尘土飞扬的送别长卷**：辚辚萧萧（声）→ 点行频（诉）→ 秦兵况复（荒）→ 边庭血流（冤）。accent=#93a8c4（青灰微蓝，queue 分配强调色）只落在 UI/人物边缘光/哭声光柱/纸钱微光/幻影人潮上；战争苦难意象克制写意——送别人潮、尘埃、暗色浪影、纸钱，不画尸骸、不直白血腥。

**有意的设计**：全卷立在一旁只看不说——"道旁过者"（杜甫的见证视角）只在卷首与境贰入画（拱手相问），境叁肆是他听来的天下，镜头独自去看荒田与青海；人物配色即叙事——征夫泥灰布袍+腰挂弓箭全诗同款，爷娘妻子各具姿态（牵衣/拦道/顿足）；境肆点击唤起的正是境壹那片送别人潮的幻影——送别一幕，正是此后一切白骨的起点。"边庭流血成海水"只给远处一带暗色浪影，"古来白骨无人收"只给湿风纸钱——苦难全部写意，不着一具形骸。

## 教学建议

1. **导入**：先只读开头三句"车辚辚，马萧萧，行人弓箭各在腰"——没有一个人字写人，却让人看见了人潮听见了哭声：请学生说说这三句里有哪些声音，体会"以声起笔"。
2. **古今异义钉子**：「耶娘妻子走相送」——耶娘=爷娘（父母）、妻子=妻和子女（两个人）、走=跑（古义）；让学生用现代汉语把这句"翻译准确"，体会古今词义的变迁。
3. **诗眼讨论**：「行人但云点行频」——征夫满腹辛酸为何只答三个字？"敢申恨"的"敢"是"岂敢"不是"敢于"：欲言又止、怨气愈压愈重，这种"吞咽式"的写法比大哭大喊更沉痛。
4. **反常之语**：「信知生男恶，反是生女好」——重男轻女的千年常态为何被反转？结合「县官急索租，租税从何出」，理解战争把民生逼到了什么地步。
5. **主旨与诗史**：「边庭流血成海水，武皇开边意未已」——借"汉武"说唐皇，是需要胆识的直笔；本诗不用古乐府旧题、就眼前事自创新题（即事名篇，无复依傍），是新乐府的先声。末四句鬼哭收束：可让学生比较"白骨无人收"若直画尸骸与现在"纸钱+暗浪+声啾啾"的写意处理，哪种更让人心惊。
