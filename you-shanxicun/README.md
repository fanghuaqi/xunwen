# 《游山西村》 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《游山西村》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。全诗首联至颈联并作三境：从"莫笑农家腊酒浑"的丰年待客，走到"柳暗花明又一村"的豁然开朗。本页属**青绿春晓**赛道（art-direction 指定游山西村适用）的**麦金黄暖夜变体**——不用青绿晨色，而以暖黄灯火、粉白花团写山村春夜，"柳暗→花明"在画面里当场上演。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（境③空格等同点击交互；末境后再按进入终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境③"柳暗花明"：画面每约 16 秒自动上演一次——左侧柳影渐散让开（"柳暗"消退），村庄与花团同步亮起（"花明"显现）；入境内 14 秒后**点击画面**重演此幕，钟声一响、题字「柳暗花明又一村」闪现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：青绿春晓（art-direction 赛道④）

| 项 | 取值 |
|---|---|
| 底色 | `#120d08`（暖黑，取自赛道⑤底色值；非赛道④典型 `#0a1410` 深绿） |
| 主色 | `#d9c98a`（麦金黄；按钮/边框/进度点/题字，替代赛道④典型主绿 `#9fce8f`） |
| 文字 | `#ece4cf`；次要 `#9a8a6a` |
| 雾 | `#1a120a`（SK 默认），逐境 fd 0.005–0.008（与赛道④典型雾密度预算一致） |
| 月 | 弯月淡金（ms 0.9–1.1），星稀（0.35–0.5）；境③天边一轮淡金色日轮（`#f2d8a0`）点出"豁然开朗"的亮 |
| 灯 | 暖窗光 `#e8b45a`（农家窗、村舍五窗各带点光）、封面远窗 `#d9a05a`——全页最暖的点 |
| 粒子母题 | 浮尘微光（makeGlow）、谷中薄雾、花团（粉白 `#e8a0b8` 小球簇缀于村舍前） |

**有意的设计**：①**赛道④的反用**——art-direction 给游山西村定的赛道是青绿春晓，本页保留其"田园、转机、喜悦"的情绪与雾密度预算，但把"晨光渐亮"换成"**春夜灯火渐明**"：全局麦金黄 + 暖窗，没有一处青绿，是六道中唯一以"灯"代"光"的页面；②境③"柳暗花明"是**可重演的机制**而非静态布景——柳影透明度与横移联动消退，村舍颜色乘 `0.55+0.45p` 渐亮，成语"柳暗花明"的转折被写成了动画曲线；③全页唯一冷色是境②溪水（`#0e1a20`，shininess 60），用来压住"疑无路"的段落。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题（"游山西村"）
- `01–03.mp3` 三境逐境朗读

页面朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音兜底。本目录无 `tts.json`，无特殊多音字副本；易错字音以页面注音为准：**重** chóng（山重水复，重叠义不读 zhòng）、**豚** tún（小猪）、**浑** hún（浑浊）、**腊** là（腊酒）。

## 教学建议

1. **导入**：问学生"走山路走到以为没路了，忽然看见村子是什么心情？"再入境②先看"疑无路"，进境③看"又一村"，顺序讲转折。
2. **境①人情**：看酒坛与待客的桌碗讲"足鸡豚"，结合注释区分"腊酒""豚"，体会丰年农家的好客。
3. **境③成语课**：等待或点击触发"柳散村亮"一次，让学生用自己的话描述过程，再落到"柳暗花明"比喻困境中出现转机——成语即从此句凝成。
4. **哲理迁移**：由画面转折讨论"山重水复疑无路，柳暗花明又一村"为何常被用来形容绝处逢生；对比陆游罢官闲居山阴的写作背景，理解"又一村"里的人生意味。
5. **易错点**：小测覆盖了"豚""浑"两个词义与"重"的读音，可先让学生互考再做题。
6. 末章做完 5 题小测（接句 ×1、词义 ×2、文学常识 ×1、成语寓意 ×1）；课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 三境，共 4 项），境名逐一对齐；首联并作境①，颔联两句分作境②境③（尾联不入境，页外延伸）。
- 交互境序号 `curIdx===3`（柳暗花明），`pointerdown`/空格均以 `state==='stage'` 守卫，点击带 `ctl.t<14` 入场守卫；自动游览末境判断以 `POEM.length=3` 对齐。
- 校验：`node _pipeline/tools/validate.js you-shanxicun/index.html` → **✓ 校验全部通过**。
