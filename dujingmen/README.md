# 循文入境 · 渡荆门送别（唐 · 李白）

单文件沉浸式诗词课件：四境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 水墨夜思·江月变体：出峡口的江面越走越开阔，月影如飞天镜，云霞结海楼，故乡水一路送舟。
> 标志性瞬间：月下飞天镜——明月倒映江中如天镜，云生结成海市蜃楼。

## 教学建议

- 「山随平野尽，江入大荒流」：一个「随」一个「入」，让学生品味动静与视角（船动而觉山动）
- 「月下飞天镜，云生结海楼」：比喻+夸张的奇景；与「月是故乡明」对读
- 「仍怜故乡水，万里送行舟」：不说人思乡、反说水送人——拟人化的含蓄深情（重点赏析）
- 注音考点：渡 dù、荆门 jīng、楚国 chǔ、平野 píng yě、大荒 dà huāng、海楼 hǎi lóu、仍 réng、怜 lián
- 背景：李白 24 岁初出蜀地，「仗剑去国，辞亲远游」，此诗写于途中
