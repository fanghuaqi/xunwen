# 马诗·其五 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《马诗·其五》（唐·李贺）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**大漠金戈**赛道——但刻意避开战阵/夜射/行军/听笛/白骨/大湖/牧马群的既有边塞构图，写的是**一匹骏马**的蓄与驰：境壹=蓄（沙月如铁的清冷骏马图——弯月如钩、沙如雪、骏马昂首空有骏骨），境贰=发（金络脑戴上、快走踏清秋）。accent=#b8905f（沙金络色）只落在金络脑/金光/人物边缘光/秋草穗/UI 上，禁艳金；**全页冷色源是「沙月」**——银灰沙雪清辉 + 蛾眉钩月（mph 0.74），清冷沙月对撞暖金络脑，正是「渴望」的色温。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"戴上金络脑"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：金络脑金光乍现戴上马首，骏马自静立换为铜奔马式飞驰之姿（前肢腾空、后肢后蹬），沿大漠加速环驰，蹄下沙雪扬起，"何当金络脑 快走踏清秋"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：大漠金戈 · 清冷独骑变体（art-direction 赛道⑤）

| 项 | 取值 |
|---|---|
| 底色 | `#120d08` |
| 主色 | `#b8905f`（沙金络色，queue 分配强调色；金络脑/金光/边缘光/题字/UI） |
| 文字 | `#f0e2cc` |
| 雾 | `#141014` 系，fd 0.0048–0.0056 |
| 月 | 蛾眉钩月（mph 0.74，ms 1.05–1.38），悬于燕山山脊之上——「月似钩」是全页唯一强月 |
| 场景母题 | 境壹：银灰沙雪大漠 + 燕山双脊 + 钩月 + 昂首骏马（自写骏马 builder，非马群）+ 望马人；境贰：静立骏马（金络脑未戴）→ 点击换铜奔马式飞驰之姿环驰 + 蹄下沙雪粒子云 |
| 粒子母题 | 月下浮尘如雪（银灰，NormalBlending）、沙风横流、沙丘秋草穗、戴上络脑的金光一闪（makeBurst） |
| 与已有边塞页的区分 | 不做战阵/夜射/行军/听笛/白骨/大湖/牧马群：主角是**一匹骏马**——沙、月、马与一副尚未戴上的金络脑，托物言志的独骑清影 |

**有意的设计**：境壹只给"盼"（沙月愈冷，骏骨愈清，络脑空缺）；境贰点击才给"酬"——金络脑戴上的一瞬就是「何当」落定的一瞬，静立换飞驰、题字同现，「快走踏清秋」由画面直接演出来。马即诗人，诗人即马。

## 教学建议

1. **导入**：先讲「诗鬼」——李贺七岁能诗、呕心沥血，却因避父讳不得举进士，二十七岁郁郁而终；这样一个被堵死在门外的人，写马只问一句「何当」。让学生带着这层身世读画面里那匹没有笼头的马。
2. **境①诗眼**：「如雪」与「似钩」——都是月下错觉：沙不是雪、月不是钩，可冷月把大漠镀成沙场，弯月本就是吴钩的形状；沙月如铁的清冷，正是骏马（千里马）该驰骋却未驰骋的天地。
3. **境②点击后**：金络脑戴上的一秒就是「何当」的回答——可讨论「何当」的问而不答：现实中这副笼头始终没有戴上（李贺终其一生未获重用）；画面让马驰出去，是把诗人的渴望替他兑现一次。
4. **写法**：托物言志——句句写马（沙雪月钩是马的天地、金络脑是马的渴望、踏清秋是马的施展），句句写人；可对照「冯唐易老，李广难封」体会怀才不遇的传统母题，再回看「快走」二字里按捺不住的急切。
5. **背景**：《马诗》共二十三首，借咏马写怀才不遇与建功之望，此为其五、最著名；李贺与「诗仙」「诗圣」并称的「诗鬼」之号，来自其奇诡冷艳的诗风。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、文学常识 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 20 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 交互境序号 `curIdx===2`（pointerdown 与空格双接线，`clicked` 标志 + 1.2s 冷却防连点；空格先交互、再按进终章）。
- fadeK 铁律：所有每帧写 opacity/intensity 的对象（金光包络/额环 gleam/金色点光/浮尘/宿雾）初值=最大且逐帧乘 fadeK；点击前金络脑与金光 `visible=false` 硬关（无幻影残影）；全页无自写 ShaderMaterial（粒子走引擎 GLOW/FLOW 着色器，uMaxA 交给引擎同步）。
- 预算：三境 drawCall 代理 ≈ 17/24/32、三角面 ≈ 0.39/0.81/1.34 万（≤120 / ≤12 万）。
- 校验：`node _pipeline/tools/validate.js mashima/index.html` → **✓ 校验全部通过**；`node mashima/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 逐境 build/update×400 帧 → fadeK 合规 → 末境点击门控 → 自动游览至终章 → 小测满分）；`node _pipeline/accept.js mashima` → **ACCEPT（2境 · 大漠金戈）**。
