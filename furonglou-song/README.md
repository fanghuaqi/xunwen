# 芙蓉楼送辛渐 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《芙蓉楼送辛渐》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页走**烟雨江南**赛道的**冷雨送别变体**——通篇冷雨黛蓝，雨丝代替柳丝成为粒子母题；结尾"一片冰心在玉壶"的玉壶寒光是全页唯一的光源级亮点，冷得干净，正如诗人自许的品格。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境叁为"冰心玉壶"触发；末境再按进入终章）
- 控制条：自动游览、自动朗读（默认均开）、注音开关、声音开关、全屏
- 境叁轻点画面（或空格）：钟声响起，玉壶中的冰心辉光涨大，"一片冰心在玉壶"题字浮现（2.2 秒防连点）
- 末章：全诗回放、学习小测（5 题）

## 美术方案：烟雨江南（art-direction 赛道⑥）

| 项 | 取值 |
|---|---|
| 底色 | `#10141a`（夜江） |
| 主色 | `#9ab8d8`（黛蓝银：按钮/边框/进度点/题字；比赛道典型色 `#8fb3c9` 更冷更银） |
| 文字 | `#e2eaf4`，次要文字 `#7c8ba0` |
| 雾 | `#131a24`，fd 0.007–0.010（低于赛道典型 0.012–0.02，江面留出更多能见度） |
| 月 | 冷银微月（辉光 `#cfe2ff`），ms 0.55–0.7，仅天边一点微光，不作主角 |
| 雨 | 雨丝 `#8fa8c8`，卷首 600 条、境壹 700 条，全页主母题 |
| 粒子母题 | 冷雨、江雾（`#7c8ba0`）、玉壶冰心辉光（`#bfe8ff`） |

**变体说明**：页面未使用赛道典型的藕荷辅色 `#d8a7b1`，整体比标准烟雨江南更"冷"一档——送别在雨夜，不该有一点暖。**有意的设计**：境叁玉壶中悬浮的"冰心"（`#dff2ff` 球体 + `#bfe8ff` 辉光与点光）是全页唯一的发光体，雨夜越暗，冰心越亮。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题（"芙蓉楼送辛渐。唐，王昌龄。寒雨连江夜入吴，平明送客楚山孤。"）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全诗连读

页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。无 tts.json 多音字副本，按页面注音提示易错点："相问"之**相 xiāng**（问起我，不读 xiàng）；"一片"之**一**页面标注原调 yī（口语句中常变调读 yí，以页面注音为准）。如需"诗朗诵"级音色，可设 `TTS_AZURE_KEY` 后重跑配音脚本。

## 教学建议

1. **导入**：先问"送别朋友时天气如何会影响心情？"再入境壹，看冷雨连江的画面读"寒雨连江夜入吴"，体会"寒"字既是体感也是心境。
2. **境贰目送**：让学生盯着渐行渐远的客船读"平明送客楚山孤"，讨论"孤"的是山还是人——结合注释讲"楚山"与"以山之孤写人之孤"。
3. **境叁言志**：点击触发冰心题字后再读后两句，讨论"冰心""玉壶"两个比喻为什么能表达"高洁清白"；可补充王昌龄当时被贬的处境——越是遭贬，越要自明心迹。
4. **送别诗比较**：与"劝君更尽一杯酒"式送别对照，本诗不写不舍、只写自守，是送别诗中的"言志"一路。
5. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×1、品格理解 ×1、文学常识 ×1、词义 ×1、题材 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 28 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 三境，POEM 第三条含两句），境名逐一对齐。
- 交互境序号 `curIdx===3`（冰心玉壶）；进度点/按键/自动游览末境判断均以 `POEM.length=3` 对齐。
- 校验：`node _pipeline/tools/validate.js furonglou-song/index.html` → **✓ 校验全部通过**。
