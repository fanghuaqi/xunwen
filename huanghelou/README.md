## 美术方案：烟雨江南 · 黄鹤白云变体（千年怀古 / 暮色吊古）

按 `art-direction.md` 赛道⑥取值。与同赛道邻作《黄鹤楼送孟浩然之广陵》（白昼春江、柳絮孤帆）刻意区隔：本页主角是**空楼与流云**，基调吊古伤今——

- 底色 `#10141a`、强调色 `--gold:#a8b8d8`（千年云色银蓝）、文字 `#e6ecef`
- 情绪曲线映射天空：暮霭苍茫（①fd 0.0062）→ 云天流转（②0.0052）→ **骤然明朗**的怀想（③0.0035、暖阳）→ 沉入日暮（④0.0062、雾霞 hor `#8a5f4a`）
- 月隐；③④改淡日/暮日；星仅在暮境微现（0.12→0.3）
- 粒子母题：流云（自写 `makeClouds`：软辉光精灵横向漂移、wrap-around，带 speedK 加速接口）替代金色流萤

## 标志性瞬间

境②"黄鹤一去不复返，白云千载空悠悠"（新 builder `bCloudAges` + 新构件 `makeClouds`/`makeCrane`/`makeTowerEmpty`）：千载流云在楼顶快速流过（时间流逝的数十倍速感），黄鹤剪影从楼顶振翅、螺旋升入云端直至消失——一去不返，22 秒一轮回。场景库无此原型，为本诗自创。

## 教学建议

1. **朗读导入**：自动游览全程约 70 秒，先让学生说"看到了什么"（空楼—流云—晴川—烟波）。
2. **逐境精读**：结合右侧释义/注释——"空余"的"空"、"历历/萋萋"叠词的效果、"鹦鹉洲"典故。
3. **多音字考点**：**载 zǎi（年，"千载"）**、乘 chéng、空 kōng（页面注音已逐字核对，小测第 2 题；音频 SUB 表已纠音 千载→千崽、空余→崆余）。
4. **互动点睛**：讲到末联请学生点击江面——白云千载加速、黄鹤虚影掠空，体会"云尚悠然、鹤已不返、乡关无处"的怅惘。
5. 结课"学习小测"（接龙 ×2、读音 ×1、典故 ×1、主旨 ×1）当堂检测。
