# 循文入境 · 虞美人（李煜）沉浸式诗词网页

生产队列第 96/117 号 · 烟雨江南赛道「月夜变体」——囚居小楼的最后一夜：绝望中的绝唱。

## 使用

双击 `index.html` 即可打开（Three.js 走 CDN，首次需联网；音频已本地打包在 `audio/`）。

- `← →` 键或空格：逐境游览；空格在第四境触发互动
- 控制条：自动游览 / 自动朗读 / 注音 / 声音 / 全屏开关
- 第四境（一江春水）：**点击画面**——问君几多愁，春水暴涨东流，题字「恰似一江春水向东流」

## 四境

| 境 | 词句 | 画面 |
|---|---|---|
| 壹 · 春花秋月 | 春花秋月何时了？往事知多少。 | 囚窗栅栏内望，落花与孤影，一烛如豆 |
| 贰 · 又东风 | 小楼昨夜又东风，故国不堪回首月明中。 | 檐下东风横流，珠帘波动，风铎摇曳 |
| 叁 · 雕栏玉砌 | 雕栏玉砌应犹在，只是朱颜改。 | 故国宫阙虚影浮现辉煌，朱颜渐渐褪成灰烬 |
| 肆 · 一江春水 | 问君能有几多愁？恰似一江春水向东流。 | 镜头出楼推向大江，愁作春水暴涨东流（点击互动） |

## 教学建议

- 逐境讲读前先让学生看画面说诗句意境，再对照释义与注释（含 了 liǎo / 砌 qì / 应 yīng / 似 sì 多音字考点）
- 叁、肆两境是「物质化情绪」的示范：褪色=朱颜改，春水=愁；可让学生讨论比喻的妙处
- 结课小测 5 题覆盖接龙、读音、词义与主旨
