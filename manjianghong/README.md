# 循文入境 · 满江红（宋 · 岳飞）

单文件沉浸式诗词课件：四境随词句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 大漠金戈·赤焰变体：赤金为骨、昏黄为底 —— 雨歇孤楼起笔，长车山缺收束，全页压着一股忠愤之气。
> 标志性瞬间：潇潇雨歇之后，孤楼凭栏、仰天长啸，一道天光自裂云中落到台上。

## 操作

- `← →` / 空格：切境（末境空格 = 触发交互，交互过后再按进终章）
- 自动游览、自动朗读默认开启，可一键关
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置 MP3 → 系统语音
- `audio/00–05.mp3`：题名、四境、全篇（云健·沉厚男声，语速 −14%；`tts.json` 多音字替换只影响读音）

## 教学建议

- 开篇"怒发冲冠"四个入声字定下全词声情，可让学生数一数词中的入声字（歇、烈、月、切、雪、灭、缺、血、阙）
- "三十功名尘与土，八千里路云和月"：对仗中见人生态度——功名如尘、征战如常
- "靖康耻"三句是全词情感闸门：短促的节奏 + 三连入声，读出切齿之恨
- 末段"壮志饥餐……笑谈渴饮"是夸张修辞（互文），教学时点明"不必坐实、只写其愤"
- 注音考点：怒发冲冠 fà / guān、凭栏 píng、长啸 cháng、白了少年头 liǎo、靖康 jìng、犹未雪 xuě、山缺 quē、匈奴血 xuè、朝天阙 cháo / què
- 用典与史实：靖康之变（1127）；贺兰山是借代的"敌巢"方向，与"匈奴""胡虏"同为泛指
