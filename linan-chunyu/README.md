# 临安春雨初霁 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《临安春雨初霁》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**烟雨江南**赛道，取「临安客舍」变体——雨中的深巷与小楼、夜里的一场春雨、清早深巷里即将响起的杏花叫卖、窗下的矮纸分茶，以及素衣归家的清明之约。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境肆为"点击卖杏花"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境肆轻点画面：夜雨渐停（雨丝收住）、深巷花担由巷口推出、四声叫卖音阶响起，"深巷卖杏花"题字同现
- 末章：全诗回放、学习小测（5 题）

## 朗读配音

`audio/` 内置 6 个 AI 朗读 MP3（Edge 神经语音 `zh-CN-XiaoxiaoNeural`，语速 −16%），0 失败：

- `00.mp3` 标题（"临安春雨初霁"）
- `01–04.mp3` 四句逐境朗读
- `05.mp3` 全篇连读

多音字处理见 `tts.json`（**sub 非空即完全接管**，不叠加脚本兜底表）：

- `明朝` → `明昭`：钉住「朝」的 **zhāo**（明天早上），避开「王朝」的 cháo —— 本诗第一考点
- `斜行` → `斜航`：钉住「行」的 **háng**（行款、行列），避开「行走」的 xíng
- 逐句核过：世味、薄似纱（似 sì）、谁令（令 lìng）、骑马 qí、京华、小楼、深巷、杏花、矮纸、闲作草、晴窗细乳、戏分茶、素衣、莫起、犹及清明——无须干预

页面朗读优先级：Edge 在线自然语音现场逐句朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"如果一夜没睡，你听见了什么？"再入境壹，先读前两句。
2. **境壹析"薄似纱"**：世态人情薄如纱——让学生找画面里那层"纱"（贴地薄雾），把抽象的"世味"变成看得见的东西。
3. **境贰析诗眼**：只写"听雨"与"卖花"，不写心情；一夜听雨说明什么？（客中无眠。）"明朝"二字把时间推到天亮，叫卖声虽未至，已在读者耳边。
4. **境叁析"闲"**：写草书、分茶都是雅事，可"闲""戏"二字越写越见其无聊——他不是闲，是无事可做（等召见）。
5. **点击体会**：点击卖杏花看雨住、花担出巷，讨论"这一声叫卖为什么是全诗最亮的一笔"。
6. **知人论世**：此诗作于淳熙十三年（1186），陆游奉召入京等候召见，闲居客舍；他一生志在恢复中原，这种"闲"正是难堪处。结句"犹及清明可到家"，收在归心。
7. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音义 ×1、心境 ×1、主旨 ×1）。
8. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（4 境约 76 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 肆境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===4`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（小楼、深巷、书案、人马）都在 8–24 单位内，fd ≤ 0.0078；雨丝用自定义 uniform `uStop` 控制"渐停"（不动 opacity），花担出巷只动位置，全页无一处手写 opacity 渐隐；窗光与花光是 Sprite 缩放。
- 场景构件（冒烟实测）：卷首 10 mesh / 3 points、境壹 14 mesh、境贰 10 mesh、境叁 11 mesh、境肆 24 mesh / 3 points；draw call 代理值 21 / 27 / 21 / 20 / 35（≤120），三角面 ≤1.7 万（≤12 万）。
