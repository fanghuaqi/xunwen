# 循文入境 · 定风波·莫听穿林打叶声（宋 · 苏轼）

单文件沉浸式诗词课件：三境随词句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 烟雨江南·旷达变体：东坡居士最著名的旷达之作——穿林打叶的暴雨中从容吟啸，最终走向「也无风雨也无晴」的超然境界。
> 标志性瞬间：一蓑烟雨任平生——雨中拄竹杖穿草鞋，吟啸徐行的从容背影。

## 教学建议

- 「莫听」与「何妨」：主动的人生态度——面对无法躲避的风雨（逆境），选择不听其聒噪、从容徐行
- 「竹杖芒鞋轻胜马，谁怕？」：平民装束胜过高头大马的心理超越
- 「山头斜照却相迎」：风雨过后必有斜阳的自然哲理
- 「也无风雨也无晴」：全词画龙点睛——自然界的晴雨皆是常态，人生的宠辱得失亦复如是，达到物我两忘、超然物外的最高境界
- 注音考点：吟啸 yín xiào、芒鞋 máng xié、一蓑 suō、料峭 liào qiào、斜照 xié zhào、萧瑟 xiāo sè
- 背景：宋神宗元丰五年（1082年）春，苏轼贬谪黄州第三年，三月七日沙湖道中遇雨所作
