# 循文入境 · 声声慢（李清照）

《声声慢·寻寻觅觅》沉浸式单文件教学网页 —— 词句推进到哪一句，三维实景就走到哪一重意境。
双击 `index.html` 即可打开（Three.js r128 走 CDN 三路回退，音频本地，无需服务器）。

## 风格赛道：烟雨江南

- 色板：底 `#10141a` · 主黛蓝 `#8fb3c9` · 辅藕荷 `#d8a7b1` · 文字 `#e6ecef` · 雾 `#151d26`（fd 0.012–0.021）
- 月隐（ms≤0.5 或藏于地下），雨丝线段粒子贯穿大部分词境
- 全词基调是"愁"的渐进：天空逐境转暗、雾逐境加重、雨从无到细到密

## 七境设计

| 境 | 词句 | 画面 | 情绪/天空 |
|---|---|---|---|
| 卷首 | —— | 烟雨江岸，柳丝垂雾，细雨初起 | 灰蒙微雨 |
| 壹 昏灯寻觅 | 寻寻觅觅，冷冷清清，凄凄惨惨戚戚 | 一盏昏灯下人影往返踱步剪影；叠字节奏的镜头微晃 | 灰蒙 |
| 贰 乍暖还寒 | 乍暖还寒时候，最难将息 | 空庭枯枝，落叶飘零，一线藕荷暖意乍现又褪 | 微冷 |
| 叁 淡酒难敌（交互） | 三杯两盏淡酒，怎敌他、晚来风急 | 点击/空格**饮一杯**：酒面下降一格、周身泛起藕荷暖意又迅速褪去、题字"怎敌他"——酒不敌风急 | 暗，风急雨斜 |
| 肆 雁过伤心 | 雁过也，正伤心，却是旧时相识 | 人立水岸望天，人字形雁阵横空而过 | 空旷 |
| 伍 黄花憔悴 | 满地黄花堆积，憔悴损，如今有谁堪摘 | 满地残菊堆积、垂头花茎、残瓣飘零 | 萎，暖灰 |
| 陆 守窗待黑 | 守着窗儿，独自怎生得黑 | 最暗室内境：守窗人影，窗外暮色在眼前一点点沉下去，残烛将尽 | 最暗，几乎无光 |
| 柒 梧桐细雨（标志性瞬间） | 梧桐更兼细雨，到黄昏、点点滴滴。这次第，怎一个愁字了得 | **雨打梧桐声画同步**：大梧桐叶剪影，可见雨滴命中叶面即触发 WebAudio 水滴声（音高随机微变）；末句雨势转密，大"愁"字淡墨晕开、被雨化去 | 雨雾弥漫，黄昏紫灰，愁极 |

## 使用

- **游览**：← → 键或空格逐境；点击顶部进度点可跳境；"自动游览"开启后可作课堂大屏无人值守展示。
- **交互**：第叁境（淡酒）点击画面或按空格举杯饮酒。
- **朗读**：优先 Edge 神经语音现场逐句朗诵；无神经语音时播放 `audio/` 内置配音；网络与配音都缺失时回退系统语音。
- **声音**：控制条可关；末境"雨打梧桐"建议佩戴耳机。

## 音频

`audio/00.mp3`（标题）+ `01–07.mp3`（各句）+ `08.mp3`（全词），由 `gen-voice.ssman.js`（百度 TTS 免密钥接口）生成，共 9 个文件。
多音字替换表（只影响音频读音）：还寒→环寒（huán）、将息→姜息（jiāng）、了得→蓼得（liǎo）、怎生得黑→怎生德黑（dé）、窗儿→窗而（ér）。
如需"诗朗诵"级音色：`set TTS_AZURE_KEY=你的密钥` 后重跑 `node gen-voice.ssman.js index.html "声声慢" "宋，李清照"`。

## 教学要点（小测覆盖）

- 十四叠字开篇：动作（寻寻觅觅）→环境（冷冷清清）→心境（凄凄惨惨戚戚），由外而内
- 多音字考点：将息 jiāng、了得 liǎo、得黑 dé、还寒 huán
- 雁足传书典故与《一剪梅》"雁字回时"互文；"黄花"即菊花，暗合"人比黄花瘦"
- 词眼"愁"：与开篇叠字首尾呼应，收束全词
