# 梦游天姥吟留别 · 循文入境沉浸式诗课

李白《梦游天姥吟留别》的沉浸式单文件教学网页：**7 境**随诗句次第入梦，3D 实景意境、逐字注音、释义注释、AI 神经语音朗读、自动游览、结课小测。双击 `index.html` 即可打开（Three.js 走 CDN，音频本地）。

## 操作

- **入境**：封面点「入 梦」；`←` `→` 或空格逐境游览（空格在交互境优先触发交互）。
- **自动游览**：默认开启（教学展示模式），控制条可一键关。
- **朗读**：进入新境 1.6s 后自动朗读；「朗读此句」重听当前句。
- **注音 / 声音 / 全屏**：控制条切换。
- 第四境**点击画面 / 空格**：石扉訇然中开，金光倾泻、仙人剪影显形；第七境点击：白鹿昂首、开心颜。

## 教学建议

1. **梦游线索**：入梦（1–2 境）→ 游山（3 境）→ 仙境（4–5 境）→ 梦醒（6 境）→ 抒怀（7 境），可让学生按境说线索。
2. **衬托手法**：第 1 墨瀛洲虚写、五岳/赤城/天台陪衬天姥之高（画面上赤城矮、天台倾）。
3. **多音字考点**：天姥 mǔ、天台 tāi、剡溪 shàn、渌水 lù、谢公屐 jī、殷岩泉 yǐn、澹澹 dàn、訇然 hōng、觉时 jué、摧眉 cuī、即骑 qí。
4. **主旨**：第 7 墨「安能摧眉折腰事权贵」与人物挺立姿态对照，讨论傲骨精神；第 6 墨由梦入理的过渡作用。
5. **梦境落差**：对比 2 墨（写实月湖）与 5 墨（超现实金银台）的画面色调，体会浪漫主义笔法。
6. **异文**：「一夜飞度」教材亦作「一夜飞渡」，从部编本作「度」（见第 2 墨注释）。
