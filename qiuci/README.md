# 秋词 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《秋词》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页走**大漠金戈**赛道的**秋日翻案变体**——前半是悲秋传统的暗褐萧瑟（枯树、落叶、昏鸦），一句"我言"翻转全页：朝阳升起、天空放晴，末境以全页唯一的碧蓝晴空托起一鹤排云，翻案本身就是美术结构。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境叁为"鹤排碧霄"触发；末境再按进入终章）
- 控制条：自动游览、自动朗读（默认均开）、注音开关、声音开关、全屏
- 境叁轻点画面（或空格）：金屑迸散、编钟一声，白鹤冲开云层扶摇直上、诗情金流随鹤尾升腾，"便引诗情到碧霄"题字浮现（2.4 秒防连点）
- 末章：全诗回放、学习小测（5 题）

## 美术方案：大漠金戈（art-direction 赛道⑤）

| 项 | 取值 |
|---|---|
| 底色 | `#120d08`（暗褐秋暮，与赛道典型一致） |
| 主色 | `#c9a06a`（赭金：按钮/边框/进度点/题字；比赛道典型主赭 `#d98e3a` 更金一些） |
| 文字 | `#f0e2cc`（与赛道典型一致），次要文字 `#a08a6a` |
| 雾 | 悲秋前半 `#17110a` fd 0.0095–0.014（贴典型 0.006–0.01 上沿）；末境晴空 `#a4c2da` fd 0.0018 |
| 日/月 | 境贰朝阳日轮 `#ffe9b0` + 双层日晕（`#ffcf7e`/`#ff9a4a`），随宣言缓缓升起；卷首与境壹按赛道"无月"处理（ms 0.001、月体移出视野） |
| 末境晴空 | top `#2f6fba`、hor `#9cc6e6`——**全页唯一的亮蓝**，与前两境暗褐构成翻案式对撞 |
| 粒子母题 | 落叶（110→210→150 枚，灰褐被朝阳"点亮成金" `#e8b45a`）、昏鸦 ×3、萧瑟横流（`#77705e`，800 粒）、诗情金流（`#f2c368`，320 粒随鹤尾升腾） |

**变体说明**：赛道⑤本为边塞怀古的沉郁调，本页取其赭金底色作"悲秋千年"的底，再让末境换上晴空碧蓝——这是全六条赛道里少见的"页内换季"设计。**有意的设计**：境贰朝阳升起有 1–10 秒的可见过程，远处已有鹤影掠过作伏笔；境叁点击后云层被鹤"排开"又缓缓合拢（17 个单位位移），一个"排"字被做成了可见的云的位移。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题（含四句全诗："秋词。唐，刘禹锡。自古逢秋悲寂寥……"）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全诗连读

页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。无 tts.json 多音字副本，关键多音字页面注音已给出并被小测点名："春**朝**"读 zhāo（早晨，不读 cháo）；另注意"寂**寥** liáo""碧**霄** xiāo"同韵易混。如需"诗朗诵"级音色，可设 `TTS_AZURE_KEY` 后重跑配音脚本。

## 教学建议

1. **导入**：先让学生说说写秋的词（悲、凉、萧瑟），再入境壹看"千年悲秋"的暗褐画面——刘禹锡偏要反对，引出"我言"。
2. **境贰翻案**：看朝阳升起读"我言秋日胜春朝"，体会一个"胜"字的自信；结合背景——此诗写于诗人被贬朗州途中，身处逆境才有"翻案"的分量。
3. **境叁炼字**：点击看鹤冲开云层再读"晴空一鹤排云上"，讨论"排"为什么不能换成"飞"（推开、冲开，有力量）；看金流升腾读"便引诗情到碧霄"，诗情随鹤而上。
4. **鹤的形象**：结合注释讲白鹤喻高洁不屈的品格，一鹤孤飞正是诗人自况。
5. **人生观教育**：对比"自古逢秋悲寂寥"与"我言秋日胜春朝"，讨论面对挫折的两种态度。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音 ×1、词义 ×1、主旨 ×1）；课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 28 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 三境，POEM 第三条含两句），境名逐一对齐。
- 交互境序号 `curIdx===3`（鹤排碧霄）；进度点/按键/自动游览末境判断均以 `POEM.length=3` 对齐。
- 校验：`node _pipeline/tools/validate.js qiuci/index.html` → **✓ 校验全部通过**。
