# 望洞庭湖赠张丞相 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《望洞庭湖赠张丞相》（唐·孟浩然）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**大漠金戈**赛道移用于八月秋水大湖——苍茫暮色的洞庭，全套赭金大湖色板，前二联壮景（动），后二联转忱（静），巨浪撼城是全页最重要的水面表现。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"点击画面"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：浪涌撼城、水汽蒸腾，"空有羡鱼情"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：大漠金戈 · 秋水大湖（art-direction 赛道⑤移用）

| 项 | 取值 |
|---|---|
| 底色 | `#120d08`（大漠深褐，秋水暮色） |
| 强调色 | `#b8905a`（暗赭金，队列分配 accent；按钮/边框/进度点/题字、人形边缘光、城垣轮廓、前景 rim 全跟随，**禁艳金**） |
| 文字 | `#f0e2cc` |
| 雾 | `#1a120a` 系，fd 0.0050–0.0060（主体雾遮蔽率均 ≤0.35、背景 ≤0.60） |
| 月 | 低垂昏黄（ms 0.38–0.42、mhaze 加重），只作点缀；境②水汽蔽天时藏月 |
| 水面 | 全篇大湖：深褐暖调湖水反射暮色天光（`uMoonColor` 调成暖琥珀光路），境②浪高 amp 2.0 直拍城基 |
| 粒子母题 | 湖面碎光浮尘、贴水碎浪、横天暮霭、竖向蒸汽柱（替代《将进酒》的金色流萤/火星） |

**有意的设计**：境②"气蒸云梦泽，波撼岳阳城"是全诗名联，也是全页唯一的**全要素动景**——三柱自写着色器蒸汽自湖面升腾、巨浪（amp 2.0）一波波拍上临湖城墙、城墙随浪微微震颤、墙脚浪花四溅；同境把月藏进水汽里、星压到 0.06，让"撼"字独占画面。境③④转静：一叶**有桨座而无楫**的空舟是"欲济无舟楫"的画眼，末境隔湖在望的岳阳城是名联的回响。

## 朗读配音

`audio/` 内置 6 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunjianNeural，大漠赛道自动选声，语速 -14%）：

- `00.mp3` 标题（"望洞庭湖赠张丞相"）
- `01–04.mp3` 四联逐境朗读
- `05.mp3` 全诗连读

多音字处理（`tts.json`，同音同调替换，只影响音频读音）：**楫**读 jí（舟吉）、**济**读 jì（欲寄）、**混**读 hùn（诨太清）。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。如需"诗朗诵"级音色，可设 `TTS_AZURE_KEY` 后重跑 `gen-voice.js`。

## 教学建议

1. **导入**：封面设问"洞庭湖在大诗人眼里有多大？"再入境①，对照"八月湖水平"看水天一色——"涵虚""混太清"为何都在写"分不清湖与天"。
2. **境②名联**：盯住三柱蒸汽与拍城巨浪，体会"蒸"（虚、向上）与"撼"（实、横向）一虚一实的对仗张力；讨论为什么孟浩然写洞庭能压过后来居上的《望洞庭》。
3. **境③转折**：画面从巨浪变成一叶无楫空舟——让学生找"船上缺了什么"，引出"欲济无舟楫"是求人引荐的比喻；结合注释讲"端居耻圣明"。
4. **境④情感**：点击画面看浪涌撼城再起，讨论"羡鱼情为什么像湖水又涌起来了"；介绍《淮南子》"临河而羡鱼，不如归家织网"的典与干谒诗的分寸。
5. **收束**：末章全诗连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 四境），境名逐一对齐；诗文与 `queue.json` 条目逐字一致。
- 交互境序号 `curIdx===4`；pointerdown 与空格双接线（空格先触发交互、再按进终章）；进度点/按键/自动游览末境判断均以 `POEM.length=4` 对齐。
- 校验：`node _pipeline/tools/validate.js wangdongtinghu-zhang/index.html` → **✓ 校验全部通过**。
- 冒烟：`node wangdongtinghu-zhang/smoke.test.js` → **SMOKE PASS**（连跑 4 次稳定）——真 THREE r128 跑完 boot → 逐境 build/update×400 帧（各境 drawCall 代理 15–29、三角面 2.0–2.9 万）→ fadeK 合规 → 末境点击门控与 pointerdown → 键盘全路径 → 自动游览至终章（约 82s）→ 小测全流程。
