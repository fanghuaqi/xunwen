# 问刘十九 · 循文入境

白居易 · 雪夜邀饮 —— 两境沉浸式 Three.js 诗词课件（单文件 `index.html`，双击即开，需联网加载三维引擎）。

## 意境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 绿蚁红炉 | 绿蚁新醅酒，红泥小火炉。 | 酒面浮渣如绿蚁的特写 + 红泥小炉炭火正旺、陶壶温酒 |
| 贰 · 暮雪邀饮 | 晚来天欲雪，能饮一杯无？ | 标志瞬间：雪夜里一扇亮着暖光的窗，窗内炉火酒盏、窗外初雪飘落；**点击画面斟酒相邀**（酒注入杯+炉火更旺+窗雪渐大+题字） |

## 操作

- 进入：封面「入 境」；逐境：← → 键 / 空格 / 「下一境」；自动游览可一键开关（课堂大屏无人值守）。
- 交互：第二境点击画面或按空格 —— 斟酒相邀。
- 朗读：进境 1.6s 后自动朗读；Edge 下优先"在线自然语音"现场朗诵，否则回退 `audio/` 内置配音。

## 文件

- `audio/00-03.mp3`：00 标题、01/02 各句、03 全诗（`gen-voice.js` 生成，SUB 表已按本诗定制：醅→胚，保 pēi 音）。
- 多音字（页面注音）：醅 pēi、蚁 yǐ、饮 yǐn、无 wú；"一杯"按变调注 yì bēi。

## 教学建议

1. 先整体自动游览一遍，让学生"走进"雪夜小屋，感受暖与寒的对照。
2. 壹境观察"绿蚁"画面理解借代；贰境点击斟酒后追问：「无」是什么语气？（疑问语气词，考点）
3. 结课用小测（5 题：接龙×2 / 读音 / 词义 / 主旨）当堂检测。
