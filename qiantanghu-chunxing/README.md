# 钱塘湖春行 · 循文入境（Three.js 沉浸式诗词课件）

> 唐 · 白居易｜风格赛道：**青绿春晓（湖堤行游）**｜强调色 `#a8cf9a`｜四境 + 卷首，共 5 个场景

「循文入境」：诗句推进到哪一句，三维实景就走到哪一重意境——学生边读诗，边走进西湖早春。

| 境 | 境名 | 诗句 | 场景与画面 | 朗读 |
|---|---|---|---|---|

**标志性瞬间（本诗自创，场景库中没有）**：第四境的「走不尽的白沙堤」——无限循环前移的堤岸母题，把抽象的「行不足」变成看得见的"怎么走也走不完"；第二景的「莺争暖树 · 燕啄春泥」双动对位（莺向上跳枝、燕向下啄泥）为交互点睛。

## 二、操作说明

| 操作 | 说明 |
|---|---|
| `入 境` 按钮 | 从封面进入第一境 |
| `← / →` 方向键、`空格` | 逐境前进 / 后退（`空格`在交互境触发交互，末境按 `→` 进入终章） |
| `自动游览 · 开/关` | **默认开启**：按各境 dwell（18/18/17/20 秒）自动推进直至终章，可用于课堂大屏无人值守 |
| `自动朗读 · 开/关` | 默认开启：进入新境 1.6 秒后自动朗读该句 |
| `朗读此句` | 重播当前句（封面境朗读课题与首句） |
| `注音 · 开/关` | 显示/隐藏逐字拼音（标点不注音） |
| `声音 · 开/关` | 环境音（湖声）总开关 |
| `全屏` | 课堂投影用 |
| 点击画面 / 空格 | **第二境**：唤早莺跳枝相争（莺争暖树）、新燕集体俯冲啄泥（燕啄春泥）；**第四境**：柳梢莺燕齐飞 |
| 进度点 | 顶部右侧 4 个圆点，点击直达对应境 |
| `学习小测` | 终章内 5 题（2 接龙 + 1 读音词义 + 1 作者典故 + 1 名句理解） |
| `诗集目录` | 封面与终章均有返回上级诗集目录的链接 |

**朗读管线**：检测到 Edge「在线自然语音」时现场逐句朗诵（句间停顿 420ms、rate 0.78，最像真人）→ 否则播放 `audio/*.mp3`（百度 TTS 生成，配置 `TTS_AZURE_KEY` 后重跑可获得诗朗诵级音色）→ 再退回系统语音。切境即 `stopSpeak()`。

## 三、教学建议

1. **导入（1 分钟）**：封面境先不放诗句，让学生说出"你看到了什么样的春天"，再揭开"西湖早春"的题目与作者。
2. **逐境推进**：每境先看画面 10 秒，再朗读、正音（重点多音字：孤山寺 **sì**、贾亭 **jiǎ**、没马蹄 **mò**、行不足 **xíng**、绿杨 **lǜ**、白沙堤 **dī**、渐欲 **jiàn**）。
3. **第一境抓"平"与"低"**：水面与岸齐平（"初平"）、白云贴着水面（"云脚低"）——把"脚"字讲成拟人化的比喻，体会"云水一体"的早春湖上。
4. **第二境抓动词**："争""啄"两个字让画面动起来；点击画面演示莺争暖树、燕啄春泥，追问"为什么是'暖树'？"（早春余寒，向阳一面最暖，鸟雀都往那里去）。
5. **第三境抓早春尺度**：草"才能没马蹄"说明草尚浅，花"渐欲"迷人眼说明花刚开——两处都写"早春"，不是暮春；顺带讲七律的颈联位置。
6. **第四境抓"行不足"**：堤走不完、绿杨阴不断，正是"最爱"之情；点题"白堤"与白居易在杭州的政绩（任杭州刺史时修堤浚湖，后世称白堤）。
7. **结课**：终章全诗齐读 → 5 题小测 → 用"诗人为何一路走、一路看、还嫌看不够"作收束，回到"最爱湖东行不足"。
8. **课堂用法**：投影 + 全屏 + 自动游览（默认已开），可全自动播放一遍（约 90 秒），再逐境精讲。

### 开发者备忘（维护时注意）

- **数量联动**：4 句 ⇒ `STAGES.length=5`，`STAGES[i].name === POEM[i-1].name`；改动境数需同步 `clamp(i,0,4)`、进度点循环 `i<=4`、`CN` 数组、自动游览 `curIdx===4`、交互境常量（2 与 4）、音频编号（00..05）、小测评语 `words`（题数+1=6）。
- **硬性约束**：主脚本顶层禁止出现 `THREE.*`（`sky` 一律写成惰性工厂 `()=>SK({...})`）；竖排诗句用块级流而非 flex；水面等着色器手动同步雾参数、穹顶/星/月 `fog:false`；`renderOrder`：穹顶 -10 < 星 -9 < 月 -8 < 水 1 < 粒子 3 < 雾 5；每帧自写 `opacity/intensity` 处一律乘 `chainFade()`（`makeMist` 的 update 已修）。
- **校验**：
  ```bash
  node _pipeline/tools/validate.js qiantanghu-chunxing/index.html
  node smoke.test.js
  cd ../_pipeline && node accept.js qiantanghu-chunxing
  ```
- **重生成配音**：`node gen-voice.local.js`（先核对顶部 SUB 表）；若想获得"诗朗诵"级真人音色，配置 `TTS_AZURE_KEY` 后重跑。
