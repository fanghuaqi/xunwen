# 己亥杂诗（其五）· 循文入境

龚自珍 · 清 ｜「烟雨江南」赛道 · 落红归泥变体（离愁 → 落红 → 春泥护花的生命循环）

双击 `index.html` 即可打开（首次需联网加载 Three.js；`audio/` 为本地 AI 朗读）。

## 漫游

- ← → / 空格逐境；封面点「入境」开始；顶栏圆点可直接跳境。
- 三境：**浩荡离愁**（白日斜、长路东去、骑者吟鞭）→ **落红飘零**（老树辞红，离枝-飘旋-触地）→ **春泥护花**（落红入泥、新花破土）。
- 第三境可**点击画面或按空格**：落红入泥、春泥泛漪、新花即刻破土——"落红护花"生命循环。

## 朗读

- `audio/00` 标题与作者、`01–03` 各境、`04` 全诗，均为 AI 生成。
- 重新生成：`node <技能目录>/scripts/gen-voice.js index.html "己亥杂诗" "清，龚自珍"`
- 删除 `audio/` 时页面自动回退浏览器语音（Edge"在线自然语音"下为逐句真人节奏朗诵）。

## 教学建议

1. 先自动游览一遍整体感受情绪曲线（离愁→静美→暖意），再逐境精读。
2. 第二境提问：落花去了哪里？引出第三境"化作春泥更护花"。
3. 结合注释讲"以落花自喻"：诗人辞官离京，仍心系家国、甘为后人作泥土。
4. 小测 5 题覆盖接龙、读音（涯 yá）、作者与名句主旨。
