# 蝶恋花·庭院深深深几许 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《蝶恋花·庭院深深深几许》（宋·欧阳修）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**水墨夜思**赛道——全套冷银水墨色板，冷月当空，全页唯一的暖彩是末境的「乱红」（落花红瓣）。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"泪眼问花"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：花枝乱颤，一阵红瓣掠过秋千，题字"乱红飞过秋千"同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主色 | `#a8b4c9`（按钮/边框/进度点/题字，全部冷银水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#101724` 系，fd 0.0048–0.0066 |
| 月 | 冷银白（ms 1.5–1.6），全页唯一主角；末境风雨如晦压至 ms 0.55 |
| 星 | 稀疏（亮度 0.22–0.45） |
| 粒子母题 | 庭中微尘、杨柳堆烟、横雨（斜掠雨丝着色器）、乱红（唯一暖彩） |

**有意的设计**：「庭院深深」以院门→回廊→四重垂帘→深闺小楼的纵深轴线做"三个深字"的视觉递深，垂帘左右交错留缝，一层层望进去；末境的**乱红**（花冠、落瓣、积红）是全页唯一的暖色点——风雨如晦里唯一的一点春色，也是被卷走的那点春色。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，`gen-voice-edge.py` 生成）：

- `00.mp3` 标题（蝶恋花·庭院深深深几许）
- `01–02.mp3` 上/下片逐境朗读
- `03.mp3` 全词连读

多音字以 `tts.json` 钉定（只影响读音不改页面文字）：`几许→己许`（几 jǐ）、`帘幕无重数→帘幕无虫数`（重 chóng）。`雨横风狂`之「横」（hèng）与`玉勒雕鞍`之「勒」（lè）经基频轨迹实证 Edge 原生即读正确口径（语境中「横」呈去声高降），且无同调同音字可替换，故不钉。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：从"三个深字"设问——庭院到底有多深？带学生数一重重的门、廊、帘。
2. **境①递深**：对照画面找"帘幕无重数"的四重垂帘；看远骑远去，体会"楼高不见章台路"的望而不得。
3. **境②炼字**：「横」读 hèng（凶暴、放纵），与「狂」互文；看院门徐徐合拢理解"门掩黄昏"的「掩」字。
4. **情感**：点击问花后讨论"为什么花不语、乱红偏要飞过秋千"——秋千是旧日嬉游之物，物是人非。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
