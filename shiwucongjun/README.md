# 十五从军征 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《十五从军征》（汉·乐府）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**宣纸留白**赛道——但刻意避开已有宣纸页的构图（终南望余雪=雪线山体+城头望雪、登乐游原=夕阳驱车、幸蜀宫=行宫宫苑），写的是这首汉乐府叙事诗的**暮年归乡·家已成冢**：宣纸上一次极克制的荒凉——浅纸为天、浓墨作剪影、大量留白，一条乡道贯穿（卷首远望→道逢→望家→庭中→檐下）。accent=#4a5060（青灰，queue 分配强调色）只落在老兵袍色衣领、UI、末境青灰暮流与泪光上，全页近零饱和。荒冢意象克制写意：松柏环冢、土馒头坟形、兔雉惊走剪影——不画碑石，不画骨骸。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"羹饭一时熟"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏

- 末章：全诗回放、学习小测（5 题）

**有意的设计**：四境是一条"回家的路"，一次比一次近，一次比一次凉——①乡道道逢（归途，问得急切）→ ②遥看望家（乡人一指，"家"是松柏下的累累坟冢，兔雉成了屋主）→ ③庭中舂炊（旅谷旅葵喧宾夺主，老兵认认真真做一顿没人等的饭）→ ④檐下饭案（羹饭一时熟，空席虚位，东望落泪）。全诗不着一字议论，只把问路、望家、舂谷、采葵、做饭、东望、落泪一连串动作摆进构图——乐府"感于哀乐，缘事而发"的力量全在动作本身。「家中有阿谁」与「不知贻阿谁」首尾两个"阿谁"，正是境壹与境肆遥遥相对的诗眼。

## 教学建议

1. **导入**：让学生只看数字——"十五""八十"，中间是多少年？六十五年的仗打成什么样，诗一个字没写，只写"始得归"的"始"。这份沉默就是汉乐府的笔法。
2. **境壹诗眼**：「家中有阿谁」——归人进乡问的第一件事不是吃饭安身，而是家人存亡。问得越急切，越见六十五年里刻骨的牵挂，也埋下全诗最不忍读的答案。
3. **境贰看点（标志性瞬间）**：乡人的回答不是一句话，而是一指——"遥看是君家，松柏冢累累"。让学生在画面里找：家在哪？松柏之下、坟冢相连处，才是"家"。再找兔与雉：野物敢从狗洞进出、敢在梁上栖身，正见屋残墙颓、久无人居。汉人墓地多植松柏，"松柏"二字即死亡的含蓄书写。
4. **境叁看点**：舂谷、采葵、做饭、煮羹——动作越认真，越见荒凉：这顿饭从一开始就注定没有人来吃。可让学生数一数老兵做了几件事，再问：他为什么要做得这么认真？
5. **境④点击后**：热气腾起的饭菜本是人间最暖的东西，在这里却成了最冷的一问。「不知贻阿谁」与境壹「家中有阿谁」遥遥相对：出门时问"还有谁"，归来后答"没有谁"。追问：老兵为什么"出门东向看"？望什么？——什么也没有，这正是极度悲怆后的茫然。
6. **主旨**：全诗不着一字议论，只摆动作——兵役之苦、家破人亡之痛尽在无言。这是乐府"感于哀乐，缘事而发"的叙事力量；可与《石壕吏》等诗互读，看"抓壮丁"的题材如何一脉相承。
7. **诵读**：五言二三节拍（十五/从军/征，八十/始得归），语速宜缓，"家中有阿谁""不知贻阿谁"两处宜轻且拖——两个"阿谁"是全诗的叹息所在；末句"泪落沾我衣"收得要轻，不要加重。
8. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示；末境留 3 秒给学生自己点击，看热气升起、空席虚位的一刻。

## 小测设计（5 题）

接龙×2（起句接下句、第四境句接第三境句）→ 读音词义×1（冢 zhǒng／雉 zhì／舂 chōng 考点钉子）→ 汉乐府叙事诗常识×1（乐府官署→诗体，主旨控诉兵役之苦）→ 细节与主旨×1（"羹饭一时熟……泪落沾我衣"以动作细节写不动声色的悲恸）。
