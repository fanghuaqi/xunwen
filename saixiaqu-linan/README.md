# 塞下曲·其二 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《塞下曲·其二》（唐·卢纶）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**大漠金戈**赛道——但刻意避开孤城/大漠/城垣的既有边塞构图，写的是这场夜射的**时间推进**：境壹=夜（密林夜惊、引弓一瞬），境贰=平明（晨光石棱、白羽没镞）。accent=#c4824a（暗赭鎏金）只落在人物边缘光/箭镞寒光/石棱受光/晨光上，禁艳金。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"重现夜射"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：幽影飞箭自夜林深处破空而来（重现昨夜一射），钉入石棱迸出石屑、白羽犹颤，"将军夜引弓 没在石棱中"题字同现
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：先讲本事——《史记·李将军列传》里"飞将军"李广见草中石、以为虎而射之，"中石没镞"，再射终不能复入。卢纶这首正是把这个典故写成了一出二十字的悬疑短剧。
2. **境①诗眼**：「惊」与「引」——风惊草动是"险"，闻声即引弓是"定"；注意诗句故意不说射中了什么、也不说射的是什么，让学生带着"箭去哪了"的问题进下一境。
3. **境②点击后**：看重现的夜射与眼前没石之箭闭环，讨论「寻」字——夜射时不知射中什么，清晨才去寻，悬念在「寻」里，惊叹在「没」里（顺带钉读音：没 mò、棱 léng）。
4. **写法**：全诗不写射的场面、不点破射的是石不是虎，只以「引弓」「寻白羽」两个动作带出悬念——侧面烘托，神力自见；可对照正面描写的写法讨论留白的力量。
5. **背景**：卢纶，大历十才子之一；《塞下曲》组诗共六首，其三「月黑雁飞高，单于夜遁逃」最为人熟知——本篇为其二，同写将军夜猎，可对读（一组写追逃、一首写射虎）。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、写法主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 20 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 交互境序号 `curIdx===2`（pointerdown 与空格双接线，`clicked` 标志 + 1.2s 冷却防连点；空格先交互、再按进终章）。

- 预算：三境 drawCall 代理 ≈ 16/25/26、三角面 ≈ 0.55/1.19/0.79 万（≤120 / ≤12 万）。
