# 登乐游原 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《登乐游原》（唐·李商隐）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**宣纸留白**赛道——浅纸为天、浓墨作远原烟树、大量留白，accent=#3e4436（苍绿墨）全页近零饱和；点睛是一轮克制的暖橙余晖——**暖调余晖是本页主视觉**，讲的是一场黄昏：从「向晚驱车」的郁郁，到「夕阳无限好，只是近黄昏」的大盛与徐沉。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"看夕阳徐沉"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：夕阳大盛、题字同现，继而徐徐沉入远原线——余晖渐敛、暮霭转灰、遥遥城郭渐隐、初星点点
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：先讲「意不适」——傍晚了心里堵得慌，怎么办？李商隐的回答是：驾车、登高。让学生带着"散心之旅会看到什么"的问题入境。
2. **境①诗眼**：「驱」「登」两个动词——不假思索、说走就走；结合画面看车影双轮徐转、车辙上行，体会"急于摆脱郁结"的劲。顺带讲「古原」的「古」：汉代乐游苑，到唐已是一座古原。
3. **境②前**：先让学生自己看画面说感受（大夕阳、半衔远原线），再对读「无限好」——赞叹到近乎失语的三个字。
4. **境②点击后**：看夕阳大盛又徐沉、暮色四合，讨论「只是」——转折一落，好景与时限同时到场；愈辉煌愈近消逝，惜黄昏即惜年华。可补一句"另解"（只是=正是），说明通行取转折说。
5. **背景**：李商隐，字义山，晚唐，与杜牧并称「小李杜」；乐游原是唐长安黄昏登高胜地，可对照杜牧《乐游原》"夕阳无限好"之外的另一种登原目光。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、典故常识 ×1、名句主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 20 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
