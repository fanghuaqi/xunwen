# 渡汉江 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《渡汉江》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**水墨夜思**赛道，取「汉江近乡」变体——岭外四层叠嶂、断绝的音书（高空孤雁）、江上一叶渡舟，以及渐近的**乡关**与迎面而来的**来人**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击问来人"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：两位来人迎面走近 7.5 单位并"欲问又止"（顿步、微晃），乡关村落整体前移 7 单位，诗人由背立侧身，"近乡情怯"题字同现
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：封面设问"越靠近家，你会越快还是越怕？"再入境壹。
2. **境壹析"断"与"复"**："断"是音信全无，"复""历"是数着季节熬过来；离乡之久、思乡之切，全在这五个字里。
3. **境贰析"怯"**：按常理近乡应更快，诗人偏说"更怯"——为什么？（怕听到坏消息，怕希望落空。）可让学生设想：他此刻最想问什么、又最怕听到什么。
4. **点击体会**：点击问来人看来人走近又顿住、乡关前移，再读"不敢问来人"，体会"欲问又止"的一瞬。
5. **知人论世**：宋之问因依附张易之被贬岭南，此诗写逃归途中渡汉江近乡时的心情；"近乡情怯"四字由此成为成语。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音义 ×1、心理 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 39 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（渡舟、来人、乡关、岸草）都在 8–50 单位内，fd ≤ 0.0066；全页**无一处手写 opacity**（村灯/渡舟/来人/乡关全走 scale、位置或旋转）。
- 场景构件（冒烟实测）：卷首 14 mesh / 13 sprite、境壹 21 mesh、境贰 23 mesh / 13 sprite；draw call 代理值 28 / 30 / 37（≤120），三角面 ≈1.1 / 2.2 / 2.9 万（≤12 万）。
