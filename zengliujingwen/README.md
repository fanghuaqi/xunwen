# 赠刘景文 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《赠刘景文》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**青绿春晓**赛道，取「初冬园圃」变体——池中凋尽的残荷、篱边残破的菊枝，与园中满树橙黄橘绿的果实；末境点击，残荷残菊褪去、果实与果园暖光次第点亮。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击橙黄橘绿"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：残荷残菊渐隐褪去，满树果实上的暖金光点次第亮起、果园点光转暖，"橙黄橘绿"题字同现
- 末章：全诗回放、学习小测（5 题）

- `00.mp3` 标题（"赠刘景文"）

- `02.mp3` 境贰（一年好景君须记，最是橙黄橘绿时。）
- `03.mp3` 全篇连读

多音字处理见 `tts.json`（**sub 非空即完全接管**，不再叠加脚本内置兜底表）：

- `荷尽` → `禾尽`：钉住「荷」的 **hé**（荷花），避开「负荷」的 hè
- 逐句核过：擎雨盖 qíng、菊残、傲霜枝、好景 hǎo、君须记、最是、橙 chéng、橘 jú、绿 lǜ——无须干预

页面朗读优先级：Edge 在线自然语音现场逐句朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"如果初冬只剩残荷败菊，还有什么好看的？"再入境壹，先读前两句。
2. **境壹析对照**："已无"对"犹有"、"尽"对"残"——注意"傲霜枝"不是写花，而是写枝：花可以残，骨不能倒。
3. **境贰析翻案**：别人悲秋，苏轼偏说初冬"最是"好景；让学生找一找，这个"最"字把前面两句的衰败翻成了什么。
4. **点击体会**：点击橙黄橘绿看残褪荣生，再说说"橙黄橘绿"为什么可以比喻人生。
5. **知人论世**：此诗赠刘景文（刘季孙），其人年近六十、仕途失意；苏轼以"一年好景君须记"勉励他，也自勉——写此诗时苏轼亦在杭州任上，正是他人生秋冬季里的豁达。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音义 ×1、背景用意 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 37 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（残荷、残菊、橙橘树、人物）都在 8–20 单位内，fd ≤ 0.0056；「每帧写 opacity」只有残荷/残菊两处渐隐，均乘 fadeK 且系数 ≤ 1；果园点光 intensity 也按 fadeK 写出（基座 = 运行期最大值 1.25）。
- 场景构件（冒烟实测）：卷首 13 mesh、境壹 11 mesh、境贰 17 mesh / 17 sprite / 3 light；draw call 代理值 21 / 19 / 35（≤120），三角面 ≈1.5 / 0.7 / 1.5 万（≤12 万）。
