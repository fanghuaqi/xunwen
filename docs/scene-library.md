# 循文入境 · 意象→场景原型库

把每句诗的"画面"归入下面的原型，参数化组合即可拼出全新诗篇的场景。所有原型函数都在
`assets/reference-jiangjinjiu.html` 里，按函数名检索复制；新意象（如战旗、孤舟、飞雪）按
§5 的配方自写 builder，一般 40-80 行。

## 1. 情绪基调 → 氛围参数速查

| 诗情 | 雾色 fd | 星 | 月 | 光 |
|---|---|---|---|---|
| 豪放/壮阔 | 0.004-0.006 冷蓝 | 0.85-1.0 | 大而高 | 月光清亮 |
| 思乡/静夜 | 0.004 暖蓝 | 0.7-0.9 | 大而低（贴地平线） | 暖烛光点缀 |
| 沉郁/愁绪 | 0.015-0.025 灰蓝 | ≤0.3 | 小/暗/被云吞 | 冷且弱 |
| 宴饮/喜庆 | 0.008-0.011 暖褐 | 0.5-0.8 | 中 | 灯笼红、篝火橙 |
| 边塞/苍凉 | 0.006-0.01 黄昏赭 | 0.6 | 低垂 | 火把暖橙 |
| 田园/恬淡 | 0.005-0.008 青绿 | 0.6-0.8 | 中 | 柔和青白 |

## 2. 意象 → 原型对照表（2026-09 升级版；★ = 本轮新增/重写）

| 意象 | 原型 | 关键参数/改造点 |
|---|---|---|
| **人物/唐人衣冠（任何有人的场面）** | ★`makeFigure({pose,robe,hat,beard,face,scale,rim})` | 六种姿态：举杯/指月/倾酒/按剑/独立/坐饮；袍身 Lathe 下摆张开、领口腰带袖口变色收边、发髻/幞头/胡须；`rim:0.5` + 暖色 `rimC` 让剪影从夜景里跳出来。坐姿=人往下沉 1.0-1.4（袍摆沉到地面以下被地面遮住），别做蹲姿骨骼 |
| **宴席器物** | ★`makeVessel({type,mat,liquid,scale})` | 樽(三足)/壶(流+鋬+盖)/杯/爵/盘/碗/坛 七种器型剖面；金/陶/玉三档材质；口沿细高光环 + 接触阴影；`liquid:true` 露酒面反光。旧 `makeGoblet/makeJar` 是兼容壳 |
| **盘飧/席面** | ★`makeDish({r,n})` + ★`makeTable({w,d,h})` | 案面有厚度、两端板足、横枨；盘有厚度 + 几团食物 + 可选油光。器物摆在案上必须有接触阴影，否则一律"浮空" |
| **火/篝火/灶** | ★`makeFlame({h,w,core,outer,light})` 或 ★`makeBrazier({r,fh,light})` | 有形状的焰体（焰心/外焰色差 + 湍流抖动 + 偶爆火星 + 地面光池）。**别再拿 makeGlow 堆两三层当火**——那是"模糊的橙黄斑块" |
| **灯/烛/灯火** | ★`makeLantern(scale,{flame,glow})` | 8 根竖筋沿剖面 + 上下箍 + 半透纸面 + 内焰 + 外辉。成列布置（檐下灯串 4-6 盏 + 立灯 1-2 座）；远景灯不给 `flame` 省 draw call |
| **远山/峰峦/天际线** | ★`makeRange({r,h,layers,peaks,seed,arc,a0,y,atmo})` | 多峰折线剖面 + 2-3 层纵深（近深远淡）+ 山脊微光 + 层间视差。**等边三角形/截头圆柱一律换成它**；`arc/a0` 可切出"两岸青山"、山口、浪墙 |
| **浪墙/惊涛** | ★`makeRange({arc,a0,h:11,r:26,color:暖白,order:4})` 竖在浪前 | 折线浪脊一眼看出是"浪"不是雾；配 `makeGlow` 白沫（box 宽 ≈ 浪宽×1.2、单层 maxA ≤0.6） |
| **明月/夕阳** | ★`makeMoon({r,phase,haze})`；旧日轮加 `map:limbTex()` | 临边昏暗 + 淡斑纹 + 圆缺 + 三层辉光。`phase` 0=满月 0.5=弦月；`ms:0.001` + 月移到地下=无月 |
| **地面/滩涂** | ★`makeGround({r,c1,c2})` | 斑驳 fbm 质感（不是一条纯黑横带）。室内境用暖褐 c1/c2 |
| **前景框景** | ★`makeForeground({kind:'岩壁'|'坡石'|'芦苇'|'栏杆'|'树枝'})` | 压暗、贴近相机、占画面下缘/左右缘 —— 画面"立起来"的关键一层 |
| **帷帐/亭柱/殿宇** | ★`makeCurtain({w,h,folds})` + ★`makePillar({h,top})` + 塔楼 builder | 帷帐要有褶皱与上亮下暗；柱子 `top:false` 时别加柱头（暗场里会变成"天上悬着一块"）；塔楼用 `GeoBag` 合成 1 个 mesh |
| **远景人群/满座** | ★`makeCrowd({n,rect,color,rimC})` | 1 个 InstancedMesh 摆一片人（1 draw call）；近处主角才用完整 `makeFigure` |
| 江河/流水 | `makeWater` | `flow:[0,1.5]` 流速表"奔流"；`amp` 大=汹涌，小=静谧 |
| 瀑布/天上来 | `makeWaterfall` + 底部 `makeGlow`(浪花) | 高 150+，双面交叉增强体积；水丝靠 shader 里的 sin 条纹出质感 |
| 海/无边 | `makeWater` size 900 + 重雾 | `fd` 加大吃掉地平线 |
| 落花/飞雪/雨 | `makeGlow` rise=0 改造 | 落雪: 白、speed 慢、y 从高处起；花瓣: 粉白、加 x 摆动 |
| 星空/怀古 | 常驻星 + 星座连线 + 金色光带 | 连线 `Line`+`fog:false`；光带=沿大圆散布的 Points |
| 梦/醉 | `bDream` 模式 | 重雾 0.02+、物体缓沉、可选 `roll:0.035` 慢滚镜 |
| 时间流逝/愁 | `makeFlow` 流动雾流 | 灰蓝 NormalBlending 低透明度，流向与"逝水"一致 |
| 战争/边塞（新） | 旗帜+火把+远山 | 旗: Plane 顶点着色器 sin 波动；火把: 竖圆柱 + ★`makeFlame` + 点光 |
| 离别/孤舟（新） | 舟+岸 | 舟: 弯曲 Box 或 Lathe 半壳+桅杆圆柱；岸柳: ★`makeForeground({kind:'树枝'})` |
| 田园/村居（新） | 茅屋+田垄 | 茅屋: 盒+大扁 Cone 草顶；田: ★`makeGround` + 起伏 |

## 3. 场景设计的四条心法

1. **一句一画，画要"立得住"**：闭上眼能不能把这句诗演出来？如"会须一饮三百杯"→三百只金杯盘旋成星河，就是把抽象数字可视化；"与尔同销万古愁"→灰蓝愁雾被江流卷走，就是把抽象情绪物质化。**具象化数字、物质化情绪**是本形式最高级的两招。
2. **镜头参与叙事**：仰视瀑布=压迫赞叹，低空掠浪=奔流之势，平视举杯=把酒言欢。cam 的 f/t 高度差和 lf 的抬升就是"镜头语言"。
3. **交互点睛不超过一处**：全诗设 1 个交互境（碰杯/点亮灯/击鼓），放在情感最高点。`click()` 里做粒子爆发+音效+题字闪烁。
4. **重复利用母题**：同一首诗让 1-2 个元素反复出现（如将进酒的"水"与"月"）形成闭环——首境的江水在末境把"愁"带走。

## 4. 交互境候选

| 诗句情境 | 交互 | 实现 |
|---|---|---|
| 劝饮/共饮 | 点击=碰杯 | 移动杯子到中心 + `makeBurst().fire()` + 铃声 + 题字闪烁 |
| 灯/烛相关 | 点击=点亮 | emissive 材质切换 + PointLight 强度补间 |
| 钟鼓/击节 | 点击=击鼓 | 火花 + WebAudio 低频鼓点 |
| 远眺/招手 | 点击=群鸟惊起 | birds 群从静止到起飞 |

## 5. 新原型配方（40-80 行模板）

```js
function bMyScene(){                       // 1) 建组
  const g=new THREE.Group();
  // 2) 地面/水体（选一）+ 3) 主视觉 2-3 件 + 4) 粒子氛围 1-2 层
  // 5) 灯光: addLights(g,{平行光},{环境光}) + 1 个 PointLight 点睛
  // 6) update(t,dt): 粒子 update + 缓动动画（sin 摆动/旋转/漂移）
  return {group:g, update(t,dt){...}, click(){...}};
}
```

材质选择：剪影用 `MeshBasicMaterial` 暗色（吃雾）；受光主体用 `MeshPhongMaterial`
（r128 无环境贴图时 Phong 高光比 Standard 更"出片"，金属给 specular+shininess）；
自发光小件（灯、窗、杯沿）用 `MeshBasicMaterial` 亮色。
