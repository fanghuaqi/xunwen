# 循文入境 · 美术方向（防同质化的关键）

> 参考实现长着一张"深蓝夜空 + 鎏金"的脸，那是《将进酒》的美术方向，不是引擎的默认样式。
> 每首诗开工前必须先完成本文件的《美术方案》，否则做出来的网页千诗一面。

## 1. 风格赛道（六选一，也可自创变体）

每条赛道给出可直接套用的取值。`SKY` 列是各境天空/雾参数的基调（逐境在此基调上微调）。

### ① 夜宴金彩（参考实现默认）——豪放宴饮、盛唐气象
- 色板：bg `#05070d`｜主金 `#d4af37`｜文字 `#e8dcc0`｜雾 `#0a1526` fd 0.004-0.006
- 月：暖白大月；星：繁密；粒子母题：金色流萤、火星、酒光
- 适用：将进酒、客至、闻官军收河南北等"欢"调

### ② 水墨夜思（默认禁用，静夜/怀乡/禅意专用）
- 色板：bg `#0d1117`｜主银 `#c9d3e0`｜文字 `#dfe6f0`｜雾 `#131a26` fd 0.005-0.009
- 月：冷银白是**唯一主角**（ms 1.6-2.2），星稀；粒子母题：微尘、霜晶、流云
- UI 去金色：边框 `rgba(180,195,215,.25)`，辉光改银蓝；版式居中窄幅
- 适用：静夜思、月夜忆舍弟、枫桥夜泊

### ③ 宣纸留白（**浅色**）——孤寂、冬日、极简禅意
- 色板：bg `#e9e2d0`（宣纸）｜主墨 `#2c2f33`｜文字 `#23272e`｜雾 `#e6dfcc` fd 0.004-0.008
- 天空：穹顶 top `#e9e2d0` / hor `#ded5bd`，山用浓墨剪影 `#2c2f33`；星 0.05-0.15；月→淡日或无
- 粒子母题：淡雪、墨点晕染；UI：面板改 `rgba(255,252,240,.72)`，**去掉所有金色辉光阴影**
- 文字阴影 `text-shadow` 全部删除或改 `0 1px 0 rgba(255,255,255,.4)`
- 适用：江雪、逢雪宿芙蓉山主人、题西林壁
- ⚠ 浅色主题必改清单：body/err 背景、--gold→墨色、--ink→深墨、.seg 与 #brand 的 text-shadow、dots 选中色

### ④ 青绿春晓——田园、春景、喜悦
- 色板：bg `#0a1410`｜主绿 `#9fce8f`｜辅杏 `#f2c94c`｜文字 `#eef4e6`｜雾 `#0e1d16` fd 0.005-0.008
- 月→弯月或晨曦（dirC 暖金），天光渐亮的晨景可用 SKY 逐境变亮
- 粒子母题：花瓣（粉白小片缓落）、黄绿萤火、燕群
- 适用：春晓、村居、游山西村

### ⑤ 大漠金戈——边塞、怀古、壮烈
- 色板：bg `#120d08`｜主赭 `#d98e3a`｜文字 `#f0e2cc`｜雾 `#1a120a` fd 0.006-0.01
- 月：低垂昏黄；天际线用台地/城垣剪影替代圆山顶；粒子母题：横流沙尘（makeFlow 赭色）、烽火火星、旗影
- 适用：出塞、凉州词、破阵子、赤壁怀古

### ⑥ 烟雨江南——婉约、离别、闺情
- 色板：bg `#10141a`｜主黛蓝 `#8fb3c9`｜辅藕荷 `#d8a7b1`｜文字 `#e6ecef`｜雾 `#151d26` fd 0.012-0.02
- 月隐（ms≤0.6 或藏），雨丝/柳丝粒子（细长下落），水面涨雾
- 版式可变体为横卷：词句自右向左横排随境推进（长词尤其合适）
- 适用：雨霖铃、一剪梅、忆江南

## 2. 必改位置清单（复制参考实现后逐项过）

CSS（`:root` 与少数字面量）：
1. `--gold` → 赛道主色（按钮/边框/进度点/题字全跟着变）
2. `--ink` → 诗句文字色；`--dim` → 次要文字色
3. `body{background:#05070d}` 与 `#err{background:#05070d}` → 赛道底色
4. `#cover`/`#ending` 渐变里的 `rgba(4,6,11,…)` → 赛道深色
5. `.seg`、`#brand`、`#dots i.on` 的 text-shadow/box-shadow 辉光色 → 主色（浅色赛道直接删）
6. `.credit`、`#coverHint` 的颜色 → 次要色

JS 数据：
7. 所有境的 `sky:()=>SK({...})` 色板（top/hor/bot/fog/dirC/ambC）按赛道重写
8. 粒子颜色（makeGlow/makeFlow 的 color）与母题按赛道换
9. 若赛道无月：`ms:0.001` + moon 移出视野（参考"明镜白发"境的做法）

## 3. 标志性瞬间（每首诗必须自创一个）

从场景库**选不出**的、只属于这首诗的画面，单独写一个新 builder（40-80 行）。这是防止"千诗一面"的第二道锁。已用掉的例子（不要再重复）：

- 将进酒：三百金杯盘旋成星河；点击碰杯
- 静夜思：月光穿窗成柱；点击逐盏点亮故乡灯火

新点子示例（仅供启发，鼓励原创）：江雪的"一舟一翁钓寒江"（天地皆白独此一点）、水调歌头的"把酒问天"（杯举向月、月随镜拉远）、春望的"草木深"（荒草从城砖缝里长出来的延时）、声声慢的"点滴到天明"（雨滴打芭蕉声画同步）。

## 4. 防同质化三查（交付前自问）

2. **母题变了吗**——粒子/光/构图是否还是"金色流萤+大月亮"的老三样？
3. **标志瞬间有吗**——这颗诗独有的画面，是不是参考库里没有的？
