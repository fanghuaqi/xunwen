# 雨霖铃 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《雨霖铃·寒蝉凄切》（宋·柳永）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**烟雨江南**赛道——黛蓝湿雾、全页禁金，月隐为常，唯设想之景悬一弯残月。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"点击兰舟"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：兰舟发入烟波，残月亮起悬上杨柳岸，"更与何人说？"题字同现
- 末章：全诗回放、学习小测（5 题）

| 月 | 常隐（ms 0.001）；唯境③设想之景由天空系统悬一弯低垂残月（mph 0.62），末境点击后再亮起一轮局部残月 |

**有意的设计**：境②"暮霭沉沉楚天阔"用两层贴水横雾把水平线压到很低、远山压到极远，做出"压迫性的开阔"——这是柳永设想别后孤旅的心理投影；全页唯一"亮起来"的时刻是末境点击后的残月，对应"千种风情"无人共说时唯一的天光。

## 教学建议

1. **导入**：从"离别"话题设问——如果注定要与最亲的人分别，你会说什么？再入境①对照"竟无语凝噎"：千言万语为何一句说不出？
2. **境①白描**：让学生数一数画面里的离别要素（寒蝉、长亭、骤雨、帐饮、兰舟），体会"未有二语能打动人如此"的镜头式铺叙。
3. **境②设想**：问学生"这一境有人物吗？"——孤舟客影是柳永**设想**的别后，两层横雾压平线就是"暮霭沉沉"的心理重量。
4. **境③名句**：先看画面再读"杨柳岸，晓风残月"，体会以景代答：问"何处"？答以三个意象。可引"凡有井水饮处，即能歌柳词"。
5. **境④收束**：点击兰舟看"舟发烟波、残月悬岸"，讨论"千种风情更与何人说"与开头"执手"的呼应——此词为宋代离别词压卷（"离别之祖"）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
