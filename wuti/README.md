# 循文入境 · 无题·相见时难别亦难（唐 · 李商隐）

单文件沉浸式诗词课件：四境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 烟雨江南·相思变体：李商隐无题诗中最著名的一首——春蚕到死、蜡炬成灰的至死相思，最终寄托于青鸟探看蓬山的缥缈希冀。
> 标志性瞬间：春蚕到死丝方尽，蜡炬成灰泪始干——巨炬垂泪凝蜡、蚕丝万缕盘旋的双重具象。

## 教学建议

- 颔联「丝/思」谐音双关：「春蚕到死丝方尽，蜡炬成灰泪始干」——以春蚕吐丝喻相思无穷，以蜡炬垂泪喻流泪难干，是千古至情名句
- 颈联「设身处地」的虚写：不写自己如何思念对方，而设想对方「晓镜但愁云鬓改，夜吟应觉月光寒」——思念之深，全在为对方设想
- 尾联寄托与自慰：蓬山虽远却说「无多路」，借西王母「青鸟」使者传递消息——在绝望中生出希冀
- 注音考点：相见 xiāng jiàn、别亦难 yì nán、东风 dōng fēng、百花残 cán、春蚕 cán、蜡炬 là jù、泪始干 gān、晓镜 xiǎo jìng、云鬓 bìn、夜吟 yín、蓬山 péng shān、青鸟 qīng niǎo、殷勤 yīn qín、探看 tàn kàn
- 体裁：七言律诗；李商隐「无题」系列的巅峰之作
