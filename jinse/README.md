# 锦瑟 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《锦瑟》（唐·李商隐）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**水墨夜思**赛道——但刻意避开既有水墨夜思页的构图（不做宣室殿内夜谈、不做满月江楼水天一色、不做孤山梅影暗香、不做古寺竹径/雨前危城/渡口渔火），写的是这首千古朦胧诗的**一瑟四典梦境化**：石台露台上一张锦瑟横陈（贯穿四境的母题），四个典故作梦境次第展开——境壹=瑟与弦光（华年），境贰=晓梦之蝶+远山鹃影（迷与托），境叁=沧海珠泪+蓝田玉烟（可望不可即），境肆=四象隐入惘然。accent=#b8c4dd（月银微紫，queue 分配强调色）只落在弦光/蝶翼/鹃啼光晕/珠光/玉烟月晕/人物边缘光/UI 上，全页近零饱和；唯境叁蓝田一側一抹极克制的暖（玉烟暖雾+山脚暖晕）——冷（沧海月明）与暖（蓝田日暖）的对切就是颈联对仗本身。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"四象叠化流转+瑟弦余音"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：蝶梦/鹃啼/珠泪/玉烟四象幻影沿远山弧次第淡现、错位流转、渐次隐入雾中；瑟弦光带沿五十弦往返起伏（余音可视），四叠下行拨弦音渐远渐杳，"此情可待成追忆 只是当时已惘然"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思 · 一瑟四典梦境化变体（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117` |
| 主色 | `#b8c4dd`（月银微紫，queue 分配强调色；按钮/边框/进度点/题字/边缘光/弦光） |
| 文字 | `#dfe6f0` |
| 雾 | `#111823`→`#131a26`，fd 0.0052–0.0062 |

| 场景母题 | 石台露台（台基/地坪/前阶/矮栏望柱）+ **锦瑟**（瑟首瑟尾琴身+五十弦细线阵+一弦一柱斜列+尾端三瑟枘+弦光 Sprite）+ 三足双耳铜香炉（一缕冷香）——三件母题贯穿四境 |
| 粒子母题 | 冷香一缕、晓梦半透蝶影、鹃啼光晕、月下珠光、玉烟暖雾、夜气横流 |
| 与已有水墨夜思页的区分 | jiasheng=宣室殿内夜谈、jianglou-ganjiu=满月江楼水天一色、shanyuan-xiaomei=孤山梅影暗香；本页=**夜台一瑟、四典如梦**：室内器物（瑟）与室外梦境（蝶/鹃/珠/玉）同框的朦胧追忆 |

**有意的设计**：四境共用同一张瑟——「一弦一柱」是全诗的记忆刻度，瑟在画在；境壹人不入画（空席待思，唯香缕如思），境贰诗人正坐瑟后而蝶影绕瑟（真幻交叠），境叁镜头拉高把「沧海月明（左·冷）／蓝田日暖（右·暖）」一联对切同框（月出山脊、水面粼光与光珠即「珠有泪」，玉烟可望而近即无即「玉生烟」），境肆万象隐雾、点击后方才短暂复现——追忆的动作本身由观众点击完成。

## 教学建议

1. **导入**：先让学生数——这张瑟有多少根弦？五十弦本是「过数之辞」，诗人偏要怪它「无端」：物本无情，人自多恨。全诗的朦胧，就从这一声没来由的埋怨开始。
2. **境①看点**：五十弦细线阵与斜列弦柱——「一弦一柱」都是年华的刻度；香炉无人，正是「思华年」的人去席空。
3. **境②点击前**：让学生找蝶（半透蝶影=「梦」）与鹃（山嘴鸟影+啼光晕=「托」）——庄周梦蝶分不清谁梦谁，望帝魂化杜鹃身死而心不死。
4. **境③诗眼**：左冷右暖一联对切——月明沧海、泪化珠光；日暖蓝田、玉烟可望而近即无。可补戴叔伦「诗家之景，如蓝田日暖，良玉生烟，可望而不可置于眉睫之前也」。
5. **境④点击后**：四象叠化流转又隐去——「追忆」这个动作由学生的点击完成；而幻影终究隐入惘然，正是「当时已惘然」。
6. **主旨**：多元解读并存（悼亡说/自伤身世说/诗集自序说）——正因四典朦胧而容许多解，「思华年」的深情与「惘然」的怅惘是共同底色；小测第 5 题即落此。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示；末境留 3 秒给学生自己点击。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 56 字）、释义/注释、境名/意境题句、5 题小测（接龙×2、读音词义×1、四典×1、主旨多元解读×1）、终章回放。
- `STAGES = POEM + 1`（封面 + 四境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=4` 对齐。
- 交互境序号 `curIdx===4`（pointerdown 与空格双接线，`clicked` 标志 + 1.2s 冷却防连点；空格先交互、再按进终章）。
- fadeK 铁律：所有每帧写 opacity 的对象（弦光/蝶翼材质/鹃啼光晕/光珠材质/玉烟暖晕/幻影月盘）初值=最大且逐帧乘 fadeK；点击前四象幻影组 `visible=false` 硬关（无幻影残影）；弦光/鹃啼晕/暖晕/幻影月盘 `fog:false` 如星月点名；水面/地面/山体着色器走引擎 `fogShaders` 雾同步。
- 预算：五次 build 的 drawCall 代理 ≈ 22/22/26/27/38、三角面 ≈ 0.6/0.6/0.6/1.9/0.8 万（≤120 / ≤12 万）。
- 校验：`node _pipeline/tools/validate.js jinse/index.html` → **✓ 校验全部通过**；`node jinse/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 逐境 build/update×400 帧 → fadeK 合规 → 末境点击门控 → 自动游览至终章 → 小测满分）；`node _pipeline/accept.js jinse` → **ACCEPT（4境 · 水墨夜思）**。
