# 迢迢牵牛星 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《迢迢牵牛星》（汉·古诗十九首）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**水墨夜思**赛道——但刻意避开既有水墨夜思页的构图（不做锦瑟夜台一瑟、不做江楼满月水天一色；更不做鹊桥仙的云海星河带+鹊群搭桥成会），写的是这首诗的**星河为界的两岸+织女机杼**：低垂的银河化作一条清浅的星水横在画面中部，两岸墨色岸渚，左岸织女机杼（札札弄机杼——全诗唯一「人间」道具，贯穿四境的母题），牵牛织女双星低垂对望（两岸光点，含蓄不具面容）。全页写一个「不成」——机杼札札而终日不成章，一水盈盈而脉脉不得语，**星河是界不是桥**。accent=#b8c4dd（queue 分配强调色，月银微紫）只落在双星晕/梭光/织线光/星子落波/星光连线/鹊影边缘光/UI 上；素练的素白与泪光微青是全页唯二亮部。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（末境为交互境：先轻点画面交互、再按空格进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境肆轻点画面：**鹊影横波，星光相望**——一道含蓄的星光细线自织女星弧牵到牵牛星（连线光点次第亮起，不画具体鹊桥），六点鹊影贴着水面自左岸掠向右岸（翅膀明灭，剪影含蓄），双星光晕徐涨、星子落波转盛，「盈盈一水间 脉脉不得语」题字同现；可反复点击
- 终章：全诗回放、学习小测（5 题）

**有意的设计**：十句六叠词 = 四境变奏——①迢迢/皎皎立起两岸的距离与光亮（远景双星）；②纤纤/札札落到织女劳作（机杼近景，札札节律驱动梭光明灭）；③清且浅把镜头压低贴着星水（水面星子、对岸牵牛剪影）；④盈盈/脉脉收束成隔水凝望的无声画（标志性瞬间）。机杼四境同在，镜头随诗推进；素练在境贰垂而未成章——「不成章」是心不在织。

## 教学建议

1. **导入**：让学生数一数十句里的叠词（迢迢/皎皎/纤纤/札札/盈盈/脉脉）——六组叠词写了什么？由远（双星）而近（素手机声），最后收在一水之间。叠词不是装饰，是本诗的呼吸。
2. **境壹诗眼**：素手不停、机声札札，她在做什么？——为下文「终日不成章」蓄势：越勤于织，越显「不成章」之痛。
3. **境贰看点**：「章」字语出《诗经·小雅·大东》「跂彼织女，终日七襄；虽则七襄，不成报章」——织女本是织云锦的，为什么织不成？心不在织，在隔河的那个人。
4. **境叁追问**：水又清又浅、相隔并不远，为什么过不去？——阻隔他们的从来不是水的深浅。障碍越「轻」，悲哀越「重」。
5. **境肆点击后**：星光连线是「望」、鹊影横波是「念」，但都过不去——连线而不画桥，正是「脉脉不得语」。可对照鹊桥仙「金风玉露一相逢」：那一首写相逢之贵，这一首写不得语之痛。
6. **主旨**：「盈盈一水间，脉脉不得语」——咫尺天涯，把离人的悲哀写到极处：没有呼喊，没有动作，只有隔水的凝望。千古写「咫尺天涯」的绝唱。
7. **诵读**：五言二三节拍（迢迢/牵牛星），叠词宜轻而连；末二句放最缓，「脉脉——不得语」宜留余韵，戛然而止。
8. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示；末境留 3 秒给学生自己点击看鹊影横波。
