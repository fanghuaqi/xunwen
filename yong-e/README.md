# 咏鹅 · 循文入境沉浸式诗词课堂

骆宾王《咏鹅》（相传七岁所作）：

> 鹅，鹅，鹅，曲项向天歌。白毛浮绿水，红掌拨清波。

单文件 Three.js 沉浸式网页：**双击 `index.html` 即开**（Three.js r128 走 CDN 三路回退；朗读音频已内置 `audio/`）。诗句逐境推进、3D 实景意境、逐字注音、释义注释、AI 人声朗读、自动游览、结课小测，可作课堂大屏无人值守展示。

## 境表（3 境）

母题复用：**绿水与涟漪**贯穿三境（封面远塘→特写微澜→末境清波），**白鹅**由封面剪影到境壹工笔特写、境叁化为主体。

## 美术方案：宣纸留白 · 工笔活色（浅色主题）

同赛道《江雪》走"雪景墨山水"，本诗做"绿水白鹅的工笔活色"区隔：

- 强调色 `--gold:#3a6b5a`（青碧，queue.json 分配色）、宣纸底 `#e9e2d0`、雾 `#e4e2ce`（fd 0.0042→0.0078 逐境加深）
- 水色为本诗区分点：青碧 `deep 0x2a6e5e / shallow 0x7cc6aa`（江雪为灰白寒江）
- 粒子母题：柳絮拂水（自写 `makeCatkin`：低空横飘、正弦摆动，非落雪）＋水面涟漪圆环（自写 `makeRipples`）
- 淡日仅封面/境壹可见，境贰叁隐入雾中

## 标志性瞬间

境壹"曲项向天歌"（新构件 `makeGoose`/`goosePose`/`makeWillow`/`makeCatkin`/`makeRipples`/`makeDuckweed`）：把首句三声鹅唤做成工笔特写——三段曲颈链每 8 秒从悠然 S 形伸直向天、喙随"歌"张合，绿水之下倒影同步伸曲、随微澜荡漾。场景库中无此原型，为本诗自创。

## 互动

第三境点击白鹅（或空格）：曲项动画定格引颈向天＋WebAudio 合成鹅鸣（锯齿波滑音＋颤音＋带通，两声"嘎——嘎"）＋白色水花迸溅＋涟漪激增。

## 朗读配音

`audio/00–04.mp3` 已由 `gen-voice.js`（百度 TTS，免密钥）生成；SUB 纠音表：**曲项→屈项**（qū，TTS 极易误读 qǔ"歌曲"）。若需"诗朗诵"级真人感：`set TTS_AZURE_KEY=你的密钥 && node gen-voice.js`。音频缺失时页面自动回退浏览器语音。

## 教学建议

1. 先自动游览一遍（约 70 秒），请学生说"看到了一只怎样的鹅"。
2. 逐境结合释义/注释精读：拟人（向天"歌"）、复沓（三个"鹅"字）、颜色对仗（白毛—绿水 / 红掌—清波）、炼字（"浮""拨"）。
3. 多音字考点：**曲 qū**（弯曲）≠ qǔ（歌曲）；互动境请学生亲手"唤鹅高歌"加深记忆。
4. 结课"学习小测"当堂检测（接龙 ×2、读音 ×1、文学常识 ×1、内容理解 ×1）。
