# 循文入境 · 西江月·夜行黄沙道中（辛弃疾）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，音频本地）。

## 内容

四境行走叙事，镜头始终在月夜黄沙道上行进：

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 月枝惊鹊 | 明月别枝惊鹊，清风半夜鸣蝉。 | 月下夜路，栖鹊经 2.6s 惊起、掠月远去，蝉声隐约 |
| 贰 · 稻香蛙声 | 稻花香里说丰年，听取蛙声一片。 | **标志性瞬间**：蛙鸣同步的声波涟漪自稻田荡开，稻香粒子随夜风飘散，"丰／年"浮字升起 |
| 叁 · 疏星淡雨 | 七八个星天外，两三点雨山前。 | 疏星为薄云所掩，山前细雨渐起 |
| 肆 · 溪桥忽见 | 旧时茅店社林边，路转溪桥忽见。 | **标志性瞬间**：石桥溪水，11.2s 镜头转过桥西，旧时茅店暖窗"忽见"；点击画面 → 蛙声齐荡+稻香涌起+题字（空格键同） |

含逐字注音（见 xiàn、蝉 chán 已核）、释义注释、AI 朗读、自动游览、结课小测。

## 使用

- 入境后：`← →` 或空格逐境游览；`第四境` 点击画面听蛙声一片。
- 控制条可切换自动游览 / 自动朗读 / 注音 / 声音 / 全屏。
- 朗读优先级：Edge 神经语音现场朗诵 → 本地 MP3（`audio/00–05.mp3`）→ 系统语音。
- 无网络时引擎加载失败会提示刷新；音频已内置，朗读不受影响。

## 再生成配音

```
node gen-voice.js index.html "西江月夜行黄沙道中" "宋，辛弃疾"
```

SUB 表已含 `['忽见','忽现']`（保证 xiàn 读音）；配置 `TTS_AZURE_KEY` 可升级诗朗诵级音色。

## 教学建议

- 适合 4–6 年级：先整体自动游览一遍，再逐境提问"画面里哪一句？"。
- 考点：忽见(xiàn)同"现"；蛙声"说丰年"的拟人；白描与侧面烘托（以声写静、以香写夜）。
- 质量自检：`node validate.js index.html`、`node smoke-test.js`（需本地 three.min.js）。
