## 使用
- `← →` / 空格逐境游览；底部控制条可开关自动游览、自动朗读、注音、声音、全屏。
- 朗读优先 Edge 神经语音现场朗诵，其次 `audio/00–04.mp3`（00 标题、01–03 各句、04 全诗），最后回退系统语音。
- 第三境的"晴"谐音"情"，是全诗考点：注释与小测均已覆盖（踏 tà、谐音双关、竹枝词民歌体裁）。

## 教学建议
1. 先整体自动游览一遍，再逐境精讲；第二境提问"水面平静，心平不平？"
