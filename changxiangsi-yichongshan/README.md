# 长相思·一重山 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《长相思·一重山》（五代·李煜）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**宣纸留白**赛道——浅色宣纸底、浓墨叠山推远、大量留白，枫叶一点丹红是全页唯一的浓彩。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"万山褪墨，唯枫独染"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：万重墨山尽数褪入宣纸留白，唯余枫叶一点丹红愈染愈明，丹叶纷飞
- 末章：全诗回放、学习小测（5 题）

## 美术方案：宣纸留白（art-direction 赛道③）

| 项 | 取值 |
|---|---|
| 底色 | `#e9e2d0`（宣纸） |
| 强调 | `#4a5060`（墨青——按钮/边框/进度点/题字；伊人衣色同源，**无一处金色**） |
| 文字 | `#23272e`（浓墨） |
| 山 | 浓墨剪影 `#2c2f33` / `#23262b`，三层推远愈远愈淡 |
| 雾 | `#e6dfcc` 暖纸色，fd 0.0045–0.0072 |
| 日/月 | 淡日高悬（ms 0.8–1.05），星几乎不见（0.04–0.06） |
| 粒子母题 | 暖纸色烟霭、寒烟横流、微尘；**枫丹是唯一浓彩**（菊取纸黄淡彩，不与枫争色） |

**有意的设计**：全页只有枫叶一处用丹红（`#a83526` 系，冠后一层丹晕）——上境它立在烟水江渚间，是"相思枫叶丹"；末境点击后万山墨色向宣纸色渐褪，枫丹晕色反而加深、丹叶纷飞，正是"万山褪墨唯枫独染"：山色会淡去，相思褪不掉。

## 教学建议

1. **导入**：让学生数一数画面里有几重山，再读"一重山，两重山"，体会叠句的层叠感。
2. **境①冷与热**：山远、天高、烟水寒，全是冷景——为什么偏偏"枫叶丹"是热的？结合注释讲"以景愈冷衬情愈炽"。
3. **境②对照**：雁尚且按时南来，人为什么未还？菊开又菊残说明等了多久；"一帘风月闲"的"闲"是风月闲还是人心闲？
4. **末境点击**：万山褪墨唯枫独染——讨论"什么会褪色，什么褪不掉"，理解以具象写抽象的词家手法。
5. **收束**：末章全词连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、反衬手法 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
