# 泊秦淮 · 循文入境（唐 · 杜牧）

双击 `index.html` 即可打开（Three.js 走 CDN，首次打开需联网；朗读音频已内置 `audio/`）。
烟雨江南 · 秦淮夜泊变体：烟月迷离的怀古，基调为迷蒙冷峻的忧时。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 烟月双笼 | 烟笼寒水月笼沙 | 烟霭一层、月华一层，双重笼罩寒水与白沙（标志性瞬间） |
| 贰 · 夜泊秦淮 | 夜泊秦淮近酒家 | 泊船靠岸，临河酒家的桨声灯影与水中倒映 |
| 叁 · 隔江犹唱 | 商女不知亡国恨，隔江犹唱后庭花 | 对岸灯影里歌女剪影隐约；**点击画面**：声波涟漪过江、对岸灯影晃动、题字浮现 |

## 操作

- 入境后：`←` `→` 或空格逐境；第三境可点击画面（或空格）听"隔江歌声"
- 自动游览 / 自动朗读默认开启（可作课堂大屏无人值守展示），控制条可一键关
- 朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3（audio/00–04）→ 系统语音兜底

## 教学要点

- 多音字：笼 lǒng（笼罩）、泊 bó（停船靠岸）
- 典故：《后庭花》即《玉树后庭花》，南朝陈后主所作，后世称"亡国之音"
- 主旨：借商女讽喻晚唐统治者沉溺享乐，忧时伤世
- 终章内置 5 道小测（接龙 ×2、读音 ×2、主旨 ×1）

## 备注

- 配音由 `gen-voice.js` 生成（百度 TTS 免密钥；本诗 SUB 表：笼→拢、泊秦淮→搏秦淮，仅影响音频读音，不改页面文字）。如需"诗朗诵"级音色，可设 `TTS_AZURE_KEY` 后重跑
