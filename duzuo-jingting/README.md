# 循文入境 · 独坐敬亭山（唐 · 李白）

单文件沉浸式诗词课件（Three.js r128，CDN 三路回退）。双击 `index.html` 即可使用，首次打开需联网加载三维引擎。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 众鸟高飞 | 众鸟高飞尽 | 八只飞鸟依次高飞远去，天空愈来愈空 |
| 贰 · 孤云独去 | 孤云独去闲 | 一朵孤云缓缓飘离，远处初见敬亭山影 |
| 叁 · 相看不厌 | 相看两不厌，只有敬亭山 | 人山对望；**点击画面**鸟尽云去，山影缓缓"低头"回应凝望，题字"相看两不厌" |

美术：宣纸留白 · 独坐对山变体（浅色宣纸底 `#e9e2d0`、淡墨远岫、墨点微尘，强调色 `#4a4438`）。

## 使用

- `← →`/空格逐境；自动游览/自动朗读默认开，可作课堂大屏无人值守展示
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置配音（00 标题、01–03 各句、04 全诗）→ 系统语音
- 结尾有 5 题学习小测；注音可一键开关

## 教学

- 多音字：尽 jìn、看 kàn、不 bú（变调）、只 zhǐ；注释含"厌=满足"、敬亭山（安徽宣城）等考点
- 情感线：空（鸟尽）→ 闲（云去）→ 静（人山相看），末境环境音随"彻底安静"收束
