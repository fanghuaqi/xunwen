# 遣怀 · 夜宴金彩（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《遣怀》（唐·杜牧）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页走**夜宴金彩**赛道，取「扬州梦华·青衫落拓」变体——不是《将进酒》的殿内豪宴、《过华清宫》的骊山晚照、《海棠》的夜庭一烛，而是**江湖水岸的繁华灯影**：临水歌台、沿岸灯串、泊岸画舫、斜挑酒旗；全页题眼是「大梦初醒的灯影」——人已醒，梦未散：末境近处空案残樽（清醒），远处歌台灯影仍亮（梦境），点击后灯影繁华如潮退去、清辉江月淡入。「青楼」意象按教学对象（中学生）含蓄雅化：只做灯影歌台与背光舞袖剪影，不画具体艳俗场景。accent=#d4a84f（queue 分配强调色，落拓鎏金）只落在歌台灯串/水面灯影/酒旗灯晕/人物边缘光/UI 上。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击扬州梦"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：沿岸灯串与水中灯影**如潮退去**（由远及近次第熄灭）、清辉江月淡入、诗人缓缓转身向月，"十年一觉扬州梦 赢得青楼薄幸名"题字同现——繁华褪尽，只余清醒江月与空案残樽
- 末章：全诗回放、学习小测（5 题）

## 美术方案：夜宴金彩 · 扬州梦华变体（art-direction 赛道①）

| 项 | 取值 |
|---|---|
| 底色 | `#05070d`（夜宴赛道底色） |
| 主色 | `#d4a84f`（落拓鎏金，queue 分配强调色；按钮/边框/进度点/题字/边缘光/灯串） |
| 文字 | `#e8dcc0` |
| 雾 | `#181009` 系暖夜褐金，fd 0.0050–0.0062 |
| 月 | 弦月微暖（卷首/境壹 ms 0.85–0.95）→ **梦醒月明**（境贰 ms 1.35 升高渐盈，mph 0.12 近满）——月随「醒」渐明；星 0.20–0.34 |
| 场景母题 | 临水歌台（台基/前阶/四柱/歇山小顶/矮栏/台口双灯）+ **岸灯一线与水中灯影**（可潮退的灯火系统）+ 画舫 + 酒旗 + 舞袖剪影——贯穿两境 |
| 粒子母题 | 暖金微尘、水面灯影纵斑、梦醒清辉（冷白横带+江面清辉微光）、夜气横流 |
| 与已有夜宴金彩页的区分 | jiangjinjiu=殿内宴席酒器星河、guohuaqinggong=骊山宫门红尘驿马、haitang=夜庭高烛海棠；本页=**水岸歌台灯影+十年梦醒**：近处清醒（空案残樽）与远处梦境（歌台灯影）同框对望，点击后繁华如潮退去 |

**有意的设计**：境壹极写繁华（歌台灯影正盛、舞袖回身、酒旗画舫），境贰同一些灯影却成了「未散的梦」——构图上让空案残樽与坐而独醒的诗人占近景右路，歌台灯影留在左半幅远方；点击「潮退」由远及近次第熄灭，是「十年」被「一觉」收走的空间化——灯灭到哪里，梦就醒到哪里。

## 教学建议

1. **导入**：让学生先找反差——境壹里诗人是「行」、是「听」、是「看舞」，境贰里他为什么坐着一动不动？（醒了。）全诗的情感转折就藏在这个姿势里。
2. **境壹看点**：歌台灯影与舞袖剪影——「楚腰」「掌中轻」两个典故连用写繁华；提醒学生注意「落魄」与繁华同框：越是热闹，越是失意人的热闹（以乐景写哀）。
3. **境贰点击前**：让学生对比——近处案上只剩什么？（倾倒的杯、扣着的碗。）远处还有什么亮着？（歌台灯影。）——人已醒，梦未散，这就是「大梦初醒的灯影」。
4. **境贰点击后**：灯影如潮退去、清辉满江——请学生用诗里的字给这个画面配注（「一觉」「梦」「醒」）；「赢得」的反讽在灯灭的这一刻最好讲：十年「换来」的，竟是「薄幸」之名。
5. **主旨**：自嘲与追悔——表面调侃「赢得薄幸名」，骨子里是怀才不遇、壮志消磨的沉痛；可补杜牧扬州幕僚生涯（淮南节度使幕掌书记）与「扬一益二」的扬州背景，小测第 4、5 题即落此。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示；末境留 3 秒给学生自己点击「潮退」。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 28 字）、释义/注释、境名/意境题句、5 题小测（接龙×2、读音词义×1、典故与杜牧扬州生涯×1、名句主旨×1）、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 交互境序号 `curIdx===2`（pointerdown 与空格双接线，`clicked` 标志 + 1.2s 冷却防连点；空格先交互、再按进终章）。
- fadeK 铁律：所有每帧写 opacity 的对象（岸灯/灯影纵斑/歌台灯晕/画舫灯晕/酒旗/清辉横带）初值=峰值且逐帧乘 fadeK；潮退为衰减包络（≤1）；点击前清辉组 `visible=false` 硬关（无幻影残影）；灯串/灯晕/清辉 `fog:false` 如灯点名；水面/地面/山体着色器走引擎 `fogShaders` 雾同步。
- 预算：三次 build 的 drawCall 代理 ≈ 36/45/50、三角面 ≈ 2.1/2.2/2.3 万（≤120 / ≤12 万）。
- 校验：`node _pipeline/tools/validate.js qianhuai/index.html` → **✓ 校验全部通过**；`node qianhuai/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 逐境 build/update×400 帧 → fadeK 合规 → 末境点击门控 → 自动游览至终章 → 小测满分）；`node _pipeline/accept.js qianhuai` → **ACCEPT（2境 · 夜宴金彩）**。
- 实拍：`shots.py` 封面/两境逐张人工检查通过；标志性瞬间（境贰空案+远处灯影）与末境交互（点击→灯影潮退→清辉满江）以 CDP 点击探针实拍确认可见——据实拍迭代修掉「诗人巨影居中遮挡歌台与空案」「画舫竹篷成浮木」等穿帮后，临时截图与探针脚本已删除。
- 文本口径：诗文逐字为「落魄江湖载酒行，楚腰纤细掌中轻。十年一觉扬州梦，赢得青楼薄幸名。」与 queue.json 一致（「扬州梦」从通行本，语料讹作「扬中梦」）。
