# 山园小梅 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《山园小梅》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**水墨夜思**赛道，取「孤山梅影」变体——月色下的小园矮墙、满园摇落的枯枝、临水横斜的一枝老梅，以及清浅水面上那道**疏影**与浮动不定的**暗香**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境肆为"点击暗香"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境肆轻点画面：水中疏影横斜摇动、暗香成雾漫开，"暗香浮动"题字同现
- 末章：全诗回放、学习小测（5 题）

**标志性瞬间**：境贰与境肆的「疏影暗香」——清浅水面上一道横斜梅影 + 银白香雾浮动；末境点击暗香，影随水摇、香雾成片漫开。

## 教学建议

1. **导入**：封面设问"怎样的两句话，能让人记住一千年？"再入境壹，先看枯枝与梅的对照。
2. **境壹析"独"**：九株枯枝对两株梅——"众芳摇落"是背景，"独暄妍"是主角；这个"独"字，也是诗人自己的样子。
3. **境贰析诗眼**：上句写「形」（影、水、横斜），下句写「神」（香、月、浮动）；让学生闭眼想一遍，再说说"横斜"为什么比"挺拔"更像梅。
4. **境叁析侧笔**：霜禽为何"先偷眼"？粉蝶"如知"是实有还是想象？——一实一虚都是从旁写梅之清绝。
5. **点击体会**：点击暗香看影摇香漫，讨论"不须檀板共金樽"：诗人为什么不要热闹？（以诗为伴，正是隐者与梅的清约。）
6. **知人论世**：林逋隐居杭州孤山二十年，不仕不娶，种梅养鹤，"梅妻鹤子"；姜夔取此二句语意另立《暗香》《疏影》两词牌。
7. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音义 ×1、典故 ×1、主旨 ×1）。
8. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（4 境约 70 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 肆境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===4`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（梅枝、浅水、霜禽、诗人）都在 10–20 单位内，fd ≤ 0.0072；水中疏影唯一一处「每帧写 opacity」已乘 fadeK 且基座 = 运行期最大值 0.42；水面/远山等着色器登记 `fogShaders`，穹顶/星/月 `fog:false`。
- 场景构件（冒烟实测）：卷首 15 mesh、境壹 18 mesh、境贰 17 mesh / 19 sprite、境叁 15 mesh、境肆 21 mesh / 21 sprite；draw call 代理值 24 / 34 / 37 / 32 / 43（≤120），三角面 ≈0.7–1.4 万（≤12 万）。
