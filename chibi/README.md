# 循文入境 · 《赤壁》（唐 · 杜牧）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js r128 走 CDN，首次打开需联网；音频已本地化）。

## 三境导览

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 折戟沉沙 | 折戟沉沙铁未销， | 暮色江岸，半埋沙中的一支断戟特写，流沙低回 |
| 贰 · 磨洗认朝 | 自将磨洗认前朝。 | 石上磨洗：磨石往复、星火微溅，「赤壁」铭文随磨洗渐显 |
| 叁 · 东风二乔 | 东风不与周郎便，铜雀春深锁二乔。 | 标志瞬间·假设的分岔：左为东风火场（暖红战船连营），右为铜雀台深锁二乔（冷青剪影），断戟居中 |

**互动（第三境）**：点击画面或按空格 —— 沙退戟现、「赤壁」铭文闪耀、东风骤起（火场爆亮、热风横流）、题字「铜雀春深锁二乔」。

## 使用

- `← →` / 空格逐境游览；空格在第三境触发互动，其余境为下一境
- 控制条可切换：自动游览、自动朗读、注音、声音、全屏
- 朗读优先级：Edge 神经语音现场朗诵 → 本地 `audio/*.mp3` → 系统语音
- `audio/` 共 5 个 MP3（00 标题 · 01–03 各句 · 04 全诗），由 gen-voice.js 生成

## 教学建议

1. 先整体自动游览一遍（开自动游览+自动朗读），让学生"走进"诗境；
2. 第二境展开「注释」，讲"将（jiāng，拿取）""前朝"；
3. 第三境点击互动前先提问：东风若不来会怎样？再演示"分岔"画面，点出**以小见大**——借二乔命运写东吴存亡；
4. 小测 5 题含接龙、词义（将）、典故（周郎）、主旨（以小见大），适合随堂检测。

多音字自查：销 xiāo、戟 jǐ、郎 láng、将（拿取义）jiāng、朝（前朝）cháo，均按教材读音。
