# 循文入境 · 渔家傲·秋思（宋 · 范仲淹）

单文件沉浸式诗词课件：三境随词句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 大漠金戈·边塞变体：宋代边塞词的开山之作——千嶂落日的苍凉，燕然未勒的沉郁，将军白发的深沉。
> 标志性瞬间：千嶂里长烟落日孤城闭——重山叠嶂、烽烟直上、孤城闭门。

## 教学建议

- 词风开拓：范仲淹变婉约柔媚为苍凉雄阔，是苏辛豪放派词风的先声
- 「长烟落日孤城闭」的构图：对比王维「大漠孤烟直，长河落日圆」，体会宋词的凝重与边塞的压迫感
- 情感的双重性：「浊酒一杯家万里」写思乡之深，「燕然未勒归无计」写报国之切——二者交织方见英雄泪
- 注音考点：塞下 sài、衡阳 héng yáng、千嶂 zhàng、浊酒 zhuó、燕然 yān rán、勒石 lè、羌管 qiāng、不寐 mèi、征夫 zhēng fū
- 背景：康定元年（1040年）范仲淹任陕西经略安抚副使兼知延州，抵御西夏侵扰，作于西北前线
