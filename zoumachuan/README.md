# 走马川行奉送封大夫出师西征 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《走马川行奉送封大夫出师西征》（唐·岑参，queue no.264）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**大漠金戈**赛道——但刻意避开既有边塞页的构图（不做雪原牧马听笛、不做拂晓誓师整甲、不做密林夜射、不做金甲烽燧孤城、不做木兰人生长卷、不做牙帐对切），写的是**狂风卷石的走马川夜行军**：风是全页的主角——横扫的沙尘流、满地乱滚的大如斗碎石、被吹得横卷的旌旗、迎风的火把长龙、马毛上蒸腾又凝冰的汗气。四境时间线：风夜吼（壹）→ 夜行军（贰）→ 奇寒中夜（叁）→ 破晓献捷（肆）。accent=#c9a06a（沙金，queue 分配强调色）只落在 UI/人物边缘光/火把光/旗面光边/碎石风暴幻影/献捷曙色上，禁艳金。

**有意的设计**：壹境低机位沿干河床看风——「一川碎石大如斗，随风满地石乱走」不用人讲，让石头自己"走"给你看：约四成走石沿风向翻滚弹跳、出界回绕，其余静石震颤摇撼；黄尘平沙黄入天，雪海远带在侧。全诗不写一场厮杀：叁境把「寒」写满（汗气蒸与砚水凝同框对置），肆境点击让风暴与疾进的长龙替大军"宣胜"——以未战写必胜，送行诗写出了凯旋曲的调子。

## 教学建议

1. **导入**：先只读「轮台九月风夜吼，一川碎石大如斗，随风满地石乱走」——风看不见，诗人怎么让你"看见"风？让学生带着问题进境壹，看石头替风表演。
2. **梳理夸张链**：黄入天→石乱走→风如刀→汗成冰→砚水凝，找出这一串夸张的递进方向（由天及地、由人及物、由帐外及帐内），体会岑参「奇」在何处——处处奇景，处处实景。
3. **侧面烘托**：全诗没有一句正面写战斗，却让人相信唐军必胜——「虏骑闻之应胆慑，料知短兵不敢接」是怎么做到的？讨论"以未战写必胜"的写法（对照《燕歌行》的正面苦战，同读更见味道）。
4. **朗读处理**：「君不见」长叹起势；「风夜吼」「石乱走」读出风声滚滚；「金甲夜不脱」读得斩截；「伫献捷」读出扬眉期待。
5. **主旨收束**：送行诗写成凯旋曲——豪迈从哪里来？结合「奇丽壮阔的边塞风物+金甲夜不脱的军威+必胜信心」三点收束；顺带记：岑参与高适并称「高岑」，走马川、雪海、轮台、车师皆西域地名。
