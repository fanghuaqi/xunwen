# 乌衣巷 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《乌衣巷》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页走**烟雨江南**赛道的**金陵怀古变体**——夜灰底、褪朱主色、全程无月，灰蓝里只留两处暖：巷口那抹斜阳，和百姓家的一窗灯火；一只燕子从王谢废宅飞入寻常檐下，就是全诗的兴亡。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境叁为"燕归百姓家"触发；末境再按进入终章）
- 控制条：自动游览、自动朗读（默认均开）、注音开关、声音开关、全屏
- 境叁轻点画面（或空格）：三声拨弦，燕子沿弧线自废宅飞入百姓檐下，落檐瞬间尘光轻扬、钟声响起、"飞入寻常百姓家"题字浮现（3.4 秒防连点）
- 末章：全诗回放、学习小测（5 题）

## 美术方案：烟雨江南（art-direction 赛道⑥）

| 项 | 取值 |
|---|---|
| 底色 | `#10141a`（金陵暮夜，与赛道典型一致） |
| 主色 | `#b8a090`（褪朱灰陶：按钮/边框/进度点/题字；非典型黛蓝，取"朱雀"褪色之后的调子） |
| 文字 | `#e6ecef`（与赛道典型一致），次要文字 `#8b98a5` |
| 雾 | `#141b24`，fd 0.013–0.018（正落赛道典型 0.012–0.02 区间） |
| 月 | **无月**：ms 0.001、月体移出视野（y=-400），按赛道"月隐"做法处理 |
| 星 | 极稀（star 0.04–0.14） |
| 暖色 | 境贰巷口斜阳（halo `#c26a30` + 日核 `#ffcf8a`）、境叁百姓家窗光（`#e8b26a`）——全页仅有的两处暖，一古一今遥遥相对 |
| 粒子母题 | 暮霭（`#8fa3b8`）、光柱浮尘（`#d9a878`）、横流雾带（`#8a93a0`）、落檐尘光（`#d9c0a0`） |

**变体说明**：主色放弃黛蓝改用褪朱灰陶，星与光全面压暗——怀古的金陵不该明艳；无月与低星也是赛道变体（烟雨江南原只要求"月隐"）。**有意的设计**：境贰巷口斜阳是全页第一处暖色，境叁百姓家窗光是第二处——昔日繁华只配一点残照，今日人间倒有一窗灯火，对比即是诗旨。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题（"乌衣巷。唐，刘禹锡。朱雀桥边野草花，乌衣巷口夕阳斜。"）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全诗连读

页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。无 tts.json 多音字副本，按页面注音提示易错点："朱**雀**桥"读 què（小测已点名）；"夕阳**斜**"页面注音 xié（今音；旧读 xiá 之说可作课堂延伸，朗读以页面注音为准）。如需"诗朗诵"级音色，可设 `TTS_AZURE_KEY` 后重跑配音脚本。

## 教学建议

1. **导入**：先讲地名——朱雀桥、乌衣巷都在金陵秦淮河边，"乌衣"得名自三国吴军乌衣营；再入境壹看"名桥+野草"的反差。
2. **境壹炼字**：让学生想象当年朱雀桥的车马喧阗，对照画面野草自摇，理解"野草花"三个字写尽冷落。
3. **境贰光影**：看狭巷尽头的斜阳读"夕阳斜"，讨论一个"斜"字压出的日暮、衰败双重意味。
4. **境叁点题**：点击让燕子飞入百姓家后再读后两句——燕子仍认旧堂前，人事已全非；讲"王谢"（王导、谢安）与"寻常百姓"的对照，这就是"以小见大"写兴亡。
5. **怀古组诗**：可与《泊秦淮》《石头城》并置，感受刘禹锡金陵怀古的深沉笔法。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音 ×1、文学常识 ×1、主旨 ×1）；课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 28 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 三境，POEM 第三条含两句），境名逐一对齐。
- 交互境序号 `curIdx===3`（燕归百姓）；进度点/按键/自动游览末境判断均以 `POEM.length=3` 对齐。
- 校验：`node _pipeline/tools/validate.js wuyixiang/index.html` → **✓ 校验全部通过**。
