# 夜宿山寺 · 循文入境（唐 · 李白）

「危楼高百尺，手可摘星辰。不敢高声语，恐惊天上人。」——水墨夜思 · 危楼摘星变体，银蓝星海、云海塔影，仙气飘飘的想象。

## 三重意境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 危楼入云 | 危楼高百尺 | 山寺七层危楼直插星空，云海横过楼腰（仰视） |
| 贰 · 手可摘星 | 手可摘星辰 | 登塔顶层，众星辰低垂环绕、触手可及 |
| 叁 · 恐惊天人 | 不敢高声语，恐惊天上人 | 屏息之静，星海间仙影飘过；**点击画面摘一颗星**（星落掌中发光 + 满屏屏息 + 题字） |

## 使用

- 双击 `index.html`（首次需联网加载 Three.js r128，音频在本地 `audio/`）。
- `←` `→` 或空格逐境；第三境轻点画面或按空格即可摘星；支持自动游览/自动朗读，可作课堂大屏无人值守展示。
- 朗读优先级：Edge 神经语音现场逐句朗诵 → 内置 MP3（`audio/00–04.mp3`）→ 系统语音。

## 教学要点

- 考点：「危」= 高（非危险）；「百尺」虚指极言其高；「语 yǔ」说话（不读 yù）；夸张与想象（楼高≈星近）。
- 多音字：宿 sù、辰 chén、恐 kǒng。
- 终章含 5 道小测（接龙 ×2、词义 ×1、读音 ×1、主旨 ×1）。
