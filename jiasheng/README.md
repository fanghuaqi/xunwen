# 贾生 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《贾生》（唐·李商隐，咏史绝句）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**水墨夜思**赛道——但刻意避开既有水墨夜思页的构图（不做满月江楼水天一色、不做古寺竹径、不做雨前危城、不做渡口斜月渔火），写的是这场**汉宫宣室里的烛光夜谈**：境壹=殷（宣室求贤访逐臣——殿柱帷幔帝座、君臣对坐烛光），境贰=讽（不问苍生问鬼神——前席愈切、所问愈错）。accent=#9ab8d8（月银青蓝，queue 分配强调色）只落在冷月/殿外夜色/鬼神异光/人物边缘光/UI 上，全页近零饱和；殿内铜烛台是全页唯一暖色——**暖（殿内殷勤）与冷（殿外苍生）的对切，就是这首诗的画面结构**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

**有意的设计**：境壹从殿内斜望——帝座帷幔在左上、君臣对坐烛光在中、东廊外冷月宫墙在右，一眼同时看到「殷勤」与「殿外的天下」；境贰夜半烛短、镜头更低更近，点击后文帝**连席前移**（前席=移动坐席凑近对方，古人倾心请教的动作）——他越凑越近，问的却是鬼神；此刻殿外苍生剪影淡现又散、殿内冷异光沉落——前席之勤与所问之误并置，托古讽时不着一字。

## 教学建议

1. **导入**：先讲一个场景——领导深夜召见你，越谈越凑近、听得入神——结果问的全是你最不希望被问的东西。贾谊就遇上了这样一夜。汉文帝在宣室召见被放逐多年的他，谈到夜半、不觉前席——然后问出了「鬼神」。
2. **境①诗眼**：「才调更无伦」——文帝把贾谊抬到诸贤之上，「求贤」「访逐臣」写得堂皇郑重；让学生记住这份「高」，下一境才有「摔」。欲抑先扬，是咏史反讽的起手式。
3. **境②点击后**：看文帝连席前移的动作——何等恳切；再看题字——「不问苍生问鬼神」——何等错位。「虚」字是诗眼：前席之勤全是徒然。可让学生找一找画面里「谁被冷落了」（殿外淡现又散的苍生剪影）。
4. **写法**：托古讽时——借汉文帝这件「明君求贤」的美谈翻案，讽的是晚唐帝王崇道佞佛、不问国计民生；为贾生哭，也为天下才士哭，更为苍生哭。可对照同题材：刘长卿《长沙过贾谊宅》、苏轼《贾谊论》。
5. **背景**：贾谊，西汉洛阳人，十八岁以能诵诗书属文闻名，政论名家（《过秦论》《治安策》）；因锋芒太露遭大臣构陷，外放长沙王太傅多年后被召回，文帝宣室夜召问鬼神事——李商隐只取这一夜，二十八字写成咏史绝句的顶点。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音 ×1——贾 jiǎ／调 diào、文学常识 ×1——贾谊宣室召对与咏史诗、讽刺手法 ×1——「不问苍生问鬼神」的对比反讽）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
