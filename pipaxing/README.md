# 循文入境 · 琵琶行（节选）（唐 · 白居易）

单文件沉浸式诗词课件：八境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 节选说明：白居易原题《琵琶引》，全篇六百一十六言；本页取"浔阳送客→琵琶女→四段音乐→同是天涯沦落人→青衫湿"主线，
> 是教材最常讲的部分。

## 八境（音乐的四种视觉语言是本页主线）

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 浔阳送别 | 浔阳江头夜送客……别时茫茫江浸月 | 枫叶荻花的秋江夜，客船无管弦，月影浸在江心 |
| 贰 · 忽闻琵琶 | 忽闻水上琵琶声……琵琶声停欲语迟 | 水上飘来琵琶声，主客俱忘归 |
| 叁 · 半遮面 | 移船相近邀相见……犹抱琵琶半遮面 | 千呼万唤，琵琶女抱琵琶侧身半遮 |
| 肆 · 转轴拨弦 | 转轴拨弦三两声……初为霓裳后六幺 | 定弦试音，未成曲调先有情（人物特写） |
| 伍 · 大珠小珠 | 大弦嘈嘈如急雨……大珠小珠落玉盘 | 标志性瞬间：四弦迸出成串珠玉，滚落玉盘 |
| 陆 · 此时无声 | 间关莺语……此时无声胜有声 | **全诗顶点**：泉流冻结、万籁俱寂，最空的一境 |
| 柒 · 银瓶乍破 | 银瓶乍破水浆迸……唯见江心秋月白 | 骤然爆裂再收拨裂帛，归于无声，只剩江月 |
| 捌 · 青衫湿 | 同是天涯沦落人……江州司马青衫湿 | **点击画面**：满座寂然，司马青衫被泪浸湿（空格先触发交互、再按进终章） |

## 操作

- `← →` / 空格：切境（交互境空格 = 触发交互）；自动游览、自动朗读默认可开
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置 MP3 → 系统语音
- `audio/00–09.mp3`：题名、八境、全篇（Edge 神经语音·晓晓；`tts.json` 里 5 条多音字替换只影响读音）

## 教学建议

- **音乐描写的博喻链**：急雨→私语→珠落玉盘→莺语→泉流→凝绝→银瓶乍破→裂帛，让学生按境对照画面读出每一步的比喻
- "此时无声胜有声"（第陆境）：以最空的一境讲"留白"，是全诗的顶点
- "同是天涯沦落人"：白居易贬江州司马的背景；"座中泣下谁最多"的自问
- 注音考点：荻 dí、幽咽 yè、铁骑 jì、霓裳 cháng、轻拢慢捻抹复挑（lǒng niǎn mǒ tiǎo）、裂帛 bó
- 异文说明：语料库所收古本作"秋索索""水下滩""银缾""东船西舫"等，本页一律从现行教材本
