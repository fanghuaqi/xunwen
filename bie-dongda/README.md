# 循文入境 · 别董大（唐 · 高适）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，音频本地）。

## 三重意境（大漠金戈 · 黄云雪原变体）

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 黄云曛日 | 千里黄云白日曛。 | 千里黄云横流压境，昏曛之日悬于雪原尽头，台地剪影吃雾 |
| 贰 · 风雪吹雁 | 北风吹雁雪纷纷。 | 朔风卷雪（风雪斜落+横流雾），V 字雁阵顶风南去，驿亭酒旗 |
| 叁 · 莫愁知音 | 莫愁前路无知己，天下谁人不识君。 | 标志瞬间：高适与负琴董大雪中拱手作别，董大转身携琴迎风雪远行，雁阵掠空 |

**互动**：第三境点击画面 / 按空格 —— 董大踏雪远行，风雪更急、雁阵高飞，题字「天下谁人不识君」昂扬浮现（15 秒无操作也会自动启程，保证自动游览走完整幕）。

## 操作

- `← →` / 空格逐境游览；`自动游览`可无人值守大屏展示；进入新境自动朗读。
- 朗读优先级：Edge 神经语音现场朗诵 → 本地 `audio/*.mp3`（00 标题、01-03 各句、04 全诗）→ 系统语音。
- 底部按钮：朗读 / 自动朗读 / 注音开关 / 声音 / 全屏；终章含全诗回顾与 5 题学习小测。

## 教学建议

1. 逐境先看画面猜诗句，再对照竖排注音诵读（多音字已按教材标注：曛 xūn、雁 yàn、识 shí、谁 shuí）。
2. 情感线：前两境苍茫压抑（黄云、风雪），末境陡转昂扬——讨论"以豪语写别情"的送别诗写法。
3. 小测覆盖接龙、读音（曛）、词义（莫愁）、典故人物（董大=琴师董庭兰）、名句主旨。
