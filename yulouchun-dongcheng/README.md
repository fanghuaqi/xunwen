# 玉楼春·东城渐觉风光好 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《玉楼春·东城渐觉风光好》（宋·宋祁）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**青绿春晓**赛道的春日行乐变体——全套青绿生机色板，红杏红（#c96a6a）是全页唯一的暖彩点（禁金），「红杏枝头春意闹」是只属于这首词的画面。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"点击红杏"，交互后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：点击红杏——枝头群蜂喧动、声浪环层层荡开、红瓣迸发、"春意闹"题字同现
- 末章：全词回放、学习小测（5 题）

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-XiaoxiaoNeural，语速 -14% 生成）：

- `00.mp3` 题名（自动提取："玉楼春·东城渐觉风光好"）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字以页面注音为准，`tts.json` 钉写 5 条同音同调替换（仅影响读音）：縠（hú）、棹（zhào）、觉（jué，"渐觉"）、长（cháng，"长恨"）、为（wèi，"为君"）。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：从"春天好在哪、怎么把'好'写闹起来"引入，再对照上片看波纹、绿杨、红杏如何层层铺好。
2. **境①炼字**：结合画面讲"縠皱"（绉纱般细波）与"闹"（蜂喧蝶舞、静景有声）——王国维评"著一'闹'字而境界全出"；宋祁因此得名"红杏尚书"。
3. **境②情理**："浮生长恨欢娱少"与"且向花间留晚照"对读：留不住斜阳，就留住花间一晌——惜时行乐背后的珍惜与无奈。
4. **主旨**：点击红杏看"春意闹"——闹是春的生命力；再讨论"劝斜阳"的拟人：人与春光平辈论交。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故炼字 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
