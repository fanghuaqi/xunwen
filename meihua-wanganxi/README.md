# 梅花 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《梅花》（宋·王安石）「循文入境」教学网页：诗句推进到哪一句，三维实景就走进哪一重意境。本页取**宣纸留白**方向——全套浅色宣纸色板，墨色取代金银，一枝胭脂寒梅是全页唯一的浓彩，雪瓣与香雾在留白处浮动。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN，多源自动回退；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在末境②为"唤暗香来"）
- 控制条：自动游览、朗读此句、自动朗读、注音、声音、全屏
- 进度点：点击圆点可直接跳境
- 末境②轻点画面：枝头梅花渐次点亮为胭脂色，一缕香雾自枝飘向观者，古琴拨弦、"为有暗香来"题字闪现
- 末章：聆听全诗、学习小测（5 题）、再游一次、回卷首

## 美术方案：宣纸留白（art-direction 赛道③）

| 项 | 取值 |
|---|---|
| 底色 | `#e9e2d0`（宣纸，body、#err、封面/终章渐变同系浅色） |
| 主墨 | `#3a3f4a`（--gold 变量改墨色；按钮/边框/进度点/题字，**无一处金色**） |
| 文字 | `#2a2e35` 深墨，次要 `#857c68`；边线 `rgba(58,63,74,.28)`；面板 `rgba(255,252,240,.72)` |
| 天穹 | top `#ece6d3` / hor `#dfd7bd` / bot `#d2c8a9`（逐境在宣纸基调上微调） |
| 雾 | `#e6dfcc`，fd 0.0035–0.0058 |
| 月 | 无（ms 0.001 藏月，浅色昼景不需要） |
| 星 | 近无（star 0.03–0.04） |
| 粒子母题 | 淡雪与花瓣同飘（makeDrift，花瓣占 0.42–0.5）、宣纸雾（paperMist）、香雾一缕（makeIncense） |

**有意的设计**：全页黑白灰宣纸调里，枝头梅花是唯一浓彩（胭脂红 `#8a312a`/`#8f342c`）；末境点击后花瓣再被点亮为更亮的 `#c44a3a` 并升起 `#e0958a` 暖点光——"暗香"本不可见，用全页唯一一次暖色爆发把"香"演给学生看。文字阴影全部改为 `0 1px 0 rgba(255,255,255,…)` 白边，符合浅色主题规范。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题与作者（"梅花。宋，王安石。"）
- `01–02.mp3` 两境逐境朗读（每境两句）
- `03.mp3` 全诗连读

页面朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音兜底。本诗多音字是教学重点，页面逐字注音已标定：**凌 líng**（冒着）、**为 wèi**（因为）、"不是"的**不读 bú**；无特殊多音字副本，小测第 2、3 题即针对这两个读音设题。如需更高级音色，可用 `_pipeline/tools/gen-voice-edge.py` 重生成。

## 教学建议

1. **导入**：封面先看"画外一枝"，设问"为什么远远就知道那不是雪？"再入境①。
2. **境①炼字**：对照画面读"凌寒独自开"，讲"凌"（líng，冒着）与"独自"——位置偏、天气冷、无人赏，偏要开。
3. **境②说理**：雪瓣花瓣同飘难辨，正是"遥知不是雪"的处境；点击点亮后讨论"诗人靠什么分辨？"——暗香，以嗅觉写梅。
4. **品格迁移**：结合王安石变法背景，谈梅花孤高坚贞是诗人自况。
5. **收束**：末章全诗连读，再做 5 题小测（接句 ×1、读音词义 ×2、内容理解 ×1、品格主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境，每境含两句），境名逐一对齐。
- 点击交互境序号 `curIdx===2`（末境）；进度点/按键/自动游览末境判断均以该长度对齐。
- 校验：`node _pipeline/tools/validate.js meihua-wanganxi/index.html` → **✓ 校验全部通过**。
- 目录内附 `smoke.js`：以 THREE 桩在 Node 中全链路冒烟（build/update/click、过场、终章/小测）。
