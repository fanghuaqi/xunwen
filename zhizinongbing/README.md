# 循文入境 · 稚子弄冰（宋 · 杨万里）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，首次打开需联网；朗读音频在本地 `audio/`）。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 晓盆脱冰 | 稚子金盆脱晓冰，彩丝穿取当银钲。 | 晨光金盆，透亮冰块自盆中缓缓脱出，冰晶微尘浮动 |
| 贰 · 玉磬穿林 | 敲成玉磬穿林响， | 彩丝提钲穿行墨松晨林，敲声化作一圈圈声波涟漪穿林荡开 |
| 叁 · 玻璃碎地 | 忽作玻璃碎地声。 | **标志性瞬间 · 交互境**：点击/空格敲冰钲，三响之后冰钲脱手落地——冰屑四溅、碎裂声起、题字"忽作玻璃碎地声"，随后新冰钲重新凝成，可反复敲 |

美术赛道：宣纸留白 · 冰钲脆响变体（浅色宣纸底 + 冷墨蓝强调 #4a5a60 + 霜晨淡日 + 墨松剪影）；全诗以"声音"为主角，WebAudio 合成清脆敲击与碎裂音效。

## 使用

- `← →` / 空格逐境游览；第三境点击画面或按空格敲冰钲。
- 控制条可开关：自动游览、自动朗读、注音、声音、全屏。
- 朗读优先级：Edge 神经语音现场朗诵 → 本地 MP3 → 系统语音。

## 配音

`audio/00–04.mp3`（00 标题、01–03 各境、04 全诗），由百度 TTS 生成。网络朗读兜底时"钲/磬"等生僻字以 Edge 神经语音读音最准；如需更高级音色可配置 Azure 密钥重跑技能的 gen-voice.js。

## 教学建议

- 先关自动游览，让学生看画面猜诗句，再逐境对照竖排注音朗读。
- 多音字考点：钲 zhēng、磬 qìng、"当银钲"之当 dàng、"玻璃"古义为天然美玉。
- 小测 5 题覆盖接龙、读音、词义与主旨，适合课堂结尾齐答。
