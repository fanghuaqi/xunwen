# 大林寺桃花 · 循文入境

白居易《大林寺桃花》沉浸式单文件课件（Three.js r128，青绿春晓 · 登山寻春变体：春随海拔而上，山脚花尽 / 山寺桃盛）。

## 使用

- 双击 `index.html` 即可（首次打开需联网加载三维引擎；朗读音频在本机 `audio/`）。
- `←`/`→` 或空格逐境游览；**第三境点击画面（或按空格）拾级登山**，看桃花随海拔次第盛放，登顶题字"山寺桃花始盛开"。
- 顶部圆点可跳境；开启"自动游览 + 自动朗读"可作课堂大屏无人值守展示。

## 结构

- 三境：① 人间芳菲（山脚四月花尽、落英满地）→ ② 山寺桃开（古寺桃花始盛、花瓣纷落）→ ③ 转入此中（盘旋石阶登山 · 互动境）。
- `audio/`：00 标题、01–03 各句、04 全诗（AI 生成；缺文件或断网时自动回退浏览器语音）。

## 教学建议

1. 先自动游览一遍整体感知，再逐境精读、想象画面。
2. 关注注音：芳菲 **fāng fēi**、觅 **mì**、长恨 cháng；讨论"始"字写出山高地寒、春色来迟的惊喜。
3. 结课用"学习小测"巩固名句接龙与主旨（春光未被带走，只是换了地方）。
