# 生查子·元夕 · 夜宴金彩（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《生查子·元夕》（宋·欧阳修）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**夜宴金彩·元夕灯市**变体——同一条灯市长街、同一轮柳梢月，去年与今年同机位对照：暖金满灯的人约黄昏，与灯依旧而人不在的物是人非。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"灯海渐暗"，再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：灯海渐暗只余月光——窗光、灯串、灯海、近灯逐次熄暗，唯月池清辉涨满，钟声与"不见去年人"题字同现
- 末章：全诗回放、学习小测（5 题）

| 月 | 暖白满月（ms 1.15）固定在柳梢上方——去年今年**同位同轮** |
| 星 | 元夕灯盛星隐（0.28–0.34） |
| 粒子母题 | 灯海两层（街尾人家灯火一路远去）、灯市暖尘、映天灯晕、街雾（替代参考实现的金色流萤/火星） |

**有意的设计：同机位今昔对照**。境①与境②共用同一 `makeStreetBase`（seed 固定：石板路、两侧楼影檐廊、跨街四道灯串、宫灯与走马灯、柳树、三片人海逐物同位），相机两境完全同位；只有三处不同——人（柳下一对 ↔ 独行的春衫客）、色温（warmth 1.0 ↔ 0.86，暖意减一分）、天际晕（0.30 ↔ 0.26）。学生看到的「月与灯依旧」，是字面上的一帧不换；「不见去年人」，是同一画面里少了两个人。金彩只属灯焰：宫灯内焰、走马灯自转的奔马剪影、灯串灯体的自发光。

## 教学建议

1. **导入**：问学生"古人没有电灯，元宵夜的长街会是什么样？"再入境①对照"灯如昼"。
2. **境①节俗**：结合注释讲元夕解除宵禁——青年男女唯此夜可名正言顺灯下相会；柳梢月上正是"黄昏后"的时刻表。
3. **境②对照**：先别点画面，让学生找"去年那两个人还在吗"；再点击灯海渐暗，体会"灯灭了还有月光，人不在就真的不在"。
4. **炼字**："月与灯依旧"的"依旧"越安稳，"不见去年人"越锥心——物是人非全在工整的今昔对照里。
5. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、元夕节俗 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
