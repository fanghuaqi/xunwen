# 塞上听吹笛 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《塞上听吹笛》（唐·高适）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**大漠金戈**赛道——但刻意避开孤城/金甲/烽燧/密林夜射/战场残垣的既有边塞构图，写的是这场闻笛的**两重「听」**：境壹=远望（雪净月明、牧马成群归来、戍楼一点灯火），境贰=近听（戍楼吹笛人、关山两重，点击后笛声化作漫天梅花）。accent=#c49a5a（沙金月色）只落在月色雪光/戍楼灯火/人物边缘光/笛纹音波/梅花上，禁艳金。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"笛声起"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏

- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：先解题——「听吹笛」三个字告诉我们，这首诗的全部奇妙都从一只耳朵开始：先让你看静夜，再让你听笛声。
2. **境①诗眼**：「净」与「还」——雪净天清是明净的底色，「牧马还」三个字透出战事稍歇的安宁（战马征用、牧地荒废是战时景象）；问学生：这样的夜晚，边塞诗里常见吗？
3. **境②点击后**：看笛声如何"被看见"——音波环是笛声，漫天梅花是曲名《梅花落》的"落地"。讲清一语双关：曲名被诗人拆开来问「梅花何处落」，笛曲就真的开满了关山。
4. **写法**：化虚为实（通感）——无形的笛声随风吹遍关山，化作看得见的春色；对照王之涣「羌笛何须怨杨柳」：同是羌笛，一个"怨"、一个"落花"，边塞诗的笛声可以不哀。
5. **背景**：高适，唐代著名边塞诗人，与岑参并称「高岑」；《梅花落》是汉乐府横吹曲名（军中笛曲），唐代诗人常借它写闻笛思乡。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1——羌 qiāng/牧 mù、典故文学常识 ×1——〈梅花落〉+高适、名句主旨 ×1——化虚为实）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 20 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 交互境序号 `curIdx===2`（pointerdown 与空格双接线，`clicked` 标志 + 1.2s 冷却防连点；空格先交互、再按进终章）。
- fadeK 铁律：所有每帧写 opacity/intensity 的对象（戍楼灯辉/灯窗点光、笛纹音波环、梅花 uMaxA、夜风 uMaxA）初值=最大且逐帧乘 fadeK；梅花/雪尘自写 ShaderMaterial 显式带 `uFade`；山脊/地面自定义着色器推入 `fogShaders` 做雾同步。
- 预算：三境 drawCall 代理 ≈ 21/26/33、三角面 ≈ 0.35/0.71/0.88 万（≤120 / ≤12 万）。
