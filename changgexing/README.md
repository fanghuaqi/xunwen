# 循文入境 · 长歌行（节选）· 汉乐府

单文件沉浸式诗词课件：Three.js 三维诗境 + 逐字注音 + 释义注释 + AI 朗读 + 自动游览 + 结课小测。

## 使用

- 双击 `index.html` 即可打开（首次需联网加载 Three.js；音频为本地 MP3）。
- 「入境」后：← → 键或空格逐境游览；第四境可**点击画面 / 按空格**触发"四季流转·川流东去"。
- 控制条可开关：自动游览、自动朗读、注音、声音、全屏。打开「自动游览 + 自动朗读」可作课堂大屏无人值守展示。
- 朗读优先级：Edge 神经语音现场朗诵 → 本地 `audio/*.mp3` → 系统语音。

## 四境

1. **园葵朝露** —— 青青园中葵，朝露待日晞。阳春布德泽，万物生光辉。（露珠滚动闪光，天光渐盛）
2. **焜黄秋至** —— 常恐秋节至，焜黄华叶衰。（同一座园子入秋，叶落风起）
3. **百川东去** —— 百川东到海，何时复西归？（贴水面随百川奔海）
4. **惜时劝勉** —— 少壮不努力，老大徒伤悲。（标志瞬间：镜头升起俯瞰百川归海 × 园葵四季速写叠影；点击四季流转并题字）

## 教学建议

- 先整体自动游览一遍，再逐境精读；第二境提问"为什么'常恐'"引出时光之忧。
- 第三境看"百川东到海"问：水能回来吗？由此过渡到时间比喻。
- 第四境点击互动后再看小测，检验名句理解与主旨（惜时奋进）。
