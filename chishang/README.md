# 循文入境 · 池上（唐 · 白居易）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，音频本地）。
「小娃撑小艇，偷采白莲回。不解藏踪迹，浮萍一道开。」——青绿荷塘、童趣变体赛道，
两重意境随诗句推进：①**偷采白莲**（近景：小娃怀抱白莲撑艇悄回）②**浮萍一道**
（标志性瞬间：满塘浮萍被小艇分开一道水路，行迹全暴露）。

## 使用

- **入境**：封面点「入境」；`← →` 键或空格逐境游览，底部按钮可控制朗读/注音/声音/全屏。
- **互动**：第二境「浮萍一道」点击画面（或按空格）——小艇再行，浮萍分开又缓缓合拢，题字「浮萍一道开」。
- **自动游览/自动朗读**：默认开启，可作课堂大屏无人值守展示。
- 朗读优先级：Edge 在线神经语音现场朗诵 → 本地 `audio/*.mp3` → 系统语音兜底（离线也可用）。

## 教学建议

- 注音含变调标注：`一道 yí dào`；多音字考点：**解 jiě**（懂得，非"解开"）、**藏 cáng**。
- 讲"踪迹"时让学生在画面里找水路——浮萍分开的一道正是小娃"暴露"的证据，体会诗人的儿童视角与幽默。
- 结尾可讨论：诗人是"责备"还是"喜爱"这个小娃？从"偷""不解"两个词读一读。

## 自查记录

- `validate.js` 全绿；`accept.js` ACCEPT（2 境 · 青绿春晓变体）。
- 多音字：艇 tǐng、萍 píng 均为单一读音，TTS 无需替换表；解/藏按语境默认读音正确。
