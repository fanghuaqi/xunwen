# 循文入境 · 望江南·梳洗罢（唐 · 温庭筠）

单文件沉浸式诗词课件：三境随词句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 烟雨江南·望楼变体：从晨起梳洗的期待，到千帆过尽的失望——全集篇幅最短、情绪最"长"的一页。
> 标志性瞬间：过尽千帆皆不是——落日贴山、江面帆阵、楼头独倚。

## 操作

- `← →` / 空格：切境（末境空格 = 触发交互，交互过后再按进终章）
- 自动游览、自动朗读默认开启，可一键关
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置 MP3 → 系统语音
- `audio/00–04.mp3`：题名、三境、全篇（晓晓·温暖女声，语速 −16%；`tts.json` 多音字替换只影响读音）

## 教学建议

- 「梳洗罢」三字藏信息：晨起精心妆扮——女为悦己者容，期待之深可见
- 「过尽千帆皆不是」：时间感与心理落差全在数字「千」与全称「皆」
- 「斜晖脉脉水悠悠」：拟人+叠词，景语皆情语
- 注音考点：梳洗 shū xǐ、独倚 dú yǐ、过尽 guò jìn、斜晖 xié huī、脉脉 mò mò、悠悠 yōu yōu、肠断 cháng duàn、白蘋 pín
- 体裁：小令（27 字）；与《望海潮》对照——同一词牌家族，一写都市繁华、一写闺中等待
