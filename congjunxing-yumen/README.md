# 从军行·其四 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《从军行·其四》（唐·王昌龄）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**大漠金戈**赛道的边塞正格——长云暗雪山、孤城、黄沙、金甲四层色板递进，前二句压抑暗色、后二句亮色誓言，风沙横流贯穿全页。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"点击金甲"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：甲光千磨百战波次明灭，楼兰方向烽火次第点亮，"不破楼兰终不还"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：大漠金戈 · 边塞正格（art-direction 赛道⑤）

|---|---|
| 底色 | `#120d08`（大漠夜） |
| accent | `#c4824a`（烽燧/城垣/旗杆/人物边缘光/甲光，取自 queue） |
| 文字 | `#f0e2cc` |
| 雾 | `#1a120a` 系，fd 0.0058–0.0070（境①最郁、境②略朗） |

| 星 | 境①压抑 0.10，境②誓师 0.26 |
| 粒子母题 | 长云横空（自写 CJX 云带着色器，漂移回绕）、甲光点阵（自写 CJX 点阵着色器，aT 波次明灭）、赭色风沙横流、烽火火星、低雾 |

**有意的设计**：四层色板递进——长云暗雪山（灰暗压抑）→ 孤城（沉赭剪影）→ 黄沙（境②转亮的暖赭）→ 金甲（accent 亮的誓言）。境①雪山只留一线雪光、被云压暗，月也缩到全页最小；境②黄沙、甲光、烽火一齐转亮——前二句愈压抑，后二句誓言愈亮，明暗递进线就是这首七绝的气骨。

## 教学建议

1. **导入**：讲题目——《从军行》是乐府旧题，王昌龄共作七首，此为其四，被誉为边塞七绝压卷；先看封面"大漠、孤城、烽燧"设问：戍边将士的生活是什么样的？
2. **境①构图**：青海在西、玉门关在西北更远处，"长云"一句横抹千里——让学生在画面里找雪山、孤城、玉门关三个方位，体会"孤城遥望"的孤悬与压抑。
3. **境②炼字**：让学生先看"穿"字——黄沙、百战、穿金甲，七个字写尽戍边岁月之久、战事之频；再点击金甲看"甲光千磨百战"，讨论"金甲虽穿，壮心不磨"。
4. **典故**：结合注释讲楼兰——汉代楼兰叛附匈奴、攻杀汉使，傅介子斩其王，"破楼兰"遂成安定西域的代称；"不破楼兰终不还"是誓言不是哀叹。
5. **收束**：对照两境的明暗——前二句愈压抑、后二句愈慷慨，这正是盛唐边塞诗的"气骨"；末章全诗连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
