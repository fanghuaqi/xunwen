# 一剪梅·舟过吴江 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《一剪梅·舟过吴江》（宋·蒋捷）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。**时光之叹装进三重词境**——舟摇帘招的春愁羁旅、渡桥风雨的归期之问、流光抛人的词眼一瞬：樱桃由青转红、芭蕉由卷转展，抽象的流光被写成看得见的两种颜色。全套黛蓝湿雾色板，樱桃红与芭蕉绿是末境唯二的暖彩点。

> 注意：本页是蒋捷《一剪梅·舟过吴江》；另一首李清照《一剪梅·红藕香残玉簟秋》在 `yijianmei-hongou/`，同名异作勿混。蒋捷另一首《虞美人·听雨》在 `yumeiren-tingyu/`。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境③为"点击流光"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境③轻点画面：流光推移——樱桃青转红透、芭蕉卷叶展绿、流光大盛、客舟被抛向远处，"红了樱桃，绿了芭蕉"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：烟雨江南（art-direction 赛道⑥）

| 项 | 取值 |
|---|---|
| 底色 | `#10141a`（黛蓝夜） |
| 主色 | `#9fb0c9`（queue 分配强调色；按钮/边框/进度点/题字，全银青调，**无一处金色**） |
| 文字 | `#e6ecef` |
| 雾 | `#151d26` 系，fd 0.012–0.014（湿雾涨江，风雨境最浓） |
| 月 | 隐月（ms 0.35–0.45，雨夜月朦胧），不是主角；烟雨才是主角 |
| 粒子母题 | 斜落雨丝（自定义着色器）、横掠风痕、江面雾团、淡尘微光 |

**有意的设计**：前两境全冷（黛蓝/烟青/墨青），境③的樱桃红与芭蕉绿是全页唯二的暖彩点——且都是"点击后才到来"的颜色：青果红透、卷叶展绿的一瞬，正是一春将尽、流光把人抛下的一瞬。叠字节奏全部转译为动态：舟摇（船体摇荡侧倾）、帘招（酒帘迎风张垂）、飘飘（柳丝横摆+风痕流走）、萧萧（雨丝一阵紧一阵疏）。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（Edge 神经语音 zh-CN-XiaoxiaoNeural，语速 -16%，`gen-voice-edge.py` 生成）：

- `00.mp3` 标题（自动提取："一剪梅·舟过吴江"）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全词连读

`tts.json` 收 3 条多音字同音替换（只影响音频读音，不改页面文字）：「笙调」→"笙条"（调 tiáo，调弄吹奏）、「红了樱桃」「绿了芭蕉」→"瞭"（了 liǎo，从吟诵读）。页面逐字注音与音频口径一致：浇 jiāo、调 tiáo、了 liǎo、抛 pāo。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：问学生"愁绪怎么浇？"再入境①，对照"舟摇""帘招"两个动词看画面动势。
2. **境②叠字**：让学生数"风又飘飘，雨又萧萧"的声音层次——飘飘是视觉的飘、萧萧是听觉的响；渡口与桥都是"归途地标"，过了一处还有一处。
3. **境③词眼**：先点击流光看时间推移，再讨论"为什么写樱桃芭蕉的颜色变化就是写时光"——不着一字感慨而感慨至深。
4. **对比联读**：与李清照《一剪梅·红藕香残》同调对读，一写闺思、一写羁旅；与蒋捷《虞美人·听雨》互证"漂泊"母题。
5. **收束**：末章全词连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 三境），境名逐一对齐；诗文逐字等于 queue.json 口径（秋娘渡/泰娘桥从通行本）。
- 交互境序号 `curIdx===3`（末境点击流光，cooldown 门控 + clicked 标志）；进度点/按键/自动游览末境判断均以 `POEM.length=3` 对齐。
- 自定义着色器均显式双 shader（酒帘/柳丝/雨丝），`uFade` 由 setFade 统一接管；水/山脊登记 fogShaders 同步雾。
- 校验：`node _pipeline/tools/validate.js yijianmei-zhouguo/index.html` → **✓ 校验全部通过**。
- 冒烟：`node yijianmei-zhouguo/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 逐境 build/update ×400 帧 → fadeK 合规 → 末境点击门控（pointerdown + 空格先交互再进终章）→ 自动游览至终章 → 小测全流程，多次运行稳定；逐境 draw call 代理 20–27，三角面 ≤2.1 万）。
- 实拍：shots.py 全 4 境截图 + 末境点击前/中/后三态人工检查（酒帘、雨丝、拱桥、时间推移均正常）。
