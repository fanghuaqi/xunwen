# 秋夕 · 杜牧 ——「循文入境」沉浸式诗词课件

双击 `index.html` 即可打开（Three.js 走 CDN，首次需联网；音频已本地内置）。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 卷首 | —— | 秋夜庭院，银烛冷光、三两点流萤 |
| 壹 · 银烛画屏 | 银烛秋光冷画屏， | 室内：清冷银烛、水墨画屏（淡月远山） |
| 贰 · 小扇流萤 | 轻罗小扇扑流萤。 | 庭院：宫女执团扇扑萤，流萤四散躲闪 |
| 叁 · 坐看双星 | 天阶夜色凉如水，坐看牵牛织女星。 | 仰望：天阶石级、银河、牵牛织女双星微光相连 |

## 使用

- `← →` 键 / 空格 / 进度点逐境；「自动游览」可无人值守课堂展示。
- 末境点击画面：**流萤四起 + 双星明亮 + 题字**（空格同效）。
- 注音/朗读/声音/全屏可在控制条切换；朗读优先 Edge 神经语音，缺省回退 `audio/` MP3（00 标题、01–03 分句、04 全诗），再回退系统语音。
- 结课含 5 题小测（接龙、作者、词义、主旨、名句理解）。

## 教学建议

先开自动游览整体入境一遍，再逐境精读：境一体会"冷"字的双重意味（烛光冷、心境冷）；境二抓住"扑"的灵动，看宫女如何以扑萤自遣；境三提问——她为什么只看牵牛织女二星？由七夕传说引出宫女对爱情与自由的向往，理解"凉如水"既是夜凉也是心凉。
