# 循文入境 · 茅屋为秋风所破歌（唐 · 杜甫）

单文件沉浸式诗词课件：四境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 水墨夜思·破庐变体：从狂风卷茅、群童抱茅的无力，到长夜冷雨的艰熬，最终升华为「安得广厦千万间」的千古呼喊。
> 标志性瞬间：安得广厦千万间——风雨暗夜中，千万座广厦拔地而起，亮窗庇护天下寒士。

## 教学建议

- 情感逻辑：从「一己之苦」（茅飞、屋漏、受冻）层层推及「天下之苦」（安得广厦），让学生体会杜甫最博大的推己及人胸怀
- 「风定云墨色」到「雨脚如麻」：环境描写的层层渲染，从风暴到阴雨，压迫感逐渐累加
- 结尾「吾庐独破受冻死亦足」：舍己为人的献身精神，现实主义诗歌的崇高境界
- 注音考点：怒号 háo、三重茅 chóng、挂罥 juàn、塘坳 ào、忍能 rěn、布衾 qīn、娇儿恶卧 è wò、雨脚如麻 má、丧乱 sāng luàn、何由彻 chè、广厦 shà、大庇 bì、突兀 wù、见此屋 xiàn
- 背景：唐肃宗上元二年（761年）秋，杜甫在成都草堂所作
