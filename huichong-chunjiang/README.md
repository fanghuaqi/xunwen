# 惠崇春江晚景 · 循文入境

宋 · 苏轼。题画诗（惠崇《春江晚景》图）。三境沉浸式课件，青绿春晓·春江鸭群变体（早春物候）：

1. **竹外桃花** —— 竹影老枝横斜，桃花初绽，花瓣缓落
2. **群鸭试水** —— 标志性瞬间：群鸭剪影先后跃入春江，涟漪圈圈扩散，水面暖汽升腾
3. **河豚欲上** —— 蒌蒿芦芽满滩，水下河豚浑圆剪影逆流缓行；**点击画面 / 空格**唤群鸭戏水（跃水 + 涟漪 + 水汽 + 题字）

## 使用

双击 `index.html`（首次需联网加载 Three.js）。← → 键或空格逐境游览；自动朗读 / 自动游览默认开启，可作课堂大屏无人值守展示。

## 教学要点

- 注音：蒌蒿 **lóu hāo**、芦芽 **lú yá**、河豚 **tún**
- 考点：题画诗（惠崇，北宋僧人画家）；「鸭先知」理趣——亲身实践者最先感知事物变化；蒌蒿、芦芽与河豚的配料呼应
- 小测 5 题：接龙×2、注音、题画典故、名句理趣
