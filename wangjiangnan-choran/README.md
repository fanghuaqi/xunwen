# 望江南·超然台作 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《望江南·超然台作》（宋·苏轼）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**烟雨江南·登台变体**——黛蓝湿雾全景色板，围绕密州超然台的春望、烟雨与新火三重意境展开。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境③为"点击新火试茶"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境③轻点画面：新火火星迸起、茶烟袅袅，千家烟雨渐次转明，"诗酒趁年华"题字同现
- 末章：全词回放、学习小测（5 题）

## 美术方案：烟雨江南·登台变体（art-direction 赛道⑥）

| 项 | 取值 |
|---|---|
| 底色 | `#10141a`（黛蓝夜） |
| 主色 | `#9ab0c9`（queue 分配强调色；按钮/边框/进度点/题字全系黛蓝） |
| 文字 | `#e6ecef` |
| 雾 | `#161e28` 系湿雾，fd 0.0046–0.0072（逐境微调） |
| 月 | 隐月（ms 0.25–0.5，低悬西天，只作天光不抢戏） |
| 粒子母题 | 斜雨丝、湿雾、花瓣缓浮、千家灯火（暖橙点阵，是烟雨里的唯一温度） |

**有意的设计**：全页只有两处暖色——境②"烟雨暗千家"的**千家灯火**（随雨势渐次黯淡，是"暗"字的画面化）与境③"新火试新茶"的**一小盆炉焰**（寒食禁火后重起的新火，点击后茶烟袅起、千家灯火重新亮起，是"超然"的温度）。除这两处外全页维持黛蓝湿雾冷调，让学生一眼读出"愁是湿冷的，超然是暖的"。

## 朗读配音

`audio/` 内置 5 个 Edge 神经语音 MP3（zh-CN-XiaoxiaoNeural，语速 -16%，烟雨赛道女声）：

- `00.mp3` 题名（望江南·超然台作）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全词连读

多音字处理见 `tts.json`：「咨嗟」以同音同调字「兹接」接管（嗟读 jiē，与页面注音一致）；「看」（台上看）按动词位 kàn 直读，无需替换。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：密州是苏轼仕途低谷（自请外放、与弟分离），先设问"登上超然台的人，为什么先说'春未老'？"
2. **境①对照**：春水、垂柳、一城花的明丽——是"乐景"，为下文"暗千家"的反差蓄势。
3. **境②定格**：雨来灯暗的瞬间让学生描述画面情绪，再讲寒食禁火的节俗，引出"酒醒却咨嗟"的乡愁。
4. **境③转折**：点击新火试茶后再读"诗酒趁年华"，讨论"新火""新茶"两个"新"字为什么能一扫愁绪——超然旷达不是没有愁，而是安顿愁。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- 三境分境取自 `queue.json`（诗文逐字照抄，分境拼接=全文）：`春未老…一城花 / 烟雨暗千家…咨嗟 / 休对故人…趁年华`；`STAGES = POEM + 1`（封面 + 三境），境名逐一对齐。
- 交互境序号 `curIdx===3`（pointerdown + 空格双接线，末境先交互、再按进终章）；进度点/按键/自动游览末境判断均以 `POEM.length=3` 对齐。
- 每境 makeRange（多峰山脊）+ makeForeground（前景框景）+ makeFigure（台上凭栏人）；draw call 代理 22–28（≤120），三角面 ≈2.2 万（≤12 万）。
- 校验：`node _pipeline/tools/validate.js wangjiangnan-choran/index.html` → **✓ 校验全部通过**。
- 冒烟：`node wangjiangnan-choran/smoke.test.js` → **SMOKE PASS**（boot → 逐境 build/update×400 帧 → 末境点击门控 → 自动游览全程 → 小测满分，多次运行稳定）。
- 实拍：`shots.py` 抽检封面 + 三境（真渲染截图），柳形、城郭密度、火盆比例均已核。
