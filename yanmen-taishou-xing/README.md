# 循文入境 · 雁门太守行（唐 · 李贺）

单文件沉浸式诗词课件：四境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 大漠金戈·玄金变体：黑云与金甲对撞、夜紫与霜白交替 —— 全集色彩最浓烈奇崛的一页（"诗鬼"配色）。
> 标志性瞬间：黑云压城城欲摧、甲光向日金鳞开 —— 乌云压顶与金甲反光的强对撞。

## 教学建议

- 色彩叙事是本诗最大特色：黑、金、紫、红、白霜、玉——让学生数一数颜色词，体会"诗鬼"的浓烈设色
- "甲光向日金鳞开"：把铠甲反光写成"金鳞绽开"，一个"开"字化静为动
- "塞上燕脂凝夜紫"：胭脂色（血色）在夜色里"凝"成紫，色彩里藏着战争的惨烈
- 用典收束："黄金台"（燕昭王置千金招贤）→ "玉龙"（宝剑），从守城写到誓死报效，完成情感升华
- 注音考点：压 yā、摧 cuī、甲光 jiǎ、金鳞 lín、角声 jiǎo、塞上 sài、燕脂 yān zhī、凝 níng、半卷 juǎn、霜重 zhòng、提携 xié、为君死 wèi
- 体裁：雁门太守行是乐府旧题；本诗为七言歌行，对仗工整、色彩对撞（可对比"两句三年得"的苦吟）
