# 循文入境 ·《观沧海》曹操

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js r128 走 CDN 三路回退，首次打开需联网；音频为本地 MP3）。

## 使用

- 双击 `index.html` → 点「入境」→ 自动朗读 + 自动游览全程无人值守（均可一键关）。
- `← →` 键或空格逐境游览；**第七境「歌以咏志」可点击画面 / 按空格擂鼓**：WebAudio 低频鼓点两声 + 题字"歌以咏志"闪烁 + 海面波光增强。
- 朗读优先级：Edge 在线神经语音现场朗诵 → 内置 `audio/*.mp3` → 系统语音兜底。删除 `audio/` 目录可在 Edge 下强制走神经语音。
- `audio/`（00 标题 + 01..07 各句 + 08 全诗）由 `gen-voice.guancanghai.js`（本诗专用 SUB 多音字表副本）生成；`smoke-test.js` 为结构冒烟测试（真实 THREE r128 无头执行全部 build/update/click/goto）。

## 七境设计

| 境 | 诗句 | 画面 | 天色（情绪曲线） |
|---|---|---|---|
| 壹 | 东临碣石，以观沧海 | 高台登临：右前景碣石台地 + 人影崖顶远眺，落日赭红悬于海平线，海面金道 | 登临·开阔（fd 0.0055，星 0.15） |
| 贰 | 水何澹澹，山岛竦峙 | 低视角贴浪，两座台地大岛左右耸峙，浪涌拍岸飞沫 | 观海·雄浑（fd 0.0065） |
| 叁 | 树木丛生，百草丰茂 | 岛顶台地：15 株树丛 + 260 株实例化草叶随风摇 + 草籽浮尘，天际落日余晖 | 秋而不凋（fd 0.008，星 0.12） |
| 肆 | 秋风萧瑟，洪波涌起 | 浪幅 2.7 的巨浪 + 赭灰风雾横流（makeFlow）+ 浪尖飞沫，天色压暗 | 动荡（fd 0.009，风声 river 0.14） |
| 伍 | 日月之行，若出其中 | **标志性瞬间①**：日与月同轨对踵，沿海平线大弧线沉浮，海水遮其下缘；金色波光道随日位实时指向；金尘自海中生 | 宇宙豪情初开（fd 0.0045，星 0.45） |
| 陆 | 星汉灿烂，若出其里 | **标志性瞬间②**：银河星带自天顶泼向海平线，**海面半透**、海中倒悬对称星带反向旋转；420 粒光柱自天际倒卷入海 | 宇宙·澄澈（fd 0.003，星 1.0） |
| 柒 | 幸甚至哉，歌以咏志 | 交互境：崖顶战鼓 + 双旌旗 + 曹公按剑剪影；点击/空格擂鼓两声、题字闪烁、波光与咏志金光暴涨 | 咏志·昂扬（fd 0.0052，星 0.35） |

情绪曲线：登临（开阔）→ 观海（雄浑）→ 秋风洪波（动荡）→ 日月星汉（宇宙豪情）→ 咏志（昂扬）。

## 美术方案（防同质化）

- 风格赛道：**大漠金戈·沧海变体**（art-direction ⑤）——bg `#120d08`、主赭金 `#d98e3a`、文字 `#f0e2cc`、雾 `#1a120a` fd 0.006-0.01。这是**秋天黄昏的沧海**：海面墨蓝（deep `#0a1018` 系）、天际线落日赭红、山岛一律为**台地状剪影**（截头锥体 + 平顶盖，区别于参考实现的圆山顶）。
- 与《将进酒》（深蓝夜空 + 鎏金宴饮）和《春晓》（青绿晨光）并排一眼可辨：本页无金色流萤、无大暖月、无酒器——母题是**落日、台地、洪波、星河**。
- 自创新 builder：`makeMesa`（台地）/ `makeSun`（落日·月轮）/ `bRiyue`（日月沿海平线沉浮弧线）/ `bXinghan`（银河倒卷入海：天上星带 + 海中倒悬星带 + 倒卷光柱，水 ShaderMaterial 的 uFade 压到 0.58 让海中星河可望）/ `bYongzhi`（战鼓交互境）/ `drumBoom`（WebAudio 低频鼓点：正弦 110→38Hz 下扫 ×2 + 皮面噪声）。
- 水面着色器新增 `moonColor` 参数，落日金道与银夜星汉波光随境换色。

## 教学要点

- 注音考点：碣 jié、澹 dàn、竦峙 sǒng zhì、萧瑟 xiāo sè、咏 yǒng（拼音逐字核对，validate.js 校验数量）。
- 名句理解："日月之行"四句借想象写出大海吞吐日月、包容星汉的气魄，虚实相生；以此体认曹操统一天下的雄心壮志（诗眼在"志"）。
- 小测 5 题：接龙 ×2（碣石→沧海 / 竦峙读音）、词义（星汉=银河）、名句理解（吞吐日月）、主旨（咏志之志）；评语按本诗定制（"壮心与沧海同阔"）。
- 适合课堂大屏：开启自动游览 + 自动朗读即可无人值守走完封面→七境→终章全诗（约 2 分半）。
