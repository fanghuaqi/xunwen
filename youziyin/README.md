# 循文入境 · 游子吟（孟郊）— 沉浸式诗词课件

双击 `index.html` 即可打开（Three.js 走 CDN 三路回退，首次打开需联网；音频已本地打包）。

## 作品说明

以「宣纸留白 · 暖烛变体」浅色暖调呈现《游子吟》：暖宣纸底 `#efe6d0`、赭褐主色 `#8a5a2a`、
暖墨剪影、烛光暖晕取代金属金辉。全诗拆为 **封面 + 三境**，情绪曲线
**烛下暖 → 烛下忧（迟）→ 天光大亮（晖）**，SKY 天穹逐境从暖昏推到亮白。

| 境 | 诗句 | 场景设计 |
|---|---|---|
| 卷首 | —— | 宣纸雾色中一根悬空的线横陈，浮尘微动 ——「线」母题预告 |
| 壹 · 手中线 | 慈母手中线，游子身上衣 | 烛下案头：油灯、针线筐、案上衣料、慈母剪影，一根悬空的线从慈母手边经案上布面连到衣架上的长衫，随烛焰轻晃 |
| 贰 · 密密缝（标志性瞬间①） | 临行密密缝，意恐迟迟归 | 油灯下一双把手特写（暖墨剪影）：一针一线缓慢缝制，细线用 TubeGeometry 被针尾牵引、随抬针松弛落针绷紧，每一针落在布面留下针脚，并合成一声轻微"噔"（WebAudio）。**点击画面/空格 = 帮慈母加一针** |
| 叁 · 三春晖（标志性瞬间②） | 谁言寸草心，报得三春晖 | 镜头从门内缓缓拉到门外：一根线自门槛延伸进原野，两侧渐次萌发参差青草 ——「线」在镜头里化作「草」；天光大亮、暖阳（大暖晕低星）铺满，归鸟掠空，慈母剪影在门边守望 |

小测 5 题（接龙×2、读音×1、比喻×1、主旨×1）；终章收在「寸草 · 春晖」，全诗竖排重读。

## 使用

- `←/→` 或空格逐境游览；第二境可轻点画面帮慈母加一针；底部可切换自动游览 / 自动朗读 / 注音 / 声音 / 全屏，可作课堂大屏无人值守展示。
- 注音核对多音字：缝 **féng**（缝制）、恐 kǒng、晖 huī；「谁」注教材读音 shuí。

## 配音

`audio/00-04.mp3`（00 标题、01-03 各句、04 全诗）已由百度翻译 TTS 生成。
生成脚本为 `gen-voice.js`（技能脚本的**本目录副本**，未改动技能共享原件）：
SUB 表用同音字「逢」锚定"临行密密缝"读 féng；任务表按 3 境改为 00-04。
注：TTS 对「谁」可能读口语 shéi，教材标注为 shuí，属可接受范围。
如需"诗朗诵"级真人感：设置 `TTS_AZURE_KEY` 后重跑本目录的 gen-voice.js 即自动切换
Azure 神经语音（zh-CN-YunjianNeural，poetry-reading 风格）。

## 教学建议

1. 先整体朗读一遍，再逐境入境：每境先看画面猜诗句，再对照竖排原文与注音。
2. 第二境让学生数一数画面上的针脚，体会"密密"二字的分量；点一点，加一针。
3. 第三境追问：画面里"线"去哪儿了？（化作原野的草）——寸草与春晖的比喻由此落地。
4. 结课用小测检验：重点考"缝 féng"的读音与"三春晖"的比喻义。
