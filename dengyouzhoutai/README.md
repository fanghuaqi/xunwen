# 循文入境 · 《登幽州台歌》（唐 · 陈子昂）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（首次需联网加载 Three.js，音频已本地内置）。

## 两重意境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 前无古人 | 前不见古人，后不见来者 | 苍茫旷野中一座夯土高台，台顶孤影独立；前后时间之野上淡影隐现而散尽——"不见" |
| 贰 · 天地悠悠 | 念天地之悠悠，独怆然而涕下 | 自诗人背后缓缓拉远升高（超广角），孤影没入苍茫天地、风卷尘沙；**点击画面：镜头极速拉远至天地无尽，题字"独怆然而涕下"** |

美术：大漠金戈 · 幽州台怀古变体（苍茫古台的天问），强调色 `#b8905a`，基调苍茫孤绝。

## 使用

- **操作**：进入后 ← → 键 / 空格逐境游览；第二境点击画面或按空格触发"天地更阔"；`注音/朗读/声音/全屏` 在底部控制条。
- **自动游览**：点"自动游览·开"可无人值守走完全程（课堂大屏投影用）。
- **朗读**：优先使用 Edge 的"在线自然语音"现场逐句朗诵；否则播放 `audio/00–03.mp3`（00 标题、01–02 各句、03 全诗）。
- **离线/无网**：Three.js 加载失败会提示刷新；无 audio 时自动回退浏览器语音。

## 教学建议

1. 先整体自动游览一遍，学生边听边看，感受"天地极大、人极小"的构图。
2. 第二境点击"天地更阔"前，先让学生齐读诗句再点击，体会镜头语言与情感的关系。
3. 小测 5 题覆盖：句序接龙、多音字（怆 chuàng）、古今异义（涕＝眼泪）、蓟北楼、主旨情感。
