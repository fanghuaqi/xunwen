# 循文入境 · 秋夜将晓出篱门迎凉有感（宋 · 陆游）

单文件沉浸式诗词课件（Three.js r128 UMD，双击 `index.html` 即开；首开需联网加载引擎，cdnjs→jsdelivr→unpkg 三路回退）。水墨夜思·黎明秋望变体：全页冷银蓝黎明前色板（强调色 #9fb3cc），穹顶带"东方将晓"的定向天光，情感曲线是**从壮阔到沉痛的陡转**。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 河岳摩天 | 三万里河东入海，五千仞岳上摩天 | **标志瞬间**：黎明的两重山河 —— 超广角水面直铺天际，浪花碎光奔流入海，晨光在河面拉出一条银亮光道；巨岳剪影直插晨空，东面黎明微光、西面仍在夜色（天光只亮一半） |
| 贰 · 泪尽胡尘 | 遗民泪尽胡尘里 | 镜头陡然落到人间：篱门残篱、枯树剪影，白发拄杖的老人在门前微驼而立，胡尘贴地横流，眼角一点将干未干的泪光 |
| 叁 · 南望王师 | 南望王师又一年 | **交互境**：老人南望的背影，南方天际悬一颗启明星；旧年的星影一颗颗缓缓沉入天际线（"又一年"的可视化）。**点击画面/按空格**：启明星升起愈亮、篱门吱呀推开、晨光微亮、老人举目，题字"南望王师又一年" |

## 操作

- `← →` 键或空格逐境；`Esc` 退出终章/小测；顶部圆点可直接跳境。
- 自动游览、自动朗读默认开启，可一键关闭（适合课堂大屏无人值守）。
- 朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音。

## 注音自查

将 jiāng（诗题，天快亮）· 仞 rèn（长度单位）· 岳 yuè（华山）· 摩 mó（摩擦、接触）· 遗 yí · 泪 lèi · 尘 chén · 一年 yì nián（变调）—— 逐字核对，拼音数与汉字数一致（validate.js 强制）。

## 教学建议

先整读一遍 → 逐境入境：第一境让学生找"哪一半山被照亮"，体会前两句写壮丽河山的深意（山河愈美，失地愈痛）；第二境转向篱门边的老人，讲"遗民""胡尘""泪尽"三词；第三境亲手点击让启明星升起、篱门吱呀推开，数一数沉落的旧年星影，体会"又"字的分量 → 结课 5 题小测（含"仞""摩"字义与"胡尘"考点）。
