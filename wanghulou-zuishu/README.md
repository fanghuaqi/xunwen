# 循文入境 · 六月二十七日望湖楼醉书（宋 · 苏轼）

单文件沉浸式诗词课件。三境随诗句推进，同一场西湖骤雨的三个瞬间，节奏急促、动感强烈：

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 黑云翻墨 | 黑云翻墨未遮山 | 墨云沸腾翻卷，山尖未没，闷光在云中滚动 |
| 贰 · 白雨跳珠 | 白雨跳珠乱入船 | 大颗雨珠如白珍珠砸入船舱，在甲板上弹跳、水花四溅 |
| 叁 · 风卷水天 | 卷地风来忽吹散，望湖楼下水如天 | 卷地大风撕开残云拉走，湖面亮如天空之镜；**点击画面 / 空格 → 白雨跳珠大作，随后风起云散** |

## 打开方式

双击 `index.html`（首次需联网加载 Three.js CDN；音频在本地 `audio/`，无网时页面自动回退浏览器语音朗读）。


## 教学建议

- 自动游览 + 自动朗读默认开启，可直接大屏无人值守播放；箭头键 / 空格逐境。
- 小注音按钮可关注音；第叁境留出时间让学生点击体验"跳珠大作"，对应诗句互动记忆。
- 结课小测 5 题：接龙 ×2、多音字「卷 juǎn」读音、望湖楼地点（杭州西湖）、名句理解。
- 多音字已按教材核对：翻墨 fān mò、跳珠 tiào zhū、卷地 juǎn dì、吹散 sàn。
