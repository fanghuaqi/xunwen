# 循文入境 · 咏柳（贺知章）

Three.js 沉浸式诗词课件：诗句推进到哪一句，三维实景就走到哪一重意境。
双击 `index.html` 即可打开（首次需联网加载 Three.js，音频已本地化）。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 碧玉妆成 | 碧玉妆成一树高 | 一株高柳的工笔特写：微弯高干、碧玉树冠、晨光穿叶、柳絮浮空 |
| 贰 · 万条丝绦 | 万条垂下绿丝绦 | 横枝当空，46 条绿丝绦随风齐舞（波浪式摆动） |
| 叁 · 春风裁叶 | 不知细叶谁裁出，二月春风似剪刀 | 标志瞬间：半透明"春风之剪"（双月牙刀刃光影）掠过柳丝，细叶沿轨迹次第"剪"出 |

## 互动

- **第三境点击画面 / 按空格**：唤春风裁叶——剪刀光影横扫 + 120 片细叶应声而出 + 题字"二月春风似剪刀"（可反复重放）；停留 6.5 秒后也会自动演示一次。
- `← →` / 空格逐境游览；自动游览 + 自动朗读默认开启，可作课堂大屏无人值守展示。

## 美术方向

青绿春晓 · 柳丝绦变体（区别于春晓/村居等已有青绿页）：晨曦由青入金的逐境渐亮，
无月、星极稀；强调色 `#9fc98f`，底色 `#0a1410`；粒子母题为柳絮与叶隙光尘。

## 朗读

`audio/00–04.mp3` 为百度 TTS 生成的 AI 配音（00 标题、01–03 各境、04 全诗）。
页面优先使用 Edge"在线自然语音"现场逐句朗诵（更近真人），MP3 为兜底；
无网络时自动回退系统语音。注音已逐字核对：妆 zhuāng、绦 tāo、裁 cái、一（变调）yí、似 sì。

## 小测

结课 5 题：接龙 ×2、读音 ×1、比喻修辞 ×1、词义理解 ×1，评语按本诗定制。

## 开发

- 结构校验：`node <skill>/scripts/validate.js index.html`
- 深度冒烟：`node smoke.test.js`（THREE 桩跑全部 build/update/click）
