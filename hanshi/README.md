# 循文入境 · 寒食（唐 · 韩翃）

单文件沉浸式诗词课件：`index.html` 双击即开（Three.js r128 走 CDN，音频本地），共三境随诗句推进。

## 诗境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 春城飞花 | 春城无处不飞花，寒食东风御柳斜。 | 漫天飞花柳絮乘东风斜飘，御柳垂枝摇曳，远处宫墙城郭 |
| 贰 · 日暮传烛 | 日暮汉宫传蜡烛， | 落日沉入宫墙，汉宫楼阙暖窗，宫门烛列初燃、内侍捧烛鱼贯而出 |
| 叁 · 轻烟五侯 | 轻烟散入五侯家。 | **标志瞬间**：传烛队列沿街巷出汉宫，火点依次点亮，烛烟袅袅飘向五侯宅邸；烛到之处朱门窗灯次第亮起 |

美术：夜宴金彩 · 春城传烛变体 —— 暮褐暖金色板（--gold #d4b050，底色 #120d06），粒子母题为飞花柳絮与烛烟，情绪曲线"暮春绮丽 → 日暮宫城 → 夜烛含讽"。

## 操作

- **入境**：点击封面「入境」；← → 或空格逐境游览
- **传烛互动（第叁境）**：轻点画面或按空格 —— 传烛队列重燃，轻烟飘散，题字「轻烟散入五侯家」
- 控制条可切换：自动游览 / 自动朗读 / 注音 / 声音 / 全屏；终章含学习小测（5 题）与全诗聆听

## 朗读

`audio/00–04.mp3`（00 标题、01–03 各境、04 全诗），百度 TTS 生成。
无音频或离线时自动回退浏览器语音（Edge 下优先神经语音逐句现场朗诵）。
如需"诗朗诵"级音色：`set TTS_AZURE_KEY=…` 后重跑技能目录 `scripts/gen-voice.js`。

## 教学要点

- 多音字：御 yù、斜 xié（统编教材读音）、传 chuán、散 sàn
- 典故：寒食禁火而皇帝特赐蜡烛；「五侯」借东汉桓帝封五宦官为侯，暗讽唐代得宠宦官——表面皇都承平，暗藏讽喻
- 结构：前两句写白日春景之绮丽，后两句写日暮传烛之特权，对比中见讽意
