# 回乡偶书 · 循文入境

贺知章（唐）三境沉浸式诗词课件。双击 `index.html` 即可打开（需联网加载 Three.js，音频本地）。

## 三境
1. **老大回乡** —— 村口老树、来路与拄杖缓行的白发归人，溪水映月（乡音如溪，无改）。
2. **相见不识** —— 村巷里老者拄杖而立，孩童在矮墙后怯生生探头（物是人非，雾重月淡）。
3. **笑问客来** —— 标志瞬间：孩童围拢仰头笑问，来时的路伸向天边。**点击画面或按空格**触发孩童跑近围拢、笑声与题字「笑问客从何处来」。

## 操作
- `←` `→` 逐境 · `空格` 下一境（末境触发互动）· `Esc` 停止朗读
- 底部按钮：自动游览 / 自动朗读 / 注音 / 声音 / 全屏
- 默认自动游览+自动朗读，可作课堂大屏无人值守展示

## 读音与注释
- **鬓毛衰（cuī）**：教材注音，同「催」；页面注音与音频（SUB 表已定制）均读 cuī。
- 多音字自查：少 shào（少小）、处 chù（何处）、偶 ǒu（题）。

## 音频
`audio/00` 标题、`01–03` 各境、`04` 全诗，共 5 个（`gen-voice.js` 为本目录副本，顶部 SUB 表已按本诗多音字定制；如需重新生成：`node gen-voice.js index.html 回乡偶书 "唐，贺知章"`）。网络不通时页面自动回退浏览器语音。

## 课堂建议
自动游览整体感受 → 逐境跟读 → 末境互动讨论「孩子们为什么把诗人当客人」→ 学习小测（5 题）。
