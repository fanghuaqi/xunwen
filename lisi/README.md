# 循文入境 · 离思（曾经沧海）｜元稹

单文件沉浸式诗词课件（Three.js r128 CDN + 本地音频），双击 `index.html` 即可打开（首次需联网加载引擎）。

## 三境结构

| 境 | 诗句 | 场景 |
|---|---|---|
| 壹 · 沧海难为 | 曾经沧海难为水 | 标志瞬间：镜头贴浪前行，浪墙高过人影，沧海的压迫性浩瀚 |
| 贰 · 巫山云外 | 除却巫山不是云 | 巫山群峰云雾缠腰，云流漫峰的缥缈柔美 |
| 叁 · 花丛懒顾 | 取次花丛懒回顾，半缘修道半缘君 | 夜色花丛中一道背身独行的剪影；**点击画面/按空格**叠化"沧浪→巫山云→花丛"三景流转，题字曾经沧海难为水 |

美术赛道：水墨夜思·沧海巫山变体（强调色 `#9fb3cc`，底色 `#0d1117`），基调深情而苍茫——"至大与至小"的对比。

## 使用

- 左右方向键 / 空格逐境游览；自动游览、自动朗读默认开，可一键关（适合课堂大屏无人值守）。
- `audio/00–04.mp3` 为 AI 配音（00 标题、01–03 各句、04 全诗）；无网络音频时自动回退浏览器语音（Edge 下为神经语音现场逐句朗诵）。
- 每字注音（沧 cāng、巫 wū、懒 lǎn、不 bú 已核对），释义与注释含考点（巫山神女典故、难为水词义）。

## 开发

- 结构校验：`node <skill>/scripts/validate.js index.html`
- 深度冒烟：`node smoke.test.js`（THREE 桩跑全部 build/update/click）
- 重新配音：`node <skill>/scripts/gen-voice.js index.html "离思" "唐，元稹"`
