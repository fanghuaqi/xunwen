# 江楼感旧 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《江楼感旧》（唐·赵嘏，又题《江楼旧感》）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**水墨夜思**赛道——但刻意避开既有水墨夜思页的构图（不做舟夜孤灯碎星、不做渡口小楼三点渔火、不做古寺竹径、不做雨前危城），写的是这场月夜独登的**两重心境**：境壹=澄（月光如水水如天——满月盛满江天、水天一色的亮夜），境贰=渺（同来望月人何处——风景依稀而人事已非）。accent=#a0b4cc（月银水青，queue 分配强调色）只落在满月晕/水中月影/银辉光路/水天光带/人物边缘光/UI 上，全页近零饱和。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- 末章：全诗回放、学习小测（5 题）

**有意的设计**：境壹用「天心满月—银辉光路—水中月影」一条纵贯线 + 地平银辉横带，把「月光如水水如天」画成上下无界的一片澄澈——景愈静澈，愈衬「独上」之渺；境贰**刻意复用境壹构图**（同一江楼同一月，月稍西沉）就是「风景依稀似去年」本身——点击后浮现的去年同游虚影是全页唯一的「人影叠影」，淡现又散去，物是人非一笔点破。

## 教学建议

1. **导入**：先让学生想一个画面——多年后回到和旧友常去的地方，东西都在，人不在了。赵嘏把这一切都放进了一座江楼、一轮满月里。
2. **境①诗眼**：「独上」——不说「人不在」，只说「独上」，怅惘已在不言中；再看「月光如水水如天」的顶针：月华如水、水光接天，七个字上递下接一气贯通，景写得越澄澈，人越显得孤单。
3. **境②点击后**：虚影淡现又散去的一瞬，就是「人何处」——一问而无答；再对照眼前的江楼与月：风景依稀「似」去年，一个「似」字最伤——像，却终究不是。
4. **写法**：以景结情、物是人非——景之「不变」反衬人之「不在」；可对照李白《峨眉山月歌》「思君不见下渝州」与崔护「人面不知何处去，桃花依旧笑春风」同读（后者的「人面桃花」与此诗章法最近）。
5. **背景**：赵嘏，字承祐，曾官渭南尉，世称「赵渭南」；此诗又题《江楼旧感》，所怀为旧日同游之人。文本从通行本「风景」（语料另作「风影」）。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、文学常识 ×1、名句手法与主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
