# 十一月四日风雨大作·其二 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《十一月四日风雨大作·其二》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**大漠金戈**赛道，取「孤村风雨」变体——风雨中的孤村茅屋与枯树、窗内一盏昏灯，以及梦里的**冰河**与**铁骑**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击入梦"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：风雨转急（雨丝 uK 涨）、冰河冷光亮起、六骑自远而近漫过孤村（火把明灭），"铁马冰河入梦来"题字同现
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：封面设问"一个六十八岁、卧病在床的人，夜里会梦见什么？"再入境壹。
2. **境壹析"不自哀"**：身已"僵卧"，心却"尚思"——一身的困顿与一心的不甘，全在这三字对照里。
3. **境贰析"化实为虚"**：现实只有"风吹雨"，梦里却是"铁马冰河"；让学生说说风雨声是怎么变成马蹄声的（声音的相似 + 心事的投射）。
4. **点击体会**：点击入梦看雨急、冰河亮、铁骑至，再读末句——现实越逼仄，梦境越壮阔。
5. **知人论世**：此诗作于绍熙三年（1192）陆游退居山阴时，年六十八；他一生主张抗金、收复中原，至死不改（临终《示儿》"王师北定中原日"）。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音义 ×1、梦境内容 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 38 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（茅屋、冰河、铁骑）都在 20–60 单位内，fd ≤ 0.0058；雨丝/冰河冷光/火把/梦境光晕全部只调 uniform 或 scale，**全页无一处手写 opacity**。
- 场景构件（冒烟实测）：卷首 14 mesh / 4 points、境壹 13 mesh / 4 points、境贰 18 mesh / 4 points / 16 sprite；draw call 代理值 26 / 26 / 38（≤120），三角面 ≤0.9 万（≤12 万）。
