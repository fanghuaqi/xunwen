# 循文入境 · 鹿柴（唐 · 王维）

单文件沉浸式诗词课件（Three.js r128 UMD，双击 `index.html` 即开；首开需联网加载引擎，cdnjs→jsdelivr→unpkg 三路回退）。水墨夜思·空山禅意变体：全页冷色深林、几乎无亮度起伏，以声写静、以光写空。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 空山人语 | 空山不见人，但闻人语响 | 层叠雾山与没入雾中的山径，画面空无一人；远处林间人语化作声纹圈隐现明灭（以声写空） |
| 贰 · 返景入林 | 返景入深林 | 幽暗密林中一束返景光柱自林冠斜插而下（体积光感），柱内浮尘缓漂，落点青苔为末境伏笔 |
| 叁 · 光落青苔 | 复照青苔上 | **标志瞬间**：游移的光斑落在青苔丘上。**点击画面/按空格**，光斑缓缓移上青苔并将其照亮，浮尘起舞（以光写空） |

## 操作

- `← →` 键或空格逐境；`Esc` 退出终章/小测；顶部圆点可直接跳境。
- 自动游览、自动朗读默认开启，可一键关闭（适合课堂大屏无人值守）。
- 朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音。

## 音频

`audio/00-04.mp3`（00 标题、01-03 各境、04 全诗），由 `gen-voice.js`（本诗定制副本）生成，多音字表已将「鹿柴」读作 **lù zhài**。删除 audio/ 目录可回退浏览器语音。

## 注音自查

柴 zhài（诗题，同"寨"）· 景 jǐng（日光，指夕阳返照）· 苔 tái · 但 dàn（只、仅仅）—— 逐字核对，拼音数与汉字数一致（validate.js 强制）。

## 教学建议

先整读一遍 → 逐境入境：第一境让学生"只闻其声、不见其人"，讲"以声写静"；第二境找那束光，讲"返景"即夕阳返照；第三境亲手点击引光上苔，体会"以光写空"的禅意 → 结课 5 题小测（含"鹿柴"读音考点）。
