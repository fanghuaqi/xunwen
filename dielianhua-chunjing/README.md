# 蝶恋花·春景 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《蝶恋花·春景》（宋·苏轼）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**青绿春晓**赛道的晚春墙垣变体——残红青杏、燕影溪流是底色，而一道灰白矮墙隔开的「墙里墙外」两个世界，是全页的标志性画面。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"听墙"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：秋千荡缓、笑语光点渐悄、柳绵飘少，"声渐悄"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：青绿春晓 · 晚春墙垣变体（art-direction 赛道④）

| 项 | 取值 |
|---|---|
| 底色 | `#0a1410`（青绿暗底） |

| 文字 | `#eef4e6` |
| 雾 | `#0e1d16` 系，fd 0.0052–0.0070 |
| 月 | 暮春晨景压低为低月（ms 0.55–0.7），让位于天光 |
| 粒子母题 | 柳绵白絮（越墙飘少）、暖杏光点（墙里笑语）、青绿流萤微尘 |

**有意的设计**：末境唯一暖色留给「墙里佳人笑」——佳人头顶一撮**暖杏色光点**（`#f2c94c`，赛道辅杏色），墙外世界全是青绿冷调；点击后光点渐悄、秋千荡缓、柳绵飘少，让学生一眼读出「一墙之隔，两个世界」「多情偏被无情恼」。第一境则以青杏果簇、残红疏簇、燕群绕溪呈现暮春物候。

## 教学建议

1. **导入**：问学生"春天将尽，哪些景物会先告诉你？"再入境①，对照"花褪残红青杏小"看残红与青杏同枝。
2. **境①写景**：找出画面中的暮春证据（柳绵变少、青杏初结），再读"天涯何处无芳草"，体会伤春中的自我宽解。
3. **境②身临**：先看画面找"两个世界"（墙内秋千佳人/墙外土道行人），点击画面听"声渐悄"，讨论行人为什么"恼"。
4. **名句流变**：结合小测第 5 题讲"天涯何处无芳草"的今义（宽慰语）与原意（伤春自解）之别，可补《离骚》"何所独无芳草兮"的出处。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
