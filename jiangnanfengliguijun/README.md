# 江南逢李龟年 · 循文入境

杜甫 | 三境 | 青绿春晓·落花逢旧变体（好风景 × 坏时世的盛衰重逢）

双击 `index.html` 打开（首次需联网加载 Three.js，音频为本地文件）。

## 结构
- 境一 · 岐王宅里：盛世乐坊记忆（殿柱灯彩、琵琶金尘）
- 境二 · 崔九堂前：几度闻歌的筵席（歌台灯山、金色光流）
- 境三 · 落花逢君：标志瞬间——满屏落花中两位老者剪影相对而立，昔日华堂虚影叠化淡出为江南青山

## 交互与教学
- 第三境点击画面 / 按空格 = 落花纷飞 + 今昔叠化 + 题字「落花时节又逢君」
- 注音 / 释义 / 注释 / 学习小测（5 题）；自动朗读、自动游览默认开，可作课堂大屏无人值守展示
- `←` `→` 或空格逐境游览；全屏按钮支持投影

## 配音
`audio/00–04.mp3`（00 标题、01–03 各境、04 全诗），由 `gen-voice.js`（本地副本，SUB 表：龟→君 jūn）经百度 TTS 生成；生成失败时页面自动回退浏览器语音（Edge 下为神经语音现场朗诵）。
