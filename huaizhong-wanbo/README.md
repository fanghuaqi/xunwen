# 淮中晚泊犊头 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《淮中晚泊犊头》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**水墨夜思**赛道，取「淮上春阴」变体——春阴低垂的旷野、连天青草、一树格外明亮的幽花，以及傍晚泊在古祠之下的**孤舟**与满川涌起的**潮头**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击看潮生"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：风急（云层翻涌、草树摇动加剧）、雨密、五道潮头自远而近推进、孤舟随浪起伏加大、水波振幅 0.14→0.44，"满川风雨看潮生"题字同现
- 末章：全诗回放、学习小测（5 题）

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 `zh-CN-YunxiNeural`，语速 −16%），0 失败：

- `00.mp3` 标题（"淮中晚泊犊头"）
- `01.mp3` 境壹（春阴垂野草青青，时有幽花一树明。）
- `02.mp3` 境贰（晚泊孤舟古祠下，满川风雨看潮生。）
- `03.mp3` 全篇连读

多音字处理见 `tts.json`（**sub 非空即完全接管**）：

- `晚泊` → `晚舶`：钉住「泊」的 **bó**（停船靠岸），避开「湖泊」的 pō。注意 `舶` 亦读 bó，故**读音完全一致**；该替换同样作用于音频标题（听觉上仍是「淮中晚泊犊头」）
- 逐句核过：春阴垂野、草青青、幽花一树明、孤舟、古祠（祠 cí）、满川、潮生——无须其他干预

页面朗读优先级：Edge 在线自然语音现场逐句朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"一片晦暗里，什么最亮？"再入境壹，先看"一树明"。
2. **境壹析"垂"与"明"**："垂"写云之低（压下来），"明"写花之亮；一暗一明，是为对比。
3. **境贰析"孤"与"满"**：孤舟、古祠是"静"与"孤"；满川风雨、潮生是"动"与"阔"。让学生找出这两组相对的词。
4. **点击体会**：点击看潮生，看潮头从远处一道道推来，再读末句——问："风雨里看潮，是害怕还是从容？"（一个"看"字，见其镇定。）
5. **知人论世**：苏舜钦因支持范仲淹新政被贬，退居苏州筑沧浪亭；此诗写旅次所见，襟怀开阔，不作愁苦语。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音义 ×1、词义 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 39 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（古祠、孤舟、幽花、潮头）都在 10–40 单位内，fd ≤ 0.0066；全页**无一处手写 opacity**（云/草/花/舟/潮头全走 scale 或位置，水面振幅走 uniform）。
- 场景构件（冒烟实测）：卷首 10 mesh / 26 sprite、境壹 11 mesh / 28 sprite、境贰 36 mesh / 29 sprite；draw call 代理值 37 / 40 / 67（≤120），三角面 ≈2.7 / 3.3 / 2.3 万（≤12 万）。
