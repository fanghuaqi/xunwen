# 春夜喜雨 · 循文入境（唐 · 杜甫）

双击 `index.html` 即可打开（需联网加载 Three.js，音频已内置本地）。适合课堂大屏、学生自学与无人值守展示。

## 内容

四境随诗句推进（一句联二行一境），配音 6 个（00 标题 / 01–04 各句 / 05 全诗）：

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 好雨知时 | 好雨知时节，当春乃发生。 | 夜雨落进春水田，新苗应雨而发 |
| 贰 潜夜润物 | 随风潜入夜，润物细无声。 | 贴地浓雾、湿叶垂露，细雨几不可闻 |
| 叁 云黑火明 | 野径云俱黑，江船火独明。 | **标志性瞬间**：漆黑旷野江岸，乌篷船一点渔火独明（点击：光晕扩大、倒影拉长） |
| 肆 红湿锦城 | 晓看红湿处，花重锦官城。 | 点击夜空唤来天光，破晓后满城红湿花重、枝头低垂 |

## 操作

- ← → 键 / 空格 / 按钮：逐境游览；第三、四境点击画面（或空格）触发互动
- 「自动游览」「自动朗读」默认可开：无人值守展示建议全开
- 朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音兜底

## 教学

- 多音字考点：潜 qián、俱 jù、重 zhòng（页面注音 + 注释均已标注）
- 内置 5 道小测：接龙 ×2、读音 ×1、词义（锦官城=成都）×1、主旨 ×1
- 美术赛道：青绿春晓 · 夜雨变体——全诗一场"整夜戏"，黑得纯粹、火光珍贵，与同赛道昼景诸篇区分
