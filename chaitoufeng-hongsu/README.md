# 钗头凤·红酥手 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《钗头凤·红酥手》（宋·陆游）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**烟雨江南**赛道——黛蓝湿雾、全页禁金，桃花红是唯一暖点；讲的是沈园本事词：陆游与前妻唐琬沈园相遇、题壁而别。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"点击宫墙柳"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：柳絮拂壁，「错、错、错」「莫、莫、莫」题字次第浮现（双调回环）
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：讲"一道宫墙"——两个人隔墙相望、近在咫尺却再不能相见，是什么滋味？再入境①对照"满城春色宫墙柳"。
2. **境①物象**：让学生数画面里的旧盟信物（红酥手、黄縢酒、宫墙柳），体会三个意象叠出的甜蜜与怅惘；讲沈园本事（陆游约 31 岁游沈园遇唐琬，题词壁上）。
3. **境②三"错"**：问学生"错的是什么？"——不敢违母命是错，重逢欲说不能更是错；三个"错"字如三声锤击，节奏与情感同步。
4. **境③对照**：切换境①/境③截图对比"同景异时"——春如旧、人空瘦；"空"字既叹己亦怜人。
5. **境④回环**：点击宫墙柳看"错→莫"次第浮现，讨论"错错错"与"莫莫莫"为什么一头一尾、互相回答；可引唐琬和词"世情薄，人情恶"与次年玉殒的结局。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
