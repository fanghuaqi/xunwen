# 静夜思 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《静夜思》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版为**水墨夜思**换肤重制版——全套冷银水墨色板，冷月是唯一主角，故乡灯火是全页唯一的暖色。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"点亮故乡灯火"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：七盏故乡灯火逐次点亮，钟声与"思故乡"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#c9d3e0`（按钮/边框/进度点/题字，全部银蓝水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#131a26`，fd 0.005–0.009 |
| 月 | 冷银白（`#f2f6ff` + 银蓝辉光），全页唯一主角；境③放大至 ms 2.2 |
| 星 | 稀疏（数量减半、亮度压至 0.45–0.55） |
| 粒子母题 | 穿窗浮尘、霜晶微闪、月华微尘、流云剪影（替代《将进酒》的金色流萤/火星） |

**有意的设计**：境④"低头思故乡"的七盏灯火保留**暖橙**（窗 `#ffb35c`、点光 `#ffa95c`）——它是全页唯一的暖色点，是"思"的温度；与全局冷银底形成唯一对比，让学生一眼读出"月是冷的，家是暖的"。除此处外，原实现里境①的暖烛已改为一盏**青灯**（冷银微光），境④原萤火暖尘也改为月光冷尘，全页不再有任何第二暖源。

## 朗读配音

`audio/` 内置 6 个 AI 朗读 MP3（百度翻译 TTS 生成，本次网络可用、全部成功）：

- `00.mp3` 标题（诗题自动提取："静夜思"）
- `01–04.mp3` 四句逐境朗读
- `05.mp3` 全诗连读

"疑是地上霜"五字无多音字险（疑 yí / 是 shì / 地 dì / 上 shàng / 霜 shuāng），未建 SUB 副本。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。如需"诗朗诵"级音色，可设 `TTS_AZURE_KEY` 后重跑 `gen-voice.js`。

## 教学建议

1. **导入**：封面设问"月光像什么？"再入境①，对照"床前明月光"看月光穿窗。
2. **境②比喻**：让学生先看画面再读诗句，体会"疑"字——是恍惚错觉，不是真下霜；结合注释讲秋夜水汽凝霜。
3. **境③动作**：让学生跟着画面做"举头"动作，感受仰头见月的开阔与孤清。
4. **境④情感**：点击点亮灯火后再读"低头思故乡"，讨论"为什么灯火是暖的、月夜是冷的"；可介绍李白 24 岁离蜀、终生未再回乡的背景。
5. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、词义 ×1、文学常识 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 四境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，杜绝过渡期绕过产生幽灵场景。
- 交互境序号 `curIdx===4`；进度点/按键/自动游览末境判断均以 `POEM.length=4` 对齐。
- 校验：`node <skill>/scripts/validate.js index.html` → **✓ 校验全部通过**（零警告）。
- 冒烟：已用忠实 THREE 桩在 Node 中真实跑完 boot → 四境 build/update/过渡 → 境④点击门控与 pointerdown → showEnding 守卫（过渡期拒绝/稳定期通过/重复调用无副作用）→ 键盘与按钮全路径 → 自动游览至终章 → 小测六档评语，全部通过。
