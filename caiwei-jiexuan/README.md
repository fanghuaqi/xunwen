# 采薇·节选 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《采薇·节选》（先秦·诗经·小雅）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**水墨夜思**赛道——但刻意避开既有水墨夜思页的构图（不做落木长江登高、不做梅雨蛙声敲棋、不做满月江楼水天一色、不做夜台一瑟四典如梦、不做孤山梅影暗香、不做玉笛光缕柳丝漫卷、不做古寺竹径/雨前危城/渡口渔火），写的是这首戍卒之歌的**同一条归途上的一春一冬**：一条归家长道贯穿四境（母题），道旁一排柳树四境同位——境壹带叶春柳（昔我往矣，杨柳依依）↔ 境贰同位冬柳叶尽（今我来思，雨雪霏霏），同位对照即「四时对切」；境叁镜头压低随长路无尽（行道迟迟，载渴载饥，远村依稀而未至），境肆点击把两景叠进同一画面。accent=#98aec8（月银青灰，queue 分配强调色）只落在雪光/柳梢边缘光/远村灯火雪帽/人物边缘光/UI 上，全页近零饱和；唯春柳（记忆）一侧一抹极克制的灰绿（柳叶 0x748a74 系+柳色微光 0x7d9080+柳絮 0xb8c4ae）——杨柳（春·记忆）与雨雪（冬·眼前）的对切就是末章前四句本身。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为「今昔对切」，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：同一排柳回到带叶的春天（记忆组淡现）、柳絮缓起、柳色微光漫开，而雨雪未停——杨柳与雨雪两景交叠于归人一身；「昔我往矣 杨柳依依 今我来思 雨雪霏霏」题字同现，下行三叠拨音如长叹
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思 · 归途四时对切变体（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117` |
| 主色 | `#98aec8`（月银青灰，queue 分配强调色；按钮/边框/进度点/题字/边缘光/雪光） |
| 文字 | `#dfe6f0` |
| 雾 | `#111823`→`#141b27`，fd 0.0050–0.0062 |
| 月 | 朦胧淡月全程薄晕（ms 0.7–0.9、mhaze 0.30–0.45）——雨雪霏霏的天空不给「满月当空」的清亮，月被雪云滤成一片冷光；星稀（0.04–0.16） |
| 场景母题 | **归家长道**（自写顶点色长路：路中踩实的暗、路缘积雪微亮、车轮辙痕，远端没入雾中=长路无尽）+ **一排柳树**（四境同位：带叶春柳↔叶尽冬柳枝头雪帽）+ 归人（灰袍发髻，全诗贯穿同一造型） |
| 粒子母题 | 霏霏落雪（自写雪着色器：自上而下缓落+风漂+`uMaxA` 雪势可收放）、柳絮（春柳记忆侧）、雪夜寒风横流、雪尘微光 |
| 与已有水墨夜思页的区分 | denggao=落木长江登高、yueke=梅雨蛙声敲棋、jianglou-ganjiu=满月江楼、jinse=夜台一瑟、shanyuan-xiaomei=孤山梅影、chunye-luocheng=玉笛光缕柳丝漫卷；本页=**归途长道+一排柳树一春一冬**的戍卒归人第一视角 |

**有意的设计**：境壹与境贰的柳树同 seed 同位置——去时与归来，是同一棵树；变的只有柳色与天色（镜头感四时对切）。境叁把镜头压到路面高度，长路在雾中无尽，路的尽头只余一带远村雪帽——「载渴载饥」而家尚远。境肆点击前冬柳枯立、雨雪独落（记忆组 `visible=false` 硬关）；点击后春柳记忆淡现而雪未停——两景交叠，物是人非不言自明。

## 教学建议

1. **导入**：先问学生——「昔」与「今」、「往」与「来」各指什么？一个戍卒离家出征又归来，中间隔了多少个春秋？《采薇》全诗六章写尽从出征到归来，课本节选的末章是情感最沉痛的部分。
2. **境①看点**：杨柳为何「依依」？既是柳条随风轻摆的实景，又似挽留行人——古人折柳送别，「柳」谐音「留」。以乐景写哀，其哀倍增。
3. **境②看点**：让学生对比境①境②的同一排柳树——去时着春色、归来披冬雪，树没有变，变的是人与岁月。「思」读 sì（语助词）、「雨」读 yù（落下）、「霏霏」是大雪纷密的样子，三处读音一起钉牢。
4. **境③诗眼**：「迟迟」既是脚步慢，也是心绪沉——近乡情怯，举步维艰；「载渴载饥」是身体的煎熬，更是多年戍边苦楚一齐涌上来。
5. **境④点击后**：春柳记忆淡现而雨雪未停——两景交叠就是「物是人非」四个字的画面版。可补《世说新语》：谢玄举「昔我往矣」四句为《诗经》中最佳。
6. **主旨**：不说「家破」、不说「人亡」，只说「莫知我哀」——归来者一肚子的沧海桑田，收在一个「哀」字的沉默里；小测第 5 题即落「以乐景写哀、以哀景写哀」的物是人非之悲。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示；末境留 3 秒给学生自己点击。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 32 字）、释义/注释、境名/意境题句、5 题小测（接龙×2、读音词义×1、文学常识×1、名句理解/主旨×1）、终章回放。
- `STAGES = POEM + 1`（封面 + 四境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=4` 对齐。
- 交互境序号 `curIdx===4`（pointerdown 与空格双接线，`clicked` 标志 + 1.2s 冷却防连点；空格先交互、再按进终章）。
- fadeK 铁律：所有每帧写 opacity 的对象（柳色微光/记忆组柳树材质/雪着色器 `uMaxA`/柳絮）初值=最大且逐帧乘 fadeK；点击前春柳记忆组 `visible=false` 硬关（无幻影残影）；柳色微光/记忆微光 `fog:false` 如星月点名；自写雪着色器显式双挂 vertexShader/fragmentShader（复用引擎 GLOW_FRAG）；长路/地面/山体走引擎 Phong 雾或 `fogShaders` 雾同步。
- 预算：五次 build 的 drawCall 代理 ≈ 20/20/22/21/24、三角面 ≈ 0.8/1.0/0.6/0.6/1.0 万（≤120 / ≤12 万）。
- 自建主体场景组全部置于骨架常驻远山环（z≈−260…−330）之前：远村 z≈−112、长路 z 止于 −165、远山环带 z≈−165，不被 bgRange 遮挡。
- 校验：`node _pipeline/tools/validate.js caiwei-jiexuan/index.html` → **✓ 校验全部通过**；`node caiwei-jiexuan/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 逐境 build/update×400 帧 → fadeK 合规 → 末境点击门控 → 自动游览至终章 → 小测满分）；`node _pipeline/accept.js caiwei-jiexuan` → **ACCEPT（4境 · 水墨夜思）**。
- 实拍：`shots.py` 封面/四境/终章逐张人工检查通过；标志性瞬间（境壹↔境贰同位四时对切、境④点击→春柳淡现与雨雪交叠）以点击探针实拍确认可见——据实拍迭代修掉「柳树远小不可读」「雪几乎不可见」「路面近景黑成空洞」「月亮过大过亮不合雪天」「远村被雾吞没」等穿帮后，临时截图与探针脚本已删除。
