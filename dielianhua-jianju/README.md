# 蝶恋花·槛菊愁烟兰泣露 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《蝶恋花·槛菊愁烟兰泣露》（宋·晏殊）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**水墨夜思**赛道——全套冷银水墨色板，冷月是唯一主角；「朱户」的深朱门扇取自词面本身，是全页唯一接近暖色的字（刻意去饱和压暗，不作金色/艳色）。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"独上高楼"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：镜头升高、望尽天涯——天际一线微光、路面月光铺开、远雾让开，钟磬余响与「望尽天涯路」题字同现
- 末章：全词回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#9ab8d8`（accent/按钮/边框/进度点/题字，全部银蓝水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#0e141f`～`#101622`，fd 0.0048–0.0060 |
| 月 | 冷银白（ms 1.55–2.0），全页唯一主角；境①放大至 ms 2.0 正对"明月不谙离恨苦"；星稀（亮度 0.42–0.5） |
| 粒子母题 | 光柱浮尘、兰上露珠、离枝碧叶（下落）、横流西风（替代金色流萤/火星） |
| 唯一非冷色 | 境①朱楼门扇「朱户」：深朱 `#5e2823`（去饱和、只在月光光柱尽头出现）——词面自有之物，非装饰 |

**有意的设计**：境①的"斜光到晓穿朱户"做成一柱从门楣斜落床前的冷月光柱（自定义着色器，亮度以"到晓"的节奏极缓呼吸，地面光池随之缓移），是"明月不谙离恨苦"的视觉化——月无情，光有痕；而朱户的深朱只在光柱尽头被"照出来"，暗合"照着彻夜无眠的人"。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，水墨赛道清朗男声）：

- `00.mp3` 题名（诗题自动提取："蝶恋花·槛菊愁烟兰泣露"）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字处理（`tts.json`，sub 非空即完全接管）：「槛菊愁烟」之「槛」读 jiàn（栏杆义，替换表 `槛菊愁烟→鉴菊愁烟` 同音同调钉音）；「明月不谙」之「谙」读 ān（钉为 `不谙→不安`）。其余自查：凋 diāo、露 lù、斜 xié（统编教材正音）、长 cháng（山长水阔）、燕 yàn、泣 qì、笺 jiān 均为神经语音默认正确读音，未钉。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"如果连月光都'不懂'你的愁，那是什么滋味？"再入境①，看月光穿朱户的光柱，对照"明月不谙离恨苦"的"无理之妙"（怨月正是情深）。
2. **境①意象**：槛菊（栏杆边含愁如雾的菊）、兰泣露（露如泪滴）、燕子双飞（反衬人的孤单）、月光到晓（人彻夜未眠）——让学生在画面里逐一对号。
3. **境②动作**：先看"西风凋碧树"的落叶纷脱，再点击登楼，体会"独上高楼"的开阔与孤清——为什么会"望尽"？望到了吗？（路上只有远行的小影，路尽是水。）
4. **文学常识**：王国维《人间词话》以此词下片三句为"古今成大事业、大学问者的第一境"——登高望远、明确方向；可顺势介绍治学三境界。
5. **收束**：末章全词连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、典故常识 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。

- 交互境序号 `curIdx===2`（pointerdown + 空格双接线；空格首次触发交互、交互后再按才进终章，`clicked` 标志 + 1.2s 冷却门控）。
