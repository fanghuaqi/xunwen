## 课堂建议

1. 先整体自动游览一遍（自动朗读默认开），感受"倔强清瘦"的基调渐变（宣纸→灰岩→风起）。
2. 第二境提问：根须是怎么"钻"进石缝的？（观察裂纹与根的生长方向）
3. 第三境让学生连点唤风，数一数四个方向，体会"任尔"的语气；随后做学习小测（5 题：接龙×2、读音×1、文学常识×1、主旨×1）。
