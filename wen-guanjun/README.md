# 循文入境 · 闻官军收河南北（唐 · 杜甫）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（需联网加载 Three.js，音频本地播放）。

## 使用

- **入境**：封面点「入境」；`← →` 键 / 空格 / 底部按钮逐境游览；右上进度点可跳境。
- **第四境「归乡航线」**：点击画面或按空格——巴峡→巫峡→襄阳→洛阳四站依次点亮，镜头沿航线飞掠还乡，到站题字「青春作伴好还乡」（有冷却防连点）。
- **朗读**：自动朗读默认开；Edge 下用神经语音现场逐句朗诵，其余浏览器播放 `audio/` 内置配音，失败自动回退系统语音。
- **自动游览**：底部「自动游览」开关打开后无人值守走完全程，适合作课堂大屏。

## 教学要点（注音 / 考点）

- **裳 cháng**：古指下身穿的裙，「初闻涕泪满衣裳」不读轻声 shang。
- **卷 juǎn**：「漫卷诗书」为卷起之义，不读 juàn。
- **还 huán**：「好还乡」返回故乡，不读 hái；**好 hǎo**＝正好。
- **青春**＝明丽的春色（古今异义）；**妻子**＝妻子和孩子（古今异义）。
- 背景粘识：安史之乱（755–763）终结于 763 年春，杜甫流寓梓州闻捷，被誉为「生平第一快诗」。
