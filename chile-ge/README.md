# 循文入境 · 敕勒歌（北朝民歌）

双击 `index.html` 即可打开（首次需联网加载 Three.js，音频已本地化）。

## 四境
1. **阴山下** —— 敕勒川平铺脚下，阴山横陈天际
2. **穹庐笼野** —— 半透明穹庐天幕罩住四野（经纬网格），地上毡帐与天呼应
3. **天苍野茫** —— 超广角草海，天色青苍、旷野无际
4. **风吹草低** —— 互动境：点击画面（或空格）唤起一阵大风，草浪伏低、牛羊群从草中浮现，题字「风吹草低见牛羊」

## 使用
- 自动游览 / 自动朗读默认开启，可直接作课堂大屏无人值守展示；← → 键或空格逐境
- 朗读优先级：浏览器神经语音现场朗诵 → `audio/00-05.mp3`（00 标题、01-04 各句、05 全诗）→ 系统语音
- 若删掉 `audio/` 目录或文件缺失，页面自动回退浏览器语音（Edge 下效果最佳）

## 注音考点（多音字）
- 勒 **lè**（敕勒）、穹 **qióng**、庐 **lú**、笼 **lǒng**（笼盖）、见 **xiàn**（同「现」）
- 音频已按 lǒng / xiàn 定音（朗读文本中以同音字替代，页面文字不受影响）

## 教学建议
- 先读后游：每境先齐读诗句，再看画面如何「演」出诗意
- 第二境问：天像什么？为什么游牧人把天比作穹庐？
- 第三境体会「苍苍 / 茫茫」叠词的空阔感
- 第四境点拨「见 = 现」：风吹草低，牛羊才「显现」——动静之间见生机
- 结课用「学习小测」5 题检验（接龙 ×2、读音、词义、主旨）
