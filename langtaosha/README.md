# 循文入境 · 浪淘沙（其一）· 刘禹锡

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，首次打开需联网；朗读与音频本地）。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 九曲黄河 | 九曲黄河万里沙 | 黄昏金浪，河心沙洲分出辫状水道，昏日低垂 |
| 贰 · 浪淘风簸 | 浪淘风簸自天涯 | 入夜风起，巨浪白沫自天涯浪墙滚来（镜头贴浪） |
| 叁 · 直上银河 | 如今直上银河去，同到牵牛织女家 | **点击画面**：黄河化作星河升空，直抵牵牛、织女双星 |

美术：大漠金戈变体（赭金 `#d9a05a`）——黄昏 → 风夜 → 星空的逐境天色渐变。

## 课堂使用

- `← →` / 空格逐境推进；**第三境点击画面（或空格）触发"直上银河"升空动画**
- 「自动游览 + 自动朗读」默认关播时开启即可无人值守放映；注音、朗读、音效均可单独开关
- 每境自带释义与注释（含考点：曲 qū、簸 bǒ、天涯、牵牛织女典）；结课有 5 题小测
- 配音 `audio/00–04.mp3`（百度 TTS，多音字已按 SUB 表校正）；Edge 下自动优先神经语音现场朗诵
