# 循文入境 · 泊船瓜洲（宋 · 王安石）

三境沉浸式诗词网页（Three.js r128 单文件）。双击 `index.html` 打开（首次需联网加载三维引擎）。

## 游览
- 入境后自动朗读、可开自动游览；`← →` 或空格逐境。
- 境次：**一水两岸**（泊船瓜洲、隔水数重钟山）→ **春风绿岸**（"绿"的蔓延：绿意自岸边一株草沿江岸染绿整岸）→ **明月照还**（点击画面/空格：明月升起 + 水面铺出银色归途光道 + 题字）。
- `audio/00–04.mp3` 为 AI 朗读（00 标题、01–03 各句、04 全诗）；缺失时自动回退浏览器语音。

## 教学要点
- 多音字按教材标注：间 **jiān**、数 **shù**、重 **chóng**、还 **huán**（页面逐字注音 + 注释均已标明）。
- 小测 5 题：接龙 ×2、多音字读音、炼字（"绿"作动词）、主旨（思归）。
- 课堂大屏可无人值守：自动朗读 + 自动游览默认开启。
