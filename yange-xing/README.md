# 燕歌行 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《燕歌行》（唐 · 高适，queue no.263）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**大漠金戈**赛道——但刻意避开既有边塞页的构图（不做拂晓誓师整甲、不做木兰人生长卷、不做骨梦对切、不做金甲烽燧、不做密林夜射/雪原听笛），写的是这首盛唐边塞七古的**牙帐一顶定褒贬**：烟尘汉家（出征）→ 萧条边庭（危局·帐内帐外对切）→ 两地悬望（征人思妇）→ 白刃沙场（死节收束）。accent=#b8906a（queue 分配强调色）只落在 UI/人物边缘光/旗面光边/帐内暖光/白刃寒光上，禁艳金；战争意象克制写意，无血腥直写。

## 教学建议

1. **导入**：先只读「战士军前半死生，美人帐下犹歌舞」——问学生：这两句写的是同一个地方的同一个时刻吗？带着"一半是海水、一半是火焰"的错位感进境贰。
2. **梳理结构**：出征（壮）→ 危局（酷）→ 悬望（思）→ 白刃（烈），四境正好是起承转转合；让学生找每一境里"最锋利的一句"，体会讽刺藏在对比里而不在议论里。
3. **对读**：「身当恩遇常轻敌」回应开头「天子非常赐颜色」——恩遇愈重，轻敌愈骄，士卒愈苦；「至今犹忆李将军」与眼前将帅对读，讽今之意尽在言外。
4. **朗读处理**：「摐金伐鼓」读出声威；「半死生／犹歌舞」两句之间停半拍，让对比立起来；「君不见」三字放长；末句「至今犹忆」放缓收束。
5. **背景讨论**：开元二十六年张守珪部先胜后败却谎报战功——高适以乐府旧题写时事。讨论：诗人替谁说话？"死节从来岂顾勋"的"岂"字里有什么？
