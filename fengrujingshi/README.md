# 循文入境 · 逢入京使（唐 · 岑参）

单文件沉浸式诗词课件：两境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 大漠金戈·驿路变体：漫漫驿路上的匆匆一瞬——全集篇幅最短的一页，28 字写尽乡思与豁达。
> 标志性瞬间：马上相逢无纸笔——两骑西东相逢于驿路，一句口信抵万金家书。

## 两境

| 境 | 诗句 | 画面 |

| 壹 · 东望泪湿 | 故园东望路漫漫，双袖龙钟泪不干 | 驿路伸向东方地平，烽燧疏柳，诗人勒马东望（背影） |
| 贰 · 马上传语 | 马上相逢无纸笔，凭君传语报平安 | **标志性瞬间**：两骑相逢首相对（**点击画面**：口信化作一线飞鸿北去；空格先交互、再按进终章） |

## 操作

- `← →` / 空格：切境（末境空格 = 触发交互，交互过后再按进终章）
- 自动游览、自动朗读默认开启，可一键关

## 教学建议

- 「龙钟」的本义辨析：泪流纵横沾湿（本诗）vs 老态龙钟（现代常用义）
- 对比手法：前句的「泪不干」与后句「报平安」——乡思与豁达并存，才是真实的岑参
- 「马上相逢无纸笔」的生活细节：不做作、不煽情，口信最见真情
- 注音考点：故园 gù、漫漫 màn màn、双袖 xiù、龙钟 lóng zhōng、泪不干 gān、相逢 féng、纸笔 zhǐ bǐ、凭 píng、传语 chuán yǔ
- 背景：岑参两度出塞，此诗作于赴安西途中（约天宝八载）
