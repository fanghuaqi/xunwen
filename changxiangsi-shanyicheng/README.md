# 长相思·山一程 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《长相思·山一程》（清·纳兰性德）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**大漠金戈**赛道的夜行营变体——雪夜军营、落雪与千帐灯是两大视觉系统，帐灯暖光是全页唯一的暖色。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"点亮千帐灯"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：帐灯连绵铺向关外，风雪声渐起，"故园无此声"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：大漠金戈 · 夜行营（art-direction 赛道⑤）

| 项 | 取值 |
|---|---|
| 底色 | `#120d08`（夜行营） |
| accent | `#b8905f`（帐灯/灯杆/人物边缘光，取自 queue；**全页唯一暖色**） |
| 文字 | `#f0e2cc` |
| 雾 | `#1a120a` 系，fd 0.0052–0.0068 |

| 星 | 境①晴夜 0.30，境②风雪 0.10 |
| 粒子母题 | 落雪（自写 SNOW 着色器，uWind 风漂）、千帐灯灯海（自定义 aT/uExt 灯阵着色器）、风雪横流、低雾 |

**有意的设计**：全页只有一处暖色系统——帐灯（帐门暖光、灯杆灯笼、灯海点阵，色 `#ffb45c/#ff9a4a/#ffb060`）。境①"夜深千帐灯"里它铺满雪原是天涯的壮阔；境②点击后灯阵连绵点亮、风雪声（ambience 噪声）渐起，正是"故园无此声"的反面——天涯愈喧，愈显故园之静。

## 教学建议

1. **导入**：讲本事——康熙二十一年纳兰性德以御前侍卫扈从康熙帝东巡祭祖、出山海关，夜里宿在军营；让学生设想"军营的夜"是什么样子，再看封面画面。
2. **境①叠句**：「山一程，水一程」让学生跟着数一程又一程，体会路途之长；再看"夜深千帐灯"，讨论为什么这五个字被王国维推为近于"千古壮观"。
3. **境②叠句**：「风一更，雪一更」对照上片——空间的长换成时间的长；点击画面听"风雪声起"，再问：故园的夜里有什么声音？
4. **收束**："夜深千帐灯"的壮阔与"故园无此声"的柔软对照，正是乡心的两面；末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、本事 ×1、主旨 ×1）。
5. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 两境），境名逐一对齐；`N=2`，边界常量（clamp/dots/末境判断/音频编号 03）全部对齐。
- 交互境序号 `curIdx===2`（pointerdown + 空格双接线，空格先交互再进终章，click 带 1.2s 冷却与 clicked 标志）。
