# 宿建德江 · 循文入境（孟浩然）

单文件沉浸式诗词课件：`index.html` 双击即开（Three.js 走 CDN，首次打开需联网；朗读音频在本地 `audio/`）。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 泊渚愁新 | 移舟泊烟渚，日暮客愁新。 | 客舟泊进烟渚，芦苇暮雾，愁绪如灰蓝轻雾漫江 |
| 贰 · 野旷天低 | 野旷天低树， | 低机位望旷野：疏树剪影挑在地平线上，远天低垂 |
| 叁 · 江清月近 | 江清月近人。 | 标志瞬间：镜头贴水，水中月影随波轻晃；**点击画面/空格**，月影漂近船舷、水面碎金、题字"江清月近人" |

美术：烟雨江南·烟渚暮江变体（日暮泊舟），底色 `#10141a`、强调色 `#8fb0c4`。

## 使用

- `入境` 进入；`← →`/空格逐境；末境可点击画面唤月影近船。
- 顶部按钮：自动游览 / 自动朗读 / 注音 / 声音 / 全屏，可作课堂大屏无人值守展示。
- 朗读优先 Edge 神经语音现场朗诵；否则播 `audio/00–04.mp3`（00 标题、01–03 各境、04 全诗）。

## 教学

- 注音：渚 zhǔ、泊 bó（多音字考点，音频已按 bó/zhǔ 生成）。
- 情感线：客愁（孤）→ 旷远（寂）→ 月近（亲），末句"近"字是全诗诗眼。
- 终章附 5 题小测（接龙、读音、词义、名句理解）。
