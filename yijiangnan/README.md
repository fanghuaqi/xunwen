# 循文入境 · 忆江南（唐 · 白居易）

单文件 Three.js 沉浸式诗词课件：词句逐境推进，3D 实景随诗意展开，含注音/释义/注释/AI 朗读/自动游览/结课小测。

## 使用

双击 `index.html` 即可（首次需联网加载 Three.js，音频本地播放）。
操作：`←` `→` 键或空格逐境游览；**第三境可点击画面（或按空格）再燃日出**——旭日跃出江面，花更红、水更绿，题字「能不忆江南」。

## 三境

| 境 | 词句 | 画面 |
|---|---|---|
| 壹 · 江南好 | 江南好，风景旧曾谙。 | 晨江初醒：青绿远山、柳岸花洲、远舟一叶、花瓣缓落 |
| 贰 · 江花胜火 | 日出江花红胜火，春来江水绿如蓝。 | 标志瞬间：旭日跃出江面，江畔花丛染成胜火之红，春水绿如蓝草，红绿交辉 |
| 叁 · 忆江南 | 能不忆江南？ | 回忆滤镜下的浓色江南（点击画面：再燃日出 + 花更红水更绿 + 题字） |

## 教学建议

- 注音已按教材读音核对：**谙 ān**（熟悉）、**蓝 lán**（蓝草，可制青绿色染料）、不 bú（变调）。
- 小测 5 题覆盖：接龙 ×2、读音、文学常识（白居易）、反问句主旨。
- 「自动游览 + 自动朗读」默认开，可作课堂大屏无人值守展示；`audio/` 为 AI 配音（00 标题、01–03 各句、04 全诗），删除该目录可回退浏览器神经语音现场朗诵。
- 美术：青绿春晓赛道变体「青绿春晓·日出江花」，主色 #9fce8f、强调色 #d88a6a（陶红），底色 #0a1410。
