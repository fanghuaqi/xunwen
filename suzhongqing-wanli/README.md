# 诉衷情·当年万里觅封侯 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《诉衷情·当年万里觅封侯》（宋·陆游）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**大漠金戈**赛道——放翁暮年壮志，苍茫悲壮；全页情绪轴是**梦里大漠金戈的暖亮 vs 现实沧洲渔屋的冷灰**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境③为"点击貂裘"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境③轻点画面（貂裘）：尘光自裘上浮起，天山侧年少戎装的「对影」显形，与沧洲老人隔水相望，"心在天山，身老沧洲"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：大漠金戈（art-direction 赛道⑤）

| 项 | 取值 |

| 主色 | `#b0906a`（queue 分配 accent，人物边缘光/旗纹/烽火光池/衣架裘色，禁艳金） |

| 月 | 低垂昏黄（境②藏月 ms 0.001，冷窗微光代月） |

**有意的设计**：境①（梦）是全页最暖最亮的一境——金黄暮色、烽燧火光、战旗军阵；境②骤然转冷（灰墙冷窗、尘封貂裘），境③冷灰水乡与冷白雪岭同框。读者凭"温差"直接读出梦与醒、心与身的撕裂。

## 教学建议

1. **导入**：封面设问"一位 65 岁的老人夜里做梦，会梦见什么？"再入境①，对照画面讲乾道八年南郑从军（1172，陆游 48 岁）。
2. **境①→②温差**：先看梦里金戈的暖亮，再切到尘暗貂裘的冷，让学生用自己的话说出"梦醒之后少了什么、多了什么"。
3. **境②三字句**：结合注释读"胡未灭，鬓先秋，泪空流"，抓"先""空"二字——岁月不待人、报国无门。
4. **境③地理撕裂**：让学生在画面里分别指出"天山"与"沧洲"，再讲薛仁贵三箭定天山之典与晚年退居山阴；对照《十一月四日风雨大作》"僵卧孤村不自哀，尚思为国戍轮台"。
5. **收束**：点击貂裘看"两地对影"，末章全词连读，再做 5 题小测（接龙 ×2、词义 ×1、典故 ×1、主旨对照 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 三境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=3` 对齐。
- 交互境序号 `curIdx===3`；末境 `click` 带 1.2s 冷却与 `clicked` 标志，空格首次触发交互、再按进终章。
- 自定义构件：军马、貂裘衣架、茅屋、渔舟、烽燧、台地、战旗、关城；每境 `makeRange`（背景）+ `makeForeground`（前景）+ `makeFigure`（人物）三层构图齐备。
- 校验：`node _pipeline/tools/validate.js suzhongqing-wanli/index.html` → **✓ 校验全部通过**（零警告）。
- 冒烟：`node suzhongqing-wanli/smoke.test.js` → **SMOKE PASS**（boot → 四境 build/update×400 帧 → 末境点击门控与 pointerdown → 自动游览至终章 → 小测全流程 → fadeK 合规，多轮稳定）。
- 实拍：封面与三境已逐张人工检查（构图/雾预算/主体可读性），末境点击后尘光与对影显形已实测。
