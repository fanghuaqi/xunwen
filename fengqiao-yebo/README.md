# 循文入境 · 枫桥夜泊（唐 · 张继）

单文件沉浸式诗词课件（Three.js r128 UMD，双击 `index.html` 即开；首开需联网加载引擎，cdnjs→jsdelivr→unpkg 三路回退）。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 月落霜天 | 月落乌啼霜满天 | 残月贴水西沉，寒鸦掠过，霜华漫天，江面月光道 |
| 贰 · 渔火愁眠 | 江枫渔火对愁眠 | 客船泊岸、两岸江枫剪影，岸边四点渔火（全页唯一暖色），愁绪如雾东流 |
| 叁 · 夜半钟声 | 姑苏城外寒山寺，夜半钟声到客船 | 远处寒山、寺塔山门与姑苏城墙剪影；**点击画面/按空格敲响夜半钟声**——声波涟漪自寒山寺沿水面扩散到客船，WebAudio 低频铜钟 |

## 操作

- `← →` 键或空格逐境；`Esc` 退出终章/小测；顶部圆点可直接跳境。
- 自动游览、自动朗读默认开启，可一键关闭（适合课堂大屏无人值守）。
- 朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音。

## 音频

`audio/00-04.mp3`（00 标题、01-03 各境、04 全诗），由 `gen-voice.js`（本诗定制副本）生成，多音字表已将「泊」读作 **bó**。删除 audio/ 目录可回退浏览器语音。

## 注音自查

泊 bó（诗题）· 寺 sì · 啼 tí · 眠 mián —— 逐字核对，拼音数与汉字数一致（validate.js 强制）。

## 教学建议

先整读一遍 → 逐境入境，每境停留讲释义/注释（第三境讲"以声衬静"）→ 让学生亲手"敲钟"体会羁旅清愁 → 结课 5 题小测。
