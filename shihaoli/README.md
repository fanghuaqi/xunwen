# 循文入境 · 石壕吏（唐 · 杜甫）

单文件沉浸式诗词课件：五境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 水墨夜思·乱世变体：「三吏三别」之首——全集唯一以"无声"收束的页面（点击末境，夜去天明）。
> 标志性瞬间：吏呼一何怒！妇啼一何苦！——怒吼与啼哭在夜里对撞。

## 操作

- `← →` / 空格：切境（末境空格 = 触发交互，交互过后再按进终章）
- 自动游览、自动朗读默认开启，可一键关
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置 MP3 → 系统语音
- `audio/00–06.mp3`：题名、五境、全诗（云健·沉厚男声，语速 −16%；`tts.json` 多音字替换只影响读音）

## 教学建议

- 「藏问于答」的叙事技巧：差吏的话被省略，从老妇致词反推——让学生补出差吏问了什么
- 「独与老翁别」的「独」：照应开头「老翁逾墙走」，老妇已代夫从军——一字千钧
- 「三吏三别」背景：乾元二年唐军九节度兵败邺城，朝廷强行补兵——诗史之笔
- 注音考点：石壕 háo、老翁逾墙 yú、吏 lì、一何 nù、啼 tí、邺城戍 yè chéng shù、更无人 gèng、乳下孙 rǔ、老妪 yù、河阳役 yì、备晨炊 bèi chén chuī、泣幽咽 yōu yè
- 体裁：五言古诗（叙事诗）；杜甫「诗史」的代表篇目
