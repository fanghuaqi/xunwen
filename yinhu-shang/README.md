## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 潋滟晴光 | 水光潋滟晴方好 | 阳光下湖面碎金波光（粼粼高光粒子随波闪烁 + 暖金波光道），白鹭掠湖 |
| 贰 · 空蒙雨意 | 山色空蒙雨亦奇 | 细雨斜织，远山被雨雾洇成层次分明的水墨剪影，小舟浮烟波 |
| 叁 · 淡妆浓抹 | 欲把西湖比西子，淡妆浓抹总相宜 | 一半晴妆一半雨抹的对切画面；**点击画面 / 空格 = 晴↔雨互换**（天空、水色、波光、雨丝、雾全程渐变），题字「淡妆浓抹总相宜」 |

## 教学建议

- 先看壹境问「晴天西湖美在哪」，再看贰境问「雨天呢」，最后用叁境的晴雨互换让学生自己说出「总相宜」的意思。
- 小测第 1 题的干扰项「卷地风来忽吹散」出自苏轼《六月二十七日望湖楼醉书》，可顺势对比两首写西湖晴雨的诗。
