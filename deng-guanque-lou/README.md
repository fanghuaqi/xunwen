# 循文入境 ·《登鹳雀楼》王之涣

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js r128 走 CDN 三路回退，首次打开需联网；音频为本地 MP3）。

## 使用

- 双击 `index.html` → 点「入境」→ 自动朗读 + 自动游览全程无人值守（均可一键关）。
- `← →` 键或空格逐境游览；**第三境「更上层楼」可点击画面 / 按空格再上一层楼**：镜头抬升后拉、天际线再拉远、题字"更上一层楼"闪烁 + 上行阶音。
- 朗读优先级：Edge 在线神经语音现场朗诵 → 内置 `audio/*.mp3` → 系统语音兜底。
- `audio/`（00 标题 + 01..03 各句 + 04 全诗，共 5 个）由共享 `gen-voice.js` 生成；`smoke-test.js` 为结构冒烟测试（真实 THREE r128 无头执行全部 build/update/click/goto）。

## 三境设计（情绪曲线：苍茫 → 奔涌 → 辽阔）

| 境 | 诗句 | 画面 | 天色 |
|---|---|---|---|
| 壹 | 白日依山尽 | 凭栏西望：白日缓缓沉入中条山脊（随 stageT 下沉），前景檐角剪影作画框，金尘暮霭、鹳鸟掠空 | 落日赭金（fd 0.006，星 0.1） |
| 贰 | 黄河入海流 | 俯瞰浊金大河奔向海天一线：双层水面（金河带 + 墨蓝海面）、浪沫、落日余晖光道；水声 ambience 0.14 | 暮霭转浓（fd 0.009） |
| 叁 | 欲穷千里目，更上一层楼 | **标志性瞬间**：三层木构鹳雀楼（台基+平座栏杆+飞檐+直棂窗+攒尖顶），镜头随诗从楼下逐层爬升至顶层，天际线逐层拉远、星光渐现，每掠过一层檐口一声阶音 | 高处澄澈（fd 0.005，星 0.32） |

封面：黄昏远景，楼影立于河畔、绕楼鹳鸟（楼以鸟名）、余晖金道。

## 美术方案（防同质化）

- 风格赛道：**大漠金戈 · 落日楼台变体（黄昏登楼）**——bg `#120d08`、强调 `#d9a05a`、文字 `#f0e2cc`、雾 `#1a120a`。与同赛道的《观沧海》（沧海台地、日月星汉）区分：本诗主视觉是**一座多层木构高塔居中，落日黄河在楼外**；无雪、无战场、无银河，基调苍茫开阔。
- 与《将进酒》并排一眼可辨：无鎏金宴饮、无金色流萤大月；母题是**落日、飞檐剪影、浊金河水、绕楼鹳鸟**。
- 自创新 builder：`makeTower`（三层木构楼：台基/柱列/扁四棱锥飞檐/发光直棂窗/塔刹）、`makeSunSet`（白日亮盘+双层辉光，随诗句沉落）、`makeStorks`（绕楼鹳鸟）、`makeEaveFg`（前景檐角画框）、`bClimb`（逐层爬楼：cam 22s 从楼下升至顶层 + `camLift` 交互抬升机制 + 天际线随 spread 拉远）。
- 引擎微调：`makeWater` 新增 `moonColor`（落日金光道）；主循环新增 `driftS`（每境镜移时长）与 `camLift`（点击抬升注入相机）。

## 教学要点

- 注音考点：穷 qióng（尽，使达到极点，非"贫穷"）、雀 què（鹳雀为水鸟，楼以鸟名）、依 yī、尽 jìn、更 gèng；「一层」按教材变调注 yì。
- 名句理解："欲穷千里目，更上一层楼" = 站得高才能看得远，常用作进取精神的格言；前两句写实景、后两句由实入虚。
- 小测 5 题：接龙 ×2、读音（雀 què）×1、作者（王之涣）×1、名句道理 ×1；评语按本诗定制（"胸有千里目，更上层楼"）。
- 适合课堂大屏：自动游览 + 自动朗读约 2 分钟走完封面 → 三境 → 终章全诗。
