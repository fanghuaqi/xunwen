# 循文入境 · 短歌行（汉 · 曹操）

单文件沉浸式诗词课件：六境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 夜宴金彩·建安变体：铜鼎列樽的军帐夜宴起笔，收束于山海归心的旷野 —— 金彩之下压着朝露般的忧思。
> 标志性瞬间：月明星稀之下，一株孤树、数点鸦影绕树三匝、四野苍茫。

## 六境

| 境 | 诗句 | 画面 |
|---|---|---|

| 贰 · 青衿沉吟 | 青青子衿……沉吟至今 | 月下按剑独立，一列青衿身影自远方小径循光而来 |
| 叁 · 鹿鸣嘉宾 | 呦呦鹿鸣……鼓瑟吹笙 | 原野鹿群食苹，席上鼓瑟吹笙、篝火夜宴 |
| 肆 · 明月可掇 | 明明如月……心念旧恩 | 高台指月，明月高不可掇；田陌纵横、故人越陌度阡 |

## 操作

- `← →` / 空格：切境（末境空格 = 触发交互，交互过后再按进终章）
- 自动游览、自动朗读默认开启，可一键关
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置 MP3 → 系统语音
- `audio/00–07.mp3`：题名、六境、全诗（云健·沉厚男声，语速 −12%；`tts.json` 多音字替换只影响读音）

## 教学建议

- 用典链是本诗主线：《子衿》思贤才 → 《鹿鸣》宴嘉宾 → 周公吐哺表诚意，三层用典都指向"求贤"
- "月明星稀，乌鹊南飞"：以景语作情语，乌鹊即贤才，"何枝可依"是全诗最深的忧虑
- "山不厌高，海不厌深"化用《管子》，与"周公吐哺"一虚一实收束全诗
- 注音考点：譬如朝露 zhāo、慨当以慷 kāng、子衿 jīn、呦呦 yōu、鼓瑟 sè、何时可掇 duō、越陌度阡 mò qiān、绕树三匝 zā、吐哺 tǔ bǔ
- 异文说明：语料库古本一作"谈宴"，本页从现行教材本作"谈䜩"（yàn，同"宴"）；网页字体缺字时会回退系统字体显示
