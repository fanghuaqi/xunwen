# 循文入境 · 相见欢（五代 · 李煜）

单文件沉浸式诗词课件：四重意境随词句推进，三维实景 + 逐字注音 + 释义注释 + AI 朗读 + 结课小测。

## 使用

- 双击 `index.html` 即可打开（需联网加载 Three.js；音频在本地 `audio/`）。
- `←` `→` 键或空格逐境游览；第四境「滋味心头」可点击画面 / 按空格，剪一剪这团剪不断的离愁。
- 控制条可开关：自动游览、自动朗读、注音、声音、全屏。开自动游览可作课堂大屏无人值守展示。

## 四境一览

| 境 | 词句 | 画面 |
|---|---|---|
| 独上西楼 | 无言独上西楼，月如钩。 | 孤影沿石阶默默登楼，一弯如钩残月悬空 |
| 深院锁秋 | 寂寞梧桐深院锁清秋。 | 四面高墙缓缓围拢压向中心，"锁"字具象化 |
| 剪理离愁 | 剪不断，理还乱，是离愁。 | 灰色丝缕垂落绞缠成乱团，剪刀剪而不断（标志瞬间） |
| 滋味心头 | 别是一般滋味在心头。 | 离愁乱丝悬在楼头孤影胸前，点击剪刀剪而复合，题字"是离愁" |

## 朗读配音

`audio/00..05.mp3` 由 AI 生成（00 标题、01-04 各句、05 全诗）。删除 `audio/` 目录后，页面在 Edge 浏览器下自动回退为"在线自然语音"逐句现场朗诵。

## 教学建议

- 先整体自动游览一遍，再逐境精读；重点品味"锁"字（囚居处境）与"剪不断，理还乱"（以丝喻愁）。
- 小测 5 题覆盖：下句接龙 ×2、多音字"还 hái"、词人称号（南唐后主）、修辞理解（以丝缕喻离愁）。
- 拓展对比：李煜《虞美人》"问君能有几多愁，恰似一江春水向东流"——同样写愁，一喻乱丝、一喻江水。
