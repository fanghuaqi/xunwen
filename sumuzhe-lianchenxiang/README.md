# 苏幕遮·燎沉香 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《苏幕遮·燎沉香》（宋·周邦彦）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**青绿春晓**赛道——雨后初晴的荷塘晓色，青绿底上唯一的暖是初阳与灯火；「水面清圆，一一风荷举」是全页的标志性瞬间。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为「宿雨滚落，风荷次第挺举」）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：宿雨从叶心滚落、荷叶次第挺举，轻舟摇入荷荡深处，芙蓉色天光渐亮
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：封面设问「雨后的荷塘是什么样？」再入境①，对照画面讲「燎沉香、消溽暑」的梅雨时节背景。
2. **境①炼字**：让学生听雀鸣看檐雀，体会「呼」「窥」的拟人之妙——鸟雀也通人性。
3. **境②词眼**：看荷由垂而举的延时动画再读「水面清圆，一一风荷举」，结合王国维「真能得荷之神理」评语，讲「干」「举」二字为何不可替换。
4. **境③转折**：荷塘越清新，「故乡遥，何日去」越沉重；讨论「不问家人偏问渔郎」的无理而妙。
5. **境④收束**：点击触发梦境化转场后，讨论「身不能至、魂梦先往」的虚实相生。
6. 课堂大屏可开「自动游览 + 自动朗读」无人值守循环展示。
