# 蒹葭 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《蒹葭》（先秦·诗经·秦风）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**烟雨江南**赛道——但刻意避开既有烟雨江南页的构图（不做深巷小楼杏花雨、不做十里柳堤六朝残影、不做客舟酒楼樱桃芭蕉），写的是这首千古朦胧诗的**一水三岸、伊人宛在**：秋晨水泽苇荡，霜白烟水，一个半透剪影的伊人立于水上（含蓄无面目），一叶苇舟与一条蜿蜒的溯洄水路贯穿。accent=#8fb3c9（queue 分配强调色）只落在 UI/伊人边缘辉光/水路光痕/露光/苇尖霜光上；霜白 0xcadbe6 系为本诗独有的冷白。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境③为"溯洄溯游"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境③轻点画面：一叶苇舟载着溯洄之人沿水路前行（水路光痕依次点亮），伊人若近若远；近前又终不可至，舟循溯游而返——"所谓伊人 宛在水中央"题字同现，可反复点击
- 末章：全诗回放、学习小测（5 题）

## 美术方案：烟雨江南 · 秋水苇荡变体（art-direction 赛道⑥）

| 项 | 取值 |
|---|---|
| 底色 | `#10141a` |
| 主色 | `#8fb3c9`（黛蓝，queue 分配强调色；按钮/边框/进度点/题字/边缘光/水路光痕） |
| 文字 | `#e6ecef` |

| 月 | 淡月高悬（ms 0.26–0.34，mhaze 0.12），水面留一道月光池——伊人立于光池之上；星稀（0.05–0.08） |
| 场景母题 | **伊人剪影**（半透淡青白深衣、顶髻、垂袖，呼吸式明灭+缓漂）+ **苇叶小舟**（细长无篷）+ **溯洄水路**（CatmullRom 曲线光痕，点击前 `visible=false` 硬关）+ 苇丛/洲坻（自建 builder） |
| 粒子母题 | 水面霜光（为霜）、苇洲露珠微光（未晞/未已）、水泽雾团、夜气浮尘 |
| 与已有烟雨江南页的区分 | linan-chunyu=深巷小楼杏花雨、taicheng=十里柳堤六朝残影、yijianmei-zhouguo=客舟酒楼樱桃芭蕉；本页=**无建筑无市井**——只有水泽苇荡、霜白烟水、一个可望而不可即的伊人 |

**有意的设计**：三章重章叠句 = 三境变奏，三个维度同时在变——①时间递进：白露为霜（霜最重、天最冷）→ 未晞（露未干、天微明）→ 未已（露未收、晨渐亮），雾密度与天光逐境微调；②位置推移：伊人在水中央（远，水光池上）→ 水中坻（左前洲湄）→ 水中沚（近岸小沚），若远若近；③苇色递变：苍苍（灰白）→ 萋萋（灰绿）→ 采采（鲜明），秆色穗色逐境递变。伊人三境同在而总隔一水——「宛」字三见，把可望不可即写进构图本身。

## 教学建议

1. **导入**：先让学生读三章找不同——只换了哪几个字？（苍苍/萋萋/采采，霜/晞/已，方/湄/涘，央/坻/沚，长/跻/右）换字之外，什么没变？——那份追寻与怅惘没变。这就是重章叠句。
2. **境①诗眼**：让学生在画面里找"伊人"——半透剪影、立在月光池上、若隐若现。追问：她真的在水中央吗？一个「宛」字告诉你——"仿佛在那里"。可望而不可即，是全诗的底色。
3. **境②看点**：伊人的位置变了（水中央→水中坻）——空间在推移；露从"为霜"到"未晞"——时间在推移。重章不是重复，是一遍遍逼近又始终追不上。
4. **境③点击后**：让学生替诗人"溯洄"一次——舟行水路、伊人似乎近了，随即又退远；舟溯游而返，她仍"宛在"原处。追问：追不上，诗人为什么还要一遍遍地追？
5. **主旨**：「伊人」是谁？恋人、贤才、理想——朦胧多义；求而不得而不息地求，是中国诗歌里"上下求索"的原型之一（可与《离骚》"路漫漫其修远兮，吾将上下而求索"互文）。
6. **诵读**：全诗四言，二二节拍（蒹葭/苍苍，白露/为霜），三章语速由缓而微扬，末句"宛在水中央/水中坻/水中沚"宜拖长——余味在"宛"字上。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示；末境留 3 秒给学生自己点击溯洄。
