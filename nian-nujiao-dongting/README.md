# 念奴娇·过洞庭 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《念奴娇·过洞庭》（宋·张孝祥）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**水墨夜思**赛道——冷银水墨、全页禁金；「更无一点风色」的静与「素月分辉，明河共影」的澄澈是全页基调，**湖面如镜映月是本页最重要的水面表现**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"点击尽挹西江"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：北斗七星亮起连芒，一柱江水离水斜升入斗（舀江斟月），远岸林木与人影显形为"宾客"，"万象为宾客"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#b8c8dc`（accent 取自 queue；按钮/边框/进度点/题字/人物边缘光，**全页无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#111826` 系，fd 0.0050–0.0068（境③孤光最沉） |
| 月 | 冷银白唯一主角（ms 1.7–2.1，近中秋几乎满圆），星稀；月路（自定义窄带着色器）入水直抵船前 |
| 水 | 镜面：amp 压到 0.08–0.22、flow 近零（"更无一点风色"），月光池落在船畔——一叶浮于一轮月华之上 |
| 粒子母题 | 天上银河带 + 水中河影（境②专属着色器对）、霜晶缓落（境③）、江水入斗的水柱（境④）、贴水横雾（替代金色流萤/火星） |

**有意的设计**：①境「琼田一叶」是标志性瞬间——三万顷玉鉴琼田铺满画面，只浮一叶扁舟、一个坐饮的扁舟客，大小对照即词眼；②境「表里澄澈」用"天上一带河汉、水中一带河影"的着色器对，把"素月分辉，明河共影"拍成可见的水天一色；③境转孤寒——远岭（岭海回望）、薄雾遮月、霜晶缓落，人以冰雪边缘光自证；④境点击后北斗为杯、江水入斗、万象显形，是全词气象的顶点。

## 朗读配音

`audio/` 内置 6 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，水墨赛道自动选声）：

- `00.mp3` 标题（"念奴娇·过洞庭"）
- `01–04.mp3` 四境逐境朗读
- `05.mp3` 全诗连读

多音字以页面拼音为准，`tts.json` 记 4 条同音同调替换：着（zhuó，"着我"→"浊我"）、挹（yì，"尽挹"→"尽意"）、应（yīng，"应念"→"英念"）、浪（láng，"沧浪"→"沧狼"）；"为（wéi）""处（chù）""会（huì）"按常规文读未钉。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：中秋的湖面可以静到什么程度？入境①对照"更无一点风色"，找一找画面里有没有风。
2. **境①名句**：先看画面再读"玉鉴琼田三万顷，着我扁舟一叶"——数一数画面里有几只船，体会"三万顷"与"一叶"的大小对照为何是词眼。
3. **境②炼字**："分辉""共影"好在哪里？看天上河汉与水中河影，理解"表里俱澄澈"既是写景也是写人。
4. **境③知人**：张孝祥因谗被贬岭南——"孤光自照，肝胆皆冰雪"是自证清白；对照"短发萧骚襟袖冷"与"稳泛"的安稳，读出贬谪不改其洁的人格。
5. **境④气象**：点击尽挹西江后，讨论"以西江为酒、北斗为杯、万象为宾"的想象链条——从"不著一字"的静到"吞吐宇宙"的豪，理解"不知今夕何夕"的物我两忘。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
