## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 泉眼惜流 | 泉眼无声惜细流 | 微距湖石泉眼，一缕细流入水，涟漪轻漾 |
| 贰 · 树阴照水 | 树阴照水爱晴柔 | 绿荫俯临水面，光斑浮尘，树影随水轻晃 |
| 叁 · 蜓立荷尖 | 小荷才露尖尖角，早有蜻蜓立上头 | 标志瞬间：小荷出水生长，红蜻蜓落下微颤稳住，水面倒影完整 |

- **互动**：第三境点击画面 / 按空格 —— 蜻蜓重演「落下 → 微颤 → 稳住」并泛起涟漪（5.2s 守卫防连点）。
- **美术**：青绿春晓 · 微距池畔变体 —— 一切小而柔，景深极浅；--gold 强调色 #8fc4c9，底色 #0a1410。
- **朗读**：进入新境 1.6s 后自动朗读；Edge 下优先神经语音现场朗诵，否则播放 `audio/00-04.mp3`（00 标题 / 01-03 各句 / 04 全诗），也可点「朗读此句」。
- **游览**：← → 键或空格逐境；「自动游览 · 开」可作课堂大屏无人值守展示；终章含 5 题小测。

## 教学建议

1. 先整体朗读一遍（封面点「朗读此句」或终章「聆听全诗」），再逐境进入。
2. 第一境让学生找「泉眼 → 细流 → 涟漪」的顺序；第二境问「树阴为什么『爱』晴柔」（拟人）。
3. 第三境等小荷长出、蜻蜓落定后再点击重演，请学生用一个词形容「立」字，体会炼字。
4. 多音字：**露 lù**（才露尖尖角）、惜 xī、晴柔 qíng róu；「树阴」不作「树荫」。
5. 小测可作课堂快练；全诗 3 境约 3 分钟，适合导入或结课环节。
