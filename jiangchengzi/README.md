# 循文入境 · 江城子·密州出猎（宋 · 苏轼）

单文件沉浸式诗词课件：三境随词句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 夜宴金彩·出猎变体：苏轼豪放词的开山之作——千骑卷冈的猎场豪情，酒酣胸胆的自负，西北射天狼的卫国壮志。
> 标志性瞬间：千骑卷平冈——左牵黄右擎苍、锦帽貂裘的太守与飞卷的千骑猎队。

## 教学建议

- 词史地位：北宋词坛以婉约为主流，苏轼此词一出，「令东坡自写，便是一出猎图」，开创了豪放派词风
- 「狂」字贯穿全篇：少年狂（外在装束行动）→ 胸胆开张（内在性情）→ 射天狼（政治抱负与爱国豪情），层层升华
- 典故运用：孙郎射虎（英武）、冯唐持节（盼起用）、射天狼（御敌卫国），用典自然无生硬感
- 注音考点：聊发 liáo、擎苍 qíng cāng、锦帽貂裘 jǐn mào diāo qiú、千骑 jì、平冈 gāng、孙郎 sūn láng、酒酣 hān、鬓微霜 bìn、何妨 fáng、持节 chí jié、冯唐 féng táng、会挽 huì wǎn、雕弓 diāo gōng、天狼 tiān láng
- 背景：宋神宗熙宁八年（1075年）冬，苏轼任密州（今山东诸城）知州，常山祈雨有应后出猎所作
