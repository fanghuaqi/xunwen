# 画菊 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《画菊》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**宣纸留白**赛道——纸底、淡墨远山、疏篱一角与秋菊数丛，全页只留一点暖黄（菊花），其余尽付留白。北风被画成可见的墨色风线：菊丛随风剧烈摇动、花瓣绕枝盘旋，却始终**抱香枝头不落**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击北风"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：风势暴涨（墨色风线加长加速），花瓣绕花盘旋而不离枝，"抱香枝头"题字同现
- 末章：全诗回放、学习小测（5 题）

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 `zh-CN-YunxiNeural`，语速 −18%，宣纸/清冷赛道音色）：

- `00.mp3` 标题（"画菊"）
- `01.mp3` 境壹（花开不并百花丛，独立疏篱趣未穷。）
- `02.mp3` 境贰（宁可枝头抱香死，何曾吹落北风中。）
- `03.mp3` 全篇连读

多音字处理见 `tts.json`（**sub 非空即完全接管**，不再叠加脚本内置兜底表）：

- `宁可` → `佞可`：钉住「宁」的 **nìng**（宁愿），避开「安宁」的 níng —— 本诗第一处读音考点
- `何曾` → `何层`：钉住「曾」的 **céng**（何尝、几曾），避开姓氏/副词的 zēng
- 「花开不并」的「不」在去声「并」前读 **bú**，页面注音已按变调标注
- 其余逐句核过：花开、百花丛、独立、疏篱、趣未穷、枝头抱香死、吹落、北风中——无须干预

页面朗读优先级：Edge 在线自然语音现场逐句朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"如果只给你一丛花和一阵风，怎么写骨气？"再入境壹。
2. **境壹析"不并"**："不并百花丛"是不与人争，"独立疏篱"是自守其位；结合陶渊明"采菊东篱下"，讲菊为何成为高洁的符号。
3. **境贰析"不落"**：先问"菊花真的不会落吗？"（菊残常枯而不落，是自然之性）——诗人偏用"宁可""何曾"两个带强烈选择的词，把自然现象写成一场抉择。
4. **点击体会**：点击北风，看风势暴涨而花仍抱枝，让学生用一句话说"此刻的菊像谁"。
5. **知人论世**：郑思肖，南宋遗民，宋亡后隐居不仕、坐卧不向北，自号"所南"；画菊题诗即以菊自况（"北风"暗喻元朝威压）。
6. **写法小结**：咏物诗"托物言志"——全诗不着一字议论，只写"不并""不落"两件事，气节自在其中。
7. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音义 ×1、典故 ×1、主旨 ×1）。
8. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 36 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（篱、菊、画者）都在 8–20 单位内，fd ≤ 0.0068；北风与绕花之瓣为自定义着色器（`uFade` 受 setFade 控制），墨雾/墨尘不写 opacity，穹顶/远山雾同步齐备。
- 场景构件（冒烟实测）：卷首 16 mesh、境壹 17 mesh / 3 points、境贰 15 mesh / 3 points；draw call 代理值 24 / 26 / 24（≤120），三角面 ≈0.78 / 0.89 / 0.78 万（≤12 万）——宣纸留白赛道最省的一页。
