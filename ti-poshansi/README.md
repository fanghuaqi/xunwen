# 题破山寺后禅院 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《题破山寺后禅院》（唐·常建）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**水墨夜思**赛道——底色 `#0d1117`、雾 `#131a26` 系、accent=`#98aec8`（淡青晨蓝）全页近零饱和；本诗是清晨时相，故以一轮**淡日**替代月（无月，晨光斜柱穿林），讲的是「路越走越深、心越走越静」的一场入寺。

## 美术方案：水墨夜思（art-direction 赛道②·清晨时相变体）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117` |
| 主色 | `#98aec8`（淡青晨蓝，queue 分配强调色；按钮/边框/进度点/题字/初日晕/音波环/人物袍缘，**无一处金色**） |

| 月 | 无（ms 0.001 且移出视野）；各境一轮**淡日**（水墨晨光：纸色日轮+银青晕+斜光柱，`fog:false`） |
| 建筑 | 重檐大殿（境壹主体）、禅房（境贰深处/境④中心，窗纸透晨光） |
| 植被 | 带节竹丛（境贰两侧渐远渐矮）、高林（境壹合抱）、花木（满树花点） |
| 粒子母题 | 花瓣缓落（NormalBlending）、晨雾横腰、微尘浮光 |
| UI | 面板 `rgba(9,13,22,.58)`，银青辉光，竖排诗句+逐字注音 |

**有意的设计**：全页近零饱和——「初日」不画成金乌而是一轮纸白淡日，光柱斜得极轻；境贰把纵深本身做成主角（石径沿弧线没入、竹丛渐远渐矮、禅房半隐花木与晨雾深处）；境④点击前把一切声光压到最低（万籁俱寂），点击后只让音波环一圈圈荡开——「但余钟磬音」的余韵，是画面里唯一的动。

## 教学建议

1. **导入**：先讲「一条路的故事」——「曲径通幽」这个成语就出自这首诗，让学生带着"一条小路凭什么著名一千多年"的问题入境。
2. **境②诗眼**：结合画面讨论「通」「幽」「深」三个字怎么共同写出纵深——路是弯的（看不到头）、竹是密的（围出静）、禅房是半隐的（欲露先藏）；再讲后世造词「曲径通幽」的来路。
3. **境③使动**：「悦」「空」都是使动用法——山光使鸟性欢悦（写物），潭影使人心涤净（写我）；让学生在画面里找"哪一半是鸟的乐、哪一半是人的静"。
4. **境④以声衬静**：先静默看完画面再点击——一声磬响之后，静得更可听见；这正是"以有声衬无声"的写法。顺势区分「万籁」的「籁」（孔穴发声，泛指一切声响）与「钟磬」的「磬」（钵形铜法器），落到考点读音 lài / qìng。
5. **小测**：5 题覆盖下一句接龙×2、读音词义×1、文学常识（破山寺即今常熟兴福寺）×1、诗眼理解×1，可作课堂即时检测。
