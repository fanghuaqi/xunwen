# 《青玉案·元夕》 · 夜宴金彩（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《青玉案·元夕》「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。全词四境：从"东风夜放花千树"的满城灯海，走到"灯火阑珊处"的一人一灯。本页取**夜宴金彩**赛道做**上元灯海变体**——深蓝夜幕下万盏灯火是绝对主角，点击画面可让满城灯海次第暗下，只剩"那人"与一盏将尽的灯。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④"蓦然回首"轻点画面：满城灯海**次第暗下**（熄灭波前从远处推向"那人"），钟声一响，题字「灯火阑珊」闪现——只余一人一灯；再点一次灯海复明，题字「蓦然回首」（1.6 秒防连点锁）
- 末章：全诗回放、学习小测（5 题）

## 美术方案：夜宴金彩（art-direction 赛道①）

| 项 | 取值 |
|---|---|
| 底色 | `#070a10`（上元深夜蓝黑，较典型色板 `#05070d` 略偏蓝） |
| 主色 | `#e0a860`（灯火金橙，较典型主金 `#d4af37` 更暖更橙；按钮/边框/进度点/题字） |
| 文字 | `#f4e8d2`；次要 `#a4906f` |
| 雾 | `#0a1526`（SK 默认，与赛道①典型雾一致），逐境 fd 0.0032–0.0072 |
| 月 | 暖白月（ms 1.02–1.35），mph 自 0.06 渐增至 0.34 —— 月晕越来越重，为末境"将尽"蓄势 |
| 灯 | 灯纸暖橙 `#ff9a44`、灯晕 `#ffb469`、檐下实体灯带内焰，满城灯海四层纵深 |
| 粒子母题 | 两层坠落火星（makeStarRain 620+150 粒，"星如雨"母题）、观灯人群、灯下光池、暖雾 |

**有意的设计**：①赛道①的金在此全部换成**灯火的橙金**——满城灯海按"离那人的远近"预排权重（`wOf` 距离函数），点击暗灯时熄灭波从远到近次第推进，热闹与清冷在同一画面里完成换位，是"于最热闹处写最清冷"的视觉直译；②境④"那人"站画面右前冷清一角，与左后方四层纵深的灯海斜向对峙；③境③三位灯下女子的头饰各有专属轮廓光（蛾儿紫、雪柳青白、黄金缕暖金），衣色区分、暗香粒子随之飘远。

## 朗读配音

`audio/` 内置 6 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题（"青玉案·元夕"）
- `01–04.mp3` 四境逐境朗读
- `05.mp3` 全词连读

页面朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音兜底。本目录无 `tts.json`，无特殊多音字副本；易错字音以页面注音为准：**更** gèng（更吹落）、**度** dù（千百度，量词不读 duó）、**蓦** mò（蓦然）、**转** zhuǎn（玉壶光转）、**处** chù（阑珊处）、词中"寻他"读 tā（词里用"他"兼指男女，页内注释有说明）。

## 教学建议

1. **导入**：问学生"元宵节你想到什么颜色？"再看画面——满城暖橙灯火 vs 深蓝夜幕，先感受"热闹"。
2. **境①比喻**：对照画面讲清"花千树"是灯不是花、"星如雨"是烟火火星不是星星（页内注释即考点）。
3. **境②–③铺陈**：数一数画面里的灯轮、鱼龙灯、雕车、头饰——上阕全在写"热闹"与"她们"，为下阕的"那人"蓄势；讨论为什么词人要先用两段写繁华。
4. **境④词眼**：点击让满城灯海暗下，只剩一人一灯，再读"蓦然回首，那人却在，灯火阑珊处"；结合注释强调"阑珊＝零落将尽，不是灯火辉煌"——这是全词最易错的词义。
5. **拓展**：用小测第 5 题引出王国维"三重境界"，讨论"那人"的孤高自守与辛弃疾自身处境的映照（豪放派词人写出最婉约的一首）。
6. 末章做完 5 题小测（接句 ×2、词义 ×1、文学常识 ×1、名句境界 ×1）；课堂大屏可停在境④暗灯画面作导入悬念。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 四境，共 5 项），境名逐一对齐；全词上下阕按"灯海→灯市→游人→那人"四层并作四境。
- 交互境序号 `curIdx===4`（蓦然回首），`pointerdown` 以 `state==='stage'` 守卫并带 `ctl.lock` 1.6 秒防连点；自动游览末境判断以 `POEM.length=4` 对齐。
- 校验：`node _pipeline/tools/validate.js qingyu-an-yuanxi/index.html` → **✓ 校验全部通过**。
