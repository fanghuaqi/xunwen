# 循文入境 · 望岳（唐 · 杜甫）

单文件 Three.js 沉浸式诗词课件：双击 `index.html` 即可打开（需联网加载 Three.js 引擎，音频本地）。

## 使用

- 双击打开 → 点「入 境」，自动朗读 + 可开自动游览（课堂大屏无人值守）。
- `← →` / 空格逐境游览；空格也可触发第四境交互。
- 控制条可关自动朗读/注音/音效，可全屏。
- 无网络音频时页面自动回退浏览器语音（Edge 下为在线神经语音逐句朗诵）。

## 四境（纵向叙事：仰望 → 登临）

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 遥望岱宗 | 岱宗夫如何？齐鲁青未了。 | 山下仰望：主峰入云，青丘绵延两侧没入纸色 |
| 贰 · 阴阳昏晓 | 造化钟神秀，阴阳割昏晓。 | 向阳面暖亮如晓、背阴面浓墨如昏，一崖割分 |
| 叁 · 曾云归鸟 | 荡胸生曾云，决眦入归鸟。 | 山腰：层云胸前涌动，归鸟群俯冲入林 |
| 肆 · 凌绝顶 | 会当凌绝顶，一览众山小。 | **点击登顶**：镜头攀上峰顶，众山缩为丘、云海落脚下、齐鲁铺展到天际，题字「一览众山小」 |

## 教学建议

- 多音字考点：曾 céng（同"层"）、眦 zì、了 liǎo、夫 fú（语气词）；「小」为意动用法。
- 第四境先让学生看"山腰石阶"画面猜诗意，再点击登顶对照"俯瞰"感受诗人心胸。
- 终章附 5 题小测（接龙 ×2、读音 ×1、词义 ×1、主旨 ×1）。

## 配音
