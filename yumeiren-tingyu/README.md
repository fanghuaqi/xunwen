# 虞美人·听雨 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《虞美人·听雨》（宋·蒋捷）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。**三场听雨写尽一生**——同一动作（听雨）三个时空（歌楼 / 客舟 / 僧庐），雨声不老，听雨的人老去。全套冷银水墨色板，歌楼红烛是全页唯一的暖色。

> 注意：本页是蒋捷《虞美人·听雨》；另一首李煜《虞美人·春花秋月》在 `yumeiren/`，两者同名异作。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"听雨"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：雨声由暖转寒、头顶屋檐由歌楼换僧庐、远山歌楼暖窗熄灭，"点滴到天明"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主色 | `#90a8c8`（queue 分配强调色；按钮/边框/进度点/题字全银蓝水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#121926` 系，fd 0.0050–0.0072（末境最浓，色温逐境下降） |
| 月 | 冷银白带重晕（雨夜月朦胧，ms 0.8–1.05），不是主角；雨幕才是主角 |
| 粒子母题 | 斜落雨丝（自定义着色器）、檐口点滴、低云横江、霜尘微光 |

**有意的设计**：情感曲线 = 歌楼暖 → 客舟苍 → 僧庐冷 → 无晴，色温逐境降。境①歌楼红烛昏罗帐是**全页唯一的暖色**（少年记忆的温度）；境②点击后连这点暖也熄灭——远山歌楼暖窗随之变冷，唯余阶前点滴，是「一任」的放下感。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，`gen-voice-edge.py` 生成）：

- `00.mp3` 标题（"虞美人·听雨"）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字自查：全词无高危多音字（少 shào、听 tīng、断 duàn、星星 xīng 皆常规读音；「一任」口播自然变调，页面拼音按教材本调标注 yī rèn），`tts.json` 只钉音色与语速、未写 sub 表。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：先问"同一夜雨，少年和老人听来有什么不同？"再入境①。
2. **境①对照**：同框看歌楼暖窗与江心冷舟，让学生找"哪个是少年、哪个是壮年"，体会红烛罗帐与断雁西风的反差。
3. **境②动作**：让学生点一下画面，听"雨声由暖转寒"，讨论"屋檐换了、雨没换"是什么意思。
4. **抓「一任」**：结合注释讲"看似放下"，对比李煜"一江春水"的奔涌，体会蒋捷的克制与苍凉。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、词牌典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- 两境（queue 分境为准）：`STAGES = POEM + 1`（卷首 + 两境），境名逐一对齐；`STAGES[1]=歌楼客舟`、`STAGES[2]=僧庐天明`。
- 交互境序号 `curIdx===2`，挂 `click`/`clicked`/1.2s 冷却；pointerdown 与空格双接线（空格先交互、再按进终章）。
- 预算：逐境 draw call 代理 15/30/34（≤120），三角面最大 2.1 万（≤12 万），雾密度 0.0050–0.0072。
- 校验：`node _pipeline/tools/validate.js yumeiren-tingyu/index.html` → **✓ 校验全部通过**（audio 补齐后零警告）。
- 冒烟：`node yumeiren-tingyu/smoke.test.js` → **SMOKE PASS**（真 THREE r128 逐境 build/update×400 帧、fadeK 合规、三层构图、末境点击门控、自动游览至终章、小测全流程），连跑 3 次稳定。
