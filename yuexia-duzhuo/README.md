# 月下独酌（其一） · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《月下独酌·其一》（唐·李白）「循文入境」教学网页：诗句推进到哪一句，三维实景就走进哪一重意境。本页取**水墨夜思**方向并加以放大——冷银墨夜、大月低垂，一人一月一影的"三人"同席是全页的画面核心，从独酌的孤清一路走向相约银河的空明。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN，多源自动回退；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"举杯邀月"、境④为"相期云汉"）
- 控制条：自动游览、朗读此句、自动朗读、注音、声音、全屏
- 进度点：点击圆点可直接跳境
- 境②轻点画面：月轮低垂靠近、影子举手相应、杯口酒花迸溅——"对影成三人"题字闪现（3.6 秒演出期防连点）
- 境④轻点画面：银河亮起、星光加速流转——"相期邈云汉"题字闪现（仅首次触发，4.2 秒演出期防连点）
- 末章：聆听全诗、学习小测（5 题）、再游一次、回卷首

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜，body 与 #err 同色） |
| 主银 | `#cdd6e6`（--gold 变量；按钮/边框/进度点/题字，全银蓝水墨调，边线 `rgba(180,195,215,.25)`） |
| 文字 | `#dfe6f0`，次要 `#8b99ad` |
| 天穹 | top `#0a1119` / hor `#22303f` / bot `#0a0e14`（逐境微调，境④夜色最深 `#070c16`） |
| 雾 | `#131a26`，fd 0.0040–0.0058（境③最浓、境④最清远） |
| 月 | 冷银大月是唯一主角：ms 1.45–2.00，带月晕（mhaze 0.02–0.30）；境③被"月晕"调浓如蒙薄云 |
| 星 | 疏密随剧情：境③最少 0.28，境④银河境最多 0.88 |
| 粒子母题 | 花瓣缓升（`#d6cdd6`/`#d8d0d8`）、月下浮尘（`#cfe0f2`/`#bcd2ec`）、雾带（`#9fb6d4`）、银河星带（1000+420 点 `#dae4f6`/`#9fb6dc` + 300 颗亮星）、杯上微光升空（`#dfe8fa`） |

**有意的设计**：境③"月不解饮"全境复冷——星最少、雾最浓、月被晕染，杯中只留一小片月色微光（`#dce8fa`）"在杯中而不可饮"；而境②点击邀月时酒杯口保留一点暖光（点光 `#ffe6c2`），是邀约瞬间唯一的人间暖意。境④三片同源影子散落开合演"影零乱"，杯上微光一柱升向银河演"相期"。

## 朗读配音

`audio/` 内置 6 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题与作者（"月下独酌。唐，李白。……"）
- `01–04.mp3` 四境逐境朗读
- `05.mp3` 全诗连读

页面朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音兜底。无特殊多音字副本；逐字注音已按诗义标定易错音——**酌 zhuó**、"暂伴月将影"的**将读 jiāng**（与、和，非 jiàng）、"不解饮"的**解读 jiě**、"相期邈云汉"的**邈 miǎo**。如需更高级音色，可用 `_pipeline/tools/gen-voice-edge.py` 重生成。

## 教学建议

1. **导入**：设问"一个人喝酒，怎么才能不孤单？"再入境①看李白四顾无人的独酌。
2. **境②诗眼**：先看画面再点击邀月，让学生数一数"三人"是谁——我、月、影；讲"成"字的妙处：孤独里硬凑出的热闹。
3. **境③转折**：杯中月色不可饮、影子只会跟人——月亮"不解饮"、影"徒随身"，两个"无情"反衬痴情。
4. **境④升华**：点击点亮银河后齐读末四句，讨论"无情游"为什么反而最深情——不带世俗利害的相交，约在银河。
5. **收束**：末章全诗连读，再做 5 题小测（接句 ×2、词义"将" ×1、内容"三人" ×1、词义"无情游" ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释（含"三人""无情游"等诗眼详注）、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 四境：2 句、2 句、4 句、6 句各成一境），境名逐一对齐。
- 点击交互境序号 `curIdx===2` 与 `curIdx===4`（境②可重复触发、境④以 `clicked()` 守卫仅首次触发）；空格键在境④亦经同一守卫。
- 校验：`node _pipeline/tools/validate.js yuexia-duzhuo/index.html` → **✓ 校验全部通过**。
- 目录内附 `smoke.test.js`：Node 冒烟测试，覆盖全境 build/update/click 链路。
