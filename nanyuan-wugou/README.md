# 南园·其五 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《南园·其五》（唐·李贺）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**大漠金戈**赛道——但刻意避开战阵/夜射/行军/听笛/白骨/骏马/剑庐的既有边塞构图，从**南园书斋田园**起手，写的是一声**投笔从戎**的慨叹：境壹=起（书案掷笔、吴钩横架，指顾关山五十州），境贰=问（凌烟高阁横空，功臣画像次第显影——若个书生万户侯）。accent=#c9a06a（沙金/绢帛金）只落在阁檐边缘光/功臣画像暖辉/铜格/窗纸暖光/UI 上，禁艳金；**全页唯一冷色源是「吴钩」**——钢青 0x8a9aaa～0xecf3f9 只属于刀，暖阁金辉与冷刃寒光对撞出「功名之问」。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"功臣画像显影"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：凌烟阁上二十四功臣画像自下而上次第显影，阁前金辉漫开，末了吴钩寒光乍现，"请君暂上凌烟阁 若个书生万户侯"题字同现
- 末章：全诗回放、学习小测（5 题）

**有意的设计**：全诗两问，画面同理——境壹只给「起」（笔已掷、刀未出，吴钩只微芒内敛），境贰只给「问」（凌烟阁在夜色里暗着，点击才让二十四功臣一一显影）。点击交互就是诗句本身：「请君暂上凌烟阁」——画像次第点亮，末了吴钩寒光乍现：功名图像的召唤与「若个书生万户侯」的不平，在同一秒里对撞。

## 教学建议

1. **导入**：先讲「投笔从戎」——班超掷笔叹「大丈夫当立功异域」；一千多年后，一个叫李贺的书生在南园的书案前，把同一声叹息问成了两句诗。
2. **境①诗眼**：「何不」二字——反问里全是激愤：不是不能，而是不甘。让学生留意画面：笔已掷在案头，刀却还横在架上——「带吴钩」三个字，是书生对自己的发问。
3. **境②点击后**：二十四功臣画像次第点亮的一瞬，就是「功名图像的召唤」；最后吴钩寒光乍现——「若个书生万户侯」：阁上皆马上取功名之人，哪个是书生？两问相对，慷慨与愤懑交织。
4. **常识**：凌烟阁在唐长安太极宫，贞观十七年（643）唐太宗命阎立本绘长孙无忌、魏徵、尉迟敬德等二十四功臣真人大小画像——「上凌烟阁」即唐人功名之顶。
5. **背景**：李贺（790—816），字长吉，人称「诗鬼」；身为宗室而出身寒微、避父讳不得举进士，《南园十三首》多写家园与书生怀抱，此首最负盛名——书生报国无路，故有此问。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、文学常识 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
