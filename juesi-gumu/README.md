# 绝句·古木阴中 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《绝句·古木阴中》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**青绿春晓**赛道，取「古木溪桥」变体——古木浓荫下系着短篷小船、石桥东边拄杖而过的老僧，以及桥东柳岸的**杏花雨**与**杨柳风**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击杨柳风"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：细雨加密 1.5 倍、柳丝拂动与杏花枝摇幅加大、杏花瓣在老僧肩头驻留，"杏花雨"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：青绿春晓 · 古木溪桥（art-direction 赛道④）

| 项 | 取值 |
|---|---|
| 底色 | `#0a1410`（青绿底色） |
| 主青 | `#8fc9b8`（按钮/边框/进度点/题字，= 本诗分配强调色） |
| 文字 | `#eef4e6` |
| 雾 | `#0e1d16`，fd 0.0056–0.0062 |
| 天光 | 早春晴光（dirC `#e0cf8e`→`#dbcd90`）、星稀 0.14、月小而低（ms 0.60–0.65） |
| 粒子母题 | 黄绿微尘、林间薄雾、**杏花瓣**（96 枚 InstancedMesh，可落肩）；杏花的粉白是唯一亮色 |
| 标志性瞬间 | 「杏花雨·杨柳风」——点击后雨细柳摇、杏花落肩（触觉写春的可见化） |

**与同赛道《三衢道中》（黄鹂绿阴）、《画眉鸟》（金笼林间）不同**：本页的"春"不是靠鸟声，而是靠**触觉**——细雨密而不湿衣、柳风柔而不寒面；画面主角是古木、石拱桥、短篷与柳岸杏花。

- `02.mp3` 境贰（沾衣欲湿杏花雨，吹面不寒杨柳风。）
- `03.mp3` 全篇连读

多音字处理见 `tts.json`：**本诗无多音字险**，`sub` 留空（脚本回落内置兜底表，本诗无一条命中，合成文本与页面逐字一致）：

- 逐句核过：古木阴中（阴同「荫」）、系短篷（系 xì，拴）、杖藜 lí、过桥东、沾衣 zhān、欲湿、杏花雨 xìng、吹面、不寒（不 bù，平声前不变调）、杨柳风——无须钉任何替换

页面朗读优先级：Edge 在线自然语音现场逐句朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"春天的雨和风，你能怎么'摸'到？"再入境壹。
2. **境壹析"扶"字**："杖藜扶我"——本来是人拄杖，诗人偏说杖扶人；一字写尽老而未衰的从容与闲趣。
3. **境贰析触觉**：全诗不写"看"而写"沾""吹"：雨"欲湿"而未湿（极细）、风"不寒"而微暖（极柔）。让学生说说这两句为什么比"花红柳绿"更耐读。
4. **点击体会**：点击杨柳风看雨密、柳摇、花落肩——把"沾衣"二字落到实处。
5. **知人论世**：志南是南宋僧人（法名志南）；此诗后两句曾被朱熹称赏，是宋诗中"以触觉写春"的名例。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、词义 ×1、手法 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 37 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（古木、短篷、石桥、老僧、柳杏）都在 8–22 单位内，fd ≤ 0.0062；全页**无一处手写 opacity**（雨/花瓣/柳/杏/水面全走 uniform、实例矩阵或旋转）。
- 场景构件（冒烟实测）：卷首 13 mesh、境壹 16 mesh、境贰 18 mesh / 3 points；draw call 代理值 21 / 24 / 28（≤120），三角面 ≈1.3 / 1.4 / 2.0 万（≤12 万）。
- 校验记录（本轮真实拦下两个问题，均已修）：
  - smoke 先抓到 **draw call 123 > 120**（花瓣初版逐枚建 Mesh，96 个 draw call）→ 改为 **InstancedMesh，1 个 draw call**，降到 28
  - `node _pipeline/tools/validate.js juesi-gumu/index.html` → **✓ 校验全部通过**
  - `node juesi-gumu/smoke.test.js` → **SMOKE PASS**（连跑 3 次稳定）
  - `node _pipeline/accept.js juesi-gumu` → **ACCEPT**（见汇报）
