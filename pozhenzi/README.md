# 循文入境 · 破阵子·为陈同甫赋壮词以寄之（宋 · 辛弃疾）

单文件沉浸式诗词课件：四境随词句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 大漠金戈·壮词变体：从挑灯看剑的孤愤，跌入八百里分炙、沙场秋点兵的雄阔梦境，最终由「可怜白发生」猛跌回冷酷现实。
> 标志性瞬间：沙场秋点兵——烈火铜盆、大纛旌旗、千军万马的壮阔阅兵阵势。

## 教学建议

- 结构大跌宕：前九句极力铺排梦中驰骋杀敌的雄壮（金戈铁马），末句五个字「可怜白发生」笔锋陡转，直落千丈，悲愤沉痛
- 「八百里分麾下炙，五十弦翻塞外声」：对仗工整，数字与典故并用，声音与色彩兼备
- 「马作的卢飞快，弓如霹雳弦惊」：两个精妙的比喻，写出短兵相接的飞快节奏
- 注音考点：挑灯 tiǎo、麾下 huī、炙 zhì、五十弦 xián、塞外 sài、的卢 dì lú、霹雳 pī lì、了却 liǎo què、可怜 lián
- 背景：宋孝宗淳熙十五年（1188年）冬，陈亮（字同甫）到铅山拜访辛弃疾，鹅湖之会两人纵论抗金大计，别后辛弃疾写下这首壮词相赠
