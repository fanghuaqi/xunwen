# 鹧鸪天·彩袖殷勤捧玉钟 · 夜宴金彩·小山词冠篇（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《鹧鸪天·彩袖殷勤捧玉钟》（宋·晏几道）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**夜宴金彩**赛道（小山词冠篇）——底色沿用夜宴基线 `#05070d`，但金不铺在「豪饮」上，只长在**歌筵灯烛、彩袖金缕、银釭灯焰**三处；上片是当年的盛欢，下片是今宵的疑梦。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为「挑亮银釭」，已交互再按才进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：银釭灯焰挑亮、灯辉涨满、梦雾涌起，二人灯下相认（五声琶音 +「犹恐相逢是梦中」题字）
- 末章：全词回放、学习小测（5 题）

## 美术方案：夜宴金彩·小山词冠篇（art-direction 赛道①）

|---|---|
| 底色 | `#05070d`（夜宴基线，style-audit 硬校验） |
| 主金 | `#e0c060`（queue 分配强调色；按钮/边框/进度点/题字/腰带金缕/金樽/银釭金环口全跟此色） |

| 月 | 卷首用引擎暖白大月；境①隐藏引擎月，改用**自建楼心月**（暖白月轮 + 双层暖辉，fog:false）；境②淡月高悬（ms 0.5） |
| 粒子母题 | 桃花色「扇底风」风屑（NormalBlending，绕舞者环游）、金尘浮粒、魂梦流光（低饱和暖雾流）——不用流萤/酒光老三样 |
| 暖源 | 境①立灯檠二 + 案上烛台二 + 席面点光；境②银釭一盏——全页只有「灯烛之金」一种色温 |

**有意的设计**：境①的标志性瞬间是「**舞低楼心月**」——楼心矮栏围出回廊口，一轮暖白月轮悬在楼外天际，随彻夜歌舞以 0.17/秒徐徐西沉，直沉到栏外山际为止：「时间的流逝」在画面里真实发生。境②转梦境：低饱和暖光 + 重雾化 + 魂梦流光做「疑在梦中」的质感，唯一的爆发点是点击挑亮银釭——灯下相认、恍然如梦，正是过片两句的词眼。

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，清朗男声——小山词深婉，不沿用夜宴赛道的高亢男声）：

- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字处理（`tts.json`，sub 接管不叠兜底表）：逐字核对全篇——**拼**（当年拼却醉颜红，读 **pàn**，甘愿不顾惜；钉写同音同调替换「拼却→判却」）、**釭**（银釭，读 **gāng**，银灯；钉写「银釭→银钢」）；几（jǐ，几回）、与（yǔ，与君同）、剩（shèng）、相（xiāng，相逢）等皆常用默认正确读音，无需另钉。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：讲「宰相父子」——晏殊之子晏几道，字叔原，号小山；「小山词」冠篇即本词。设问：一场旧日的歌筵，为什么会让词人「犹恐相逢是梦中」？
2. **境①炼字**：抓「拼却」（pàn，甘愿豁出去）与「殷勤」；再看画面里的月正徐徐西沉——「舞低杨柳楼心月，歌尽桃花扇底风」把**时间**写进了对仗，让学生体会「彻夜歌舞」与「盛极而散」的伏笔。
3. **境②的情感翻转**：从别后只有魂梦相逢（几回魂梦与君同），所以今宵真相逢反而**不敢信**（剩把银釭照、犹恐相逢是梦中）——点击挑亮银釭后讨论：灯越亮，为什么越「疑」？
4. **名句对读**：与本册晏殊《浣溪沙》「无可奈何花落去」对读，体会大小晏「情语」与「理语」之别。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、名句妙处 ×1、主旨 ×1）。
6. 课堂大屏可开「自动游览 + 自动朗读」无人值守循环展示。
