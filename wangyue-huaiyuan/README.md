# 望月怀远 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《望月怀远》（唐·张九龄）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**水墨夜思**赛道——全套冷银水墨色板，海上一轮冷月是唯一主角，灭烛前的一豆烛火是全页唯一的暖色。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"点击明月"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：明月满升，两地对望光带相连，"梦佳期"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 强调色 | `#9fb3cc`（冷银蓝，队列分配 accent；按钮/边框/进度点/题字全跟随，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#111826` 系，fd 0.0050–0.0066（末境海面最透，室内感境最浓） |
| 月 | 冷银白（`#eef3ff` + 银蓝辉光），全页唯一主角；境①大月自海面缓缓升起（入场 26 秒的升月动画），境④点击后月轮满升 |
| 星 | 稀疏（0.26–0.45，夜愈深星愈隐） |
| 粒子母题 | 月华微尘、银浪沫、贴地露光霜晶、高天流云（替代《将进酒》的金色流萤/火星） |

**有意的设计**：境③"灭烛怜光满"保留一豆**暖橙烛火**（焰心 `#ffe0a8`）——它是全页唯一的暖色点，随入境约 2.8 秒后缓缓熄灭，月光光池随之涨满全室：烛灭的瞬间就是"怜光满"三个字。与全局冷银底形成唯一对比，让学生一眼读出"烛是暂时的暖，月是恒久的清"。除此处外，全页再无第二暖源（亭柱、案、器物一律冷银墨色）。

## 朗读配音

`audio/` 内置 6 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，水墨赛道自动选声，语速 -16%）：

- `00.mp3` 标题（"望月怀远"）
- `01–04.mp3` 四联逐境朗读
- `05.mp3` 全诗连读

多音字处理（`tts.json`，同音同调替换，只影响音频读音）：**还寝**读 huán（环寝）、**觉露滋**读 jué（绝露滋）。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。如需"诗朗诵"级音色，可设 `TTS_AZURE_KEY` 后重跑 `gen-voice.js`。

## 教学建议

1. **导入**：封面设问"月亮从哪里升起来最美？"再入境①，对照"海上生明月"看大月临海、月路铺波——一个"生"字为何比"升"好。
2. **境①冠联**：找出画面里的两个"人"（近岸望月人、远渚小影），理解"天涯共此时"——空间上隔天涯，月光里共此时。
3. **境②炼字**：为什么"怨"夜长？因念而怨、因怨更见念深；结合注释讲"竟夕"即终夜无眠。
4. **境③观察**：盯住烛火——它熄灭的时刻恰是月光满室的时刻，体会"灭烛"是为了"怜光满"；披衣久立故"觉露滋"，痴态皆由相思来。
5. **境④情感**：点击明月看月满升、光带相连，讨论"月光为什么不能盈手相赠"（陆机"照之有余辉，揽之不盈手"）；可介绍张九龄罢相外贬荆州的本事。
6. **收束**：末章全诗连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、本事 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 四境），境名逐一对齐；诗文与 `queue.json` 条目逐字一致。
- 交互境序号 `curIdx===4`；pointerdown 与空格双接线（空格先触发交互、再按进终章）；进度点/按键/自动游览末境判断均以 `POEM.length=4` 对齐。
- 校验：`node _pipeline/tools/validate.js wangyue-huaiyuan/index.html` → **✓ 校验全部通过**。
- 冒烟：`node wangyue-huaiyuan/smoke.test.js` → **SMOKE PASS**（连跑 4 次稳定）——真 THREE r128 跑完 boot → 逐境 build/update×400 帧 → fadeK 合规 → 末境点击门控与 pointerdown → 键盘全路径 → 自动游览至终章 → 小测全流程。
- 实拍：无头 Chrome 抽检封面 + 四境 + 末境点击态（月轮满升、光带相连），构图均达"前景剪影 → 中景主体 → 背景层次"三层要求。
