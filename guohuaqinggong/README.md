# 过华清宫 · 夜宴金彩（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《过华清宫》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**夜宴金彩**赛道，取「骊山华清」变体——晚照里的骊山宫阙、山腰层层叠叠如锦绣的宫树花木、骊山绝顶次第洞开的千重宫门，以及驿道上一骑扬尘直上长安的**红尘**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击红尘"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：驿马加速飞驰、红尘暴涨，山顶千门大开、宫灯齐亮，"妃子笑"题字同现
- 末章：全诗回放、学习小测（5 题）

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 `zh-CN-YunjianNeural`，语速 −12%，夜宴/豪放赛道音色）：

- `00.mp3` 标题（"过华清宫"）
- `01.mp3` 境壹（长安回望绣成堆，山顶千门次第开。）
- `02.mp3` 境贰（一骑红尘妃子笑，无人知是荔枝来。）
- `03.mp3` 全篇连读

多音字处理见 `tts.json`（**sub 非空即完全接管**，不再叠加脚本内置兜底表）：

- `一骑` → `一其`：钉住「骑」的今音 **qí**（1985 年《普通话异读词审音表》已把「一人一马」的 jì 并入 qí；教材注释亦作 qí），注释里同时保留了旧读说明供考点讲解
- 其余逐句核过：长安 cháng ān、回望、绣成堆、千门、次第、红尘、妃子、荔枝、无人知是荔枝来——无多音字险，无需干预

页面朗读优先级：Edge 在线自然语音现场逐句朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"一位诗人回望一座山，会看到什么？"再入境壹，先看画面再读诗。
2. **境壹析景**："绣成堆"是什么在堆？——宫殿楼台与花木层层掩映，远望如一堆堆锦绣；"千门次第开"看似写景，其实写人：宫人一早依次开门，说明宫中已为贵妃的到来忙作一团。
3. **境贰析事**：讲清"荔枝来"的史实（贵妃嗜鲜荔枝，驿站昼夜换马接力南果北送），再让学生找诗中最刺人的两个字——"笑"与"无人知"。
4. **讽喻手法**：全诗不着一字议论，只用"一骑红尘"与"无人知是荔枝来"两笔白描，把荒唐写尽（可与"一骑红尘"与"无人知"的对比朗读配合）。
5. **知人论世**：杜牧《过华清宫》共三首，此为第一首；晚唐回望盛唐旧事，讽在今而意在史。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音义 ×1、典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 38 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（宫门/驿马/宫台）都在 30–80 单位内，fd ≤ 0.0055，实测主体遮蔽率远低于 0.35 上限；自定义着色器（水面/远山/红尘流）全部登记 `fogShaders` 同步雾参数，穹顶/星/月/晚照 `fog:false`。
- 场景构件（冒烟实测）：卷首 22 mesh / 20 sprite、境壹 33 mesh / 21 sprite、境贰 31 mesh / 3 points / 16 sprite；draw call 代理值 43 / 55 / 50（≤120），三角面 ≈1.6 / 2.7 / 1.9 万（≤12 万）。
