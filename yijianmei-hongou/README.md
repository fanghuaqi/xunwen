# 一剪梅·红藕香残玉簟秋 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《一剪梅·红藕香残玉簟秋》（宋·李清照）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。全套冷银水墨色板（accent `#b4c2d4`），冷银满月是唯一主角；荷塘残红、兰舟、西楼、雁阵、水中月串成全页意象链。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"雁字掠月、锦书浮来"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：雁阵排「人」字掠月而过，锦书虚影自月旁雾中浮来、近人渐淡（锦书终是影），"雁字回时"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主色 | `#b4c2d4`（queue 分配 accent；按钮/边框/进度点/题字/人物边缘光，全部银蓝水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#131a26` 系，fd 0.0050–0.0066 |
| 月 | 冷银满月（全页唯一主角）：封面 ms 1.7 → 境② 2.05（月满）→ 境④ 1.95；境④月沉至檐角（与雁阵掠月航线相接） |
| 星 | 稀疏（亮度压至 0.22–0.38） |
| 粒子母题 | 水面残红漂瓣、浮尘微光、月前流云、愁绪薄雾流（替代参考实现的金色流萤/火星） |

**有意的设计**：①荷塘残红（瓣 `0x4e2f36` 系哑红、水面漂瓣 `0x7a4a54`）是全页唯一的暖色残迹——「红藕香残」的温度，除此之外全页禁暖；②境③「一种相思，两处闲愁」做**两地同月对切**：左岸西楼凭栏的她、右岸随流的孤舟上的他，共顶一轮居中满月，水中月影在两地之间呼吸；③末境点击后的锦书是半透绢帛，浮至人前渐淡而散——盼到的终究是影子，正是"云中谁寄"的怅惘。

## 朗读配音

`audio/` 内置 6 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，水墨夜思赛道音色，语速 -16%）：

- `00.mp3` 标题（自动提取："一剪梅·红藕香残玉簟秋"）
- `01–04.mp3` 四境逐境朗读
- `05.mp3` 全词连读

多音字以页面注音为准，`tts.json` 钉了两条同音同调替换：`玉簟→玉电`（簟 diàn）、`罗裳→罗常`（裳 cháng，「轻解罗裳」）；「谁」读 shuí 无同调同音字可替，交由语音原读。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"荷花谢了、竹席凉了，是一个什么季节？"再入境①，对照"红藕香残"看荷塘残红与漂瓣。
2. **境①动作**：让学生注意"轻解""独上"两个动作，体会"独"字领起全词离情；结合注释讲簟（diàn）与罗裳（cháng）。
3. **境②典故**：先看雁阵掠月再读"雁字回时"，讲雁足传书（苏武）与锦书（苏蕙织锦）；追问"月满西楼，人圆了吗？"
4. **境③对切**：让学生在画面里找"两个人"，体会"一种相思，两处闲愁"——两地同望的是同一轮月。
5. **境④点击**：点击看雁字掠月、锦书浮来又散，讨论"为什么锦书只是影子"；再讲"才下眉头，却上心头"与范仲淹词的承化关系。
6. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 四境），境名逐一对齐；诗文逐字与 queue.json 一致（"云中"从教材通行本）。
- 交互境序号 `curIdx===4`（pointerdown + 空格双接线，空格先交互、交互后再按进终章）；`clamp(i,0,4)`、进度点、自动游览末境判断均以 `POEM.length=4` 对齐。
- 每境三层构图（makeRange 山脊 + makeForeground 框景 + 主体）、fadeK 铁律（每帧写 opacity/intensity 必乘 fadeK）、draw call ≤33、三角面 ≤2.8 万。
- 校验：`node _pipeline/tools/validate.js index.html` → **✓ 校验全部通过**；`smoke.test.js` → **SMOKE PASS**（自动游览全生命周期、末境交互门控、小测、fadeK 合规、三层构图）。
