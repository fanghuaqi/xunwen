# 循文入境 · 所见（清 · 袁枚）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，首次需联网；音频已本地化）。

- **三境推进**：骑牛高歌（歌声波纹+黄牛缓行）→ 意欲捕蝉（驻足仰望高枝鸣蝉）→ 闭口凝立（标志性瞬间：歌声骤停、波纹消散、万籁俱寂）。
- **互动**：第三境点击画面/按空格，重演「欲捕鸣蝉」——歌声骤停 → 牧童凝立 → 蝉在高枝轻鸣（WebAudio 蝉声）。
- **配套**：逐字注音（振 zhèn / 樾 yuè / 捕 bǔ / 蝉 chán 已核）、释义注释、AI 朗读（audio/00–04.mp3，00 标题、01–03 各境、04 全诗）、自动游览、结课小测 5 题。
- **课堂建议**：投屏后开「自动游览+自动朗读」可无人值守展示；讲到第三境时先让学生猜"他为什么突然不唱了"，再点击重演点题。
- 朗读失败或无网络时，页面自动回退浏览器语音（Edge 下为在线神经语音现场朗诵）。
