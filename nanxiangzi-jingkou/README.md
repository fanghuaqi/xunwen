# 南乡子·登京口北固亭有怀 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《南乡子·登京口北固亭有怀》（宋·辛弃疾）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**大漠金戈**赛道——底色 #120d08、雾 #1a120a 系、accent `#c49a5a`（取自 queue，用于栏柱/人物边缘光/旗纹），禁用艳金；赛道母题落于「暮色大江」：江涛与战旗是全页动态元素，烽火、尘霭、旗影替代金色流萤。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"点击北固亭"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②运镜：亭上凭栏，千叠浪滚滚东去（标志性瞬间——大江回答千古一问）
- 境④轻点画面：江浪千叠自远涌起，答千古一问，"生子当如孙仲谋"题字同现，拨弦和声相答
- 末章：全诗回放、学习小测（5 题）

多音字以诗目录 `tts.json` 同音同调替换（只影响读音，不改页面文字）：兜鍪→兜谋（兜 dōu、鍪 móu，鍪生僻以谋定音）、兴亡→星亡（兴 xīng，防误读 xìng）。年少 shào、谁 shuí、处 chù、当 dāng 经查为常规读音，未列替。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：先问"登上北固楼，词人为什么开口先问『何处望神州』？"——满眼风光里，唯独望不见的那块地方，才是心头的痛。
2. **境①对比**：「满眼风光」与「望神州」一正一反，让学生体会"风光越美，怅惘越深"的写法。
3. **境②名句**：「悠悠」二字把千古兴亡收住交给长江——先看千叠浪的画面，再讨论"以景作答"妙在何处；对照杨慎「滚滚长江东逝水」与苏轼「大江东去」。
4. **境③用典**：「兜鍪」（dōu móu）以头盔代士兵；孙权十九岁继领江东，"年少"+"坐断东南"读出少年英主气魄。
5. **境④结穴**：第三问只答「曹刘」二字，斩截有力；「生子当如孙仲谋」借曹操之口赞孙权——字面赞古人，骨子里刺当朝（《三国志》裴注引《吴历》濡须之事）。
6. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
