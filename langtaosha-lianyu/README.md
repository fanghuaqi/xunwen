# 浪淘沙令·帘外雨潺潺 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《浪淘沙令·帘外雨潺潺》（五代·李煜）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**烟雨江南**赛道——黛蓝湿雾、雨夜囚居、梦境微暖，绝笔词里"梦与醒的诀别"。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境③为"凭栏远望"，再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境③轻点画面：凭栏化作栈桥伸向无限江山雾影，天上宫阙点亮、江面浮起光路
- 末章：全诗回放、学习小测（5 题）

## 美术方案：烟雨江南（art-direction 赛道⑥）

| 项 | 取值 |
|---|---|
| 底色 | `#10141a`（黛蓝湿夜） |
| 主色 | `#90a8c0`（队列分配 accent；按钮/边框/进度点/题字，**无一处金色**） |
| 文字 | `#e6ecef`，次要 `#7e8ea0` |
| 雾 | `#151d26` 系，fd 0.013–0.020（湿雾最浓的一篇，末境 0.020） |
| 月 | 雨夜月隐（ms 0.001 藏于地下）；唯境②梦境留一轮 ms 0.22 的朦胧胧月 |
| 粒子母题 | 自写"下落"小着色器的斜雨丝、无主落花（淡藕荷）、梦境烛橙微尘、水上雾流 |

**有意的设计：梦里暖、醒后寒**。境②"一晌贪欢"是全页唯一的暖境——低饱和烛橙点光（`#d88a50`，非金）、暖褐帷帐、梦境光尘；前后两境（雨夜囚居、冷江凭栏）全部转冷蓝。梦境帷帐里的宴席只用陶器与玉杯，不设金银。

## 朗读配音

`audio/` 内置 5 个 Edge 神经语音 MP3（zh-CN-XiaoxiaoNeural，语速 −16%，烟雨江南赛道默认女声）：

- `00.mp3` 标题（自动提取："浪淘沙令·帘外雨潺潺"）
- `01–03.mp3` 三境逐句朗读
- `04.mp3` 全诗连读

多音字以诗目录下 `tts.json` 接管（同音同调替换，不改页面文字）：潺潺→缠缠（chán）、阑珊→兰山（lán shān）、罗衾→罗亲（qīn）、五更寒→五耕寒（gēng）、一晌→一赏（shǎng）。页面拼音以逐字标注为准（一晌标 yì shǎng，从变调）。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：李煜绝笔词——先讲"这首词写成不久，词人就离开了人世"，再入境听雨。
2. **境①冷暖**：让学生找画面里的"冷"（雨、罗衾、冷光），体会"以身体之寒写心境之寒"。
3. **境②对比**：唯一暖的一境为什么是梦？"梦里不知身是客"——梦越暖，醒越寒。
4. **境③点击**：点击凭栏看栈桥伸向江山、宫阙亮起，讨论"天上人间"是什么距离。
5. **收束**：末章全诗连读，再做 5 题小测（接龙 ×2、读音词义 ×1、比喻理解 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
