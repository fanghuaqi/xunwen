## 标志性瞬间

境④"独钓寒江雪"（新 builder `bSnowSolo` + 新构件 `makeSnow`/`makeBoat`/`makeAngler`/`makeRod`）：把"千山万径的绝对空寂"压缩成一个画面——白到只剩江面，黑到只剩一点舟影与一竿钓线；雪落即化写出"寒"，镜头缓推写出"独"，点击唤雪写出天地间唯一的动。场景库中无此原型，为本诗自创。

## 教学建议

1. **朗读导入**：点"入境"后自动逐境朗读；先整体自动游览一遍（约 75 秒），学生说"看到了什么"。
2. **逐境精读**：每境结合右侧释义/注释展开——"绝/灭"的夸张与对比、"蓑/笠"的字音字形（多音字、生僻字考点）。
3. **主旨突破**：境④驻留提问"天地间为什么只剩这一点墨？"——柳宗元被贬永州，以不惧寒雪的独钓翁自喻孤高不屈（小测第 4、5 题收束）。
4. **互动点睛**：讲到末句时请学生点击江面"唤雪"，用身体记忆"雪落更急，翁自不动"的动静对照。
5. 结课用"学习小测"（接龙 ×2、读音 ×1、文学常识 ×1、主旨 ×1）当堂检测。
