# 循文入境 · 过零丁洋（宋 · 文天祥）

单文件沉浸式诗词课件：四境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 大漠金戈·正气变体：民族气节的千古绝唱——兵戈四年的苦战，山河破碎身世浮沉的悲歌，最终迸发出「留取丹心照汗青」的浩然正气。
> 标志性瞬间：山河破碎风飘絮，身世浮沉雨打萍——风卷飞絮与暴雨打萍的悲壮互喻。

## 教学建议

- 颔联「风飘絮」「雨打萍」两个比喻：国家如絮、个人如萍，巧妙将国破与家亡融为一体
- 颈联巧妙双关：借「惶恐滩」「零丁洋」两个地名，既实写行军途经之处，又双关昔日战败的惶恐与今日被俘的孤苦伶仃
- 尾联千古名句：「人生自古谁无死？留取丹心照汗青」——大义凛然、慷慨就义的民族气节，让学生齐读体会磅礴力量
- 注音考点：遭逢 zāo féng、干戈 gān gē、寥落 liáo luò、四周星 sì zhōu xīng、风飘絮 piāo xù、浮沉 fú chén、雨打萍 dǎ píng、惶恐 huáng kǒng、零丁 líng dīng、丹心 dān xīn、汗青 hàn qīng
- 背景：宋祥兴二年（1279年）正月，文天祥战败被俘后，元将张弘范押解他经过零丁洋，逼迫他写信招降张世杰，文天祥作此诗以明志
