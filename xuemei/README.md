# 雪梅 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《雪梅》（宋·卢梅坡）「循文入境」教学网页：诗句推进到哪一句，三维实景就走进哪一重意境。本页取**宣纸留白**方向——浅色宣纸冬景、蓝灰墨色 UI，淡雪与白梅在留白天地里"争春"，一缕金米色香雾是末境唯一的暖调。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN，多源自动回退；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在末境④为"唤香雾"）
- 控制条：自动游览、朗读此句、自动朗读、注音、声音、全屏
- 进度点：点击圆点可直接跳境
- 末境④轻点画面：香雾自梅枝涌出放大，铃声、"雪却输梅一段香"题字闪现
- 末章：聆听全诗、学习小测（5 题）、再游一次、回卷首

## 美术方案：宣纸留白（art-direction 赛道③）

| 项 | 取值 |
|---|---|
| 底色 | `#e9e2d0`（宣纸，body 与 #err 同色） |
| 主墨 | `#4a5060`（--gold 变量改蓝灰墨；按钮/边框/进度点/题字，**无一处金色**） |
| 文字 | `#23272e` 深墨，次要 `#6a707c`；边线 `rgba(74,80,96,.3)`；面板 `rgba(255,252,240,.72)` |
| 天穹 | top `#e9e2d0` / hor `#ded5bd` / bot `#cfc5ab`；采光暖白（dirC `#fff2d8`） |
| 雾 | `#e6dfcc`，fd 0.0034–0.0042 |
| 月 | 淡月高悬（ms 0.75–0.85，月面 `#f2f6ff`），在宣纸天穹里如冬日淡日 |
| 星 | 近无（star 0.03–0.05） |
| 粒子母题 | 淡雪（`#9aa4b8`，160–220 点逐境加密）、白雾（`#ffffff`）、香雾（`#c9b98a` 金米色） |

**有意的设计**：全域雪白与宣纸底几乎融为一体——雪团（`#f4f7fc`）、梅瓣（`#d8ccc4`）、纸面（`#f6f0dc`）互相近色，正是"梅雪争春难分辨"的视觉化；唯独末境的香雾用了金米色 `#c9b98a`，是全页唯一的暖调粒子，"雪输梅一段香"就输在这一缕颜色上。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题与作者（"雪梅。宋，卢梅坡。……"）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全诗连读

页面朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音兜底。无特殊多音字副本；逐字注音已按诗义标定关键音——"未肯降"的**降读 xiáng**（服输，非 jiàng），小测第 2 题即针对此音设题。如需更高级音色，可用 `_pipeline/tools/gen-voice-edge.py` 重生成。

## 教学建议

1. **导入**：设问"梅和雪同是冬天的白色，谁更胜一筹？"再入境①看两不相让的画面。
2. **境①读音**：读"未肯降"先正音 xiáng（服输），再体会拟人——梅和雪都"不服"。
3. **境②情境**：看诗人搁笔踱步，理解"骚人"即诗人、"评章"即评判高下——难评判正说明各有千秋。
4. **境③哲理**：点击唤出香雾后齐读后两句，让学生用"梅逊雪____，雪输梅____"填空复述，引出"各有所长、各有所短"的道理，再联系自己与同学的长短处。
5. **收束**：末章全诗连读，再做 5 题小测（接句 ×1、读音 ×1、词义 ×1、内容理解 ×1、哲理 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 三境；三四句"梅须逊雪三分白，雪却输梅一段香"合为一境），境名逐一对齐。
- 点击交互境序号 `curIdx===3`（末境）；进度点/按键/自动游览末境判断均以该长度对齐。
- 校验：`node _pipeline/tools/validate.js xuemei/index.html` → **✓ 校验全部通过**。
