# 循文入境 · 示儿（宋 · 陆游）

单文件沉浸式诗词课件（Three.js r128 UMD，双击 `index.html` 即开；首开需联网加载引擎，cdnjs→jsdelivr→unpkg 三路回退）。美术赛道：水墨夜思 · 病榻遗嘱（全页唯一光源是烛，强调色 `#b0c4de`，底色 `#0d1117`）。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 万事皆空 | 死去元知万事空 | 深夜病榻：衾下老人剪影微微呼吸，纱帐轻晃，床头一豆烛火垂泪，冷窗透进北国夜色 |
| 贰 · 悲不见同 | 但悲不见九州同 | 壁上九州舆图挂轴，北地大片沉在阴影里；拄杖老人剪影对图伫立，烛光在图面上明灭 |
| 叁 · 家祭遗言 | 王师北定中原日，家祭无忘告乃翁 | 标志性瞬间：烛光摇曳中浮想家祭——供桌、香炉青烟、后辈叩首剪影皆半透虚影；**点击烛火/按空格拔亮烛光**，舆图北地阴影揭开、中原重光，青烟转盛，题字「家祭无忘告乃翁」 |

## 操作

- `← →` 键或空格逐境；`Esc` 退出终章/小测；顶部圆点可直接跳境。
- 自动游览、自动朗读默认开启，可一键关闭（适合课堂大屏无人值守）。
- 朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音。

## 音频

`audio/00-04.mp3`（00 标题、01-03 各境、04 全诗），由 `gen-voice.js`（本诗定制副本）生成；逐字自查多音字：元知 yuán · 祭 jì · 乃 nǎi · 翁 wēng · 忘 wàng · 空 kōng，均无需替换表。删除 audio/ 目录可回退浏览器语音。

## 教学建议

先整读一遍 → 逐境入境，每境停留讲释义/注释（第二境讲"以图写悲"，第三境讲"虚景写情"）→ 让学生亲手"拔亮烛光"体会临终嘱托的滚烫 → 结课 5 题小测。
