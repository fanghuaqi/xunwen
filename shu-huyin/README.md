# 循文入境 · 书湖阴先生壁（宋 · 王安石）

单文件沉浸式诗词课件：`index.html` 双击即开（Three.js 走 CDN，音频本地）。

## 内容

- **三境**：茅檐净扫（一尘不染的茅檐庭院、斜倚的扫帚、花木成畦手自栽）→ 一水护田（标志性瞬间：溪水如带绕田而流，青绿反光随水流旋转，两山静候天际作伏笔）→ 排闼送青（交互境：点击画面，两座青山"推门而入"平移入院，青色涌入门框涌入庭院，题字"两山排闼送青来"）。
- 逐字注音（长 cháng / 苔 tái / 畦 qí / 闼 tà 已核）、释义注释、AI 朗读（`audio/00–04.mp3`）、自动游览、学习小测 5 题。

## 操作

- `入境` 进入；`← →` / 空格逐境；第三境点击画面或空格触发"两山排闼送青"（7 秒防连点守卫）。
- 控制条：自动游览、自动朗读、注音、声音、全屏均可开关。
- Edge 下优先用"在线自然语音"现场朗诵；无网络时回退浏览器语音。

## 课堂建议

1. 先整体自动游览一遍，让学生说"看到了什么"再对读诗句。
2. 第三境提问：青山怎么会"排闼"（推门）？——体会拟人手法的妙处（本诗最常见考点）。
3. 对比"一水护田"与"两山排闼"：溪水是"绕"，青山是"闯"，一静一动皆是"有情"。

## 音频重生成

```bash
node gen-voice.js index.html "书湖阴先生壁" "宋，王安石"
```

`gen-voice.js` 为技能脚本的本地副本，SUB 表含 `长扫→常扫`（长 cháng）、`无苔→无台`（苔 tái）、`成畦→成其`（畦 qí）、`排闼→排踏`（闼 tà）四处同音替换，仅影响音频读音。若配置 Azure 免费密钥（`TTS_AZURE_KEY`）可升级诗朗诵级音色后重跑。
