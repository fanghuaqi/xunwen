# 循文入境 ·《出塞》王昌龄

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js r128 走 CDN 三路回退，首次打开需联网；音频为本地 MP3）。

## 使用

- 双击 `index.html` → 点「入境」→ 自动朗读 + 自动游览全程无人值守（均可一键关）。
- `← →` 键或空格逐境游览；**第三境「龙城飞将」可点击画面 / 按空格**：关头火盆先自燃一处，点击后烽火一燧一燧传向天边（共 13 处），传遍时题字"不教胡马度阴山"闪烁 + 钟音（有 0.55s 冷却防连点）。
- 朗读优先级：Edge 在线神经语音现场朗诵 → 内置 `audio/*.mp3` → 系统语音兜底。
- `audio/`（00 标题 + 01..03 各句 + 04 全诗，共 5 个）由本目录 `gen-voice.js` 生成（SUB 纠音：塞 sài→赛、还 huán→环、将 jiàng→匠、教 jiào→叫）；`smoke-test.js` 为深度冒烟测试（真实 THREE r128 无头执行全部 build/update/click/goto）。

## 三境设计（情绪曲线：苍茫怀古 → 悲壮 → 昂扬）

| 境 | 诗句 | 画面 | 天色 |
|---|---|---|---|
| 壹 | 秦时明月汉时关 | **标志性瞬间①**：古关城垣横陈，巨月清冷高悬；月下城垣的影子以约 140s 周期缓缓扫转——明月照过秦、又照着汉 | 冷月高悬（星 0.75，ms 2.2，雾 0.005） |
| 贰 | 万里长征人未还 | **标志性瞬间②**：烽燧一燧一燧排向天际尽头，剪影队列渐被雾吞没；折戟沉沙、残旗猎猎、沙尘横流 | 低月浑黄（星 0.35，雾 0.008） |
| 叁 | 但使龙城飞将在，不教胡马度阴山 | 飞将军按戈立于戍楼（披风摆动），身后烽燧线直抵雾中阴山远脊——交互点烽传薪 | 月渐升扬（星 0.55，ms 1.7） |

封面：大漠孤关远景（关城与烽燧剪影、沙尘薄雾）；终章回览全诗 + 小测 5 题。

## 美术方案（防同质化）

- 风格赛道：**大漠金戈 · 边关古月变体（秦月汉关）**——bg `#120d08`、强调 `#b0906a`（古铜月金）、文字 `#f0e2cc`、雾 `#150e08`。
- 与同赛道已做的《观沧海》（沧海日月星汉）、《登鹳雀楼》（落日楼台大河）、《塞下曲》（月黑夜营雪弓刀）区分：本诗主打**"古今同月"的时空感**——同一轮冷月 + 城影流转 + 烽燧天际线；基调苍茫怀古，末境转昂扬。
- 自创新 builder：`makeBeacon`（夯土烽燧）、`makeFire`（暗置烽火：辉光 Sprite + 火焰粒子按 litAt 依次燃起）、`makeBanner`/`waveBanner`（顶点波动残旗）、`makeSpear`（折戟）、`makeDune`（沙丘）、`bQinMoon`（巨月古关 + 城影扫转）、`bWanLi`（烽燧天际线）、`bFeijiang`（飞将 + 传烽交互）。

## 教学要点

- 注音考点：**还 huán**（人未还）、**将 jiàng**（飞将）、**教 jiào**（不教，让/使）、长 cháng（长征）。
- 修辞考点：**互文**——"秦时明月汉时关"秦汉互见，极言时间悠久；明月为千年见证。
- 用典："龙城飞将"教材多指"飞将军"李广（一说卫青奇袭龙城）；阴山为中原屏障。
- 主旨：由千年边患引出对良将的渴望与和平安定的愿望，悲壮而不哀伤。
- 适合课堂大屏：自动游览 + 自动朗读约 1 分半走完封面 → 三境 → 终章全诗。
