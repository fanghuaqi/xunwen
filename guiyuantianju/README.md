# 循文入境 · 归园田居·其三（魏晋 · 陶渊明）

单文件沉浸式诗词课件：四境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 青绿春晓·月归变体：从南山豆田的晨起，到带月荷锄的夜归——全集最"辛劳而甘美"的一页。
> 标志性瞬间：带月荷锄归——月光下荷锄独行的背影，田园劳动诗意化的千古名画。

## 教学建议

- 「种豆南山下，草盛豆苗稀」的自嘲开场：诗人坦承农事不精，却毫无沮丧——先抑后扬
- 「带月荷锄归」的画面美：让学生描述这幅剪影（月、人、锄、田埂），体会劳动的诗意
- 「衣沾不足惜，但使愿无违」点题：「愿」是全诗灵魂——归隐耕作、不违本心
- 注音考点：种豆 zhòng、草盛 shèng、晨兴 xīng、荒秽 huì、荷锄 hè、道狭 xiá、草木长 zhǎng、夕露 zhān、违 wéi
- 比较阅读：与《饮酒·其五》同读——一个写"心远"，一个写"身劳"，合看陶渊明的完整田园
