# 循文入境 · 四时田园杂兴（其三十一）

宋 · 范成大：「昼出耘田夜绩麻，村庄儿女各当家。童孙未解供耕织，也傍桑阴学种瓜。」

三境沉浸式网页（Three.js 单文件课件，青绿田园赛道 ·「村庄一日」变体）：

1. **昼耘夜绩** —— 昼/夜双景同框：白日田垄农人荷锄耘禾，入夜茅屋亮灯、妇人绩麻、流萤点点。
2. **儿女当家** —— 村庄全景：男耘田、女纺麻、晾麻线、炊烟篱笆，人人各当其家。
3. **桑阴学瓜**（标志性瞬间）—— 桑树荫下小童学着大人挖坑点种，旁边立着真农具；**点击画面/按空格**看瓜苗入土、抽芽、伸藤、结小瓜的全过程（可重复观看）。

## 使用

- 双击 `index.html` 打开（首次需联网加载 Three.js CDN；音频本地）。
- `← →`/空格逐境；「自动游览 + 自动朗读」默认开，可作课堂大屏无人值守展示。
- `audio/00–04.mp3`：AI 配音（00 标题、01–03 各句、04 全诗）。删除 audio/ 目录可在 Edge 下回退"在线自然语音"逐句朗诵。

## 教学要点

- 多音字注音：**耘 yún、绩 jì、供 gòng（从事，考点，不读 gōng）、傍 bàng**；种 zhòng（种瓜，动词）。
- 逐字注音可开关；释义/注释含考点（对举手法、多音字、童趣反衬勤劳风气）。
- 小测 5 题：接龙 ×2、读音 ×1、词义 ×1、主旨理解 ×1。
