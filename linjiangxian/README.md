# 循文入境 · 临江仙

> 明 · 杨慎 ｜ 风格赛道：**大漠金戈 · 江山怀古变体**（长江沧浪、夕阳西下，不是沙漠）
> 强调色 `#c9a06a` ｜ 底 `#120d08` ｜ 五境 + 卷首 + 终章 ｜ 单文件网页，双击 `index.html` 即开

杨慎因「大礼议」被贬云南三十余年，此词是《廿一史弹词》第三段《说秦汉》的开场词，后被《三国演义》
用作卷首词。页面基调：**苍茫 → 空茫 → 壮丽（夕阳红）→ 清旷（秋月）→ 温暖超脱（笑谈）**，
与同赛道《观沧海》的沧海、《潼关怀古》的关隘、《塞下曲》的大漠、《赤壁怀古》的江涛各不相同——
本页落在「人世沧桑与超脱」上：浪淘英雄、转头成空、青山不老、渔樵浊酒、古今笑谈。

## 二、操作说明

- **入境**：封面「入 境」按钮 → 逐境推进；`←/→` 方向键、空格键、底部「上一境／下一境」皆可。
- **自动游览**（默认**开**）：「自动游览 · 开」按钮，每境停留 15~20 秒后自动进入下一境，走完自动进终章；
  课堂可无人值守投屏（再点一次按钮即关）。
- **自动朗读**（默认开）：进入每境 1.6 秒后自动朗诵该句；「朗读此句」可重播；切境即 `stopSpeak()` 静默上一句。
- **注音**：「注音 · 开／关」切换逐字拼音显隐。
- **声音**：`声音 · 开／关` 静默全部音效（江声、拨弦、钟磬）。
- **全屏**：大屏教学用。
- **两处点击交互**（画面点按 或 空格键）：
  - **第叁境 · 青山夕阳**：点击 → 夕阳「几度」循环染色**疾走**（金乌→残阳→暮紫连续染过），江面金光迸散、钟磬一响，题字「几度夕阳红」。
  - **第伍境 · 笑谈古今**：点击 → 舟中两樽**浊酒相碰**、金光迸散、题字「都付笑谈中」，江上流光转盛。
- **返回诗集目录**：封面按钮下方与终章按钮组内均有 `← 返回诗集目录 / 诗集目录`（`../index.html`）。

## 三、教学建议

1. **入境先看画面再读句**：第壹境先让学生找出「浪里被卷走的人影」，再回到「浪花淘尽英雄」——抽象的「淘尽」就被看见了。
2. **第叁境是本词的题眼**：讲「青山依旧在」（不变）与「几度夕阳红」（易变）的对比时，先点一次画面让夕阳连续染过，再问
   「不变的是什么？变的是什么？」；顺势带出「是非成败转头空」的回照。
3. **第肆境的三个考点一次讲透**：白发（fà）、江渚（zhǔ）、渔樵的隐者身份；「惯看秋月春风」＝把漫长时光说成「看惯」，
   是超脱的写法，「一壶浊酒喜相逢」把镜头从千古收到一桌一壶。
4. **第伍境收束主旨**：点一次「浊酒相碰」，问「为什么'古今多少事'要'付笑谈中'？」——引出杨慎被贬云南三十余年的身世与旷达。
5. **文学常识三连**：词牌《临江仙》／作者杨慎（明，字用修）／《廿一史弹词》第三段《说秦汉》开场词、《三国演义》卷首词。
6. **收尾**：终章「学习小测」5 题（接龙×2、读音词义×1、出处典故×1、名句手法×1），「聆听全词」可整篇跟读。

## 四、朗读与音频

朗读走统一 `aiSpeak` 管线：**① Edge「在线自然语音」现场逐句朗诵**（句间停顿 420ms、rate 0.78，最像真人）
→ **② 内置 MP3** → **③ 系统语音兜底**。未联网时自动回退浏览器语音。

配音由本目录的 `gen-voice.local.js`（`gen-voice.js` 的本词副本）生成，**SUB 多音字表已按本词改编**
（只改读音、不改页面文字）：

| 替换 | 理由 |
|---|---|
| 白发→白髮 | 白发渔樵：发 fà（头发），避免读成 fā（发现） |
| 几度→己度 | 几度夕阳红：几 jǐ（几多、多少），避免读成 jī（几乎） |
