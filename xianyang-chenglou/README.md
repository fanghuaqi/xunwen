# 咸阳城东楼 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《咸阳城东楼》（唐·许浑）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**水墨夜思**赛道——但刻意避开舟夜孤灯、雨夜棋枰、古寺竹径、渡口星火、暮雨洒江天等既有水墨构图，写的是一座危城雨前的**登楼与预感**：全诗的时间停在暴雨前一瞬——溪云初起、残日半沉、风已满楼而雨点未落，直到末境点击才让山雨真的来。accent=#93a8c4（雨前青灰，queue 分配强调色）只落在残日晕/云缘光/城楼边缘光/渭水天光/UI 上，全页近零饱和；无月（ms 0.001 移出视野），被云啃去的残日是全页唯一暖源。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"风满楼"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：云阵涌动压城、雨点初落渐密、楼头旗幡乱卷、风声骤起，"溪云初起日沉阁 山雨欲来风满楼"题字同现——而渭水依旧东流
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思 · 雨前危城变体（art-direction 赛道②）

| 项 | 取值 |

| 主色 | `#93a8c4`（雨前青灰，queue 分配强调色；按钮/边框/进度点/题字/边缘光/残日晕） |

| 场景母题 | 垛口城墙+城防楼（自写 makeChenglou，与小山楼/江楼完全不同形）、楼头旗幡（自写旗幡着色器，摆幅随诗情渐紧）、溪云横推（makeXiyun）、风线穿楼（makeFlow）、蒹葭/杨柳/汀洲、秦苑断墙+绿芜黄叶、渭水东流 |
| 粒子母题 | 风线横流、黄叶缓落、雨点（自写斜雨着色器 makeYudian——点击前 visible=false 硬关，一滴不落） |
| 与已有水墨页的区分 | 不做孤灯碎星/雨夜灯花/古寺竹径/渡口星火，更不做从天而降的大雨（bashengganzhou）：本页是「山雨未至、风已满楼」的雨前压迫感——雨只是"欲来"，落下要等读者亲手点击 |

**有意的设计**：全诗的诗眼是「欲来」二字——画面同理。境贰把溪云、残日、风线、旗幡全部推到临界点，却坚持一滴雨都不落；点击交互就是诗句本身：「山雨欲来风满楼」——云涌、雨落、幡卷在一秒内兑现，而渭水不言不语依旧东流：危机预感（国势将倾的风雨）与家国愁思（万古长流的渭水）在风雨与流水的对切里合拢。

## 教学建议

1. **导入**：先讲"许浑千首湿"——许浑诗里水、雨意象极多，后人戏称「许浑千首湿」；这首《咸阳城东楼》正是"湿"的巅峰：全诗还没下雨，你已经觉得浑身发潮。
2. **境①诗眼**：「一上」与「万里」——脚还没站稳，愁已经到了万里之外；再问学生：咸阳在西北内陆，为什么看着蒹葭杨柳却"似汀洲"？（诗人是润州丹阳人，一眼水乡看得见的是汀洲，放不下的是故乡。）
3. **境②点击前后**：点击前让学生数画面里的"雨前征兆"（云、日、风、幡）；点击后雨落幡卷——「欲来」二字为什么要憋这么久才兑现？讨论名句的双关：自然风雨 × 晚唐时局（藩镇割据、王朝飘摇），景中含忧。
4. **境③写法**：绿芜、黄叶都是眼前实景，秦苑、汉宫却是六百年前的帝业——「夕」与「秋」把一天与一年同时推向尽头；体会"以虫鸟之微写兴亡之大"。
5. **境④收束**：「莫问」不是无话可说，是千头万绪无从说起；以景结情——流水无言，却是对兴亡最沉默的回答。
6. **背景**：许浑身处晚唐，宦游万里、登临怀古；此诗约作于宣宗大中三年（849）前后任监察御史时，「日沉阁」从教材通行本（语料作「日沈阁」）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示；末境记得留给学生亲手点击——让山雨在他们手里"欲来"。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 56 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 四境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=4` 对齐。
- 交互境序号 `curIdx===4`（pointerdown 与空格双接线，`clicked` 标志 + 1.2s 冷却防连点；空格先交互、再按进终章）。
- fadeK 铁律：所有每帧写 opacity/intensity 的对象（溪云/残日/掩腰云带/地平青灰/雾/前景）初值=最大且逐帧乘 fadeK；点击增强量（雨势 uOn、云涌、幡卷）在 base 包络内；点击前雨点 `visible=false` 硬关（无幻影）；旗幡/斜雨为自写 ShaderMaterial（vertexShader+fragmentShader 齐全，uFade 走引擎约定）；山脊/地面/水面自定义着色器走引擎 `fogShaders` 雾同步。
- 预算：五境 drawCall 代理 ≈ 30/23/42/27/35、三角面 ≈ 2.0/2.6/0.7/0.8/2.4 万（≤120 / ≤12 万）。
