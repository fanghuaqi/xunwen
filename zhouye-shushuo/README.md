# 舟夜书所见 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《舟夜书所见》（清·查慎行）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版为**水墨夜思**赛道——全套冷银水墨色板；因「月黑」故**无月轮**，一盏渔灯的暖光是全页唯一的暖点；末境由一点萤火孤光爆成满河碎星，是"由一到万"的标志性瞬间。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"风起浪簇"：先交互、再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：风起浪簇，渔灯碎作满河星光（暖火星迸散 + 星光粒子自灯下一点荡开 + "散作满河星"题字）
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 强调色 | `#a8b4c0`（queue 分配 accent；按钮/边框/进度点/题字全银蓝水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#0f151f` 系，fd 0.0046–0.0062 |
| 月 | **无**——「月黑」故 ms 0.001 且月轮移出视野，全页不留月 |
| 星 | 稀疏压暗（star 0.26–0.34） |
| 唯一暖点 | 渔灯（焰心 `#ffc37a`、暖辉 `#ff9a4a`、点光 `#ffa050`）+ 水面暖光柱（水着色器 uMoonColor 指向灯位实现灯下倒影高光带） |
| 粒子母题 | 冷银浮尘、水墨江雾、横流风雾；末境满河星光粒子由灯下一点荡开（自定义 shader，uT0 触发） |

**有意的设计**：整幅冷银墨夜里只保留渔灯一处暖色——"月黑见渔灯"的孤与暖全靠这唯一对比读出；末境点击后暖光碎成满河冷银星子，暖与冷、一与万在同一画面里完成交接。

## 教学建议

1. **导入**：先遮住诗句问"月黑的夜里你能看见什么？"——再入境①，画面里只有一盏灯。
2. **境①比喻**：讲"孤光一点萤"——把渔灯的微光比作一点萤火，写光之孤、之微、之暖；对照注释"孤光"。
3. **境②炼字**：点击河星看"由一到万"再读"微微风簇浪，散作满河星"，体会"簇"（cù，风把浪吹簇起来）与"散作"——光是静的，风与浪让光活了。
4. **主旨**：讨论"为什么星星会在河里？"——是灯光倒影被浪揉碎，是观察加上想象的奇迹，不是天上的星落下来。
5. **收束**：末章全诗连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、炼字 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（末境停留 18s 后自动进终章）。
