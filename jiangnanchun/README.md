# 江南春 · 循文入境（Three.js 沉浸式诗词课件）

唐 · 杜牧：千里莺啼绿映红，水村山郭酒旗风。南朝四百八十寺，多少楼台烟雨中。

## 使用

双击 `index.html` 即可（首次需联网加载 Three.js r128，三路 CDN 回退）。

- **自动游览**：默认开启，从封面逐境推进至终章；控制条可关。
- **三境**：壹·莺啼绿红（近岸春色）→ 贰·水村酒旗（村郭酒风）→ 叁·烟雨楼台（千里俯瞰）。
- **交互**：第三境点击画面（或空格）——烟雨渐浓，四十八座寺塔次第隐入雨雾、只剩钟声隐约；再点渐散、楼台重现。
- **键位**：← → 逐境，空格下一境/触发交互，Esc 停止朗读。

## 音频

`audio/00-04.mp3`（百度 TTS 免密钥生成；`南朝`已按 cháo 校音）。
00 标题、01-03 各境、04 全诗。文件缺失时自动回退浏览器语音（Edge 下为神经语音逐句朗诵）。

## 教学要点

- 逐字注音（啼 tí、郭 guō；多音字：朝 cháo、少 shǎo），释义+注释随境展开。
- 标志瞬间：镜头升至高天，"四百八十寺"化为 48 座塔影散布千里江面，烟雨中明灭——"多少"的不可数感。
- 结课含 5 道小测（接龙×2、读音、词义、主旨）。

管线校验：`validate.js` 全绿；`accept.js` ACCEPT（3 境 · 烟雨江南）。
