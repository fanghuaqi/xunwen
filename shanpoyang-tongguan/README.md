# 《山坡羊·潼关怀古》 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《山坡羊·潼关怀古》「循文入境」教学网页：曲文推进到哪一句，三维实景就走到哪一重意境。全曲四境：从"峰峦如聚，波涛如怒"的潼关天险，走到"兴，百姓苦；亡，百姓苦"的一声长叹。本页取**大漠金戈**赛道做**黄土尘霾怀古变体**——暮色黄土、漫天尘霾，金碧宫阙虚影当着学生的面缓缓崩塌。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（境④空格等同点击交互；末境后再按进入终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏等
- 境④"兴亡之叹"轻点画面：中央宫阙虚影当场坍塌化土，尘柱冲起、钟声一响，「兴」「亡」两个大字先后浮沉，题字「兴，百姓苦；亡，百姓苦」叠现（有约 1.6 秒计时守卫，防连点）
- 末章：全诗回放、学习小测（5 题）

## 美术方案：大漠金戈（art-direction 赛道⑤）

| 项 | 取值 |
|---|---|
| 底色 | `#120d08`（与赛道⑤典型底色一致） |
| 主色 | `#b0906a`（黄土怀古调，较典型色板 `#d98e3a` 更灰更沉；按钮/边框/进度点/题字） |
| 文字 | `#f0e2cc`（与赛道⑤典型文字一致）；次要 `#a68d68` |
| 雾 | `#1a120a`（SK 默认），fd 自 0.0075 起，逐境加浓至 0.014 —— 尘霾越走越深 |
| 月 | 低垂昏黄小月（ms 1.0 渐落至 0.5），star 0.3 渐稀至 0.05 —— 一条"日暮尘深"的时间线 |
| 河水 | 咆哮黄河（amp 2.6，deep `#1a1106` / shallow `#5a3d1a` 浊浪色），月光在浊浪上泛 `#e8c890` |
| 粒子母题 | 横流尘沙（makeFlow）、宫阙坍塌扬尘与弥天尘霾（makeGlow）、暮霭雾片、浊浪泡沫 |

**有意的设计**：①全曲**雾密度单调递增**（0.0075→0.011→0.012→0.014）、星月同步退场——"宫阙万间都做了土"不是一句词，是眼前越来越浓的尘；②境③六座宫阙的**金碧虚影**（面 `#c8a468`、描边 `#e6c488`、窗光 `#ffb35c`）是全页唯一的亮暖点，专供崩塌之用：升起（1.2–5s）→ 缓缓压塌、向两侧摊开（6–15s）→ 扬尘落定、黄土残垣从尘里显形（10.5–16s），鼎盛与废墟在同一画面完成交接；③境②长安城郭虚影以 0.3 透明度在尘霾中明灭——"望西都"望见的本就是若隐若现的兴亡。

页面朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音兜底。本目录无 `tts.json`，无特殊多音字副本；易错字音以页面注音为准：**阙** què（宫阙，不读 kuì/jué）、**踌躇** chóu chú、**兴** xīng（王朝兴起，"亡，百姓苦"对举处不读 xìng）。

## 教学建议

1. **导入**：先看境①画面问"山怎么会'聚'、水怎么会'怒'？"——对照两岸群峰向河谷倾侧的造型，体会化静为动的写法。
2. **境②"意踌躇"**：看城头诗人背影与远处明灭的长安虚影，讨论"望见故都为什么不是激动而是踌躇"。
3. **境③核心画面**：完整看完"金碧亮起→崩塌→残垣显形"一轮，再读"宫阙万间都做了土"；可回放一遍让学生口述时间线（鼎盛→崩塌→落定）。
4. **境④主旨**：亲手点击让宫阙化土，看「兴」「亡」二字先后浮沉，再齐读"兴，百姓苦；亡，百姓苦"——兴亡变、百姓苦不变，这是全曲点睛之笔。
5. **背景**：结合注释介绍张养浩赴关中赈灾的写作背景，理解"伤心"二字之重。
6. 末章做完 5 题小测（接句 ×1、读音 ×1、文学常识 ×2、主旨 ×1）；课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排曲文 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 四境，共 5 项），境名逐一对齐；散曲按"潼关路→望西都→宫阙成尘→兴亡之叹"四层并作四境。
- 交互境序号 `curIdx===4`（兴亡之叹），`pointerdown`/空格均以 `state==='stage'` 守卫，点击带 `ctl.t<1.6` 防连点计时；自动游览末境判断以 `POEM.length=4` 对齐。
- 校验：`node _pipeline/tools/validate.js shanpoyang-tongguan/index.html` → **✓ 校验全部通过**。
