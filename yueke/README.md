# 约客 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《约客》（宋·赵师秀）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**水墨夜思**赛道的江南梅雨夜——冷银水墨、雨幕蛙声，灯花是全页唯一的暖色。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在末境为"灯花簌落"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 末境轻点画面：指落棋枰、灯花簌落、蛙声一片，"灯花簌落"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#8fa4b8`（强调色，按钮/边框/进度点/题字/雨丝，全部冷银蓝水墨调，**禁金**） |
| 文字 | `#dfe6f0`（次要说`#7e8ea8`） |
| 雾 | `#101722` 系，fd 0.0050–0.0075 |
| 月 | 冷银白而**被雨云遮掩**（ms 1.15–1.45、重 haze、星 0.10–0.14）——雨夜的主角是雨与蛙声，月只在天幕后淡淡一痕 |
| 粒子母题 | LineSegments 细长雨幕（显式双 shader、入雾同步）、塘雾、灯花暖烬（点击后缓落） |
| 声音 | 河声氛围（filtered noise 作雨声）+ **WebAudio 合成蛙声**（锯齿波+颤音+带通，稀疏两三声/点击后蛙声一片） |

**有意的设计**：全页水墨禁金，唯一暖色是末境那一盏**油灯**（焰心 `#ffd9a4`、点光 `#ffa050`、暖晕 `#ffb066`）——"灯花一点暖"是等客之夜里唯一的温度；冷银雨幕与暖灯同框，正是"闲敲棋子落灯花"的画面注脚。

## 朗读配音

`audio/` 内置 4 个 Edge 神经语音 MP3（`gen-voice-edge.py` 生成，zh-CN-YunxiNeural，语速 -16%）：

- `00.mp3` 标题（"约客"）
- `01–02.mp3` 两联逐境朗读
- `03.mp3` 全诗连读

读音自查：处 chù（处处）、敲 qiāo、落 luò、约 yuē 均为常规读音，与页面注音一致，未钉 SUB 替换表。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。如需"诗朗诵"级音色，可设 `TTS_AZURE_KEY` 后重跑 `gen-voice.js`。

## 教学建议

1. **导入**：问学生"等人不来说说是什么滋味？"再入境①，听雨声蛙声，读"家家""处处"两组叠字，体会雨的绵密与蛙的喧闹。
2. **境①以声衬静**：蛙鸣愈闹，夜愈静，人愈孤单——讨论"热闹为什么反而衬托等待"。
3. **境②诗眼**：看独坐敲棋的画面，讨论"敲"字——为什么不是"等"不是"叹"？闲适的动作里藏着怎样的心情？
4. **灯花意象**：介绍古人以灯花为喜兆，反衬客不至的怅惘；点击画面看灯花簌落，体会"一点暖"与"满页冷"的对比。
5. **收束**：末章全诗连读，做完 5 题小测（接龙 ×2、读音词义 ×1、文学常识"永嘉四灵" ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 两境），境名逐一对齐；交互境序号 `curIdx===2`，末境空格先交互、再按进终章；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 标志性瞬间为原创 builder：雨幕（LineSegments 着色器，入 fogShaders 同步）、WebAudio 蛙声（croak/frogChorus）、灯花簌落（LAMPFALL 着色器 uGo 点亮）。
- 校验：`node _pipeline/tools/validate.js yueke/index.html` → **✓ 校验全部通过**（零警告）。
- 冒烟：`node yueke/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 三境 build/update×400 帧 → 末境点击门控（冷却期返回/触发置 clicked）→ pointerdown/空格门控 → 自动游览至终章 → 小测 5 题满分 → fadeK 合规（每帧写 opacity/intensity 均乘 fadeK）→ 三层构图与 draw call ≤120、三角面 ≤12 万）。
