# 循文入境 · 乡村四月（宋 · 翁卷）

单文件沉浸式诗词课件：`index.html` 双击即开（Three.js 走 CDN，音频本地）。

## 内容

- **三境**：绿原白川（山原全绿、水田如镜白满川）→ 雨如烟（极细雨丝＋烟霭层，子规两声一停的杜鹃啼）→ 插田忙（蚕屋蚕匾剪影、弯腰插秧身影一排带水面倒影；点击画面：雨烟弥漫、身影加速忙碌、秧苗一行行铺开变绿）。
- 逐字注音（了 liǎo / 川 chuān / 蚕 cán 已核）、释义注释、AI 朗读（`audio/00–04.mp3`）、自动游览、学习小测 5 题。

## 操作

- `入境` 进入；`← →` / 空格逐境；第三境点击画面或空格触发农忙交互。
- 控制条：自动游览、自动朗读、注音、声音、全屏均可开关。
- Edge 下优先用"在线自然语音"现场朗诵；无网络时回退浏览器语音。

## 课堂建议

1. 先整体自动游览一遍，让学生说"看到了什么"再对读诗句。
2. 第三境提问：为什么"闲人少"？蚕桑与插秧是什么时节的活计？
3. 小测可作当堂检测；"了 liǎo"读音是本诗最常见考点。

## 音频重生成

```bash
node gen-voice.js index.html "乡村四月" "宋，翁卷"
```

`gen-voice.js` 为技能脚本的本地副本，SUB 表含 `才了→才蓼`（了 liǎo）、`翁卷→翁倦`（卷 juàn）两处同音替换，仅影响音频读音。若配置 Azure 免费密钥（`TTS_AZURE_KEY`）可升级诗朗诵级音色后重跑。
