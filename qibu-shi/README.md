# 循文入境 · 七步诗（魏 · 曹植）

单文件沉浸式诗词课件：三境随诗句推进（煮豆漉菽 → 萁燃豆泣 → 同根相煎），逐字注音、释义注释、AI 朗读、自动游览、结课小测。美术走「宣纸留白 · 釜中悲歌」变体：浅色宣纸 UI + 灶火暗红的压迫特写。

## 打开

双击 `index.html`（首次需联网加载 Three.js；朗读音频在本地 `audio/`）。

- `audio/00.mp3` 标题 · `01-03` 各境 · `04` 全诗，共 5 个（百度 TTS 生成，页面亦自动回退浏览器语音）

## 标志瞬间与互动

- 第二境「萁燃豆泣」：半剖釜特写——釜下萁柴烈火，釜中豆粒翻滚下沉、泣泡上浮；背景七枚脚印通向书案，呼应"七步成诗"。
- 第三境「同根相煎」：点击画面（或按空格）——釜火更烈、豆泣加剧、低泣声效，题字"相煎何太急？"；釜边同根的豆萁豆荚与地下根脉直连釜中。

## 教学建议

1. 境一讲劳作画面，落实"羹 / 漉 / 菽"注释与多音字读音；
2. 境二借剖面看拟人："燃"与"泣"一火一泪，可让学生指认画面中的对应；
3. 境三先点击互动体会"同根生 / 相煎"的兄弟相逼之悲愤，再讲曹丕曹植典故，最后用小测巩固。
