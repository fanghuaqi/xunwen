# 忆秦娥 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《忆秦娥》（唐·李白，传）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**水墨夜思**赛道——全套冷银水墨色板，冷月是唯一主角；「西风残照」取锈赭而非金，是全页唯一的非冷色，取"帝国余温将尽"之意。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"点击残照西风"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：西风残照里汉家陵阙剪影显形（残照增亮 + 银月光晕 + 五声箫韵余响 +「汉家陵阙」题字）
- 末章：全词回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#9fb3cc`（accent/按钮/边框/进度点/题字，全部银蓝水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#111826`～`#121520`，fd 0.0048–0.0065 |
| 月 | 冷银白（ms 1.6–1.9），全页唯一主角；星稀（亮度 0.45–0.5） |
| 粒子母题 | 微尘、灞柳飞絮、横流西风（替代《将进酒》的金色流萤/火星） |
| 唯一非冷色 | 境②「残照」：锈赭余晖带 + 残日之魂（`#7a4638` 系，非金），点击后增亮——兴亡将烬的一点余温 |

**有意的设计**：全页严格冷银，唯有境②天边一道锈赭残照。它不是暖色点缀，而是本词题眼——西风残照与冷月同天，正见"人间的黄昏"与"千古的月光"相照。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，水墨赛道清朗男声）：

- `00.mp3` 题名（诗题自动提取："忆秦娥"）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字处理（`tts.json`，sub 非空即完全接管）：「箫声咽」之「咽」读 yè（呜咽），替换表 `箫声咽→箫声夜` 同音同调钉音。乐游原之「乐」（lè）、陵阙之「阙」（què）经核为默认读音，未钉。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"箫声为什么是'咽'的？"再入境①，对照画面听"呜咽"的叠句节奏（秦楼月，秦楼月——词牌回环）。
2. **境①意象**：箫声、月、柳三层意象逐层看——楼头窗月微光即"秦楼月"；桥上人影即"灞陵伤别"；结合注释讲汉唐灞桥折柳赠别之俗。
3. **境②动作**：让学生先看空旷古道再点击画面，体会"音尘绝"到"陵阙显形"的惊喜与苍凉；讨论"为什么陵阙是剪影、残照不是金色"。
4. **主旨**：王国维评"西风残照，汉家陵阙"寥寥八字"遂关千古登临之口"——由月夜伤别上升到千古兴亡，是本词高于一般闺怨词之处。
5. **收束**：末章全词连读一遍，再做完 5 题小测（接龙 ×2、读音 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 两境），境名逐一对齐（秦楼月咽 / 汉家陵阙）；分境拼接与 queue.json 文本逐字一致。
- 交互境序号 `curIdx===2`（pointerdown + 空格双接线；空格首次触发交互、交互后再按才进终章，`clicked` 标志 + 1.2s 冷却门控）。
- 三层构图逐境齐备：`makeRange` 山脊背景 + `makeForeground` 前景框景（坡石/芦苇/树枝）+ 中景主体（`makeFigure` 秦娥与石翁仲、`makeCrowd` 灞桥人影）；每帧写 opacity/intensity 均乘 fadeK，会每帧写的材质初值=最大值；残照着色器显式传 vertexShader/fragmentShader。
- 校验：`node _pipeline/tools/validate.js yi-qin-e/index.html` → **✓ 校验全部通过**。
- 冒烟：`node yi-qin-e/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 两境 build/update ×400 帧 → 末境点击门控与 pointerdown → 自动游览至终章 → 键盘全路径 → 小测全流程；逐境 drawCall 代理 15/22/24，三角面 ≤2.9 万，fadeK 合规）。
