# 题临安邸 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《题临安邸》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**水墨夜思**赛道，取「西湖灯影」变体——夜色里的湖山楼台层层叠叠、画舫灯影正盛；末境点击西湖歌舞，暖风横流、灯影虚化，**汴州**故都的残影自湖上渐渐浮现。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击西湖歌舞"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：暖风横流、五盏湖灯的光团放大变柔（灯影虚化）、湖上浮出汴州故都的楼台残影，"杭州作汴州"题字同现
- 末章：全诗回放、学习小测（5 题）

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 `zh-CN-YunxiNeural`，语速 −16%），0 失败：

- `00.mp3` 标题（"题临安邸"）
- `01.mp3` 境壹（山外青山楼外楼，西湖歌舞几时休？）
- `02.mp3` 境贰（暖风熏得游人醉，直把杭州作汴州。）
- `03.mp3` 全篇连读

多音字处理见 `tts.json`（**sub 非空即完全接管**）：

- `几时` → `己时`：钉住「几」的 **jǐ**（几时=何时），避开「几乎」的 jī（与库中《卜算子·我住长江头》同一处高置信替换）
- 「熏得」的「得」在句中作补语标志读轻声 **de**，页面注音照此标注
- 逐句核过：山外青山、楼外楼、西湖歌舞、休、暖风、游人醉、直把、杭州、汴州——无须干预

页面朗读优先级：Edge 在线自然语音现场逐句朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"如果一个人在旅店墙上写诗骂人，他会怎么写？"再入境壹。
2. **境壹析"外"与"休"**："山外青山楼外楼"两个"外"字把繁华推得没有尽头；"几时休"由赞转问，是全诗的转折点。
3. **境贰析双关**："暖风"既是春风、也是奢靡之风；"游人"不是普通游客，是在此寻欢的权贵。
4. **点击体会**：点击西湖歌舞看灯影虚化、故都浮现——问学生："为什么灯越亮，诗人越难过？"（因为汴州已经沦陷。）
5. **知人论世**：林升生平不详，此诗题在临安旅舍墙上；南宋偏安江南近一百五十年，"直把杭州作汴州"是对整个时代的判词。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、词义 ×1、典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 39 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（楼台、画舫、湖灯）都在 10–45 单位内，fd ≤ 0.0064；汴州残影是全页唯一"每帧写 opacity"处，基座 0.58 = 运行期最大值并乘 fadeK 与进度；灯影虚化只调 scale。
- 场景构件（冒烟实测）：卷首 43 mesh / 22 sprite、境壹 58 mesh / 26 sprite、境贰 45 mesh / 19 sprite；draw call 代理值 66 / 85 / 66（≤120），三角面 ≈2.1 / 2.9 / 2.6 万（≤12 万）。
