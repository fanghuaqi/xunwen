# 嫦娥 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《嫦娥》（唐·李商隐）「循文入境」教学网页：诗句推进到哪一句，三维实景就走进哪一重意境。本页取**水墨夜思**方向——冷银墨夜色板贯穿全页，孤月与银河是唯一主角，屏风前一炬暖烛是全页唯一的暖色，正合"夜夜心"的孤清。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN，多源自动回退；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在末境③为"闪现题字"）
- 控制条：自动游览、朗读此句、自动朗读、注音、声音、全屏
- 进度点：点击圆点可直接跳境
- 末境③轻点画面：闪现"碧海青天夜夜心"题字
- 末章：聆听全诗、学习小测（5 题）、再游一次、回卷首

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题与作者（"嫦娥。唐，李商隐。……"）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全诗连读

页面朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音兜底。无特殊多音字副本；逐字注音已按诗义标定易错音——"应悔"的**应读 yīng**（想必、应当，非 yìng）。如需更高级音色，可用 `_pipeline/tools/gen-voice-edge.py` 重生成。

## 教学建议

1. **导入**：先讲嫦娥奔月神话，设问"飞升成仙是福是祸？"再入境①看烛影。
2. **境①②写景**：让学生从"深""沉"两个字读出时间——烛影越暗、晓星越沉，是通宵未眠的一夜。
3. **境③由景入情**：点击闪现题句后齐读，讨论"应悔"是推测语气——诗人替嫦娥想，也是自况。
4. **情感升华**：对照"碧海青天"的开阔与"夜夜心"的孤寂，谈"得不到的永远喧嚣，得到了的独对青天"。
5. **收束**：末章全诗连读，再做 5 题小测（接句 ×1、文学常识 ×1、内容理解 ×2、诗句理解 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 三境；三四句"嫦娥应悔偷灵药，碧海青天夜夜心"合为一境），境名逐一对齐。
- 点击交互境序号 `curIdx===3`（末境）；进度点/按键/自动游览末境判断均以该长度对齐。
- 校验：`node _pipeline/tools/validate.js chang-e/index.html` → **✓ 校验全部通过**。
