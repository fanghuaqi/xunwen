# 木兰花·拟古决绝词柬友 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《木兰花·拟古决绝词柬友》（清·纳兰性德）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。全套冷银水墨色板（底色 `#0d1117`、强调色 `#c4cfe0`、无一处金色），冷月是唯一主角；「人生若只如初见」与「秋风悲画扇」的初见之好 / 见弃之悲，以**一柄画扇的两面**贯穿全页。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在末境为"画扇翻面"，交互后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 末境轻点画面：秋风画扇翻转——初见的并蒂莲面 ↔ 见弃的秋风枯枝面，翻到初见面时有一线低饱和暖忆微光（全页唯一暖色）
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 强调色 | `#c4cfe0`（按钮/边框/进度点/扇骨/人物边缘光，全部冷银，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#131a26` 系，fd 0.0048–0.0066 |
| 月 | 冷银白（ms 1.5–2.0，境①最大 2.0），全页唯一主角 |
| 星 | 稀疏（0.35–0.5），末境细雨压星光 |
| 粒子母题 | 辞枝落叶（冷灰）、骊山夜雨（细密银丝）、风流横雾、封面月华微尘 |

**有意的设计**：末境点击画扇翻到「初见」面时，扇侧浮起一线 `#b08e80` 低饱和暖光——它是全页唯一的暖源，且刻意低饱和：暖忆是隔着诀别看回去的，不许发艳；翻回「诀别」面即冷对如霜。初见的暖忆与见弃的冷对是全页情绪轴。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，免密钥生成）：

- `00.mp3` 标题（自动提取："木兰花·拟古决绝词柬友"）
- `01–02.mp3` 上下片逐境朗读
- `03.mp3` 全词连读

多音字处理见 `tts.json`：骊（lí）、薄幸（bó）以同音同调字替换接管 TTS 读音（狸山 / 勃幸），其余（却 què、语 yǔ、当日 dāng 等）神经语音默认读对，未钉写。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：从「人生若只如初见」这句人人会背的名句设问——它其实是"决绝词"里的反问？再入境①看画扇被弃的画面。
2. **境①用典**：结合注释讲班婕妤《怨歌行》"秋扇见捐"——夏日随身、秋来见弃；体会「等闲」二字的凉薄。
3. **境②用典**：对照骊山盟誓与蜀道闻铃（白居易《长恨歌》互文），讲"终不怨"的怨而不敢怨；「薄幸锦衣郎」一问的双关。
4. **末境交互**：让学生亲手点击画扇翻面——初见面（并蒂莲、暖光）与诀别面（枯枝、冷雨）的翻转，就是全词"初见之好 ↔ 见弃之悲"的对切；讨论：为什么暖光是低饱和的？
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
