# 循文入境 · 寻隐者不遇（唐 · 贾岛）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，音频本地）。

## 内容

- **三境**（诗句推进）：松下一问 → 言师采药 → 云深一望
- **风格**：宣纸留白 · 云山问答变体（强调色墨松绿 #3e4436，底色宣纸 #e9e2d0）
- **标志瞬间**：境三「云吞山径」—— 云海自山坳涌起漫过石径，草庐与斗笠（隐者踪迹）被云掩没；隐者全程不露面，"不遇"即留白
- **互动**：境三点击画面或按空格 —— 云卷云舒（云涌掩径 / 云开见径），配题字"云深不知处"
- 逐字注音（多音字已按教材核对：松 sōng、采 cǎi、只 zhǐ、处 chù）、释义、注释、AI 朗读、自动游览、学习小测（5 题）

## 操作

- `← →` 或空格：逐境游览；`Esc`：停止朗读/关闭弹层
- 控制条：自动游览、自动朗读、注音、声音、全屏
- 第三境提示：轻点画面看云涌掩径

## 音频

`audio/00–04.mp3`：00 标题（寻隐者不遇。唐，贾岛）、01–03 各境、04 全诗。
百度 TTS 免密钥生成；如需"诗朗诵"级音色，配置 `TTS_AZURE_KEY` 后重跑 gen-voice.js。
网络不通时页面自动回退浏览器语音（Edge 下为神经语音现场逐句朗诵）。

## 教学

问答体五言绝句：首句问、次句答、三四句补答，可让学生在页面三境中找出"问—答—指"的对话结构；"云深不知处"的留白可讨论"不遇之遇"的禅意。
