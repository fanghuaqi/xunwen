# 辛夷坞 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《辛夷坞》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**宣纸留白**赛道，取「空山辛夷」变体——纸色空山里一株**先花后叶**的辛夷，花开在**木末**（树梢）之上，红色的花萼在山中绽出；末境点击开且落，花纷纷绽放，又纷纷落下。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击开且落"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：十处花光次第点亮（0.5→1.5 倍）、枝摇幅度 0.25→0.75 加剧、130 枚花瓣**落速 ×3.2**（纷纷开且落），"纷纷开且落"题字同现
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：封面设问"如果一朵花开了没人看，它还算开过吗？"再入境壹。
2. **境壹析"木末"与"红萼"**：「木末」定位置（高枝之梢）、「红萼」定颜色（空山一点红）；先花后叶，正是辛夷的物候（可配实物图）。
3. **境贰析"寂无人"与"开且落"**：无人之境与花开花落并置——**不为谁开，也不为谁落**，是万物自得，也是诗人自己的心境。
4. **点击体会**：点击开且落看花光点亮、落花加速，问："没有人看，花为什么还开得这么认真？"
5. **知人论世**：王维晚年隐居辋川，《辛夷坞》是《辋川集》二十首之一；他诗画兼擅（苏轼评"诗中有画，画中有诗"），此诗正是"无人的画"。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、词义 ×2、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 37 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（辛夷、岩壁、涧水）都在 8–34 单位内，fd ≤ 0.0060；全页**无一处手写 opacity**（花光/落花/辛夷/涧水全走 scale、实例矩阵或 uniform）。
- 场景构件（冒烟实测）：卷首 11 mesh、境壹 11 mesh、境贰 11 mesh / 17 sprite；draw call 代理值 19 / 19 / 29（≤120），三角面 ≤1.1 万（≤12 万）。
