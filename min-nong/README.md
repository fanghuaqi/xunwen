# 循文入境 · 悯农（其二）｜唐 · 李绅

三境沉浸式诗词课件：Three.js 单文件网页，诗句推进到哪一句，就走进哪一重田垄。

## 打开

双击 `index.html` 即可（首次需联网加载 Three.js 引擎，音频为本地 MP3）。

## 三境

1. **烈日当午** —— 正午烈日高悬，田垄灼灼，农人弯腰挥锄，禾苗在热风里轻摆。
2. **汗滴入土**（标志瞬间）—— 汗珠从额角坠落的慢镜头特写，坠入土中溅起微尘；**点击画面 / 空格：烈日更炽、汗滴更密**。
3. **粒粒辛苦** —— 桌上白米饭与烈日汗滴两相对照，碗沿拢一把金黄禾穗；**点击画面：烈日更炽、米粒生辉**。

## 使用

- `← →` 键或空格逐境游览；「自动游览」打开后可作课堂大屏无人值守展示。
- 朗读优先级：Edge 神经语音现场逐句朗诵 → `audio/` 内置配音 → 系统语音。`audio/` 内 00 为标题、01–03 为各境、04 为全诗。
- 「注音」可开关；每境附释义与注释（含多音字考点：当 dāng/dàng、谁 shuí、中 zhōng 等）。

## 教学建议

- 先整体自动游览一遍，再逐境提问："画面里哪里看出'日当午'？""汗滴到哪里去了？"
- 讲"粒粒辛苦"时切到第三境，用盘中白米与前面两境的烈日、汗珠对照，落实"珍惜粮食"主旨。
- 小测 5 题覆盖接龙、多音字、文学常识与主旨，可在结课时全班抢答。
