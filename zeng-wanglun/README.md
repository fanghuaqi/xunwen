# 循文入境 · 赠汪伦（李白）

三境随诗句推进的沉浸式单文件教学网页。双击 `index.html` 即可打开（Three.js r128 走 CDN 三路回退，音频本地，无需服务器）。

## 风格赛道：烟雨江南 · 桃花潭变体

- 色板：底 `#10141a` · 主黛蓝 `#8fb3c9` · 强调藕荷粉 `#d8a7b1` · 文字 `#e6ecef` · 雾 `#151d26`（fd 0.009–0.014）
- 与同赛道《声声慢》（愁雨）刻意区分：本诗是"踏歌送别"的欢快 —— 无雨，母题为**桃花瓣**（落瓣、潭面浮瓣、花瓣火星），暖粉霞光，基调深情而明朗
- 情绪曲线：晨潭清朗 → 暖粉霞光的踏歌高潮 → 沉入碧潭后的深情

## 三境设计

| 境 | 诗句 | 画面 |
|---|---|---|
| 卷首 | —— | 晨雾桃花潭，远岸桃林剪影，粉瓣微尘 |
| 壹 乘舟将行 | 李白乘舟将欲行 | 乌篷船载李白将离岸，两岸桃林落英，潭面浮瓣 |
| 贰 忽闻踏歌（标志性瞬间） | 忽闻岸上踏歌声 | **九人踏歌人影随 109 拍/分节拍齐顿足、挥袖，WebAudio 踏步声与影像同步**；每拍自岸边荡开一圈涟漪，潭面桃花瓣随歌轻荡 |
| 叁 潭水情深（交互） | 桃花潭水深千尺，不及汪伦送我情 | 近岸"剖开"露出**深水断面**：上碧下墨的水体剖面 + 水下悬浮微粒 + 斜入光柱，镜头 30 秒缓缓下潜看"深千尺"；岸上人群仍在 |

**交互**：第叁境点击画面 / 按空格 —— 岸上人群齐顿足而歌（踏步声 + 五声音阶歌句 + 花瓣迸溅 + 涟漪强荡开 + 题字"踏歌声"）。

## 使用

- **游览**：← → 键或空格逐境；顶部进度点可跳境；"自动游览"开启后可作课堂大屏无人值守展示。
- **朗读**：优先 Edge 神经语音现场逐句朗诵；无神经语音时播放 `audio/` 内置配音；两者都缺失时回退系统语音。
- **声音**：潭水底噪 + 踏歌节拍建议佩戴耳机。

## 音频

`audio/00.mp3`（标题）+ `01–03.mp3`（各句）+ `04.mp3`（全诗），共 5 个文件，由 `gen-voice.zwl.js`（共享 gen-voice.js 的本诗副本）生成。
多音字替换表（只影响音频读音）：将欲行→江欲行（将 jiāng）；踏 tà、乘 chéng 无歧义。
如需"诗朗诵"级音色：`set TTS_AZURE_KEY=你的密钥` 后重跑 `node gen-voice.zwl.js index.html "赠汪伦" "唐，李白"`。

## 教学要点（小测覆盖）

- "不及"的比较手法：以千尺潭水之深衬托送别之情更深，化无形为有形
- 多音字考点：将欲行 jiāng（将要）、踏 tà
- "踏歌"：以脚踏地为节、且行且唱的民间歌舞形式（连接《竹枝词》"闻郎江上踏歌声"）
- 汪伦：泾县桃花潭人，以美酒与踏歌相待，成就这段友情佳话
