# 画眉鸟 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《画眉鸟》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**青绿春晓**赛道，取「山花鸟鸣」变体——春山高低树、山花红紫、林间画眉千百声婉转；末境一只**金笼**挂在枝上，点击自在啼，笼门开启、笼中画眉飞向林间。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击自在啼"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：金笼的笼门旋开（1.9 弧度）、笼中画眉飞出盘旋 2.6 秒落向林间、四鸟一同振羽对啼（五声音阶）、"自在啼"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：青绿春晓 · 山花鸟鸣（art-direction 赛道④）

| 项 | 取值 |
|---|---|
| 底色 | `#0a1410`（青绿底色） |
| 主绿 | `#a3c98f`（按钮/边框/进度点/题字，= 本诗分配强调色） |

| 粒子母题 | 黄绿微尘、林间薄雾；**山花的红紫**是全页唯一的艳色，**金笼的金**是唯一的金属亮色 |
| 标志性瞬间 | 「笼开·鸟飞」——点击后笼门旋开，笼中画眉划一道弧线飞向林间，与三只林间画眉一同振羽 |

**与同赛道《三衢道中》（黄鹂绿阴）不同**：那一首是黄鹂（黄羽黑枕）啼绿阴；本页主角是**画眉**——褐羽、白色眼圈与白眉纹，且有一只十四根笼条的**金笼**（拱顶、三道箍、挂钩、食罐、可开的笼门）与之对置。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 `zh-CN-XiaoxiaoNeural`，语速 −14%），0 失败：

- `00.mp3` 标题（"画眉鸟"）
- `01.mp3` 境壹（百啭千声随意移，山花红紫树高低。）
- `02.mp3` 境贰（始知锁向金笼听，不及林间自在啼。）
- `03.mp3` 全篇连读

多音字处理见 `tts.json`（**sub 非空即完全接管**）：

- `金笼` → `金龙`：钉住「笼」的名词读音 **lóng**（笼子），避开「笼罩」的 lǒng —— 与页面注释第 3 题同点
- **未替换**：`百啭` 的「啭」读 zhuàn（鸟鸣回旋）；现代汉语里没有更常见且同音同调的替代字（转 zhuàn 与 zhuǎn 两读、传 chuán 与 zhuàn 两读，替换反而更糟），故按"宁缺勿滥"保留原字
- 逐句核过：百啭千声、随意移、山花红紫、树高低、始知、锁向、不及、林间自在啼——无须其他干预

页面朗读优先级：Edge 在线自然语音现场逐句朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"如果能问一只鸟：你愿意住在金笼子里吗？"再入境壹。
2. **境壹析"随意移"**：三个字是自由的注脚；配合"山花红紫树高低"，让学生找一找画面里"高低"的层次。
3. **境贰析对比**："金笼"越华美，越显出"锁"字的分量；"始知"与"不及"是一悟一判。
4. **点击体会**：点击自在啼看笼门开、鸟飞去，再读末句——问学生："飞出去的那只鸟，会飞向哪里？"
5. **知人论世**：此诗作于欧阳修贬谪滁州时（他在滁州写下《醉翁亭记》），借鸟喻人：厌倦官场束缚，向往林泉自在。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、词义 ×1、背景寓意 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 37 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（金笼、画眉、花丛、树）都在 8–24 单位内，fd ≤ 0.0062；全页**无一处手写 opacity**（笼门/飞鸟/花丛/树冠全走旋转或 scale）。
- 场景构件（冒烟实测）：卷首 15 mesh、境壹 19 mesh、境贰 18 mesh；draw call 代理值 23 / 27 / 26（≤120），三角面 ≤2.1 万（≤12 万）。
