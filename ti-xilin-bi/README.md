# 循文入境 · 题西林壁（宋 · 苏轼）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（需联网加载 Three.js，音频已内置本地）。

## 页面结构（三境）

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 横岭侧峰 | 横看成岭侧成峰，远近高低各不同。 | 同一座庐山模型，镜头自动巡游：横看绵延成岭 → 侧看孤峭成峰 → 远看全山在目 → 近看但见崖壁 |
| 贰 · 雾掩真面 | 不识庐山真面目。 | 云雾渐合，主峰没入云中 |
| 叁 · 身在此山 | 只缘身在此山中。 | 镜头落入谷底，崖壁云雾包围——身在山中不见山。**点击画面/按空格**在横看/侧看/远看/近看/山中五个机位间切换 |

美术：宣纸留白 · 墨色山势变体（底色 `#e9e2d0`，主墨 `#3a3f4a`），山体为确定性高度场水墨渐变，配西林寺塔与淡墨飞鸟。

## 使用

- `← →` / 空格逐境游览；自动游览、自动朗读默认开，可一键关（适合课堂大屏）。
- `audio/00–04.mp3`：AI 配音（00 标题、01–03 各境、04 全诗）；网络不通时自动回退浏览器语音（Edge 下为神经语音现场逐句朗诵）。

## 教学建议

- 先让学生只看画面猜诗句，再逐境对照原文与注音。
- 第三境点击切换机位时提问：为什么换了位置，山的模样全变了？引出"当局者迷，旁观者清"。

## 开发

- `node smoke.test.js`：深度冒烟测试（THREE 桩跑全部 build/update/click）。
- 结构校验：`node <技能目录>/scripts/validate.js index.html`。
