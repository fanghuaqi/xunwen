# 夜书所见 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《夜书所见》（宋·叶绍翁）「循文入境」教学网页：诗句推进到哪一句，三维实景就走进哪一重意境。本页取**水墨夜思**方向——冷银墨夜、秋风梧叶的全冷色板里，深夜篱落那一盏暖橙篱灯是全页唯一的暖色，也是"所见"的落点。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN，多源自动回退；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在末境③为"点亮篱灯"）
- 控制条：自动游览、朗读此句、自动朗读、注音、声音、全屏
- 进度点：点击圆点可直接跳境
- 末境③轻点画面：篱灯骤然增亮，铃声、"夜深篱落一灯明"题字闪现
- 末章：聆听全诗、学习小测（5 题）、再游一次、回卷首

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜，body 与 #err 同色） |
| 主银 | `#b8c4dd`（--gold 变量；按钮/边框/进度点/题字，全银蓝水墨调） |
| 文字 | `#e2e8f2`，次要 `#7e88a0`；边线 `rgba(184,196,221,.28)` |
| 天穹 | top `#0d141b` / hor `#19222d` / bot `#090d13` |
| 雾 | `#121a24`，fd 0.005–0.007（末境最浓，夜最深） |
| 月 | 冷月高悬，ms 0.7–1.05（逐境缓缓降低，天色渐深） |
| 星 | 稀疏（star 0.2–0.45，逐境减暗） |
| 粒子母题 | 梧叶飘落（枯叶褐 `#6a5a3a` 翻旋下落）、风痕横流（`#8fa2c2`）、夜雾（`#7e88a0`） |

**有意的设计**：全页风、叶、江、月一路冷银，只有末境篱灯保留**暖橙**（灯 `#e8a44a`，辉光与点光同色）——它是全页唯一的暖色点。冷是游子的秋夜，暖是篱下孩童的一灯，色彩对比直接演出了"客情"与"所见"的温度差。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题与作者（"夜书所见。宋，叶绍翁。……"）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全诗连读

页面朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音兜底。无特殊多音字副本；逐字注音已按诗义标定易错音——"挑促织"的**挑读 tiǎo**（用细长东西拨动）、**促织 cù zhī** 即蟋蟀。如需更高级音色，可用 `_pipeline/tools/gen-voice-edge.py` 重生成。

## 教学建议

1. **导入**：设问"秋夜里，什么声音最能让你感到冷？"再入境①听梧叶"萧萧"。
2. **境①②写景起兴**：梧叶寒声、江上秋风都是"动客情"的引子——让学生找一找前两句里"送"和"动"两个字各自的方向（景送寒、风动情）。
3. **境③转折**：诗人夜里看见的不是景而是人——点击点亮篱灯，讨论"为什么一盏灯能让他想到儿童捉蟋蟀？"
4. **情感对比**：孩童玩得高兴，客子看得想家——以乐景写哀情，可联系"独在异乡"的体验。
5. **收束**：末章全诗连读，再做 5 题小测（接句 ×1、词义"促织" ×1、文学常识 ×1、画面理解 ×1、主旨情感 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 三境；三四句"知有儿童挑促织，夜深篱落一灯明"合为一境），境名逐一对齐。
- 点击交互境序号 `curIdx===3`（末境）；进度点/按键/自动游览末境判断均以该长度对齐。
- 校验：`node _pipeline/tools/validate.js yeshu-suojian/index.html` → **✓ 校验全部通过**。
