# 菩萨蛮·平林漠漠烟如织 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《菩萨蛮·平林漠漠烟如织》（唐·李白，传）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**烟雨江南**赛道——黛蓝湿雾色板、斜风细雨母题；「寒山一带伤心碧」的碧是全页唯一的彩色点，取"愁眼观物，物皆著愁"之意。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境③为"点击宿鸟归飞"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境③轻点画面：宿鸟一头投林渐隐，长亭短亭被一线光带逐亭牵向天际（游走光点 + 五声琶音 +「长亭更短亭」题字）
- 末章：全词回放、学习小测（5 题）

## 美术方案：烟雨江南（art-direction 赛道⑥）

| 项 | 取值 |
|---|---|
| 底色 | `#10141a`（黛蓝夜） |
| 主色 | `#8f9ab8`（accent/按钮/边框/进度点/题字，全部黛蓝调，**无一处金色**） |
| 文字 | `#e6ecef` |
| 雾 | `#131a22`～`#161c26`，fd 0.012–0.014（湿雾) |
| 月 | 隐月（ms 0.3–0.5，低垂天际），星稀（亮度 0.03–0.1） |
| 粒子母题 | 斜风细雨（NormalBlending 雨丝）、横流烟带（「烟如织」双层数交叉）、水面雾 Sprite、微尘 |
| 唯一彩点 | 境①「伤心碧」：寒山上空一带青碧雾光着色器（`#22564a` 系），轻透缓息——愁眼里的春山 |

**有意的设计**：全页严格黛蓝单色系，唯境①寒山浮一带青碧。它是本词题眼——暝色四合之中，那带碧色"伤心"难辨是山色还是愁色；此后两境再无彩色，愁意随暮色愈染愈深。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（Edge 神经语音 zh-CN-XiaoxiaoNeural，语速 -16%，烟雨赛道温婉女声）：

- `00.mp3` 题名（诗题自动提取："菩萨蛮·平林漠漠烟如织"）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全词连读

多音字处理（`tts.json`，sub 非空即完全接管）：「宿鸟」之「宿」读 sù（栖息），替换表 `宿鸟→素鸟`；「暝色」之「暝」读 míng（暮色），替换表 `暝色→冥色`——均同音同调钉音。「织」（zhī）、「伫」（zhù）、「更」（gèng，长亭更短亭之"接连"义）经核为默认读音，未钉。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"烟怎么会'如织'？"再入境①，对照画面看双层烟带在平林上穿梭交织。
2. **境①炼字**：抓住"漠漠""织""伤心碧"三个词——让学生讨论"山色本无情的碧，为什么诗人说'伤心'"（移情于景）；结合注释讲暝色入楼、愁亦入楼。
3. **境②反衬**：看急急归巢的鸟影与伫立不动的人影，体会"鸟犹知返，人归何处"的反衬笔法；"空"字是眼——伫立再久也是枉然。
4. **境③收束**：点击画面看宿鸟投林、亭亭相连的瞬间，讨论"长亭更短亭"为何能写尽归程之遥（十里一长亭、五里一短亭，亭亭无尽即愁绪无尽）。
5. **收束**：末章全词连读一遍，再做完 5 题小测（接龙 ×2、读音 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
7. 可补背景：此词相传李白作（《菩萨蛮》被视为文人词鼻祖之一），黄升《花庵词选》题作"闺情"。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 三境），境名逐一对齐（平林烟织 / 玉阶宿鸟 / 长亭短亭）；分境与 queue.json 逐字一致（长亭更短亭独立成境）。
- 交互境序号 `curIdx===3`（pointerdown + 空格双接线；空格首次触发交互、交互后再按才进终章，`clicked` 标志 + 1.2s 冷却门控）。
- 三层构图逐境齐备：`makeRange` 山脊背景 + `makeForeground` 前景框景（坡石/芦苇/树枝）+ 中景主体（`makeFigure` 愁人、`makeCrowd` 路上行人）；每帧写 opacity/intensity 均乘 fadeK，会每帧写的材质初值=最大值；碧光带与亭链光带着色器均显式传 vertexShader/fragmentShader。
- 校验：`node _pipeline/tools/validate.js pusaman-pinglin/index.html` → **✓ 校验全部通过**。
- 冒烟：`node pusaman-pinglin/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 三境 build/update ×400 帧 → 末境点击门控与 pointerdown → 自动游览至终章 → 键盘全路径 → 小测全流程；逐境 drawCall 代理 18/23/20/26，三角面 ≤2.4 万，fadeK 合规）。
- 实拍：`shots.py` 无头 Chrome 全境实拍 3 轮定稿——修楼身比例与楼头人物可读性（亭柱加高、人物移出锥顶遮蔽）、雾团糊屏（烟带粒子 size/maxA 减半）、宿鸟加大、长亭链加密。
