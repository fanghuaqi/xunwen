# 循文入境 ·《晓出净慈寺送林子方》杨万里（宋）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js r128 走 CDN 三路回退，首次打开需联网；音频为本地 MP3）。

## 使用

- 双击 `index.html` → 点「入境」→ 自动朗读 + 自动游览全程无人值守（均可一键关）。
- `← →` 键或空格逐境游览；**第三境「莲碧荷红」可点击画面 / 按空格**——朝阳升起、光晕大涨，荷花四朵一组次第点亮成"别样红"（WebAudio 铃音 + 五声拨弦 + 题字）。
- 朗读优先级：Edge 在线神经语音现场朗诵 → 内置 `audio/*.mp3` → 系统语音兜底。删除 `audio/` 目录可在 Edge 下强制走神经语音。
- `audio/00-04.mp3`（共 5 个）由 `gen-voice.js`（本目录副本，含逐字读音自查表，本诗无需同音替换）生成。

## 三境设计（晓出净慈 → 风光独绝 → 莲碧荷红）

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 | 毕竟西湖六月中 | 净慈寺山门剪影（立柱+双重飞檐+canvas 匾额"净慈寺"）前景，石阶寺墙，晨雾穿门，门外西湖在破晓天光里醒来 |
| 贰 | 风光不与四时同 | 登高望湖全景：朝阳贴着湖平线（借月位画日），湖面拉出金色日光道，莲叶初铺、荷苞点点，远处净慈寺畔塔影两座 |
| 叁 | 接天莲叶无穷碧，映日荷花别样红 | **标志性瞬间**：镜头从叶海低处（贴着莲叶）升至高天——莲叶 220 株双重视差层 + 三道远景莲带渐没入雾，"接天"天际线；十二朵荷花静候，点击朝阳升起、荷花次第点亮（自发光红荷+辉光） |

情绪曲线：天光逐境变亮（星 0.14→0.02、雾 0.0065→0.0042、日光道 spec 0.5→1.5、dirC 由晨青转暖金），末境仰镜随镜头升顶，莲海尽头一点红。

## 防同质化

- 风格赛道：**青绿春晓 · 西湖莲海变体**（art-direction ④）——bg `#0a1410`、主绿强调色 `#95c98f`、雾 `#1c3527`→`#2e5038`。
- 与同赛道区分：《江南》近景小鱼戏莲、《小池》微距蜻蜓立荷尖，本页做**远景铺天盖地的尺度**——山门剪影、双重视差莲叶海、天际线消失、映日"别样红"，为全库独有母题。
- 自创新 builder：`makeLeaves`（Instanced 莲叶场）/`makePagoda`（塔影）/`plaqueTex`（匾额题字）/`makeLotus`（双层花瓣荷花+点亮辉光）/`bCover`/`bGate`/`bLakeView`/`bLotusSea`。

## 教学要点

- 多音字：中 zhōng（六月中）、与 yǔ、荷 hé、别 bié、毕 bì 竟 jìng；「穷」＝尽（词义考点）、「别样」＝格外（考点）。
- 章法：先总赞（毕竟……不与四时同）后细写（接天/映日一联），以景写别情的送别诗（考点）。
