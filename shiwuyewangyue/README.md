# 十五夜望月 · 循文入境

王建《十五夜望月》沉浸式三境课件（水墨夜思 · 中庭月白变体：清辉如水、思念无声）。

- 境一 **地白栖鸦**：月光铺满中庭，地白如霜，鸦鹊栖定枝头
- 境二 **露湿桂花**：冷露无声，枝头桂花与露珠的特写
- 境三 **月明尽望**（交互境）：点击画面或按空格——镜头升空俯瞰万家窗影（每家窗内一点望月人影），一缕银色"秋思"自月轮洒向其中一家，题字"不知秋思落谁家"

## 使用

双击 `index.html` 即可（首次需联网加载 Three.js）。← → / 空格逐境；自动游览、自动朗读默认开启，可作课堂大屏无人值守展示。全程无操作约 50 秒走完三境并进入终章。

## 目录

- `index.html`：单文件网页（引擎 CDN 三路回退，音频本地）
- `audio/`：`00` 标题与作者、`01–03` 各境朗读、`04` 全诗（百度 TTS 生成；如需更真人音色，可删除 audio/ 由 Edge 神经语音现场朗诵，或设置 `TTS_AZURE_KEY` 重新生成）

## 教学建议

- 逐字注音已按教材标注（栖 qī、露 lù、湿 shī；"秋思"注 sī，注释中说明）
- 每境含意境题句、释义、注释；结课 5 题小测（接龙 / 读音 / 词义 / 内容 / 主旨）
- 建议：先自动游览整体感受，再逐境精读；境三交互后讨论"落谁家"的推己及人之妙
