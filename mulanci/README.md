# 木兰辞 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《木兰辞》（北朝 · 乐府民歌，queue no.261）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**大漠金戈**赛道——但刻意避开既有边塞页的构图（不做雪原戍楼听笛、不做拂晓誓师整甲、不做密林夜射、不做行军出关），写的是这首乐府长篇的**木兰一人六境人生长卷**：闺夜织机 → 市鞍赴边 → 关山铁衣 → 辞赏还乡 → 家人相迎 → 火伴惊忙。accent=#c4823a（沙金赭，queue 分配强调色）只落在 UI/人物边缘光/军帖光晕/烽火/铁衣寒光/双兔幻影/门内灯火；贯穿母题一扇「当户」的木门与一匹马（市鞍马/驰千里足）。

## 教学建议

1. **导入**：先遮住标题只读开头两句——「唧唧复唧唧」到底是织机声还是叹息声？让学生带着争论进境壹（本页取「叹息声」，注意与「不闻机杼声」的呼应）。
2. **梳理叙事**：六境恰好是六幅连环画——请学生用一句话给每境拟小标题（本页境名可作参考答案：机杼叹息／市鞍赴边／关山铁衣／辞赏还乡／家人相迎／火伴惊忙），体会详略：何以「万里赴戎机」六句就打完十年仗，而买鞍马、理红妆却句句铺排？——繁简安排都是立意。
3. **互文与数字**：「将军百战死，壮士十年归」是互文；「十二卷」「十二转」「十二年」三个「十二」皆是虚数——找出它们，讨论乐府民歌的夸张习惯。
4. **朗读处理**：两组「旦辞」「暮宿」读出奔赴的急促；「磨刀霍霍」读出欢喜；末句反问读出扬眉吐气。可分组分境配乐朗读。
5. **主旨讨论**：双兔之喻妙在何处？——静时可辨、动则难分，正如木兰闺中是女儿、阵前是壮士。再议「不用尚书郎」：她不要什么、要什么？结合「乐府双璧」（与《孔雀东南飞》）与北朝民歌的刚健气质收束。
