# 三衢道中 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《三衢道中》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**青绿春晓**赛道，取「三衢山行」变体——初夏梅子黄时、小溪尽头系着一叶小舟、石径折上山去，归途绿荫夹道、枝头黄鹂四五声。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击黄鹂"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：四只黄鹂挺颈振羽啼鸣（五声音阶：5-4-5-3-5）、两侧树冠与地面叶隙光斑一起摇动明灭，"绿阴黄鹂"题字同现
- 末章：全诗回放、学习小测（5 题）

- 逐句核过：梅子黄时、日日晴、泛尽（泛 fàn，泛舟）、却山行（行 xíng，行走）、绿阴 lǜ yīn（阴同「荫」）、不减（不 bù，上声前不变调）、添得（得读轻声 de，作补语标志）、黄鹂 lí、四五声——无须钉任何替换

## 教学建议

1. **导入**：封面设问"同一条路，去时和来时有什么不一样？"再入境壹。
2. **境壹析"晴"与"却"**：江南梅雨季偏逢"日日晴"，是意外之喜；"泛尽却山行"一句一转折，出游的兴致全在"却"字上。
3. **境贰析"不减"与"添得"**：一"不减"是旧景仍在，一"添得"是新趣又来——把一次返程写成"景同而趣增"。
4. **点击体会**：点击黄鹂听四五声（音阶）、看绿阴光影摇动，再读末句：为什么是"四五声"而不是"千百声"？（疏落断续，愈显山中之静。）
5. **知人论世**：曾几是陆游的老师，诗风清新活泼（陆游称"茶山先生"）；此诗写初夏出行的小欢喜，是宋诗"以日常为诗"的典型。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音义 ×1、时令 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 37 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（梅树、小舟、树冠、黄鹂）都在 8–25 单位内，fd ≤ 0.0062；全页**无一处手写 opacity**（树冠/黄鹂/光斑/水面全走 scale 或引擎 uniform）。
- 场景构件（冒烟实测）：卷首 12 mesh / 25 sprite、境壹 16 mesh / 23 sprite、境贰 16 mesh / 33 sprite；draw call 代理值 38 / 40 / 50（≤120），三角面 ≤2.0 万（≤12 万）。
