# 苔 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《苔》（清·袁枚）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**宣纸留白**赛道——浅色宣纸为天、淡墨远山作剪影、大量留白，全页唯一的生命焦点是一点青苔灰绿微光。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"看苔花盛放"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：日光让位，苔米微光升腾、牡丹形虚影盛放，"苔花如米小 也学牡丹开"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：宣纸留白（art-direction 赛道③）

| 项 | 取值 |
|---|---|
| 底色 | `#e9e2d0`（宣纸） |
| 主色 | `#3a4444`（青苔灰绿，queue 分配强调色；按钮/边框/进度点/题字，**无一处金色**） |
| 文字 | `#23272e`（浓墨） |
| 雾 | `#e6dfcc`，fd 0.0046–0.0070 |
| 月 | 无（ms 0.001 且移出视野）；左上角一轮**淡日**（宣纸上的淡色日轮） |
| 山 | 浓墨剪影 `#2c2f33` 两层远山（多峰折线 makeRange，吃雾出层次） |
| 粒子母题 | 青意微尘（非 additive）、贴地纸色雾、苔米微光（灰绿 NormalBlending，浅底上不用 additive） |
| UI | 面板 `rgba(255,252,240,.72)`，金色辉光阴影全部去除 |

**有意的设计**：全页几乎零饱和——苔藓的灰绿是唯一"颜色"，青苔灰绿微光是全页唯一的光点。末境之前淡日是画面里最大的光；点击之后日光敛去、苔米微光接棒——"白日不到处"的光，最后由苔花自己发出来。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（`gen-voice-edge.py` / Edge 神经语音 zh-CN-YunxiNeural，语速 −18%，免费无密钥）：

- `00.mp3` 标题（诗题自动提取："苔"）
- `01–02.mp3` 两句逐境朗读
- `03.mp3` 全诗连读

多音字自查（以页面拼音为准：bái rì bú dào chù / qīng chūn qià zì lái / tái huā rú mǐ xiǎo / yě xué mǔ dān kāi）：**苔**钉了同音替换「苔→抬」（保证读 tái 不读 tāi，沿用《游园不值》"苍苔→苍台"先例）；处（chù）、恰（qià）、学（xué）、枚（méi）在语句中读音唯一或 Edge 高置信，未另钉替换，见 `tts.json`。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：让学生先猜"一种不开花、也晒不到太阳的植物，凭什么写进诗？"再入境①对照画面看"白日不到处"。
2. **境①古今异义**：「青春」在句中指**春天的生机**，不是青年时期——结合注释讲清这层，再体会"恰自来"的"自"字（不假外求）。
3. **境②微距体验**：让学生想象自己俯身趴到墙根，进入苔藓的"丛林"——苔丘如林、苔花比人高，理解"如米小"是客观的小，"学牡丹开"是主观的盛放。
4. **境②点击后**：看日光让位、苔花自己发光，讨论"阳光不给的光，自己发"——平凡生命不待眷顾的自我完成。
5. **背景**：袁枚是清代"性灵派"诗人，主张诗写性情；这首小诗近年经《经典咏流传》乡村教师梁俊与孩子们的传唱广为人知，可顺势播放对比。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 20 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 交互境序号 `curIdx===2`（pointerdown 与空格双接线，`clicked` 标志 + 1.5s 冷却防连点）。
- fadeK 铁律：所有每帧写 opacity 的材质初值=最大值（日轮/光柱/微光晕/牡丹虚影/苔米微光），两个自定义 ShaderMaterial（光柱、苔米微光）均显式双 shader 且带 `uFade`。
- 预算：三境 drawCall ≈ 25–31、三角面 ≈ 0.9–1.6 万（≤120 / ≤12 万）。
- 校验：`node _pipeline/tools/validate.js tai/index.html` → **✓ 校验全部通过**；`node tai/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 逐境 build/update×400 帧 → fadeK 合规 → 末境点击门控 → 自动游览至终章 → 小测，多轮稳定）。
- 实拍：`shots.py --all-stages` 封面/两境/终章 + 末境点击后盛放瞬间逐张人工检查通过。
- 文本口径：本诗语料未收，按通行本登记（queue.json note 已标注），诗文逐字为「白日不到处，青春恰自来。苔花如米小，也学牡丹开。」
