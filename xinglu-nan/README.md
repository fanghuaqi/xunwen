# 循文入境 · 行路难·其一（唐 · 李白）

单文件沉浸式诗词课件：四境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 夜宴金彩·行路变体：盛宴与茫然的强反差开场，冰塞雪满、溪钓梦日，收束于云帆济沧海的豪兴反转。
> 标志性瞬间：长风破浪——沧海之上云帆满张，破浪前行。

## 四境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 停杯投箸 | 金樽清酒……心茫然 | 盛宴陈设（金樽、玉盘、盘飧）与停下的杯、投下的箸；诗人按剑四顾，茫然雾流绕行 |
| 贰 · 冰塞雪满 | 欲渡黄河……雪满山 | 冰封大川、浮冰青白，远处雪满太行的冷雪山脊，风雪横流 |
| 叁 · 溪钓梦日 | 闲来垂钓……梦日边 | 月下蓑笠翁碧溪垂钓（竿线浮子俱全），远处日边一叶金舟如梦 |
| 肆 · 长风破浪 | 行路难……济沧海 | **标志性瞬间**：沧海大浪中云帆大船（**点击画面**：帆满张、船前倾、长风提速、金光铺浪；空格先交互、再按进终章） |

## 操作

- `← →` / 空格：切境（末境空格 = 触发交互，交互过后再按进终章）
- 自动游览、自动朗读默认开启，可一键关
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置 MP3 → 系统语音
- `audio/00–05.mp3`：题名、四境、全诗（云健·沉厚男声，语速 −12%；`tts.json` 多音字替换只影响读音）

## 教学建议

- 情感三折：茫然（停杯拔剑）→ 期待（溪钓梦日两典故）→ 豪兴（长风破浪），让学生找出情绪转折点
- 两个典故对比讲：吕尚垂钓（遇文王）、伊尹梦日（受商汤）——都是"未被重用时的等待"
- "冰塞川""雪满山"是象征：不是写景，是写仕途受阻
- 注音考点：金樽 zūn、珍羞 xiū（同"馐"）、直 zhí（同"值"）、投箸 zhù、冰塞 sè、太行 háng、歧路 qí、济沧海 jì
- 名句必背："长风破浪会有时，直挂云帆济沧海"——逆境中的自信与豪迈
