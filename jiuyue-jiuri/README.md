# 循文入境 · 九月九日忆山东兄弟（唐 · 王维）

单文件沉浸式诗词课件（Three.js r128 UMD，双击 `index.html` 即开；首开需联网加载引擎，cdnjs→jsdelivr→unpkg 三路回退）。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 客舍异乡 | 独在异乡为异客 | 异乡客舍一灯如豆，旅人独坐门前，秋叶缓落，石径离乡 |
| 贰 · 佳节思亲 | 每逢佳节倍思亲 | 远村佳节灯火（都是别人的团圆），归雁南去，思念如雾流向故乡方向 |
| 叁 · 遥见登高 | 遥知兄弟登高处，遍插茱萸少一人 | 标志瞬间：**镜头升空两地对望**——近处客舍一点孤灯，远方故乡山顶兄弟群像，五席之地居中一席空着；**点击画面/按空格遥见故乡**：客舍淡出、群像渐显、茱萸红点亮、空位山风处题字「少一人」 |

## 操作

- `← →` 键或空格逐境；`Esc` 退出终章/小测；顶部圆点可直接跳境。
- 自动游览、自动朗读默认开启，可一键关闭（适合课堂大屏无人值守）。
- 朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音。

## 音频

`audio/00-04.mp3`（00 标题、01-03 各境、04 全诗），由 `gen-voice.js`（本诗定制副本）生成，多音字表已将「为异客」的**为**读作 **wéi**。删除 audio/ 目录可回退浏览器语音。

## 注音自查

为 wéi（作为）· 倍 bèi · 处 chù（登高处）· 茱萸 zhū yú · 少 shǎo（缺少）· 一人 yì rén（变调）—— 逐字核对，拼音数与汉字数一致（validate.js 强制）。

## 教学建议

先整读一遍 → 逐境入境，每境停留讲释义/注释（第一境讲两个"异"字的重叠，第三境讲"对面落笔"的写法）→ 让学生亲手点击"遥见故乡"，数一数山顶少的那一席 → 结课 5 题小测。
