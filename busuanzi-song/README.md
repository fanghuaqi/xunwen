# 卜算子 · 送鲍浩然之浙东 · 王观（循文入境 · 烟雨江南）

`index.html` 双击即开（Three.js 走 CDN，首次打开需联网；朗读音频在本地 `audio/`）。

- 赛道：**烟雨江南**（明媚变体），强调色 `#9fc2b0`（春水青）
- 与同赛道已有的两首刻意错开：不取《声声慢》的「梧桐细雨 / 雁过」，也不取《如梦令》的「夜雨海棠 / 卷帘」，
  本词走**春水碧、柳絮白、眉峰青**的**明媚送别**——全词不写愁苦，只写祝福
- 标志性瞬间：**山水化作眉眼的盈盈春色**——横长的春水叠成「眼波」，远山聚成「眉峰」，
  眼睑、睫毛、瞳仁层层浮现（一境之内完成叠化），眉眼还会缓缓眨一下；
  第二境兰舟驶入「眉眼盈盈处」，第四境点击画面让**春色随人同行**

## 三、教学建议

1. **导入（问比喻）**：先只给第壹境画面，问「水像什么？山像什么？」再对读原句。
   要点：通常说「眼波如水」「眉峰似山」，王观偏偏反过来说「**水是眼波，山是眉峰**」——
   喻体与本体倒置，山水便成了美人的眉眼（借景写人，也是把浙东山水写成了一张明媚的脸）。
2. **入境（第贰境）**：让学生带着问题看画面：「行人去那边？——哪边？」
   「**眉眼盈盈处**」答的正是浙东的山水胜处：那里山明水秀，如美人眉眼般盈盈可爱。
   顺手讲「那」读 **nǎ**（同「哪」）。
3. **对比（第叁境）**：把「才始送春归，又送君归去」读成两个层次：一春一友，两番离情。
   追问：一般送别词写什么？（柳永「执手相看泪眼」、王维「西出阳关无故人」——都写愁。）
   本词写愁了吗？——没有。它把惜春与送别叠在一起，语气反而轻快温厚。
4. **点睛（第肆境）**：请学生先猜「千万和春住」是什么意思，再点击画面看春色随人同行。
   两层意：① 愿友人赶上江南春色、与春同住；② 暗祝他留住青春、与心上人相守。
   全词至此，离愁化作了祝福——这就是它高于一般送别词的地方。
5. **朗读**：跟读音频，注意六处读音——卜算子 **bǔ**、鲍 **bào**、浙 **zhè**、那边 **nǎ**、
   横 **héng**、和春住 **hé**。

## 五、备注

- 五境皆**藏月**（`ms:0.001`），走烟雨赛道的「月隐」；雾色偏青绿（`#16211e`），不是夜宴蓝黑。
- 江水由 WebAudio 现场合成（低通棕噪声），随各境 `river` 权重渐变；拨弦音效为 WebAudio 合成，非音频文件。
- 水面为自定义 ShaderMaterial（不吃场景雾），每帧手动同步 `uFogColor/uFogDensity`；
  穹顶/星/月材质 `fog:false`；透明物分层 穹顶 -10 < 星 -9 < 月 -8 < 水 1 < 粒子 3 < 雾 5。
- 大团雾 `makeMist` 的 opacity 每帧重写，已显式乘父链 `fadeK`（参考实现遗留的交叉淡化隐患已修）。
- 语音优先级：Edge「在线自然语音」现场逐句朗诵 → 内置 MP3 → 系统语音；切境即停。
- 若首句朗读无声，多为浏览器未授权/离线：页面会自动降级到内置 MP3。
