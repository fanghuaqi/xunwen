# 循文入境 · 天净沙·秋（元 · 白朴）

单文件沉浸式诗词课件：三境随曲句推进，逐字注音、释义注释、AI 朗读、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

## 三境

| 境 | 曲句 | 画面 |
|---|---|---|
| 壹 · 孤村残霞 | 孤村落日残霞，轻烟老树寒鸦 | 落日熔金、残霞满天；孤村茅屋炊烟，老树虬枝栖寒鸦 |
| 贰 · 飞鸿影下 | 一点飞鸿影下 | 一只鸿雁剪影自残霞深处掠过，缓缓影下（循环飞行动画） |
| 叁 · 五色秋光 | 青山绿水，白草红叶黄花 | 标志性瞬间：镜头拉高，青山/绿水/白草/红叶/黄花全景；**点击画面**五色渐次点亮 + 飞鸿掠霞 + 题字"白草红叶黄花" |

## 操作

- `← →` / 空格：切境（第三境空格=触发交互）；自动游览、自动朗读默认可开
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置 MP3 → 系统语音
- `audio/00–04.mp3`：标题、三境、全诗（百度 TTS；`朴` 已按 Bái Pú 处理，页面文字不变）

## 教学建议

- 注音考点：残霞 `cán xiá`、寒鸦 `hán yā`、绿 `lǜ`；"飞鸿"即大雁
- 主旨对比：与马致远《天净沙·秋思》同调异趣——彼萧瑟悲凉，此绚烂明媚（小测第 5 题）
- 适用课堂大屏无人值守展示：开启"自动游览 + 自动朗读"即可全程自走
