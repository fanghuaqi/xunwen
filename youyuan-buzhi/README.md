# 游园不值 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《游园不值》（宋·叶绍翁）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。**前二句写「抑」——屐齿苍苔、柴扉久不开的冷寂；后二句写「扬」——春色满园、一枝红杏出墙的惊喜。红杏红是全页唯一的浓彩点。**

> 本篇语文语料未收，诗文按统编教材通行本登记（见 `_pipeline/queue.json` note）。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"柴扉虚掩、红杏招展"，交互后再按才进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：柴扉缓缓虚掩，门缝漏出一线春光，墙头红杏招展、落英骤密，"春色满园关不住"题字同现
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **解题导入**：先问"『不值』是不是『不值得』？"——是不遇、没遇上主人；再看封面那扇紧闭的柴门。
2. **境①品「抑」**：找一找画面里的屐齿印，体会「怜」（爱惜苍苔）与「小」（轻轻敲）两个字的分寸——诗人越是斯文有礼，久不开就越怅然。
3. **境②品「扬」**：点击画面看柴扉虚掩、红杏招展，讨论"为什么满园春色关不住""这枝红杏好在哪里"。
4. **名句积累**：与陆游「一枝红杏出墙头」对读（见小测第 4 题），体会「关不住」三字后出转精；引申"新生事物不可阻挡"的主旨。
5. **收束**：末章全诗连读一遍，再做 5 题小测（接龙 ×2、字词 ×1、渊源 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
