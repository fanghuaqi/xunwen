# 过故人庄 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《过故人庄》（唐·孟浩然）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**青绿春晓**赛道——鸡黍相邀、绿树合抱、开轩把酒、重阳菊约的田家做客，是全集里最亲切淳朴的页面之一。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"重阳菊约"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：篱畔菊花次第开放，重来访路一盏盏亮起，远天透出重阳的暖金，与"还来就菊花"题字
- 末章：全诗回放、学习小测（5 题）

## 美术方案：青绿春晓（art-direction 赛道④）

| 项 | 取值 |
|---|---|
| 底色 | `#0a1410`（青绿夜底） |
| 主绿 | `#a3c98f`（本诗分配强调色：按钮/边框/进度点/题字） |
| 文字 | `#eef4e6` |

| 月 | 晨景淡月（mph 0.44–0.46，ms ≤0.45） |
| 光 | 暖金晨光（dirC `#e6cd92`→`#f2d89c` 逐境转暖），东天一抹暖曦 |

**有意的设计**：全页只让"生活的温度"带暖色——灶烟、暖窗、酒气、黍穗的金、菊花的金；树、山、田、天色全部压在青绿调里。末境点击前菊花只作花苞（scale 0.22），点击后 12 朵按 delay 逐朵舒展（次第开），重来访路七盏灯逐盏点亮——期许是慢慢亮起来的。

## 朗读配音

`audio/` 内置 6 个 AI 朗读 MP3（Edge 神经语音 zh-CN-XiaoxiaoNeural，青绿赛道自动选声，免费无密钥）：

- `00.mp3` 标题（"过故人庄"）
- `01–04.mp3` 四联逐境朗读
- `05.mp3` 全诗连读

多音字经 `tts.json` 同音同调接管（非空 sub，不叠兜底表）：鸡黍→鸡薯（黍 shǔ）、场圃→长圃（场 cháng）、还来→环来（还 huán「还来」）；斜 xié 为现代标准音无需接管。`--dry` 逐句核对后合成，0 失败。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：问学生"老朋友请你吃饭，他会怎么说？"再入境①，对比"邀"与"请"——随口一唤才是熟人。
2. **境②名联**：让学生在画面里找"合"（两弧绿树在村后合拢）与"斜"（青山斜倚郭外），体会一近一远、一收一放的环抱构图。
3. **境③农事**：数一数窗外有哪些农家物事（打谷场、菜圃、桑树、麻田），为什么宾主"话桑麻"而不谈别的——只有知己不必应酬。
4. **境④相约**：点击看菊花次第开、来路亮起，讨论"为什么不说'再见'而约定重阳再来"——真率自然，余味无穷；顺带介绍重阳赏菊、饮菊花酒的风俗。
5. **背景**：孟浩然一生多隐居襄阳鹿门山，与王维并称"王孟"，是盛唐山水田园诗代表；本诗是他田园诗中最平淡天真的一首。
6. **收束**：末章全诗连读，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 四境），境名逐一对齐；诗文逐字同 queue.json（「开轩」从教材通行本，语料作「开筵」）。
- 交互境序号 `curIdx===4`（clicked 标志 + 1.2s 冷却 + 可重复触发菊开）；进度点/按键/自动游览末境判断均以 `POEM.length=4` 对齐；全诗音频 `05.mp3`。
- 校验：`node _pipeline/tools/validate.js guo-gurenzhuang/index.html` → **✓ 校验全部通过**。
- 冒烟：`node guo-gurenzhuang/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 五境 build/update×400 帧 → fadeK 合规 → 三层构图 → 末境点击门控 → 自动游览至终章 → 小测全流程；单境 drawCall 代理 30–60、三角面 ≤1.7 万，连跑 3 次稳定）。
