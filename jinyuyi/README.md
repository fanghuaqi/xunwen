# 金缕衣 · 夜宴金彩（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《金缕衣》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版为**夜宴金彩·中唐劝时曲**变体——夜宴庭园金彩底色，金缕衣的金线光华是题面主色，花开是对比的生命色（低饱和暖粉）。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"点击花开"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：金缕光华渐淡，花枝盛放催折，瓣光迸落，"花开堪折"题字同现
- 末章：全诗回放、学习小测（5 题）

**有意的设计**：全诗警策「花开堪折直须折，莫待无花空折枝」画面化为末境的**时序对切**——点击之前金缕衣光华流转、花枝含苞；点击之后金缕光华渐淡（富贵退色）、花枝盛放催折（生机催人），一淡一盛同框发生，就是"金缕衣 vs 少年时"的取舍。

## 教学建议

1. **导入**：封面设问"华贵的金缕衣和少年时光，哪个更该珍惜？"再入境①对照诗句看"取舍对切"。
2. **境①对举**：让学生在画面里找两样东西——金缕衣（富贵）与手中花枝（光阴），体会"莫惜/惜取"一反一正。
3. **境②警策**：先看含苞的花枝与光华正盛的金缕衣，再点击"花开"，讨论画面里"什么在变淡、什么在盛放"，为什么这是"催"。
4. **背景**：这是中唐流行的劝时之曲，通行署杜秋娘（语料署不详）——《唐诗三百首》以它压卷收官；可顺势讲"劝君"二字的歌者口吻。
5. **收束**：末章全诗连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、文学常识 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；诗文与 `_pipeline/queue.json` 分境口径逐字一致。
- 交互境序号 `curIdx===2`；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐；末境空格先交互、再按进终章。
- 校验：`node _pipeline/tools/validate.js jinyuyi/index.html` → **✓ 校验全部通过**。
- 冒烟：真 THREE r128 跑完 boot → 三境 build/update×400 帧 → fadeK 合规（opacity/intensity ≤ base×fadeK）→ 三层构图 → 末境 click 冷却/触发门控与 pointerdown/空格接线 → 封面→自动游览→终章全程 → 小测五题满分，SMOKE PASS（多次运行稳定）。
