Three.js 沉浸式诗词课件（单文件网页，双击 `index.html` 即开，需联网加载三维引擎）。

| 肆 · 歧路莫沾 | 无为在歧路，儿女共沾巾 | 岔路长亭作别；**点击画面/按空格**点亮两城灯火连线，题字"天涯若比邻" |

- 操作：← → 逐境、空格下一境/触发互动、`自动游览`+`自动朗读`默认开，可作课堂大屏无人值守展示。
- 朗读优先级：Edge 神经语音现场朗诵 → 本地 `audio/*.mp3`（百度 TTS 已生成 00–05 共 6 个）→ 系统语音。
- 美术：烟雨江南 · 风烟五津变体（强调色 `#9ab8d8`，底色 `#10141a`），基调为壮阔旷达的送别，区别于悲戚送别页。

## 教学建议

1. 先整体自动游览一遍，让学生用画面反推诗意；再逐境精读 `释义/注释`。
2. 注音考点：阙 què、宦 huàn、歧 qí、为（无为）wéi；名句考点：海内存知己，天涯若比邻（离别诗中的豪迈之音）。
3. 结课用内置 5 题小测检验；全诗朗读与逐境画面可配合背诵。
