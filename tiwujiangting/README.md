# 题乌江亭 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《题乌江亭》（唐·杜牧）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页走**大漠金戈**赛道，取「乌江史迹」变体——不是战阵厮杀、不是夜射骏马、不是白骨剑客，而是**史迹渡口的苍凉怀古**：江亭（石台四柱攒尖小亭）、断碣（题诗残碑）、渡口石阶、大江东去（水面原型+着色器雾同步）、对岸江东（常驻滩头+远岸轮廓弧带）；全页题眼是「乌江岸的假设历史」——境贰入夜隔江悬想，假设的历史尚未发生，只等一次点击。accent=#b8906a（queue 分配强调色，暮金亭柱色）只落在亭匾/碑刻受光/人物边缘光/军阵幻影幽光/UI 上，禁艳金。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击卷土重来"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：对岸烟尘渐起，**江东子弟军阵虚影三列自江雾中集结**（前后排相位错落、幻影军旗同现、淡金幽光边缘）→ 持驻明灭数息 → **复又散入江雾**（由后排先散、烟尘上飘，终至全无），"江东子弟多才俊 卷土重来未可知"题字同现
- 末章：全诗回放、学习小测（5 题）

**有意的设计**：两境同一组史迹母题贯穿——境壹暮色沉江，江亭无言、断碣犹在，立「包羞忍耻」之论；境贰月升星密，同一江亭退为远处剪影，画幅让给大江与对岸——「江东」就在水线之外，人却过不去；点击后军阵在烟尘与江雾中集结又散，是「未可知」三字的空间化：历史推开一道门缝，又轻轻合上。

## 教学建议

1. **导入**：先讲地点——乌江亭相传是项羽自刎处。问学生：如果你路过英雄末路的旧址，会写什么？再看杜牧写的是什么——不是哀悼，是讲道理。
2. **境壹看点**：断碣无言、残照沉江——「胜败兵家事不期」近乎常语，「包羞忍耻是男儿」才是卓识；让学生比较「哀悼式凭吊」与「议论式翻案」的不同。
3. **境贰点击前**：让学生盯着对岸——江东就在水线之外，什么都看不见；这正是「假设历史」的起点：还没有发生，只等一次点击。
4. **境贰点击后**：军阵集结又散——请学生用诗里的字给这个画面配注（「卷土」「重来」「未可知」）；追问：为什么杜牧让军阵「散去」而不让他「渡江」？（一个「未」字：不说必可，只推开一道门缝。）
5. **主旨与公案**：补王安石《叠题乌江亭》「江东子弟今虽在，肯与君王卷土重来？」的反驳——人心已散，纵有子弟谁肯再战；一正一反对读，看古人如何「以议论入诗」，小测第 4、5 题即落此。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示；末境留 3 秒给学生自己点击「卷土重来」。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 28 字）、释义/注释、境名/意境题句、5 题小测（接龙×2、读音词义×1、项羽乌江典故与王安石反驳×1、翻案史论主旨×1）、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 交互境序号 `curIdx===2`（pointerdown 与空格双接线，`clicked` 标志 + 1.2s 冷却防连点；空格先交互、再按进终章）。
- fadeK 铁律：所有每帧写 opacity/intensity 的对象（军阵三列/幻影军旗/烟尘/幽光/幽光点灯/月光光带）初值=峰值且逐帧乘 fadeK；集结-持驻-散场为包络（≤1）；点击前幻影组 `visible=false` 硬关（无幻影残影）；月光光带/烟尘幽光 `fog:false` 如光点名；水面/地面/山体着色器走引擎 `fogShaders` 雾同步。
- 预算：三次 build 的 drawCall 代理 ≈ 32/33/42、三角面 ≈ 2.4/2.4/2.8 万（≤120 / ≤12 万）。
- 校验：`node _pipeline/tools/validate.js tiwujiangting/index.html` → **✓ 校验全部通过**；`node tiwujiangting/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 逐境 build/update×400 帧 → fadeK 合规 → 末境点击门控 → 自动游览至终章 → 小测满分）；`node _pipeline/accept.js tiwujiangting` → **ACCEPT（2境 · 大漠金戈）**。
