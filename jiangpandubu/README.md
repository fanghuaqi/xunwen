# 循文入境 · 江畔独步寻花（其六）｜唐 · 杜甫

黄四娘家花满蹊，千朵万朵压枝低。留连戏蝶时时舞，自在娇莺恰恰啼。

三境沉浸式诗词课件：**花满蹊**（花团锦簇的小径、千朵万朵把枝头压弯的重量感）→ **戏蝶留连**（五对彩蝶绕花丛成对起舞）→ **莺啼恰恰**（枝头双莺 + 啼鸣声波；**点击画面或按空格**：蝶群飞起、莺啼声波激荡、花瓣轻颤、题字闪现）。

## 使用

- 双击 `index.html` 即可打开（需联网加载 Three.js，音频本地播放）。
- 逐境：`←` `→` / 空格 / 底部按钮 / 右上进度点；「自动游览」可无人值守循环展示。
- 朗读：优先 Edge「在线自然语音」现场朗诵，其次本地 `audio/00-04.mp3`（00 标题、01–03 各境、04 全诗），最后回退系统语音。
- 美术赛道：青绿春晓 · 花满蹊变体（暖杏花气晨光 + 粉白落英母题，区别于其他青绿页）。

## 教学建议

- 注音已按教材标注：**蹊 xī（小路）**、恰恰 qià qià（拟声词）、啼 tí；可点「注音 · 开/关」切换。
- 讨论点：①「压」字如何写出花的繁茂（重量感）；②「留连」「自在」分别写出蝶与莺的什么情态；③ 诗人的「独步寻花」之乐藏在哪里。
- 结尾附 5 题小测（接龙 ×2、读音 ×1、词义 ×1、主旨 ×1）。
