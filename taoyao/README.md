# 桃夭 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《桃夭》（先秦·诗经·周南）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**青绿春晓**赛道——但刻意避开既有青绿页的构图（不做三色花田春游、不做山寺桃花、不做村居田园），写的是这首婚礼祝歌的**三章一境·桃之婚嫁**：春晓桃林，一场婚嫁被整个春天祝福——花是其人（灼灼其华喻新嫁娘之美）、实是其家（有蕡其实祝多子多福）、叶是其族（其叶蓁蓁祝家族兴旺）。accent=#c9a0a8（queue 分配强调色，桃粉）只落在 UI/花瓣/桃花盛放光点/灯笼暖光/队伍亮起上；底色仍是青绿春晓全套色板（bg #0a1410、雾 #0e1d16）。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境③为"桃花次第盛放"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境③轻点画面：桃花沿林间次第再放（盛放光点逐簇点亮），送嫁队伍灯笼亮起、暖光满路——"之子于归 宜其室家"题字同现，可反复点击
- 末章：全诗回放、学习小测（5 题）

## 美术方案：青绿春晓 · 桃林送嫁变体（art-direction 赛道④）

| 项 | 取值 |
|---|---|
| 底色 | `#0a1410` |
| 主色 | `#c9a0a8`（桃粉，queue 分配强调色；按钮/边框/进度点/题字/花瓣/灯笼暖光） |
| 文字 | `#eef4e6` |
| 雾 | `#0e1d16`，fd 0.0050–0.0072（春晓桃林，晨光熹微） |
| 月 | 晨月低悬渐淡（ms 0.22–0.42），星稀（0.06–0.10）——天光随三章渐亮渐暖 |
| 场景母题 | **桃树三态**（同源 builder 参数变奏：华=桃花团簇+桃粉柔光、实=青枝缀实、叶=浓荫成盖）+ **送嫁队伍**（含蓄剪影：花轿居中、轿夫送行人相随，无面目）+ **落英**（自写着色器缓落）+ **家宅炊烟** + 一湾溪水（溪带横陈林后） |
| 粒子母题 | 落英缤纷（壹）、残英零落（贰）、树冠桃花盛放光点（叁·点击）、水边雾团、春气浮尘 |
| 与已有青绿页的区分 | xingxiangzi-shurao=三色花田春游、dalinsi-taohua=山寺桃花、cunju 等=村居田园；本页=**桃林深处一场婚嫁**——桃花、桃实、桃荫三章递进，送嫁队伍与家宅炊烟是画面叙事的两岸 |

**有意的设计**：三章重章叠句 = 三境变奏，两个维度同时在变——①物候递进：灼灼其华（花期，晨光初明）→ 有蕡其实（果期，天光大亮）→ 其叶蓁蓁（叶茂期，浓荫微暮），雾密度、天光、光色逐境推移；②婚嫁推进：花路上行轿（于归）→ 家宅在望炊烟起（宜室）→ 队伍抵达门前（宜家）。末境点击把三章"回放"一遍——桃花沿林间簇序次第再放（华），灯笼暖光依次点亮（归），是全诗祝福的落点。

## 教学建议

1. **导入**：先让学生通读三章，找"换了哪几个字"（华/实/叶，室家/家室/家人）——换字之外什么没变？祝福没变，而且一层层加深。这就是重章叠句。
2. **境①诗眼**：「灼灼」二字——为什么用"灼烧"的「灼」写花？让学生在画面里找"花路"与"花轿"：以花之艳起兴，引出人之美，这是比兴。追问：「于归」的「归」为什么训"出嫁"？（古人以夫家为归宿）
3. **境②看点**：画面从花转到果实与炊烟——由"貌美"祝到"多子多福、家室兴旺"，是先民最朴素的婚姻观。可讨论：今天的婚礼祝福词里还有哪些与之相通？（早生贵子、宜室宜家）
4. **境③点击后**：桃花次第再放、灯笼次第亮起——让学生说说这一"回放"对应三章的什么（华→实→叶；于归→宜室→宜家）。「家人」比「室家」「家室」范围更广——祝福从一对新人扩大到整个家族。
5. **主旨**：《桃夭》是「宜室宜家」一词的出处，是中国婚礼祝福的原型；比兴（以桃喻人）与重章叠句两大手法在此典范呈现，可与《蒹葭》的重章对读（一首怅惘、一首喜庆，情异而章法同）。
6. **诵读**：全诗四言，二二节拍（桃之/夭夭，灼灼/其华），三章语速由明快而舒展，末句「宜其家人」宜一字一顿收束——祝意在余音里。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示；末境留 3 秒给学生自己点击"再送一程"。
