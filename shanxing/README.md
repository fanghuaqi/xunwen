# 山行 · 循文入境沉浸式诗词课件

杜牧《山行》——「远上寒山石径斜，白云生处有人家。停车坐爱枫林晚，霜叶红于二月花。」

## 使用

双击 `index.html` 即可打开（Three.js r128 走 CDN 三路回退，首次需联网；音频本地）。

- **三境随诗句推进**：① 石径秋山（石径斜上寒山，青绿秋木梢头初染）→ ② 白云人家（白云缭绕的山坳里几点屋舍炊烟）→ ③ 枫晚霜红（夕照枫林）。
- **标志性瞬间**：末境点击画面（或空格）——满山枫叶自山脚向山顶被「点燃」，青绿渐变霜红，夕照随之增强，题字「霜叶红于二月花」。
- ←/→ 或空格逐境游览；「自动游览」可无人值守课堂展示；逐字注音、释义、注释、AI 朗读、学习小测齐备。
- 朗读优先级：Edge 在线神经语音现场朗诵 → 内置 MP3（audio/00–04）→ 系统语音兜底。

## 教学要点

- 多音字/考点：**径 jìng**（石径）、**坐 zuò**（坐＝因为，「停车坐爱」）、**于 yú**（比较，「红于」）；斜读 xié（教材统读，旧读 xiá）。
- 情感基调：秋高气爽的**喜爱与赞美**（非悲秋）；末句以霜叶比二月春花，是全诗诗眼。
