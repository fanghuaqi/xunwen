# 循文入境 · 《赠花卿》（唐 · 杜甫）

单文件沉浸式诗词课件（Three.js r128 CDN 加载，音频本地）。双击 `index.html` 即可打开（首次需联网加载三维引擎）。

## 内容

- **三境**：丝管纷纷（锦官城丝管日日不歇）→ 半入江云（标志性瞬间：金色乐声流一分为二，半随江风贴江流淌、半盘旋入云）→ 天上人间（云上天宫乐影对照人间江畔；**点击画面/按空格，乐声再起**——音符半冲云霄、半落江面，题字「人间能得几回闻」）。
- 逐字注音、释义注释（含「花卿僭用天子礼乐」的弦外之音考点）、AI 朗读（audio/00–04，Edge 下自动优先神经语音现场朗诵）、三境自动游览、5 题学习小测。

## 教学建议

1. 先整体自动游览一遍（默认开启自动朗读+自动游览），再逐境精讲；
2. 第二境让学生观察「乐声分流」画面，对应「半入江风半入云」的对举句式；
3. 第三境点击互动后，引出「明赞暗讽」的弦外之音再讨论小测第 5 题。

- 音频由 `gen-voice.js` 生成（百度 TTS）；如无 audio/ 或播放失败，页面自动回退浏览器语音（Edge 神经语音最佳）。
- 左上「返回诗集目录」可回到 `../index.html` 总目录。
