# 循文入境 · 望海潮（宋 · 柳永）

单文件沉浸式诗词课件：五境随词句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 青绿春晓·钱塘变体：青绿为底、金屑为点缀 —— 从城郭气象一路走进湖山，是全集最"热闹"的一页。
> 标志性瞬间：三秋桂子、十里荷花 —— 湖山满铺荷田，桂香与菱歌一齐漫过堤岸。

## 操作

- `← →` / 空格：切境（末境空格 = 触发交互，交互过后再按进终章）
- 自动游览、自动朗读默认开启，可一键关
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置 MP3 → 系统语音
- `audio/00–06.mp3`：题名、五境、全篇（晓晓·温暖女声，语速 −14%；`tts.json` 多音字替换只影响读音）

## 教学建议

- 本词是"铺叙"的教科书：从城市形势→市井→湖山→人物，镜头一步步推近，可让学生画"游览路线图"
- "三秋桂子，十里荷花"相传金主完颜亮读后起投鞭渡江之志（罗大经《鹤林玉露》），一句词写尽杭州之美
- 数量词的夸张：十万人家、三吴、千骑——与"怒涛卷霜雪"的比喻并用，铺出盛世气象
- 注音考点：参差 cēn cī、天堑 qiàn、珠玑 jī、罗绮 qǐ、重湖 chóng、叠巘 dié yǎn、羌管 qiāng、钓叟 sǒu、千骑 jì、图将 jiāng
- 写作背景：干谒之作，赠两浙转运使孙何；结句"归去凤池夸"点出投赠本旨
