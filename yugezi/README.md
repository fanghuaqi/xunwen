# 循文入境 · 渔歌子（唐 · 张志和）

单文件 Three.js 沉浸式诗词课件。双击 `index.html` 即可打开（首次需联网加载 Three.js 引擎，音频已本地打包在 `audio/`）。

## 三重意境

| 境 | 词句 | 画面 |
|---|---|---|
| 壹 · 鹭飞鱼肥 | 西塞山前白鹭飞，桃花流水鳜鱼肥。 | 西塞山影下白鹭翱翔，桃花逐流水，鳜鱼剪影游过江底 |
| 贰 · 箬笠蓑衣 | 青箬笠，绿蓑衣， | 特写岸石上青笠绿蓑的钓翁，鱼竿斜探水面，疏雨初起 |
| 叁 · 不须归 | 斜风细雨不须归。 | 标志瞬间：斜风细雨密织，鱼线入水纹丝不动，白鹭掠水 |

**互动**：第叁境轻点画面或按空格 —— 雨势渐急、白鹭惊起又落，钓翁依旧，题字"斜风细雨不须归"。

## 使用

- `← →` 键或底部按钮逐境游览；开启"自动游览"可无人值守循环播放（课堂大屏推荐）。
- 每境自动朗读；朗读优先用 Edge 的在线神经语音，否则播放 `audio/00–04.mp3`（00 标题、01–03 各境、04 全诗）。
- 右侧可开关注音；左下角"注释"折叠面板含多音字（鹭 lù、鳜 guì、箬 ruò、蓑 suō）与考点。

## 教学建议

1. 先整体自动游览一遍，再逐境提问："画面里哪些景物对应哪句词？"
2. 第叁境互动处停顿，讨论"不须归"背后的渔父情怀（悠然自得、寄情山水）。
3. 结尾小测 5 题可作当堂检测（接龙、读音、词义、主旨、文学常识）。
