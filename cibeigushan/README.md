# 循文入境 · 次北固山下（唐 · 王湾）

单文件沉浸式诗词课件：四境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 青绿春晓·江行变体：青山绿水间一叶行舟，江面越走越开阔，海日与残夜同框，雁阵驮着乡书北去。
> 标志性瞬间：海日生残夜——残夜未尽一轮红日已跃出海面，旧年里江春已入（东西同框的时序交替）。

## 操作

- `← →` / 空格：切境（末境空格 = 触发交互，交互过后再按进终章）

## 教学建议

- 「潮平两岸阔，风正一帆悬」：以"一帆"小景写"两岸阔"大景，让学生体会以小衬大
- 「海日生残夜，江春入旧年」是千古名句："生""入"的拟人 + 时序交替的哲理（新事物必将取代旧事物）
- 尾联与颈联呼应： seeing 时序更替 → 引出思乡，归雁承载乡愁
- 注音考点：次 cì、客路 kè、潮平 cháo、一帆悬 xuán、残夜 cán、归雁 yàn、洛阳 luò
- 体裁：五言律诗；王湾是盛唐初期的洛阳诗人，此诗当时即被宰相张说题于政事堂
