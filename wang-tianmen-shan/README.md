# 望天门山 · 循文入境（Three.js 沉浸式诗词课件）

双击 `index.html` 即可打开（首次需联网加载 Three.js；朗读音频为本地 MP3）。

## 四境

| 境 | 诗句 | 画面 |
|---|---|---|
| 一 · 天门中断 | 天门中断楚江开 | 两座台地青壁如巨门对峙，楚江自断口奔涌而出 |
| 二 · 碧水回旋 | 碧水东流至此回 | 江水撞上东面横壁，回旋成巨大涡流 |
| 三 · 两山相对 | 两岸青山相对出 | 镜头穿行峡中，两岸青山迎面相对而出 |
| 四 · 孤帆日边 | 孤帆一片日边来 | 落日正悬断门之间，孤帆自日边缓缓驶来 |

## 操作

- ← → 键 / 空格 / 底部按钮逐境；进度点可直达任意境。
- **第四境可交互**：点击画面或按空格——两山对合又分开（天门开合）、碧水回旋加剧、孤帆加速驶来。
- 自动朗读、自动游览默认开启，可一键关闭；适合课堂大屏无人值守展示。

## 音频

`audio/00–05.mp3`：00 标题+作者，01–04 各句，05 全诗。由 AI 配音生成；
删除 `audio/` 目录后，Edge 浏览器下自动回退为"在线自然语音"现场逐句朗诵。

## 教学建议

先自动游览一遍整体感知，再逐境停驻，抓"断、开、回、出、来"五个动词的画面感；
结课用内置 5 题小测检测（接龙 ×2、多音字"相"、词义"楚江"、名句理解）。
