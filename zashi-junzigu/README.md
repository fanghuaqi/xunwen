# 循文入境 · 杂诗（君自故乡来）· 王维

唐诗《杂诗》「君自故乡来，应知故乡事。来日绮窗前，寒梅著花未？」的沉浸式教学网页：诗句逐境推进，三维实景随诗入境。

## 使用

- 双击 `index.html` 即可打开（Three.js 走 CDN，首次需联网；音频在本地 `audio/`）。
- 控制条：上一境 / 自动游览 / 下一境 / 朗读 / 自动朗读 / 注音 / 声音 / 全屏；`← →` 键或空格逐境，`Esc` 退出覆盖层。
- 进入新境约 1.6 秒后自动朗读本句；终章可「聆听全诗」并做 5 题学习小测。

## 两重意境

1. **客从故乡** —— 驿路风尘，遇见故乡来客（斗笠、行囊、杖）；远处故乡亮着一扇暖窗。
2. **绮窗问梅**（标志瞬间，可交互）—— 游子与来人对坐，画面焦点移向想象中悬浮的绮窗寒梅：花苞含而未放，「未？」悬停。**点击画面 / 按空格**，花苞次第绽放、花瓣飘落、题字「寒梅著花未」上屏。

## 教学

- 多音字：绮 qǐ、著 zhuó（著花=开花）、应 yīng（应当）。
- 讲点：以小见大——不问人事只问一株梅，一株寒梅里装着整个故乡；可结合「近乡情更怯」比较怀乡诗的不同写法。
- 注音可开关；释义/注释在左下面板，「注释」可展开。
