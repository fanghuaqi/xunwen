# 古朗月行（节选） · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《古朗月行·节选》（唐·李白）「循文入境」教学网页：诗句推进到哪一句，三维实景就走进哪一重童年想象。本页取**水墨夜思**方向——冷银墨夜色板，天上明月被做成一件可切换的"道具"：小时看它是白玉盘，再一看又疑是瑶台镜。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN，多源自动回退；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在末境③为"切换玉盘/瑶台镜"）
- 控制条：自动游览、朗读此句、自动朗读、注音、声音、全屏
- 进度点：点击圆点可直接跳境
- 末境③轻点画面：白玉盘与瑶台镜相互切换，铃声明响、题字闪现
- 末章：聆听全诗、学习小测（5 题）、再游一次、回卷首

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜，body 与 #err 同色） |
| 主银 | `#d6dee9`（--gold 变量；按钮/边框/进度点/题字，全银蓝水墨调） |
| 文字 | `#dfe6f0`，次要 `#7e8a9c`；边线 `rgba(214,222,233,.28)` |
| 天穹 | top `#0d1520` / hor `#1b2534` / bot `#080d12` |
| 雾 | `#10161f`，fd 0.0038–0.0046 |
| 月 | 卷首大月 ms 1.5；境① ms 1.05 玉色冷月（moonC `#c9d2dd`）；境②③系统月藏起（ms 0.001），天上只挂场景内建的"道具月" |
| 星 | 稀疏（star 0.5–0.6） |
| 粒子母题 | 银灰浮尘（`#d6dee9`）、低回薄雾（`#9fb0c8`）、青云云影（`#33415c` 光斑） |

**有意的设计**：境②③把系统月亮整个藏掉，让"白玉盘/瑶台镜"道具本体成为天上唯一的主角——同一位置、同一尺寸，儿童眼中它是玉盘（`#eef3ee` 盘身），再疑是仙镜（`#e9f2f8` 镜面 + 镜柄），一物两读正是这首诗的比喻内核。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题与作者（"古朗月行。唐，李白。……"）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全诗连读

页面朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音兜底。无特殊多音字副本；逐字注音已按诗义标定——"不识"的**不读 bù**、"呼作"的**作读 zuò**。如需更高级音色，可用 `_pipeline/tools/gen-voice-edge.py` 重生成。

## 教学建议

1. **导入**：先让学生说说"你小时候觉得月亮像什么？"再入境①对照李白小时的不识月。
2. **境①稚趣**：看小儿仰望的姿态读"小时不识月"，体会回忆口吻里的天真。
3. **境②③比喻**：点击切换玉盘/瑶台镜，让学生自己说出两个比喻各抓什么特点（圆而亮 / 明而高悬），体会"呼作"与"又疑"的递进。
4. **语言积累**：这两个比喻是千古名喻，可让学生仿说"月亮像____，因为____"。
5. **收束**：末章全诗连读，再做 5 题小测（接句 ×1、词义 ×1、文学常识 ×1、比喻内容 ×1、情感主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 三境；三四句"又疑瑶台镜，飞在青云端"合为一境），境名逐一对齐。
- 点击交互境序号 `curIdx===3`（末境，玉盘/瑶台镜切换）；进度点/按键/自动游览末境判断均以该长度对齐。
- 校验：`node _pipeline/tools/validate.js gu-lang-yue-xing/index.html` → **✓ 校验全部通过**。
