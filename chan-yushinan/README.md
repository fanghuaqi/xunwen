# 循文入境 · 蝉（虞世南）

Three.js 沉浸式古诗词单文件网页 —— 诗句推进到哪一句，三维实景就走到哪一重意境。

- 诗题：**蝉**
- 作者：虞世南（唐）
- 全文：`垂緌饮清露，流响出疏桐。居高声自远，非是藉秋风。`
- 风格赛道：**宣纸留白（xuanzhi，全站唯一浅色系）** —— 宣纸底 `#e9e2d0`、淡墨远山、墨点微尘；强调色 `#3a4048`
- 标志性瞬间：**居高声远** —— 声波自高树层层向外扩散的墨痕涟漪（横波 + 迎面波 + 远山回声）
- 交互：第二境点击画面（或按空格）→ 蝉鸣响起、墨圈加速层层扩散、题字「流响自远」

## 三、教学建议

1. **入境先读**：封面停留时先齐读全诗，再点「入 境」，让画面与诗句同步展开。
2. **第一境抓「垂緌」「清露」**：引导学生看蝉头下垂的长须（緌，古人帽带打结下垂的部分）与叶尖露珠 —— 借「饮露」写高洁不染，这是咏物诗「以物比德」的第一层。
3. **第二境抓「居高」「非是藉秋风」**：点击画面听声波层层扩散，讨论「声远」的原因：不是风送，而是「居高」。点明双关 —— 既写蝉栖高枝，也喻人品高洁。
4. **考点串讲**：唐人咏蝉三绝（虞世南《蝉》· 骆宾王《在狱咏蝉》· 李商隐《蝉》），此诗居首；「藉」读 jiè（凭借），「緌」读 ruí。
5. **课堂可无人值守**：自动朗读 + 自动游览默认开启，大屏展示可全程自动走完至终章与小测。
