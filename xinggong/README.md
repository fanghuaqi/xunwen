# 行宫 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《行宫》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**宣纸留白**赛道，取「荒宫白头」变体——纸色天地里一座半塌的古行宫、宫阶前的枯草、一树**寂寞深红**的宫花，以及两位坐在残阶上的**白头宫女**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击说玄宗"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：残宫之上浮现昔日行宫的**完整宫殿虚影**（1.6 秒内浮现→驻留→淡去，带一排宫灯暖光），宫女闲坐剪影不动，"说玄宗"题字同现
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：封面设问"如果花还在开，人却老了，你会想到什么？"再入境壹。
2. **境壹析"寂寞红"**：花开得正红，却无人欣赏——"红"是浓色，"寂寞"是冷意，两字相撞，荒凉尽出。
3. **境贰析"在"字**：宫已寥落，花仍寂寞，唯有白头人"在"；一个"在"字把时间拉开了几十年。
4. **点击体会**：点击说玄宗看繁华虚影一闪而过——问学生："她们说的是什么？为什么只说给彼此听？"
5. **知人论世**：元稹是中唐诗人（与白居易并称"元白"）；玄宗时的行宫，到中唐已成荒宫，白头宫女是活着的"盛唐遗物"。
6. **写法小结**：二十字，不着一字感慨，只写"花红""白头""闲坐"——**以小见大**，是唐诗绝句的典范。
7. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、词义 ×1、炼字 ×1、主旨 ×1）。
8. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 37 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（残宫、宫花、宫女）都在 10–26 单位内，fd ≤ 0.0060；虚影的 opacity 由 `sin` 时间轴驱动、恒 ≤ 基座 0.42，宫灯暖光同一驱动、恒 ≤ 基座 0.30（两处均乘 fadeK）。
- 场景构件（冒烟实测）：卷首 9 mesh、境壹 11 mesh、境贰 16 mesh / 13 sprite；draw call 代理值 17 / 19 / 30（≤120），三角面 ≈1.4 / 2.1 / 2.3 万（≤12 万）。
