## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 泗滨寻芳 | 胜日寻芳泗水滨，无边光景一时新。 | 泗水春波、两岸草坡垂柳，镜头拉高见"无边光景"豁然开阔 |
| 贰 · 东风识面 | 等闲识得东风面， | 青色气流带横扫草野，草浪伏仰、柳丝拂动——东风的具象化 |
| 叁 · 万紫千红 | 万紫千红总是春。 | **标志瞬间**：东风扫过，百花沿紫→红→黄→粉的色彩波浪次第绽放 |

交互：第叁境**点击画面或按空格**，唤一阵东风拂过，百花波浪式再绽放并题字"万紫千红总是春"。

## 使用

- `← →`/空格逐境，`自动游览`可无人值守循环播放；`朗读此句`/`自动朗读`接 AI 配音。
- 声音开关、注音开关、全屏均在底部控制条；终章附 5 题学习小测。
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置 MP3 → 系统语音兜底。

## 教学建议

- 抓"泗水滨"用典：暗指孔门（洙泗之上），"寻芳"喻求圣人之道——全诗是"藏在春光里的哲理诗"。
- 第贰境提问：诗人凭什么"等闲"就识得东风？——春意无处不在，故处处可识。
- 第叁境色彩波浪对应"万紫千红"四字，可让学生边看边数颜色，体会"总是春"的收束感。
