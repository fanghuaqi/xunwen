# 清平乐·春归何处 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《清平乐·春归何处》（宋·黄庭坚）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**青绿春晓·山谷寻春**变体——春山无路听溪看落花的青绿底色、蔷薇架的残春粉白、枝头黄鹂的一点明黄。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"问取黄鹂"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：黄鹂引颈百啭（滑音啼啭），随后振翅飞越蔷薇架、风卷落瓣漫架而过，题字「因风飞过蔷薇」同现；黄鹂绕高弧归栖后可再问
- 末章：全词回放、学习小测（5 题）

**有意的设计**：全页唯一的亮彩是枝头**黄鹂的鸟羽黄**（`#e2bd46`，非金），栖点常驻一圈微弱暖晕，百啭时增强——在青绿底与粉白蔷薇之间只此一点明黄，正是「除非问取黄鹂」的视觉焦点。境①全境压在青绿色域内：石板小径愈远愈稀、到乱石处而断（「寂寞无行路」），落花点点评过溪面（春随流水去）；境②蔷薇架的粉白花团是唯一的浅暖色，晚春残花呼应「因风飞过蔷薇」。

## 教学建议

1. **导入**：讲背景——黄庭坚晚历贬谪，此词写于暮春；先问学生"春天走了会去哪里？"再入境①。
2. **境①品味**：起句一问「春归何处」，看断在小径尽头的乱石与随溪漂去的落花——「寂寞无行路」不是无路可走，是无迹可寻；「唤取归来同住」的痴语让学生读出词人对春的一往情深。
3. **境②点击**：先问"找不到春天还能问谁？"再点击画面问黄鹂——鸟语人不解、因风过蔷薇：问而不得，奇想落空，惜春之情反而更深。
4. **手法**：全词妙在以拟人痴问写寻春，把「春」当作可以同住的朋友、把「黄鹂」当作可以问路的故人，童趣与深情一体。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音 ×1、构思奇想 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
