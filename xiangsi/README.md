# 循文入境 · 相思（唐 · 王维）

单文件沉浸式诗词课件：`index.html` 双击即开（Three.js 走 CDN，音频本地）。
三境随诗句推进：**南国春枝 → 愿君采撷 → 此物相思**，第叁境可点击画面（或空格）采撷红豆——红果依次点亮串起、掌心特写、题字「此物最相思」。

## 美术
- 赛道：青绿春晓 · 南国红豆变体。深绿底 `#0a1410`，强调色（唯一浓色）红豆红 `#c96a6a`。
- 标志瞬间：①红豆树特写——浓绿枝叶间红豆成串微光如灯、雨后新芽抽出；③一颗红豆捧在掌心，与远处南国山影叠化。

## 内容
- 逐字注音（撷 xié、发 fā、思 sī 等已核）、释义、注释（含考点：一作《江上赠李龟年》，怀念友人之作）。
- 5 道小测：接龙×2、读音×1、词义×1、主旨×1。
- 配音 `audio/00–04.mp3`（00 标题、01–03 各句、04 全诗）；无音频时自动回退浏览器语音（Edge 下为神经语音现场朗诵）。

## 使用
- 左右键 / 空格逐境游览；控制条可开关自动游览、自动朗读、注音、声音、全屏。
- 课堂大屏：开启「自动游览」「自动朗读」即可无人值守播放。
- 首次打开需联网加载 Three.js；朗读与交互音效需浏览器允许自动播放（点「入境」即授权）。
