# 循文入境 ·《村居》高鼎（清）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js r128 走 CDN 三路回退，首次打开需联网；音频为本地 MP3）。

## 使用

- 双击 `index.html` → 点「入境」→ 自动朗读 + 自动游览全程无人值守（均可一键关）。
- `← →` 键或空格逐境游览；**第三境「忙放纸鸢」可点击画面 / 按空格**——东风骤起，五色纸鸢齐齐爬升、风筝线绷紧（WebAudio 铃音 + 琥珀拨弦）。
- 朗读优先级：Edge 在线神经语音现场朗诵 → 内置 `audio/*.mp3` → 系统语音兜底。删除 `audio/` 目录可在 Edge 下强制走神经语音。
- `audio/00-04.mp3` 由 `gen-voice.js`（本目录副本，含「草长 zhǎng」多音字替换表）生成。

## 三境设计（草长莺飞 → 杨柳春烟 → 忙放纸鸢）

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 | 草长莺飞二月天 | 起伏草坡上 260 株嫩草随风摇曳，4 只杏黄莺雀双翼对拍绕圈翻飞，粉白飞絮浮尘缓漂 |
| 贰 | 拂堤杨柳醉春烟 | 青绿河水缓波，长堤上三株垂柳 36 条柳丝低垂慢摆，水面春烟低伏 + 堤岸雾带慢流（"醉"态） |
| 叁 | 忙趁东风放纸鸢 | **标志性瞬间**：村塾剪影旁五名放学孩童剪影，五只异色菱形纸鸢（朱红/杏黄/青蓝/藕粉/青绿，带骨架尾穗）随风阵摇曳爬升，17 段贝塞尔风筝线从孩童手中连到鸢上，弧度随风阵绷紧；点击=东风大作，纸鸢齐升、线绷直、题字"放纸鸢！" |

情绪曲线：全诗最"轻"最欢快的一首——天光逐境变亮（星 0.15→0.06、雾密度 0.005→0.0042、暖金天光渐强），末境仰镜随纸鸢升入高天。

## 防同质化

- 风格赛道：**青绿春晓·纸鸢春烟变体**（art-direction ④）——bg `#0a1410`、主绿 `#9fce8f`（强调色）、文字 `#eef4e6`、雾 `#0e1d16`。
- 与同赛道《春晓》（晨光+落花+啼鸟）、《江南》（莲叶游鱼）、《绝句》（黄鹂白鹭）等区分：本页做**"放纸鸢"的儿童欢趣**——纸鸢、风筝线、孩童、村塾为全库独有母题。
- 自创新 builder：`kiteGeo`/`makeKite`（菱形鸢面+骨架+尾穗）/`makeOriole`/`bGrass`/`bWillow`/`bKite`；封面即有纸鸢遥影伏笔。

## 教学要点

- 多音字：长 zhǎng（生长）、散 sàn（散学）、拂 fú、堤 dī、趁 chèn；纸鸢 zhǐ yuān＝风筝。
- 考点：「草长莺飞」写景名句；「醉春烟」拟人；「忙趁」体现儿童欢趣与对春天/东风的敏锐。
- 小测 5 题：接龙×2、读音×1、词义×1、主旨×1。
