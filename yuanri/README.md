# 《元日》 · 夜宴金彩（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《元日》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。全诗三境：从"爆竹声中一岁除"的除旧，走到"总把新桃换旧符"的迎新。本页取**夜宴金彩**赛道做**年画金彩变体**——年画暖金的节庆夜色，全页唯一的红留给新桃符与爆竹串，"换符"在画面里循环上演。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（境③空格等同点击交互；末境后再按进入终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境①"爆竹除岁"：一挂红爆竹斜挂门前（静物陈列，本境无点击交互）
- 境③"新桃换符"：入镜即自动上演换符——四户门旁新桃符（红）渐显、旧桃符（灰褐）渐隐，每约 14 秒循环一次；入镜 6 秒后**点击画面**（或空格）重演此幕，鼓声钟声齐响、题字「总把新桃换旧符」闪现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：夜宴金彩（art-direction 赛道①）

| 项 | 取值 |
|---|---|
| 底色 | `#120d06`（暖棕黑年画夜，较典型色板 `#05070d` 更暖） |
| 主色 | `#d4b050`（年画暖金，与赛道①典型主金 `#d4af37` 同源；按钮/边框/进度点/题字） |
| 文字 | `#f0e6d0`；次要 `#a08a5e` |
| 雾 | `#1a1208`（SK 默认，暖棕雾，较典型雾 `#0a1526` 更暖更沉），逐境 fd 0.0048–0.0055 |
| 月 | 弯月淡金（ms 0.6–0.9），星渐稀（0.4→0.2）；境③旭日一颗（`#ffd890` + 辉光），"曈曈日"的画面直译 |
| 金尘 | 金色浮尘（makeGlow `#d4b050`）与横向暖风（makeFlow `#d4b050`，"春风送暖"的母题） |
| 红 | 全页仅两处：爆竹串红 `#c23a2a`、新桃符红 `#d4444a`；爆竹火星 `#ff8a5a`、屠苏酒淡绿 `#c8e0a0` 为辅 |

**有意的设计**：①赛道①的金在此收窄成**年画式的暖金**，底色与雾都偏暖棕，酒光流萤一概不用——节庆感靠"金尘 + 红"两色撑起；②全页唯一的红是叙事色：境①挂的是爆竹之红，境③门旁是新符之红，而"新桃换旧符"被写成一条颜色渐变（新符透明度 0.25→1、旧符 0.9→0，联动 14 秒循环）——"换"字是动画不是布景；③境②三盏屠苏酒杯微微起伏、金风横扫，写"春风送暖"最轻的一境。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题（"元日"）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全诗连读

页面朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音兜底。本目录无 `tts.json`，无特殊多音字副本；易错字音以页面注音为准：**曈** tóng（曈曈，日字旁勿误读为"瞳"）、**屠苏** tú sū（酒名）、**符** fú（桃符）、**除** chú（一岁除）。

## 教学建议

1. **导入**：问学生"古人过年没有春晚和手机，他们做什么？"再依次入境，对照画面找爆竹、屠苏酒、桃符三样年俗。
2. **境①年俗**：结合注释讲"爆竹"的来历——烧竹使爆驱邪，后来才演变成鞭炮；看画面里挂的是"竹节串"的原型。
3. **境②习俗**：讲饮屠苏酒的迎春习俗（页内注释从简，可口头补充"年少者先饮"的古人讲究），看金风粒子体会"送暖"。
4. **境③字词+画面**：先讲"曈曈"是日出光亮的样子（小测考点），再看画面东升的旭日；等待或点击触发换符一次，让学生口述"什么换下了什么"，落到"桃符是春联的前身"。
5. **背景升华**：介绍王安石写此诗时正推行新法，"新桃换旧符"也是除旧布新的政治寓意——讨论这句诗为什么写得格外有精神。
6. 末章做完 5 题小测（接句 ×1、文学常识 ×3、词义画面 ×1）；课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示，境③换符会自动循环上演。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 三境，共 4 项），境名逐一对齐；绝句四句按"爆竹→屠苏→曈曈日换符"三景并作三境。
- 交互境序号 `curIdx===3`（新桃换符），`pointerdown`/空格均以 `state==='stage'` 守卫，点击带 `ctl.t<6` 入场守卫；自动游览末境判断以 `POEM.length=3` 对齐。
- 校验：`node _pipeline/tools/validate.js yuanri/index.html` → **✓ 校验全部通过**。
