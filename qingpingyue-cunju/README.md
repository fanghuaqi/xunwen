# 循文入境 · 清平乐·村居（辛弃疾）

Three.js 单文件沉浸式诗词课件：词句推进到哪一句，三维实景就走到哪一重意境。
双击 `index.html` 即可使用（首次需联网加载 Three.js，音频本地播放）。

## 四重意境

| 境 | 词句 | 画面 |
|---|---|---|
| 壹 · 茅檐溪草 | 茅檐低小，溪上青青草。 | 低小茅檐傍清溪，青草成片，燕掠水面 |
| 贰 · 醉里吴音 | 醉里吴音相媚好，白发谁家翁媪？ | 翁媪对酌，微醺摇曳，白发相向而语 |
| 叁 · 溪东劳作 | 大儿锄豆溪东，中儿正织鸡笼。 | 大儿挥锄、中儿织笼、母鸡啄食的全景群像 |
| 肆 · 卧剥莲蓬 | 最喜小儿亡赖，溪头卧剥莲蓬。 | 标志瞬间：镜头推近溪头，小儿趴卧、双腿翘起摇晃剥莲蓬；**点击画面/按空格**看莲壳抛落入溪、涟漪扩散 |

美术赛道：青绿春晓 · 村居五口变体（强调色 `#a3c98f`）；情绪曲线为晨雾微明 → 晨光暖 → 日高明亮 → 午后金晖，渐入安宁温暖。

## 使用要点

- **游览**：← → 键或下方按钮逐境；「自动游览」可作课堂大屏无人值守展示；进入新境自动朗读。
- **朗读**：优先 Edge「在线自然语音」现场朗诵；否则播 `audio/` 内置配音；再退回系统语音。
- **多音字**（页面注音与配音均已按教材处理）：媪 ǎo、亡赖 wú（同"无赖"）、剥 bō、乐（词牌）yuè。
- **小测**：终章「学习小测」5 题（接龙 ×2、读音 ×1、词义 ×1、主旨 ×1），评语随得分变化。
- 配音由 `gen-voice.js` 生成（百度 TTS 免密钥）；如需更真人感的诗朗诵音色，配置 `TTS_AZURE_KEY` 后重跑脚本即可自动升级。
- 无网络时页面仍可打开（引擎加载失败会提示刷新）；本地双击即可运行，无其他依赖。
