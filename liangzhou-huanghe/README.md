# 循文入境 · 凉州词（黄河远上）| 王之涣

Three.js 沉浸式诗词课件（单文件，双击 `index.html` 即用；Three.js r128 走 CDN 三路回退，需联网加载引擎，音频本地）。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 远上白云 | 黄河远上白云间， | 超级纵深峡谷：镜头自低处沿九曲黄河北望，黄河金带蜿蜒数百单位、直没入白云之间（标志瞬间） |
| 贰 · 孤城万仞 | 一片孤城万仞山。 | 万仞台地群山环抱一片孤城，城垣雉堞、戍旗顶点波动、两名戍卒剪影 |
| 叁 · 羌笛玉门 | 羌笛何须怨杨柳，春风不度玉门关。 | 玉门关城楼前枯柳垂枝，关外寸草不生、关内极淡一抹柳色；点击画面羌笛声起（WebAudio 合成笛声 + 涟漪 + 枯柳摇曳 + 题字） |

美术赛道：大漠金戈 · 孤城羌笛变体（`--gold:#d09148`，底色 `#120d08`）。与已做的同赛道页（观沧海/登鹳雀楼/塞下曲）区分点：本诗为**白昼高远**基调（淡蓝天穹 + 金带黄河 + 白云），配 gradual 转苍凉的逐境天空插值。

## 使用

- 双击 `index.html`；自动朗读 / 自动游览默认开，可作课堂大屏无人值守展示。
- 键盘：← → 逐境、空格（第三境=羌笛声起）、Esc 停止朗读。
- `audio/00–04.mp3`：00 标题、01–03 各境、04 全诗（百度 TTS 生成，免密钥；如需诗朗诵级音色可配 Azure 密钥重跑 gen-voice.js）。
- 无网络加载失败时按提示刷新；朗读可回退浏览器神经语音。

## 教学

- 多音字考点：**间 jiān**（白云间）、**一 yí 片 / 不 bú 度**（变调）、**仞 rèn**（古代七/八尺）。
- 注释含典故：《折杨柳》曲（柳谐"留"）、玉门关（通往西域要道）、羌笛（羌族乐器）。
- 小测 5 题覆盖接龙 ×2、读音 ×1、词义典故 ×1、主旨理解 ×1。
