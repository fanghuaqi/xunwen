# 循文入境 ·《春晓》孟浩然

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js r128 走 CDN 三路回退，首次打开需联网；音频为本地 MP3）。

## 使用

- 双击 `index.html` → 点「入境」→ 自动朗读 + 自动游览全程无人值守（均可一键关）。
- `← →` 键或空格逐境游览；**第二境「处处闻啼鸟」可点击画面 / 按空格**，群鸟振翅、众啭齐鸣（WebAudio 现场合成鸟鸣）。
- 朗读优先级：Edge 在线神经语音现场朗诵 → 内置 `audio/*.mp3` → 系统语音兜底。删除 `audio/` 目录可在 Edge 下强制走神经语音。

## 四境设计（春眠 → 啼鸟 → 风雨 → 落花）

| 境 | 诗句 | 画面 | 天光（SKY 表现"晓"字） |
|---|---|---|---|
| 壹 | 春眠不觉晓 | 茅屋夜窗一点烛光随境渐黯，黄绿流萤渐熄，弯月低垂 | 夜，暗闷（fd 0.008，星 0.22） |
| 贰 | 处处闻啼鸟 | 一枝横斜、七只鸟剪影轮流啼鸣俯仰，远处飞鸟掠晨曦；点击则齐鸣振翅 | 晨曦破晓，低日金辉（星 0.05） |
| 叁 | 夜来风雨声 | 忆中之夜：雨丝着色器斜落 + 树影摇曳 + 风雾横流，茅屋窗内烛光微弱 | 夜，最暗最闷（fd 0.0095，月没星藏） |
| 肆 | 花落知多少 | **标志性瞬间**：雨霁天青，240 片花瓣漫天缓落，620 片渐次落地铺成花毯；镜头自俯视花毯缓缓仰起花树晨空，俯仰之间呼应"知多少"的怅然 | 全诗最亮：天青水绿（fd 0.0045） |

壹③暗、贰④亮的往复，正是诗的叙事线：夜（眠）→ 晓（鸟鸣）→ 忆夜（风雨）→ 晓（落花）。

## 防同质化

- 风格赛道：**青绿春晓·晨光版**（art-direction ④）——bg `#0a1410`、主绿 `#9fce8f`、辅杏 `#f2c94c`、文字 `#eef4e6`、雾 `#0e1d16`；与《将进酒》的"深蓝夜宴金"完全两路。
- 母题：花瓣（粉白实例化小片）+ 黄绿流萤 + 燕雀剪影，不用金色流萤、大月亮、酒器。
- 与同为青绿系的《关雎》区分：本页做"晨光 + 落花 + 啼鸟 + 风雨"，无水泽荇菜、无雎鸠。
- 自创新 builder：`makePetalFall` / `makePetalCarpet` / `makeBlossomTree` / `makeBird` / `makeBranch` / `makeRain` / `makeCottage` / `makeTree`，鸟鸣为 WebAudio 频率扫频合成（`chirp`/`birdCall`）。

## 教学要点

- 多音字：**觉 jué**（察觉，不读 jiào）、处 chù（处处）；注音已按教材标注入页面。
- 小测 5 题：接龙 ×2（上下句）、读音 ×1（觉）、词义 ×1（夜来=昨夜）、主旨 ×1（惜春怅然）。
- 情感线：恬睡之安 → 闻鸟之喜 → 忆雨之念 → 惜花之怅，映在天光由暗转明的渐变上。

## 配音

`gen-voice.js`（本目录副本，SUB 表已按本诗改编：`不觉晓→不决晓` 防"觉"误读 jiào）+ 百度 TTS 免密钥生成，`audio/00-05.mp3` 全部成功。
如需"诗朗诵"级真人感：配置 `TTS_AZURE_KEY` 后删除 `audio/` 重跑脚本即可自动切换 Azure 云健神经语音。
