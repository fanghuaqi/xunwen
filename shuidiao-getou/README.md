# 循文入境 · 水调歌头·明月几时有（苏轼）

「循文入境」沉浸式诗词课件：词句推进到哪一句，三维实景就走到哪一重意境。
本作为「循文入场」技能管线的第二个作品，与《将进酒》（夜宴金彩）同引擎、不同美术方向。

## 打开方式

双击 `index.html` 即可（Three.js r128 走 CDN 三路回退，首次打开需联网；音频为本地 MP3）。
- `←` `→` 键 / 空格 / 底部按钮逐境游览；「自动游览 · 开」可作课堂大屏无人值守展示
- 第一境（把酒问天）为交互境：**点击画面或按空格 = 举杯向天，酒光柱射月**
- 右下「注音」可开关逐字拼音；朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音

## 八境设计（境名 / 画面 / 情绪）

| 境 | 境名 | 词句 | 3D 场景 | 情绪 |
|---|---|---|---|---|
| 壹 | 把酒问天 | 明月几时有？把酒问青天 | 月下水榭，人影把盏；点击举杯，酒光柱直射明月 | 豪 |
| 贰 | 今夕何年 | 不知天上宫阙，今夕是何年 | 仰观天穹，云掩琼楼（多层檐发光宫阙半隐云后） | 神往 |
| 叁 | 乘风归去 | 我欲乘风归去……高处不胜寒 | **标志性瞬间①（两段式）**：镜头自人间灯火离地升天，穿云海，云上浮现琼楼玉宇；升至高处色温转冷、雾转寒蓝、月升高变大 | 徘徊 |
| 肆 | 起舞人间 | 起舞弄清影，何似在人间 | 月台舞者挥袖回旋，清影投地与身周旋，石案酒具 | 旷 |
| 伍 | 照无眠 | 转朱阁，低绮户，照无眠 | 朱阁绮户透烛光，无眠人影立于格窗之后，月帘斜照；镜头自右向左缓移（"月转"） | 郁 |
| 陆 | 别时圆 | 不应有恨，何事长向别时圆 | 满月低悬，掠月之云聚而复散，孤雁掠水，月光道满江 | 怨 |
| 柒 | 阴晴圆缺 | 人有悲欢离合，月有阴晴圆缺 | 七相月弧（朔→望→晦）横陈天际，阴云掠过月面 | 哲思 |
| 捌 | 千里婵娟 | 但愿人长久，千里共婵娟 | **标志性瞬间②**：镜头拉至极高处俯瞰千里江山（层叠山影、一江月光），一轮满月垂两道"月光如练"宽光柱，各照一地人影 | 释然 |

情绪曲线：把酒问天（豪）→ 欲去又恐（徘徊）→ 起舞人间（旷）→ 照无眠（郁）→ 婵娟共千里（释然），
由 SKY 系统（天空/雾/月大小/光温）逐境插值完成。

## 美术方向

**夜宴金彩 · 天界琼楼变体**（与《将进酒》的差异）：
- 主色由鎏金 `#d4af37` 改为**月银金 `#d9c98a`**，文字/边框/辉光全套跟随
- 雾更薄（基准 fd 0.003，参考实现 0.0045 起），"清冷仙气"
- 多数境有**地平线云海层**；中人把酒、天上琼楼（天/人两界对照是全片构图母题）
- 粒子母题：月金微尘、银色天风、掠月之云；弃用《将进酒》的橙色灯笼/篝火
- 自创新 builder：`makePalaceTower`（多层檐琼楼）、`bAscent`（升天穿云两段式）、`bPhases`（七相月弧）、`bChanjuan`（千里江山双光柱）、`bAsk`（举杯问天交互）

## 内容与考点

- 逐字注音已核对多音字：阙 què、琼 qióng、胜（不胜）shēng、绮 qǐ、婵娟 chán juān、长（长向/长久）cháng、处 chù、似 sì、几 jǐ
- 注释含教材考点：宫阙、琼楼玉宇、不胜（旧读 shēng）、婵娟（指月亮/美好月光，化用谢庄《月赋》"隔千里兮共明月"）
- 小测 5 题：下一句接龙 ×2、作者、词义（婵娟）、主旨理解

## AI 配音

`audio/` 内 00–09 共 10 个 MP3 已由 `gen-voice.js`（百度翻译 TTS 免密钥接口）生成：
00 标题、01–08 各境、09 全诗。生成时已改编曲脚本 SUB 多音字替换表（宫阙→宫却、琼楼玉宇→穷楼玉宇、不胜寒→不生寒、绮户→起户、婵娟→禅娟，仅影响读音、不改页面文字）。
如需"诗朗诵"级真人感，可配置免费 Azure 密钥后重跑：`set TTS_AZURE_KEY=你的密钥` 再运行 gen-voice.js。
网络不通时删除 `audio/` 即可回退：Edge 下自动用"在线自然语音"逐句现场朗诵。
