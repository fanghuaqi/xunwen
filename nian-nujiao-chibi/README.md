## 二、操作说明

- **入境**：封面「入 境」按钮 → 逐境推进；`←/→` 方向键、空格键、底部「上一境／下一境」皆可。
- **自动游览**（默认**开**）：「自动游览 · 开」按钮，每境停留 20~22 秒后自动进入下一境，走完自动进终章；
  课堂可无人值守投屏（关掉提示：再点一次按钮）。
- **自动朗读**（默认开）：进入每境 1.6 秒后自动朗诵该句；「朗读此句」可重播；切境即 `stopSpeak()` 静默上一句。
- **注音**：「注音 · 开／关」切换逐字拼音显隐。
- **声音**：`声音 · 开／关` 静默全部音效（江声、浪声、琴音、钟磬）。
- **全屏**：大屏教学用。
- **两处点击交互**（画面点按 或 空格键）：
  - **第贰境 · 惊涛拍岸**：点击 → 涌浪暴起、白沫炸成「千堆雪」，江面月光道大盛（江月酹地），涛声轰鸣（标志性瞬间）。
  - **第肆境 · 一尊酹月**：点击 → 举尊长酹、涟漪荡开、月华骤亮（一尊还酹江月）。
- **返回诗集目录**：封面按钮下方与终章按钮组内均有 `← 返回诗集目录 / 诗集目录`（`../index.html`）。

## 四、教学建议

1. **入境读词**：开自动游览 + 自动朗读，让学生先「看」一遍赤壁，再回头逐境析句——先入境，后析文。
2. **第贰境做「炼字」**：暂停在惊涛境，点击激起千堆雪，问「卷」字换成「溅／涌」行不行？（「卷」有裹挟、堆积之势，才有下文「千堆雪」）。
3. **第叁境的对比阅读**：画面里周瑜「羽扇纶巾」从容谈笑，与「樯橹灰飞烟灭」的烈火并置，问：写战争为何不写刀兵血火，只写「谈笑间」？（以从容写豪迈，衬托周瑜儒将风采与词人的倾慕）。
4. **第肆境的朗读与讨论**：「人生如梦，一尊还酹江月」是消极还是旷达？结合「早生华发」——被贬黄州、年近半百的东坡把酒洒向江月，是自解自放，非消沉。
5. **板书/考点**：豪放派代表词作；借景怀古（赤鼻矶非真赤壁）；周瑜形象的三层笔法（新婚衬年少、装束写儒雅、战果显雄才）。
6. **结课小测**：终章「学习小测」5 题——两句接龙、纶巾读音、公瑾人物、末句主旨；答完给分评语按本词定制（「东坡知己，江月同酹」之类）。
