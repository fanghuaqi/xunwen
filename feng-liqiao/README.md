# 循文入境 · 风（李峤）

《风》沉浸式单文件教学网页 —— 诗句推进到哪一句，三维实景就走到哪一重意境。
双击 `index.html` 即可打开（Three.js r128 走 CDN 三路回退，音频本地，无需服务器）。

## 风格赛道：烟雨江南 · 变体「风过留痕」

- 色板：底 `#10141a` · 强调 `#9fc2cf`（风线/题字/进度点）· 文字 `#e6ecef` · 雾 `#1c2a33`（fd 0.006–0.011）
- 与同赛道《声声慢》（愁雨梧桐、逐境转暗）刻意区分：本诗**不愁、不雨**，天光清朗明亮，基调明快；月亮缩为远天淡日（ms≤0.5）
- 全诗母题：**风线**（`makeWindLines`，淡青流线掠过每一境）——风看不见，用看得见的痕迹写风

## 四境设计（一句一境）

| 境 | 诗句 | 画面 | 新 builder |
|---|---|---|---|
| 卷首 | —— | 风之原野：微波江面、远岸低丘、风线掠场 | bCoverWind |
| 壹 秋风扫叶 | 解落三秋叶 | 三两疏树，两群黄叶绕涡心旋舞而起、周期阵风时急时缓 | bLeaves |

标志性瞬间：**同一阵风四境显形**（落叶→催花→卷浪→斜竹），风线母题贯穿全部四境。

## 使用

- **游览**：← → 键或空格逐境；点击顶部进度点可跳境；"自动游览"开启后可作课堂大屏无人值守展示。
- **交互**：第四境（风入竹林）点击画面或按空格，唤一阵疾风掠过竹林。
- **朗读**：优先 Edge 神经语音现场逐句朗诵；无神经语音时播放 `audio/` 内置配音；再缺失时回退系统语音。
- **声音**：控制条可关；环境声为低频"林涛"风声。

## 音频

`audio/00.mp3`（标题）+ `01–04.mp3`（各句）+ `05.mp3`（全诗），由技能脚本 `gen-voice.js`（百度 TTS 免密钥接口）生成，共 6 个文件。
多音字核对（页面注音为准）：解 jiě、落 luò、过 guò、尺 chǐ、斜 **xié**（古诗旧读 xiá，教材从今音）、峤 qiáo（李峤）。
如需"诗朗诵"级音色：`set TTS_AZURE_KEY=你的密钥` 后重跑
`node <技能目录>/scripts/gen-voice.js index.html "风" "唐，李峤"`。

## 教学要点（小测覆盖）

- 谜语诗：全诗句句写风，却未着一个"风"字——四句即四个谜面
- "解落/能开/过江/入竹"四个动词：风的四副面孔（扫、催、掀、压），摧毁与成全并存
- "三秋叶"对"二月花"：季节对举，见风跨越时空
- 虚数"千尺"：极言浪高；多音字考点：落、尺、斜
