# 题金陵渡 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《题金陵渡》（唐·张祜）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**水墨夜思**赛道——但刻意避开既有水墨夜思页的构图（不做舟夜孤灯碎星、不做雨夜棋枰灯花、不做古寺竹径），写的是这场夜渡的**两重「望」**：境壹=近泊（栈桥泊船、临江小楼一点暖窗、斜月初上），境贰=远望（潮落江空、斜月西沉，极目处两三点星火）。accent=#a8b4c0（银青水月，queue 分配强调色）只落在斜月晕/边缘光/楼窗灯晕/水月反光/UI 上，全页近零饱和。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"点亮瓜州星火"，交互过后再按进终章）

- 境②轻点画面：横江夜雾散开，瓜州方向两三点渔火次第亮起（火苗微颤+水面拉出微光倒影），"潮落夜江斜月里 两三星火是瓜州"题字同现
- 末章：全诗回放、学习小测（5 题）

**有意的设计**：全诗的暖色只有两处——楼上孤窗（人的居处）与远处星火（前路的方向），一近一远互为呼应；末境点击把「江雾散开、星火次第亮起」做成一眼可辨的 reveal：雾在（看不清）→ 雾散火现（是瓜州），正是「是」字里辨认与推想的可视化。

## 教学建议

1. **导入**：先讲「金陵渡不是南京」——唐时润州（今镇江）地界古称金陵，此渡口即今镇江西津渡；再在地图上指瓜州：长江北岸、与镇江隔江相望（今扬州邗江）。
2. **境①诗眼**：「自」——孤身羁旅、潮声月色相逼，愁不招自来；注意起句七字把时间（夜）、地点（津渡）、居处（小山楼）一并落定，还没写愁字愁已先住进来。
3. **境②点击后**：看雾散火现的一瞬，讨论「是」字——深夜隔江，两三点微光本是渔火、村灯难辨，诗人却宁可笃定「是瓜州」；远望的一瞥里装着孤寂，也装着对前路的悬念。
4. **写法**：由近及远的空间展开（小楼→夜江→斜月→星火），末句以极远极小的「两三星火」收束全篇——景愈远愈小，愁愈显愈长；可对照「夜半钟声到客船」的以声写夜，本诗是以光写夜。
5. **背景**：张祜，唐代诗人（字承吉，人称「张公子」），一生浪迹江湖，此诗是其羁旅夜泊名作；「瓜州」一作「瓜洲」。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、文学常识 ×1、名句理解 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 28 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 交互境序号 `curIdx===2`（pointerdown 与空格双接线，`clicked` 标志 + 1.2s 冷却防连点；空格先交互、再按进终章）。
- fadeK 铁律：所有每帧写 opacity/intensity 的对象（楼窗/灯晕/点光、星火火核/晕圈/倒影、江雾横带、微尘）初值=最大且逐帧乘 fadeK；山脊/地面/水面自定义着色器推入 `fogShaders` 做雾同步；星火与斜月同属"光点"取 `fog:false`。
- 预算：三境 drawCall 代理 ≈ 24/22/37、三角面 ≈ 2.3/2.5/2.4 万（≤120 / ≤12 万）。
- 校验：`node _pipeline/tools/validate.js ti-jinlingdu/index.html` → **✓ 校验全部通过**；`node ti-jinlingdu/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 逐境 build/update×400 帧 → fadeK 合规 → 末境点击门控 → 自动游览至终章 → 小测满分）；`node _pipeline/accept.js ti-jinlingdu` → **ACCEPT（2境 · 水墨夜思）**。
