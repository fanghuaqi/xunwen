# 苏幕遮·碧云天 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《苏幕遮·碧云天》（宋·范仲淹）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**水墨夜思**赛道——冷银水墨底色，冷月是唯一主角；黄叶枯橄榄、寒烟空翠、斜阳锈赭是全页仅有的三处低饱和色彩层次，全篇禁金。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境③为"点击斜阳芳草"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境③轻点画面：斜光铺水、芳草蔓出画外，"斜阳芳草"题字同现——泪眼中重见的那片斜阳
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#b0bccd`（按钮/边框/进度点/题字，全部银蓝水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#111a26` 系，fd 0.0048–0.0062 |
| 月 | 冷银白大月（境③ ms 2.0 满月）；境①白昼、境②黄昏则月隐（ms 0.001 移出视野） |
| 星 | 境①白昼几乎无星（0.06），黄昏 0.12，入夜 0.5 |
| 粒子母题 | 流云剪影、微尘、缓落黄叶、贴水寒烟（替代《将进酒》的金色流萤/火星） |

**有意的设计**：全页唯一非冷色是**斜阳的锈赭**（日轮 `#8a5038`、光路 `#9a664a`）——境②它铺在水面作"斜光铺水"，境③只在点击后才如泪眼中重见般浮现；它是"思"的温度，与冷银底的唯一对比。黄叶取暗橄榄枯色（`#494424` 系），寒烟取空翠灰绿（`#6a8a80`），均压低饱和，不破水墨底。

## 教学建议

1. **导入**：先看封面设问"秋天的高天是什么颜色？"再入境①，对照"碧云天，黄叶地"看天高地阔的对起。
2. **境①炼字**：让学生找"连"和"翠"——秋色如何"连"波、寒烟为何是"翠"的，体会冷而不衰的秋色。
3. **境②名句**：先看画面再读"芳草无情，更在斜阳外"——斜阳已是极目所尽，故乡更在其外；结合注释讲芳草喻离恨（绵延不尽）与"黯然销魂"典出江淹《别赋》。
4. **境③情感**：点击看斜光铺水、芳草蔓出画外，讨论"为什么楼头人眼里又出现了斜阳芳草"；体会"酒入愁肠，化作相思泪"四层递进（楼头、月下、酒中、泪里）。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
