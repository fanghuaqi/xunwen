# 循文入境 · 凉州词（葡萄美酒夜光杯）

唐 · 王翰。三境沉浸式诗词课件（夜宴金彩 · 边塞军宴变体：玉绿酒光 × 火把暖橙 × 沙场冷月，豪迈中带悲凉）。

## 使用

双击 `index.html` 即可打开（需联网加载 Three.js；朗读音频为本地 MP3）。

- `←` `→` 或空格逐境游览；第三境**点击画面（或按空格）**：琵琶声起、众军举杯、题字「古来征战几人回」
- 自动游览 / 自动朗读默认开启，可作课堂大屏无人值守展示
- `audio/00–04.mp3` 为 AI 朗读；删除 `audio/` 目录后，Edge 浏览器会自动改用在线神经语音现场朗诵

## 三境

1. **夜光杯** —— 标志性瞬间：军帐案上特写，半透明绿玉杯中葡萄酒泛着幽光
2. **琵琶催饮** —— 骑士马上横抱琵琶弹拨（WebAudio 拨弦声、声声催饮），篝火旁众军举杯
3. **醉卧沙场**（互动境）—— 空旷沙场、孤月、倒掉的夜光杯；点击琵琶催饮、众军举杯

## 教学建议

- 境一：观察"夜光杯"细节，理解葡萄、琵琶、夜光杯等西域风物与边塞诗的关系
- 境三：点击互动后出示"古来征战几人回"，引导学生讨论"豪放"与"悲凉"一体两面
- 注音已核对多音字：催 cuī、卧 wò、回 huí、几 jǐ、场 chǎng
- 小测 5 题可作课堂快问快答
