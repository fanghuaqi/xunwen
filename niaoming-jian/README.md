# 鸟鸣涧 · 循文入境（王维 · 唐）

水墨夜思·春山月出变体沉浸式网页，三境随诗句推进，以动写静：

1. **桂落山空** —— 人闲桂花落，夜静春山空（桂瓣无声缓落，反衬山空）
2. **月出惊鸟** —— 标志性瞬间：月亮蓦然跃出山脊，月光渐亮，惊起满林栖鸟，鸣声在涧面荡开声波涟漪
3. **时鸣春涧** —— 鸟鸣声声回荡春涧；**点击画面/按空格**：重看月出惊鸟（月升+鸟群惊飞+涧中鸣声+题字）

## 使用

双击 `index.html` 打开（需联网加载 Three.js，音频本地）。`audio/` 内含 AI 配音 5 个
（00 标题、01–03 各句、04 全诗）；删除 audio/ 后 Edge 下自动改用"在线自然语音"现场朗诵。

- ← → 或空格：逐境 / 触发交互；Esc：停止朗读
- 自动游览 + 自动朗读默认开，可作课堂大屏无人值守展示
- 含逐字注音（桂 guì、涧 jiàn、空 kōng、中 zhōng 已核）、释义注释、结课小测 5 题

## 教学建议

先静音让学生看画面猜诗句；再开自动游览完整走一遍；重点讨论"以动衬静"——桂花落、
月出、鸟鸣三处"动"，恰恰写尽春山的"静"。
