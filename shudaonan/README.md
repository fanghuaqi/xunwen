# 《蜀道难》 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《蜀道难》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。全诗三大段并作七境，从"噫吁嚱，危乎高哉"的仰天一叹走到"侧身西望长咨嗟"。本页取**大漠金戈**赛道做**蜀山赭金变体**——白日层峦直逼天穹，赭金绝壁、横流沙尘、漫天星宿，是六条赛道里最"高"最"险"的一页。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键：逐境推进
- 空格：境⑥"连峰飞湍"/境⑦"剑阁崔嵬"触发交互；其余境等同"下一境"；末境为进入终章
- 控制条：上一境 / 自动游览 / 下一境 / 朗读此句 / 自动朗读 / 注音开关 / 声音开关 / 全屏
- 境⑥"连峰飞湍"点击画面（或空格）：远处"高标"自雾中拔地长出，低频惊涛轰鸣，题字「万壑雷！」闪现
- 境⑦"剑阁崔嵬"点击画面（或空格）：关外高标显形，轰鸣与题字「万夫莫开！」同现
- 末章：全诗回放（`08.mp3`）、学习小测（5 题）

| 月 | 大多数境 `ms:0.001` 隐月、改用赭金白日（`#ffeac4` 日盘 + `#e08a30` 辉光）；仅"扪参历井"清寒月（ms 0.62）与"悲鸟子规"啼夜月（ms 2.05）现月 |

**有意的设计**：①**隐月用日**——赛道⑤典型的"低垂昏黄月"在此替换为白日金盘，七境中五境无月，唯独把月还给"子规啼夜月"和"扪参历井"两个非它不可的诗句，是全页最克制的取舍；②**情感曲线入色**——页内注释明写七境情感线"苍茫→幽深→惊险→清寒·星空→凄厉→壮烈→森然苍凉"，天光随之从赭金白日（危乎高哉）转暗（鸟道天梯）、转清寒蓝紫（扪参历井）、再回暖金（连峰飞湍）、终于暮色关城（剑阁崔嵬）；③境⑦镜头带轻微 roll 倾侧，走栈道的不稳感。

## 教学建议

1. **导入**：先只放标题问"为什么开口就是一声'噫吁嚱'？"入境①看层峦压顶的画面，体会惊叹起笔的气势。
2. **三次咏叹**："蜀道之难，难于上青天"在境①⑤⑦各出现一次，让学生跟读三遍，对比三次的情感递进（叹其高→惊其险→忧其乱）。
3. **境④星图**：指着画面上的参宿与井宿讲"扪参历井"——秦属井宿、蜀属参宿，仰头摸星就是跨过秦蜀分野；这是本页独有的天文写实。
4. **典故考点**：境②"地崩山摧壮士死"对应"五丁开山"，境③"六龙回日"、境⑤"子规啼夜月（杜宇化鹃）"，结合注释逐一指认。
5. **交互收束**：在境⑥点击触发"高标出雾 + 万壑雷"，用声画同步体会"砯崖转石万壑雷"的夸张；末章做完 5 题小测（接句 ×2、读音 ×1、典故 ×1、手法主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示；注意页面前段天光较暗，演示环境建议调低环境光。
