# 循文入境 · 将进酒（Three.js 沉浸式诗词网页）

以李白《将进酒》为内容的「循文入境」互动课件：诗句推进到哪一句，三维实景就走到哪一重意境，
学生边读诗、边"走进"诗里 —— 看黄河天上来、揽镜悲白发、与岑夫子丹丘生举杯共酌，最终同销万古愁。

## 运行方式

双击 `index.html` 即可在浏览器打开（Chrome / Edge 均可）。

- 首次打开需联网加载 Three.js（cdnjs → jsdelivr → unpkg 三路自动回退）。
- 页面全部三维内容为程序化生成，无任何图片/模型资源，加载后可离线漫游。

## 十三境结构（诗句 → 意境场景）

| 境 | 诗句 | 场景 |
|----|------|------|
| 壹 | 君不见，黄河之水天上来 | 天河瀑布自天际倾落 |
| 贰 | 奔流到海不复回 | 低空掠浪东流、飞鸟掠过 |
| 叁 | 君不见，高堂明镜悲白发，朝如青丝暮成雪 | 高堂烛影、铜镜，青丝渐成雪 |
| 肆 | 人生得意须尽欢，莫使金樽空对月 | 湖上金樽对月、流萤 |
| 伍 | 天生我材必有用，千金散尽还复来 | 千金硬币散尽又重聚（循环） |
| 陆 | 烹羊宰牛且为乐，会须一饮三百杯 | 篝火夜宴 + 三百金杯星河 |
| 柒 | 岑夫子，丹丘生，将进酒，杯莫停 | 三人举杯（点击画面/空格 = 同酌碰杯） |
| 捌 | 与君歌一曲，请君为我倾耳听 | 古琴弦振、音符升起 |
| 玖 | 钟鼓馔玉不足贵，但愿长醉不复醒 | 雾中钟玉沉落（梦境） |
| 拾 | 古来圣贤皆寂寞，惟有饮者留其名 | 寂寥星座 vs 金色饮者星河 |
| 拾壹 | 陈王昔时宴平乐，斗酒十千恣欢谑 | 洛阳宫阙灯宴 |

| 拾叁 | 五花马，千金裘，……与尔同销万古愁 | 万古愁随江流而逝、金光升起 |

## 学习功能

- 逐境展示诗句（竖排楷体 + 逐字入场动画），每个字带拼音注音（可开关）
- 每境配【释义】与【注释】（将 qiāng、馔玉、陈王、恣欢谑 等考点）
- 「朗读此句」：手动重听当前句
- **自动朗读**：默认开启，进入每一境后自动朗读该句（可一键关闭）
- **真人感朗读 v2**：优先调用 Edge 浏览器的"在线自然语音"（云健/晓晓等神经网络音色）
  **逐句现场朗诵**——句间停顿、放慢语速，节奏接近真人；无神经语音时播放内置
  MP3（`audio/` 15 个文件，任何浏览器可用）；再退普通系统语音
- 终章与「聆听全诗」按钮播放完整全诗朗诵
- 升级打包音色：`set TTS_AZURE_KEY=密钥` 后运行 `node tools/gen-voice.js`，
  即用 Azure"云健·诗朗诵"神经风格重新生成全部 MP3（免费层每月 50 万字符）
- 自动游览模式：适合课堂大屏投影循环播放
- 终章：全诗回放 + 5 题学习小测（即时判分与评语）

## 操作

- `←` `→` 或按钮：上一境 / 下一境；`空格`：下一境（第七境中为"碰杯"）
- 底部控制条：自动游览、朗读、注音、声音、全屏
- 每境有雾色、月位、光色的过渡运镜，鼠标移动有轻微视差

## 技术要点

- Three.js r128（UMD 单文件引入），场景全程序化：自写水面着色器（波浪 + 菲涅尔 + 月光高光）、
  瀑布 fbm 流动着色器、粒子系统（火焰/浪花/流萤/愁绪/星河）、千斤顶 InstancedMesh 金币与三百金杯
- 十三重"境" = 独立场景组，切换时相机运镜 + 场景淡入淡出 + 天空/雾/光参数整体插值
- Web Audio：程序合成江声环境音（brown noise）与古琴拨弦（Karplus–Strong 算法）

## AI 配音生成

`audio/` 里的 MP3 由 `tools/gen-voice.js` 调用百度翻译 TTS 开放接口批量生成（免密钥），
已对多音字做了音频级替换（将 qiāng / 朝 zhāo / 还 huán / 乐 lè）。重新生成：

```bash
cd tools && node gen-voice.js
```
