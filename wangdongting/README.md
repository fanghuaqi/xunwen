# 望洞庭 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《望洞庭》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页走**水墨夜思**赛道的**秋月平湖变体**——冷银蓝的夜空下，大月是唯一主角，洞庭湖的水面着色器随月而亮；终境升上高空俯瞰"白银盘里一青螺"，是全页的标志性瞬间。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境叁为"月升泛银"触发；末境再按进入终章）
- 控制条：自动游览、自动朗读（默认均开）、注音开关、声音开关、全屏
- 境叁轻点画面（或空格）：银屑迸散、钟声响起，明月自湖面升起、湖光泛银，"白银盘里一青螺"题字浮现（1.8 秒防连点）
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#120d06`（暖褐墨，比赛道典型 `#0d1117` 略暖） |
| 主色 | `#d9c98a`（柔和月金：按钮/边框/进度点/题字；非全银蓝，是本页变体） |
| 文字 | `#e9e6da`，次要文字 `#a29a82` |
| 天空/雾 | top `#0a1420`、hor `#1e3242`、雾 `#0d151b`（冷银蓝），fd 0.003–0.013 |
| 月 | 冷银大月，**唯一主角**：ms 1.5（卷首）→ 1.9（境壹）；辉光偏 `#dceaf6` 冷银白 |
| 水 | 自定义水面着色器：深水 `#0b1826`、浅水 `#2a4c62`，月光方向镜面反射 |
| 粒子母题 | 银蓝浮尘（`#cfe0ee`/`#d6e6f2`/`#dcecf8`）、贴地雾霭、银屑迸散（`#d8ecfa`） |

**变体说明**：页面保留了"冷月唯一主角"的水墨内核（境壹大月 ms 1.9、天空湖水全冷银蓝），但主色取月金 `#d9c98a`、底色偏暖褐——那是月光落在水面上的温度，与赛道典型"无一处金色"的纯银蓝不同，属于秋月平湖的暖调变体。**有意的设计**：境贰湖面叠一层贴水柔光薄膜并加大雾密度（fd 0.013），做出"未磨铜镜"的雾面；境叁湖心君山一点翠色（`#5fae86` 辉光），是全页唯一的绿。

## 朗读配音

`audio/` 内置 5 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题（含四句全诗："望洞庭。唐，刘禹锡。湖光秋月两相和……"）
- `01–03.mp3` 三境逐境朗读
- `04.mp3` 全诗连读

页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。无 tts.json 多音字副本，两个关键多音字页面注音已给出并被小测点名：**和 hé**（"两相和"和谐义，不读 hè/huó）、**磨 mó**（打磨，不读 mò）。如需"诗朗诵"级音色，可设 `TTS_AZURE_KEY` 后重跑配音脚本。

## 教学建议

1. **导入**：问"月亮照在湖面上是什么样？"再入境壹，看两道光带缓缓合拢，理解"两相和"的"和"是融为一体。
2. **境贰比喻**：先看雾面湖面再读"潭面无风镜未磨"，讨论为什么是"未磨"的镜子——铜镜未打磨则朦胧，恰似月下湖面柔而不刺眼。
3. **境叁视角**：强调镜头升上高空——只有"遥望"才看得出"白银盘里一青螺"；点击月升泛银后，让学生说出两个比喻各指什么（湖面→白银盘，君山→青螺）。
4. **多音字随测**：借小测第 3 题当堂巩固"和 hé、磨 mó"。
5. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×1、句序 ×1、读音 ×1、词义 ×1、比喻理解 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 28 字）、释义/注释、境名/意境题句、5 题小测、终章回放。

- 交互境序号 `curIdx===3`（白银青螺）；进度点/按键/自动游览末境判断均以 `POEM.length=3` 对齐。
