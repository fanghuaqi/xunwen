# 循文入境 · 早发白帝城（唐 · 李白）

单文件沉浸式诗词课件：双击 `index.html` 即可运行（Three.js 走 CDN，音频本地）。

## 使用

- **入境**：封面点「入 境」；`← →` 方向键 / 空格逐境游览，也可点顶部进度点跳境。
- **自动游览**：控制条「自动游览」打开后无人值守自动走完全部 4 境并进入终章（适合课堂大屏）。
- **朗读**：进入新境自动朗读；Edge 浏览器下优先用"在线自然语音"现场逐句朗诵，其他浏览器回退内置 `audio/*.mp3`。
- **互动**：第四境「轻舟万山」**点击画面 / 按空格**为轻舟加速——两岸群山后掠更快、舟头水花更急，题字"轻舟已过万重山"（标志性瞬间"乘舟穿峡"）。
- **注音 / 声音 / 全屏**：控制条可随时开关。

## 四境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 彩云辞城 | 朝辞白帝彩云间。 | 白帝高城踞崖顶，晨曦彩云缭绕城头 |
| 贰 · 千里江陵 | 千里江陵一日还。 | 俯身急流，浪花飞卷、水雾疾驰，远处江陵城郭隐现 |
| 叁 · 两岸猿声 | 两岸猿声啼不住。 | 两岸陡峭峡壁夹江，崖间猿影悬臂，远处猿啼断续 |
| 肆 · 轻舟万山 | 轻舟已过万重山。 | 镜头乘轻舟穿峡，三层群山视差后掠 + 点击加速 |

## 文件

```
index.html        主页面（单文件）
audio/00-05.mp3   AI 朗读（00 标题、01-04 各境、05 全诗）
gen-voice.js      配音再生成脚本（SUB 表：朝→招 / 还→环 / 重→虫，保 zhāo/huán/chóng 读音）
smoke.test.js     深度冒烟测试（node smoke.test.js，26 项）
```

## 教学建议

- 先整体自动游览一遍，再逐境提问："为什么说'轻'舟？'轻'字轻在哪里？"体会遇赦东归的轻快心境。
- 多音字考点：**朝 zhāo**（早晨）/ **还 huán**（返回）/ **住 zhù**（停止）/ **重 chóng**（重叠）。
- "千里一日""万重山"为夸张手法；可对照郦道元《水经注》"朝发白帝，暮到江陵"。
- 网络不通时页面自动回退浏览器语音；重新生成配音：`node gen-voice.js index.html "早发白帝城" "唐，李白"`。
