# 鹊桥仙·纤云弄巧 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《鹊桥仙·纤云弄巧》（宋·秦观）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版为**水墨夜思·星海变体**——全套冷银水墨色板之上，以**银河/星海为全页主景**：斜贯天际的星河带、云海上的星河光路、冷月作伴，全页无一处金色。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②/末境为"鹊鸟搭桥"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 末境轻点画面：80 只鹊鸟错峰飞越银汉、合抱成桥，双星沿桥渐近相会，"鹊桥相会"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思·星海变体（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#adc0d8`（本诗分配强调色；按钮/边框/进度点/题字全银蓝水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |

| 星 | 银河自带双层程序化星点 + 星尘微闪；天星星度 0.55–0.62 |

**有意的设计**：天上一条银河（shader 星河带：fbm 星云 + 双层星点 + 中缝暗隙），云海上一条光路（星河自天际流向观者脚下）——两相衔接，构成"银汉迢迢"的纵轴；牛郎织女分立两岸云崖，唯一点题的暖意全交给"相逢"一刻的双星光晕。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，免费无密钥）：

- `00.mp3` 标题（"鹊桥仙·纤云弄巧"）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字以页面拼音为准，`tts.json` 同音同调替换 2 条：纤云弄巧→先云弄巧（纤 xiān）、朝朝暮暮→昭昭暮暮（朝 zhāo）；度（dù，渡过）、忍（rěn）、似（sì）按默认读音即正确，未钉写。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"牛郎织女一年只能见一面，你觉得是遗憾吗？"再入境①。
2. **境①意象**：对照画面讲"纤云弄巧"（云彩变花样，暗合七夕乞巧）与"飞星传恨"（流星递离恨）；数一数画面里的"银河—光路—双星"三层。
3. **境②传说过桥**：点击搭桥后讲鹊桥传说的来历，讨论"忍顾鹊桥归路"的不舍。
4. **主旨升格**：借"两情若是久长时，又岂在朝朝暮暮"讨论秦观超越朝夕相守的爱情观——这也是它成为七夕第一名篇的原因。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 两境），境名逐一对齐；词文与 `_pipeline/queue.json` 条目逐字一致（两境分境）。
- 交互境序号 `curIdx===2`（pointerdown + 空格双接线，先交互后进终章）；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 逐境预算：drawCall 代理 23–33（≤120）、三角面 2.2–2.9 万（≤12 万）、雾密度 0.0050–0.0060（主体 fog 遮蔽 ≤0.35）。
- 校验：`node _pipeline/tools/validate.js queqiaoxian-xianyun/index.html` → **✓ 校验全部通过**（零警告）。
- 冒烟：`node queqiaoxian-xianyun/smoke.test.js` → **SMOKE PASS**（真 THREE r128：boot → 逐境 build/update×400 帧/click 门控 → fadeK 合规 → 三层构图 → 自动游览至终章 → 小测 5 题全流程）。
- 实拍：`shots.py` 封面/两境 + 末境点击前中后三态逐张人工核图（鹊桥成形、双星相会、人物落位无误）。
