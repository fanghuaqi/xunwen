# 绝句（两个黄鹂）· 循文入境

杜甫《绝句》四境沉浸式课件 —— Three.js 单文件网页，属「青绿春晓·草堂四景」变体：
每境如一幅装框小景（黄鹂翠柳 / 白鹭青天 / 窗含雪岭 / 门泊东吴），基调明丽安适。

## 使用

双击 `index.html` 即可（首次打开需联网加载 Three.js；朗读音频已内置）。
`← →` / 空格逐境游览；**第四境可点击画面**：白鹭掠窗而过、雪岭窗景流转、船帆受风微动。
自动游览与自动朗读默认开启，可作课堂大屏无人值守展示。

## 四境

| 境 | 诗句 | 场景 |
|---|---|---|
| 壹 黄鹂翠柳 | 两个黄鹂鸣翠柳 | 翠柳丝绦、双鹂对语、鸣声化作音符 |
| 贰 白鹭青天 | 一行白鹭上青天 | 仰视蓝天，一行白鹭排空而上 |
| 叁 窗含雪岭 | 窗含西岭千秋雪 | **标志性场景**：木格窗为画框，雪岭春江在窗格中缓缓流动（画中画） |
| 肆 门泊东吴 | 门泊东吴万里船 | 门框含江、泊船三艘；点击触发白鹭掠窗 + 雪岭流转 |

## 朗读

`audio/00–05.mp3`（00 标题、01–04 各句、05 全诗），百度 TTS 生成。
多音字已在音频生成时以同音字表校正（不影响页面文字）：**行 → háng（一航白鹭）、泊 → bó（门博东吴）**。
无音频时页面自动回退浏览器语音（Edge 下为在线神经语音现场朗诵）。

## 教学要点

- 多音字考点：「一行」的**行 háng**（量词）、「门泊」的**泊 bó**（停泊）；另有 鹂 lí、含 hán 已逐字注音。
- 炼字：「含」——窗框如画框，雪山含于窗中，虚实结合。
- 全诗两两对仗：两/一、黄鹂/白鹭、翠柳/青天、窗含/门泊、千秋雪/万里船。
- 背景：杜甫定居成都草堂时的即景之作，四句四景、一静一动。
