# 天净沙·秋思 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《天净沙·秋思》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页走**烟雨江南**赛道的**暮秋萧瑟变体**——底色沿用赛道夜灰，主色转为一层暮紫，从昏鸦到残阳逐境下沉，最后落在"断肠人在天涯"的剪影上。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境肆为"断肠人在天涯"触发；末境再按进入终章）
- 控制条：自动游览、自动朗读（默认均开）、注音开关、声音开关、全屏
- 境肆轻点画面（或空格）：一声低鼓，"断肠人在天涯"题字浮现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：烟雨江南（art-direction 赛道⑥）

| 项 | 取值 |
|---|---|
| 底色 | `#10141a`（暮秋夜灰，与赛道典型一致） |
| 主色 | `#9a90b8`（暮紫：按钮/边框/进度点/题字；非典型黛蓝 `#8fb3c9`，是本页的"暮色"变体） |
| 文字 | `#e8e2ee`，次要文字 `#837a9c` |
| 雾 | `#171320`，fd 0.0055–0.008（低于赛道典型 0.012–0.02，视野更旷远） |
| 月 | 暮空微明月影，ms 0.85 → 0.4 逐境下落变暗，与夕阳交接天光 |
| 夕阳 | 暖橙 `#d88a4a`（境叁）、残阳 `#c9784a`（境肆）——全页仅有的暖色，越接近地平线越暗 |
| 粒子母题 | 西风横流（`#9a90b8` 长条流雾，speed 10）、暮霭（`#837a9c`） |

**变体说明**：主色由黛蓝转为暮紫、雾密度低于典型值——秋思是塞北秋暮，取烟雨江南的"灰底湿雾"、去掉"江南"的暖意。**有意的设计**：境叁大夕阳从高处缓缓沉向地平线（伴随辉光渐弱），是全页唯一的暖色光源，也是"断肠人"登场的逆光。

## 朗读配音

`audio/` 内置 6 个 AI 朗读 MP3（edge-tts 生成）：

- `00.mp3` 标题（"天净沙秋思。元，马致远。枯藤老树昏鸦，小桥流水人家。"）
- `01–04.mp3` 四境逐境朗读
- `05.mp3` 全篇连读

页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。无 tts.json 多音字副本；四句正文按页面注音无多音字险，仅题名两处留意："**曲牌**天净沙"之曲读 qǔ、"秋**思**"读 sī（思虑义），二者只出现在标题朗读与讲解中，不入正文注音。如需"诗朗诵"级音色，可设 `TTS_AZURE_KEY` 后重跑配音脚本。

## 教学建议

1. **导入**：让学生数一数境壹画面里有哪些景物（枯藤、老树、昏鸦、小桥、流水、人家），再对照诗句——九个名词直接并置，这正是这首小令最著名的写法。
2. **冷暖对照**：境壹"小桥流水人家"画面其实是安宁的，讨论它为何反而让游子更愁（他人有家，我无家）。
3. **境叁时间**：盯着夕阳下沉读"夕阳西下"，体会一个"下"字压出的日暮途远之感。
4. **境肆点题**：点击出题字后讲"断肠人""天涯"，回看前三境——前面所有景物都是"断肠人"眼里的景，情在景中。
5. **常识**：结合小测讲"天净沙"是曲牌名、"秋思"是题目，体裁是元曲中的小令。
6. **收束**：末章全篇连读一遍，再做完 5 题小测（接龙 ×1、词义 ×1、文学常识 ×2、意象主旨 ×1）；课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，正文 28 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 四境，POEM 第一条含两句），境名逐一对齐。
- 交互境序号 `curIdx===4`（断肠天涯）；进度点/按键/自动游览末境判断均以 `POEM.length=4` 对齐。
