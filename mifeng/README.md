# 循文入境 · 蜂（唐 · 罗隐）

双击 `index.html` 即可打开（首次需联网加载 Three.js）。三重意境随诗句推进：

1. **平地山尖** —— 晨光花田，花一路开到山尖（不论平地与山尖）
2. **无限风光** —— 大全景全域花开，金色蜂群拖着发光轨迹线穿行（无限风光尽被占）
3. **百花成蜜** —— 标志瞬间：蜂群循金色轨迹归巢，琥珀蜜缓缓注满六边形巢脾；镜头缓缓拉远，只余小小蜂巢（采得百花成蜜后，为谁辛苦为谁甜）

## 操作

- `←` `→` 或空格逐境游览；右上角可点进度点跳境
- **第三境**点击画面或按空格：蜂群归巢酿蜜 + 题字「为谁辛苦为谁甜」
- 可开关：自动游览 / 自动朗读 / 注音 / 声音 / 全屏

## 朗读

- 优先 Edge「在线自然语音」现场逐句朗诵；亦内置 `audio/00-04.mp3`（00 标题、01-03 各句、04 全诗）
- 配音多音字已按教材读音校正（占 zhàn、为 wèi、得 dé，仅影响音频）

## 教学建议

- 先无人值守自动游览一遍整体感知，再逐境提问「蜂在做什么」
- 末境追问：诗人是在夸蜂还是替蜂抱不平？（借蜂喻人：劳者不获、获者不劳）
- 结课含 5 题小测（接龙 ×2、读音 ×1、主旨 ×2）
