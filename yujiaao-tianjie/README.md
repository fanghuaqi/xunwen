# 循文入境 · 渔家傲·天接云涛连晓雾（宋 · 李清照）

单文件沉浸式诗词课件：四境随词句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 水墨夜思·星海神游变体：易安居士词中极为罕见的雄奇浪漫杰作——从星河千帆的壮阔，到梦入天宫闻天语的奇遇，最后由「九万里风鹏正举」高飞出世。
> 标志性瞬间：天接云涛连晓雾，星河欲转千帆舞——浩瀚云涛星海中千帆乘风起舞的神话幻境。

## 教学建议

- 词风转变：对比《如梦令》《声声慢》，体会李清照南渡后词风的壮阔飞跃——易安不仅有闺怨，更有豪情
- 神话意象与《庄子》化用：「星河」「帝所」「大鹏」「蓬莱三山」——融屈原《离骚》与庄子《逍遥游》于一炉
- 「学诗谩有惊人句」的深层悲慨：一个才华绝代的女子在乱世中的真实叹息
- 注音考点：云涛 yún tāo、晓雾 xiǎo wù、星河 xīng hé、帝所 dì suǒ、殷勤 yīn qín、嗟 jiē、日暮 rì mù、谩有 màn yǒu、鹏正举 péng zhèng jǔ、蓬舟 péng zhōu、三山 sān shān
- 背景：宋高宗建炎四年（1130年）前后，李清照避难浙江沿海，泛海往来于明州、温州一带，见沧海浩瀚而有此梦
