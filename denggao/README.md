# 登高 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《登高》（唐·杜甫）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。**七律四联各一境**，全套冷银水墨色板，落木与长江的冠联对仗动景是全页的标志性瞬间。被明胡应麟《诗薮》推为「古今七言律第一」的这首诗，页面以「动景写所见、静景写所感」的对切结构呈现：前二境是急风、哀猿、飞鸟、落木、江浪的**动**，后二境是常作客、独登台、霜鬓、停杯的**静**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"点击落木长江"，交互过后再按才进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境④轻点画面：落叶如雨骤盛、江浪层叠加高、远处世界整体下沉（镜头拔高感），题字「落木长江」同现
- 末章：全诗回放、学习小测（5 题）

## 朗读配音

`audio/` 内置 6 个 Edge 神经语音 MP3（zh-CN-YunxiNeural，语速 -16%，与页面赛道自动选声一致）：

- `00.mp3` 标题（登高。唐，杜甫。……）
- `01–04.mp3` 四联逐境朗读
- `05.mp3` 全诗连读

多音字以页面拼音为准，`tts.json` 同音同调替换 4 条：渚 zhǔ（煮）、啸 xiào（笑）、潦 liáo（缭）、鬓 bìn（殡）。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：先讲写诗背景——唐代宗大历二年（767）秋，杜甫五十六岁流寓夔州，重阳独自登高；再入境①对照"一句三景"数一数急风、高天、哀猿、清渚、白沙、回鸟。
2. **境②冠联**：先看画面（左天落木、前江江浪）再读诗句，体会"无边"对"不尽"、"萧萧"对"滚滚"——空间之无垠对时间之无穷。
3. **境③八重悲**：结合注释讲透罗大经《鹤林玉露》的"十四字八意"，让学生逐词数出八重悲，体会层层加码的抒情密度。
4. **境④尾联**：点击落木长江后再读"潦倒新停浊酒杯"，讨论"为什么连酒都不能喝了愁更深"（因病戒酒、借酒浇愁而不得）；"艰难"兼指国运与身世的双关。
5. **收束**：末章全诗连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故（夔州重阳）×1、主旨（八重悲）×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 四境），境名逐一对齐；交互境序号 `curIdx===4`（pointerdown + 空格双接线，先交互后进终章）；进度点/按键/自动游览末境判断均以 `POEM.length=4` 对齐；诗文与 `_pipeline/queue.json` 条目逐字一致（滚滚从教材通行本）。
- 由 `_pipeline/_dgx/build.py` 骨架管线生成，配置在 `_pipeline/_dgx/denggao.py`。
- 校验：`node _pipeline/tools/validate.js denggao/index.html` → **✓ 校验全部通过**。
- 冒烟：`node denggao/smoke.test.js` → **SMOKE PASS**（真 THREE r128 全生命周期：逐境 build/update×400 帧、fadeK 合规、三层构图、末境点击门控、自动游览至终章、小测满分；多轮复跑稳定）。
- 实拍：封面 + 四境全截图抽检，冠联落叶雨/江浪与末境点击前后对比均确认可读。
