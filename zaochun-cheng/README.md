# 早春呈水部张十八员外 · 循文入境（唐 · 韩愈）

双击 `index.html` 即可打开（需联网加载 Three.js，音频已内置本地）。适合课堂大屏、学生自学与无人值守展示。

## 内容

三境随诗句推进，配音 5 个（00 标题 / 01–03 各句 / 04 全诗）：

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 天街酥雨 | 天街小雨润如酥。 | **标志性瞬间**铺垫：长安天街细雨如酥，湿街映光，皇城门楼隐在雨雾尽头 |
| 贰 遥看草色 | 草色遥看近却无。 | **标志性瞬间**："草色悖论"——远望满坡鹅黄草色，镜头推近却尽数隐没，只见稀疏草芽；镜头自动来回推移呈现悖论 |
| 叁 绝胜皇都 | 最是一年春好处，绝胜烟柳满皇都。 | 烟柳夹道、皇都天际线晨霭中显现；**互动**：点击画面（或空格）镜头远近推移，草色隐现并题字"草色遥看近却无" |

## 操作

- ← → 键 / 空格 / 按钮：逐境游览；第三境点击画面（或空格）触发远近推移
- 「自动游览」「自动朗读」默认可开：无人值守展示建议全开
- 朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音兜底

## 教学

- 多音字考点：酥 sū、处 chù（春好处）、绝 jué、胜 shèng、都 dū（皇都）、看 kàn（页面注音 + 注释均已标注）
- 内置 5 道小测：接龙 ×1、词义（酥）×1、读音（处）×1、文化常识（皇都=长安）×1、主旨 ×1
- 美术赛道：青绿春晓 · 天街酥雨变体——以"草色遥看近却无"的距离驱动视觉悖论为全诗之眼，与同赛道诸篇（春晓/江南/村居等）区分
- 配音：百度 TTS 生成（00–04.mp3）；若在 Edge 打开可自动优先神经语音现场朗诵
