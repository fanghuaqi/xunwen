# 循文入境 ·《塞下曲》卢纶

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js r128 走 CDN 三路回退，首次打开需联网；音频为本地 MP3）。

## 使用

- 双击 `index.html` → 点「入境」→ 自动朗读 + 自动游览全程无人值守（均可一键关）。
- `← →` 键或空格逐境游览；**第三境「雪满弓刀」可点击画面 / 按空格**：大雪骤落满弓刀、弓刀寒光凛冽、题字"大雪满弓刀"闪烁 + 战鼓钟音（有冷却防连点）。
- 朗读优先级：Edge 在线神经语音现场朗诵 → 内置 `audio/*.mp3` → 系统语音兜底。
- `audio/`（00 标题 + 01..03 各句 + 04 全诗，共 5 个）由本目录 `gen-voice.js` 生成（SUB 纠音：单→蝉 chán、遁→顿 dùn、骑→记 jì）；`smoke-test.js` 为深度冒烟测试（真实 THREE r128 无头执行全部 build/update/click/goto）。

| 壹 | 月黑雁飞高 | 边营寨栅/帐篷/望楼剪影、一点守营篝火，宿雁惊起盘旋高飞入暗 | 月黑无月（星 0.16，雾 0.007） |

## 美术方案（防同质化）

- 风格赛道：**大漠金戈 · 雪夜边营变体（月黑雁飞）**——bg `#120d08`、强调 `#c4823a`、文字 `#e9dcc4`、雾 `#0d0b09`。
- 与同赛道已做的《观沧海》（沧海台地/日月星汉）、《登鹳雀楼》（落日楼台/浊金大河）区分：本诗**月黑无月**（ms 0.001 藏月）、满天落雪、马队剪影与弓刀冷光为主视觉；基调紧张肃杀、末句转豪壮。
- 自创新 builder：`makeSnow`（自写落雪着色器：顶点回绕下落 + 横向风漂，双层雪作交互雪势开关）、`makeRider`（马队剪影：四腿奔跑摆动）、`makeBanner`+`waveFlag`（顶点波动军旗）、`bGongDao`（弓/刀建模 + 积雪帽 + 寒光辉光 + 骤雪交互）、`drum`（WebAudio 战鼓）；远景改台地剪影（大漠地平线）。

## 教学要点

- 注音考点：**单 chán**（单于）、**遁 dùn**、**骑 jì**（轻骑，旧读，按教材）、将 jiāng（欲将，将要）。
- 名句理解："欲将轻骑逐，大雪满弓刀"——追敌之势引而未发，大雪已落满弓刀：以雪夜苦寒衬将士豪壮肃杀，"欲逐"比"逐"更有张力。
- 小测 5 题：接龙 ×2、读音（单于 chán yú）×1、词义（单于=匈奴首领）×1、名句主旨 ×1；评语按本诗定制（"月黑雪满，壮心如铁"）。
- 适合课堂大屏：自动游览 + 自动朗读约 1 分半走完封面 → 三境 → 终章全诗。
