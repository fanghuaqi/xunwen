# 菩萨蛮·人人尽说江南好 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《菩萨蛮·人人尽说江南好》（五代·韦庄）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**烟雨江南**赛道——黛蓝湿雾色板、斜风细雨母题；「春水碧于天」的碧染透整片春水，是全页唯一的彩色点；末境雾色光温转沉，暗合"景愈美、情愈断"的反转结构。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"点击画船听雨"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：雨落春水，画船轻摇愈显（雨声渐密 + 船影浮沉摆幅渐大 + 五声琶音 +「画船听雨」题字）
- 末章：全词回放、学习小测（5 题）

## 美术方案：烟雨江南（art-direction 赛道⑥）

| 项 | 取值 |
|---|---|
| 底色 | `#10141a`（黛蓝夜） |
| 主色 | `#9ab0c9`（accent/按钮/边框/进度点/题字，全部黛蓝调，**无一处金色**） |
| 文字 | `#e6ecef` |
| 雾 | `#141b23`～`#17222b`，fd 0.012–0.015（湿雾，末境最沉） |
| 月 | 隐月（境① ms 0.35 高淡；境② ms 0.55 悬于垆边人身后——人月相映），星稀 |
| 粒子母题 | 斜风细雨（NormalBlending 雨丝，末境点击后另有雨幕层）、水面雾 Sprite、微尘、柳丝（前景树枝风摆） |
| 唯一彩点 | 境①春水：水面着色器通染碧色（`#1d4f45` 系）+ 水天相接一带碧光着色器，轻透缓息——春水碧于天 |

**有意的设计**：全页严格黛蓝单色系，唯境①春水通染碧色——那是江南给游人的第一重挽留；境②夜泊垆边，碧色沉入夜水，月白人影与霜雪皓腕接住月光，末二句"未老莫还乡"随雾色转沉。前境越美，末境越断肠。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-XiaoxiaoNeural，语速 -16%，烟雨赛道温婉女声）：

- `00.mp3` 题名（诗题自动提取："菩萨蛮·人人尽说江南好"）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字处理（`tts.json`，sub 非空即完全接管）：「还乡」之「还」读 huán（回归故里），替换表 `还乡→环乡`（覆盖"未老莫还乡，还乡须断肠"两处）；「垆边」之「垆」读 lú（垒土为台的酒垆），替换表 `垆边→炉边`——均同音同调钉音。「合」（hé，应当）、「似」（sì）、「皓」（hào）、「凝」（níng）经核为默认读音，未钉。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"人人都说江南好，江南到底好在哪？"再入境①，对照画面找三个"好"的证据：水碧、船眠、雨声。
2. **境①炼字**：抓住"合""碧""眠"三个字——"只合"是何口气（应当、近乎任性）？"碧于天"与"听雨眠"一动一静，写尽江南的安闲。
3. **境②用典**：看酒垆、酒瓮与月白人影，讲"垆"与卓文君当垆之典；"皓腕凝霜雪"如何以一腕写整个人。
4. **境②反转**：点击画船听雨后读末二句，讨论"江南这么好，为什么'莫还乡'？"——引出中原离乱的背景，体会以乐景写哀情：景愈美，还乡之念愈断肠。
5. **收束**：末章全词连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
7. 可补背景：此词为韦庄《菩萨蛮》组词之一，晚年寓蜀追忆江南旧游之作；"人人尽说"是他人语，"未老莫还乡"才是自家痛语。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 两境），境名逐一对齐（春水画船 / 垆边月寒）；分境与 queue.json 逐字一致（上片一境、下片一境）。
- 交互境序号 `curIdx===2`（pointerdown + 空格双接线；空格首次触发交互、交互后再按才进终章，`clicked` 标志 + 1.2s 冷却门控）。
- 三层构图逐境齐备：`makeRange` 山脊背景 + `makeForeground` 前景框景（坡石/芦苇/树枝柳丝）+ 中景主体（`makeFigure` 游人/垆边人、`makeHuachuan` 画船、`makeLu` 酒垆、`makeCrowd` 归乡行人）；每帧写 opacity/intensity 均乘 fadeK，会每帧写的材质初值=最大值；碧光带着色器显式传 vertexShader/fragmentShader。
