# 无衣 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《无衣》（先秦·诗经·秦风）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**大漠金戈**赛道——但刻意避开既有边塞页的构图（不做密林夜射白羽、不做雪原闻笛戍楼、不做行军出关、不做战阵残垣），写的是这首千古第一「军歌」的**战前誓师**：拂晓大漠营盘，王旗初展，军士并肩整甲列阵，主将振臂誓师，戈矛成架——无战斗、无残垣，只有整肃与慷慨。accent=#b8905a（queue 分配强调色）只落在 UI/人物边缘光/兵刃寒光/旗面光边/炉火光晕上；玄色王旗的 accent 光边为本诗独有的旗面处理。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境③为"共修甲兵·戈矛同举"，交互过后再按进终章）

- 境③轻点画面：鼓声三通，长兵自握点逐支举起成林，兵刃寒光次第点亮，火星腾起——"修我甲兵 与子偕行"题字同现，可反复点击（收而复举，再誓一回）
- 末章：全诗回放、学习小测（5 题）

**有意的设计**：三章重章叠句 = 三境变奏，三个维度同时在变——①时间递进：拂晓誓师（晨光低照、残火未熄）→ 日暮修备（暮色四合、锻炉大起）→ 夜火出征（星火满空、列火通明），晨→暮→夜的光线曲线把"王于兴师"的紧迫感层层推高；②兵器递修：架上与手中之兵同步换装——戈矛（戈横刃+矛直刺）→ 矛戟（戈矛合一）→ 甲兵（甲架入列）；③誓言递进：同仇（心齐）→ 偕作（行动齐）→ 偕行（并肩开拔）。末境点击"戈矛林立同举"即全诗"偕行"二字的具象化——一令之下，万兵齐举。

## 教学建议

1. **导入**：先让学生通读三章找不同——只换了哪几个字？（袍/泽/裳，戈矛/矛戟/甲兵，同仇/偕作/偕行）换字之外，什么没变？——那份闻战则喜、同赴国难的慷慨没变。这就是重章叠句，而且是递进式的重章。
2. **境①诗眼**：让学生在画面里找"王旗"与"主将"——旗初展、人列队。追问：「岂曰无衣」是真没有衣吗？——是不甘示弱的反问：衣可以同穿，难可以同当。「袍泽之谊」这个成语就从这两句来。
3. **境②看点**：锻炉火起、矛戟换装——让学生注意兵器架和手中的兵都换了：从戈矛到矛戟，武备愈修愈精；「泽」是贴身汗衣，比「袍」更贴身一层——同穿之谊更近一层。
4. **境③点击后**：让学生替秦人"誓师"一次——鼓声三通，戈矛齐举。追问：从「同仇」（心齐）到「偕作」（行动齐）到「偕行」（并肩开拔），递进的是什么？——是行动，是把誓言一步步变成出征。
5. **主旨**：《无衣》是《诗经·秦风》的战歌、最早的军歌之一：慷慨从军、同仇敌忾的背后，是秦地「与子同袍」的互助风尚。可联系后世的"袍泽"一词，理解战友之谊的文化源头。
6. **诵读**：全诗四言，二二节拍（岂曰/无衣，与子/同袍），三章一气贯注、语速渐急，末句「与子同仇／偕作／偕行」宜重读收束——读出战鼓三通的层层推进。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示；末境留 3 秒给学生自己点击誓师。
