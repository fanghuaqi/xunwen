# 浣溪沙·一曲新词酒一杯 · 夜宴金彩·闲雅暮宴（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《浣溪沙·一曲新词酒一杯》（宋·晏殊）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**夜宴金彩·闲雅暮宴变体**赛道——底色沿用夜宴基线 `#05070d`，但把"豪饮之金"换成"暮色之金"：落日熔金、灯烛初上、金樽淡酒、香径落花，是一座暮色里的池畔亭台与一座小园，不是一场喧宴。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"燕子掠过香径，落花飘零"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：归燕自右侧檐下入画、贴着香径低掠而过，两树落花应声飘零更急（五声琶音 +「似曾相识燕归来」题字）
- 末章：全词回放、学习小测（5 题）

## 美术方案：夜宴金彩·闲雅暮宴（art-direction 赛道①变体）

| 项 | 取值 |
|---|---|
| 底色 | `#05070d`（夜宴基线，style-audit 硬校验） |
| 主金 | `#e0b060`（queue 分配强调色；按钮/边框/进度点/题字/灯檠/金樽全跟此色） |
| 文字 | `#e8dcc0` |
| 雾 | 境①暖褐 `#1a110a` fd 0.0068，境②暮紫 `#141019` fd 0.0075（室内感） |
| 月 | 全程隐月（ms 0.001、月沉地下）——本篇的主角是**落日**：临边昏暗日轮 + 双层暖辉，境①内以 0.16/秒徐徐下沉，即「夕阳西下几时回」的时间性元素 |
| 粒子母题 | 落花缓落（NormalBlending 粉白衣钵，非流萤）、金尘浮粒、香篆一缕——不用流萤/酒光老三样 |
| 暖源 | 落日熔金（水面拉出金色粼光）、亭角立灯檠二 + 案上双烛、暮色初灯一盏——全页只有「暮金」一种色温，通篇禁艳红 |

**有意的设计**：与宴饮金的"三百金杯"区别开——本篇的金全部长在"暮"上：境①落日徐沉、水面金鳞、灯烛初上（宴席的信息量齐全：案有厚度、盘飧二、金樽陶壶金杯七器、灯檠双烛四盏、人物四位）；境②转暮紫，落花与归燕**同框对切**——花自树冠及地缓落、燕绕园而飞，点击才让归燕低掠香径，是全页唯一的爆发性瞬间。

- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字处理（`tts.json`）：逐字核对「曲」（yī **qǔ**，一曲新词）、「几」（jǐ，几时回）、「似」（**sì**，似曾相识）、「徊」（pái **huái**）——皆为常用搭配下的默认正确读音，与页面拼音一致，无需钉写替换；页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"天气依旧、亭台依旧，词人为什么还要问'几时回'？"再入境①。
2. **境①炼字**：抓「新」与「旧」的对仗——新词一曲、淡酒一杯，是闲适；而落日在画面里徐徐下沉，让学生看着太阳问出「几时回」，理解"以景语作结"的怅惘。
3. **境②名句**：花落去（消逝、无可奈何）与燕归来（重来、似曾相识）**同框对切**——一去一来、一挽一认，讨论这千古名对里的时光哲思；点击画面强化这个瞬间。
4. **结句收束**：「小园香径独徘徊」——诗人背影在落花与归燕之间独自踱步，让学生体会"淡语中的深情"与「独」字的分量。
5. **结课**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、名句赏析 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
7. 可补背景：晏殊被称为"北宋倚声家初祖"，此词是其闲雅词风的代表；「无可奈何」一联曾被誉为"天然奇偶"。
