# 醉花阴·薄雾浓云愁永昼 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《醉花阴》（宋·李清照）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**宣纸留白**赛道——浅色宣纸底、淡墨云山、大量留白；东篱黄菊以浅赭黄淡彩点染，是全页唯一的暖彩。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在末境为"帘卷西风"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 末境轻点画面：西风卷帘，帘自下而上卷起，帘内人影与东篱瘦菊同框对瘦，菊瓣纷飞、"人比黄花瘦"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：宣纸留白（art-direction 赛道③）

| 项 | 取值 |
|---|---|
| 底色 | `#e9e2d0`（宣纸） |
| 强调色 | `#50484a`（墨紫灰，取自 queue 分配 accent；按钮/边框/进度点/题字，无金色辉光） |
| 主墨 | `#23272e`（诗句文字）/ 山用浓墨剪影 `#2c2f33` |
| 雾 | `#e6dfcc`，fd 0.0045–0.0070 |
| 天空 | 穹顶 top `#e9e2d0` / hor `#ded5bd`；星稀（0.03–0.05） |
| 日 / 月 | 永昼用一轮淡日（场景内淡色日轮，日光淡弱）；半夜月色清冷（mph 0.14）；黄昏暮色稍暖（dirC `#d9ccb0`） |
| 粒子母题 | 淡墨浓云横流、瑞脑香烟一缕、贴地凉雾、暗香菊瓣（替代夜宴赛道的金色流萤/火星） |

**有意的设计**：全页唯一的暖彩是**浅赭黄淡彩的菊**（花瓣 `#cabb82` 系低饱和淡彩，非金）——宣纸的冷灰白上，唯有东篱这一点秋色；末境西风卷帘后，帘内墨色人影与篱边黄菊同框对瘦，"菊瘦人更瘦"一眼可读。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -18%，与页面注音口径一致）：

- `00.mp3` 标题（醉花阴·薄雾浓云愁永昼）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全诗连读

多音字以页面拼音为准（薄 bó / 销 xiāo / 厨 chú / 重阳 chóng / 帘卷 juǎn），`tts.json` 内置同音同调替换表（薄雾→勃雾、帘卷→帘捲）只影响音频读音、不改页面文字。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：重阳佳节为什么会"愁"？先看封面设问，再入境一，对照"薄雾浓云"看淡日如何被浓云吞没。
2. **境一时间线**：让学生找出画面里"白天"与"半夜"两半——永昼愁长、半夜凉透，体会"愁"如何从早熬到晚；结合注释讲瑞脑香、金兽炉、重阳独守。
3. **境二名句**：先看纱帘后隐约人影，再点击"卷帘"，让帘内人影与篱边黄菊同框——讨论"人比黄花瘦"妙在以形写神；可补《琅嬛记》赵明诚闭门三日夜、陆德夫唯称三句的本事。
4. **收束**：末章全诗连读一遍，再做 5 题小测（接龙 ×2、词义 ×1、典故 ×1、主旨 ×1）。
5. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；诗文与 `queue.json` 逐字一致。
- 交互境序号 `curIdx===2`（末境），点击带 1.2s 冷却与 `clicked` 标志；空格首按触发交互、再按进终章；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- fadeK 铁律合规：淡日/香烟等逐帧写 opacity 必乘 fadeK、初值=最大值；菊瓣爆发用 ShaderMaterial 显式 `uFade` 双 shader；单境 draw call 代理 ≤44、三角面 ≤1.2 万。
- 校验：`validate.js` → **✓ 校验全部通过**；`smoke.test.js` → **SMOKE PASS**（真 THREE r128 全生命周期：boot、逐境 build/update×400 帧、末境点击门控、自动游览至终章、小测满分、fadeK 合规、三层构图）；`accept.js` → **ACCEPT（2境 · 宣纸留白）**；实拍抽检封面/两境/末境点击态，浅色页面里菊与人影对瘦构图可读。
