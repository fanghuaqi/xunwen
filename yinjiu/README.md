# 循文入境 · 饮酒·其五（魏晋 · 陶渊明）

单文件沉浸式诗词课件：四境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 宣纸留白·菊隐变体：人境结庐的静，采菊东篱的遇，飞鸟相与还的归，欲辨忘言的悟——全集最"淡"的一页。
> 标志性瞬间：采菊东篱下，悠然见南山——不经意间山入眼帘。

## 教学建议

- 「心远地自偏」是全诗之眼：不在于住在哪，而在于心在哪
- 「悠然见南山」的「见」：教材读 jiàn；不经意的遇见，苏东坡说"境与意会"
- 「飞鸟相与还」与「欲辨已忘言」：万物有所归，真意不可言传——陶诗"言有尽而意无穷"
- 注音考点：结庐 jié、车马喧 xuān、何能尔 ěr、采菊 jú、东篱 lí、悠然 yōu、山气 qì、日夕 xī、相与还 huán、欲辨 biàn
- 比较阅读：与《归园田居·其三》同读，体会陶渊明的两种田园笔法
