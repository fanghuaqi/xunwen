## 四境导览（宣纸留白 · 野火春风变体）

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 原上草 | 离离原上草，一岁一枯荣。 | 枯黄波浪周期性扫过绿原，草籽浮游 |
| 贰 · 野火春风 | 野火烧不尽，春风吹又生。 | **标志瞬间**：火烧线席卷（草成灰烬），青色春风掠过，新绿沿同方向蔓延复生 |
| 叁 · 古道晴翠 | 远芳侵古道，晴翠接荒城。 | 芳草漫过古道，翠色遥接荒城剪影 |
| 肆 · 萋萋别情 | 又送王孙去，萋萋满别情。 | 古道送别，行者渐远；**点击画面/按空格**重演"火→风→复绿"完整轮回并题字"春风吹又生" |

## 操作

- `← →` 或空格逐境游览；空格在第四境触发互动
- 自动游览 / 自动朗读 / 注音开关在底部控制条
- 朗读优先级：Edge 神经语音现场朗诵 → 内置 MP3 → 系统语音

## 教学

- 逐字注音（多音字已核：荣 róng、侵 qīn、萋 qī；一/不 变调按教材）
- 每境含释义 + 注释（含"王孙"化用《楚辞》典故）
- 终章附 5 题小测（接龙×2、读音、典故、主旨）
- 适用：课堂大屏无人值守展示 / 学生自主浏览
