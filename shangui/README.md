# 循文入境 · 山鬼（屈原）

单文件沉浸式诗词课件：边读《山鬼》，边走进屈原笔下那位"被薜荔兮带女萝"的山中女神的世界。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地），无需安装任何东西。

## 操作

- **入境**：封面点「入 境」；`← →` 键或空格逐境游览；
- **自动游览**：默认开启（右上按钮可关），无人值守走完全程；
- **交互**：第 3 境点击画面（或按空格）——赤豹、文狸自云海现身，辛夷车上桂旗招展；第 7 境点击画面唤雷雨（雷声 + 电闪 + 题字「思公子兮徒离忧」）；空格先触发交互、再按才进终章；
- **朗读**：自动朗读默认开启（Edge 神经语音 Yunxi 现场朗诵，离线时回退本地 `audio/*.mp3`）；可点「朗读此句」重听；
- **注音**：逐字拼音默认显示，可一键关闭；
- **小测**：终章「学习小测」，5 题（接龙 ×2、读音 ×1、典故 ×1、名句理解 ×1）。

## 教学建议

1. **先看后读**：每境先让学生看画面猜诗句意境，再展开竖排诗句逐字正音；
2. **多音字考点**：山之阿 ē、被（通"披"）pī、含睇 dì、遗（赠）wèi、憺 dàn、岁既晏 yàn、孰华予 huá、蔓 màn、荫（动）yìn、狖 yòu——注释里已逐条标注；
3. **香草美人**：第 1/2/5 境对照看——薜荔、女萝、石兰、杜衡、杜若、三秀，全是比兴：以香草装束喻高洁，以采秀遗人所思喻痴情守望；
4. **人神恋的结构**：盛装赴约（1-2）→ 登高候人（3-4）→ 采秀忘归（5）→ 信疑交加（6）→ 怨慕离忧（7），可与《湘夫人》对读（"眺悱"结构互为姊妹篇）；
5. **屈原与《九歌》**：《山鬼》出自《九歌》，据楚地祭神乐歌改写，借山中女神之口写人神遇合的怅惘——也是屈原"信而见疑、忠而被谤"的投影。
