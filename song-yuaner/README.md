# 循文入境 · 送元二使安西（唐 · 王维）

Three.js 沉浸式诗词课件（单文件网页，生产队列 21/72 · 烟雨江南赛道 · 渭城客舍变体）。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；朗读音频已内置在 `audio/`，无网时自动回退浏览器语音）。

## 三重意境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 朝雨浥尘 | 渭城朝雨浥轻尘 | 晨雨初歇的渭城：湿亮街面、细雨渐歇、城垣客舍剪影 |
| 贰 · 客舍柳新 | 客舍青青柳色新 | 青瓦客舍暖窗、垂丝新柳摇曳、柳梢滴露、向西土路 |
| 叁 · 酒尽阳关 | 劝君更尽一杯酒，西出阳关无故人 | 双盏饯别 + 戈壁残墩 + 西沉日色长路（**点击画面 / 空格：更尽一杯酒**，双盏相碰、酒光泛起、题字「西出阳关无故人」） |

## 操作

- `← →` / 空格：切境；点击进度点跳境；「自动游览」默认开，可课堂无人值守展示。
- 第三境可点击画面触发互动（每 2 秒可重复）。
- 控制条：朗读此句 / 自动朗读 / 注音开关 / 声音开关 / 全屏。

## 文件结构

```
song-yuaner/
├── index.html        # 单文件网页（POEM 3 境 + 封面）
├── audio/            # 00 标题、01-03 各境、04 全诗（共 5 个 MP3）
├── gen-voice.sy.js   # 配音脚本副本（本诗多音字表见下）
└── smoke.test.js     # 深度冒烟测试（node smoke.test.js 自跑）
```

## 配音生成

```bash
node gen-voice.sy.js index.html "送元二使安西" "唐，王维"
```

`gen-voice.sy.js` 在共享脚本基础上加了本诗多音字替换表（只影响音频读音，不改页面文字）：
`朝雨→招雨`（朝 zhāo）、`浥→意`（浥 yì）、`更尽→更进`（尽 jìn）。
配置 `TTS_AZURE_KEY` 环境变量可升级为 Azure 神经语音「诗朗诵」音色。

## 教学建议

- 多音字：**浥 yì**（沾湿）、**舍 shè**（客舍）、**尽 jìn**（喝完）、**朝 zhāo**（早晨）。
- 典故：折柳送别（"柳"谐"留"）；阳关为出西域必经关隘，王维以一杯酒写尽惜别。
- 名句「劝君更尽一杯酒，西出阳关无故人」对比体会：前句劝酒之暖 vs 后句西出之荒凉。
