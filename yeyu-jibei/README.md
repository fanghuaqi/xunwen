# 循文入境 · 夜雨寄北（李商隐）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，音频本地）。

## 页面结构

- **三境推进**（随诗句逐境入境）
  1. 巴山夜雨 —— 冷蓝雨夜，秋池水位随雨缓缓上涨，孤雁掠过
  2. 共剪西窗 —— 想象中的重逢：暖黄烛光下两人并肩夜话
  3. 却话夜雨 —— 标志瞬间：冷（今夜巴山雨）与暖（来日西窗烛）两个时空缓慢对切；**点击画面 / 空格键 = 共剪西窗烛**（烛花剪落、烛光更亮、暖色锁定，题字浮现）
- 逐字注音、释义、注释、AI 朗读、自动游览、结课五题小测
- 全程自动朗读 + 自动游览默认开启，可作课堂大屏无人值守展示

## 操作

`入境` 进入；`← →` 或空格逐境；第三境点画面剪烛；底部可切换自动游览 / 自动朗读 / 注音 / 声音 / 全屏。

## 朗读与音频

- `audio/00-04.mp3`：00 标题、01–03 各句、04 全诗（百度 TTS 生成）。
- 断网或音频缺失时自动回退浏览器语音（Edge 下用"在线自然语音"逐句朗诵，近似真人）。
- 多音字：页面注音**涨 zhǎng**（水位升高）、剪 jiǎn，已按教材定音。

## 教学建议

- 先整体听 04 全诗一遍，再逐境进入，请学生用画面反推诗意（"池水为什么在涨？""窗外为什么在下雨？"）。
- 重点讲"时空对写"：身在巴山雨夜（现在·冷），心驰西窗剪烛（未来·暖），末境交互即此主旨的具象化。
- 小测 5 题覆盖接句、读音（涨）、词义（何当）、名句理解与主旨。
