# 终南望余雪 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《终南望余雪》（唐·祖咏）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**宣纸留白**赛道——浅纸为天、浓墨作山、大量留白，accent=#4a5060（青灰雪影）全页近零饱和，讲的是一场雪从「浮在云端」到「寒到身上」的过程。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"看暮色四合"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：林表霁色渐冷、青灰暮流横城、暮雪又起、城中灯火初上，"林表明霁色 城中增暮寒"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：宣纸留白（art-direction 赛道③）

| 项 | 取值 |
|---|---|
| 底色 | `#e9e2d0`(宣纸) |
| 主色 | `#4a5060`（青灰雪影，queue 分配强调色；按钮/边框/进度点/题字/暮流/人物袍色，**无一处金色**） |
| 文字 | `#23272e`（浓墨） |
| 雾 | `#e6dfcc`，fd 0.0046–0.0066 |
| 月 | 无（ms 0.001 且移出视野）；左上角一轮**淡日**（雪后初晴的纸色日轮） |
| 山 | 浓墨雪山（自写雪线着色器：雪冠停在山肩、参差雪线，雪线以下青灰雪影渐入浓墨）+ 淡墨远山 |
| 粒子母题 | 疏疏落雪（NormalBlending，浅底不用 additive）、山腰横云海、青灰暮流（`#4a5060`——暮色正是这个颜色） |
| UI | 面板 `rgba(255,252,240,.72)`，金色辉光阴影全部去除 |

**有意的设计**：全页几乎零饱和——雪不著「白漆」，而以纸色留白为雪、以青灰 `#4a5060` 作雪影与暮色；末境点击前，画面里最大的光是左上的淡日（霁色），点击之后日光转冷、暮流漫城、灯火初上——「城中增暮寒」的寒，是从光里退出来的。

## 教学建议

1. **导入**：先讲本事——这是祖咏在科举考场上写的应试诗，按规定该写十二句，他只写四句就交卷，主考官问为什么，答「意尽」。让学生带着"四句凭什么交卷"的问题入境。
2. **境①诗眼**：「浮」字是千古诗眼——结合画面看云海横腰、雪冠悬浮，讨论雪明明长在山顶，为什么说它"浮"（雪与云相接、山基被云遮住，看到的只有云上一段雪）。
3. **境①立足点**：「阴岭」暗写"望"的方向——人在长安城中北望，见的是山的北面；顺带讲"山北水南为阴"。
4. **境②点击后**：看霁色渐冷、暮色四合、灯火初上，讨论「增」字——寒不是一直都在，是暮色一合才"增"出来的；由视觉（霁色）转体感（暮寒），是后一联的笔法。
5. **背景**：祖咏，洛阳人，盛唐诗人，与王维友善；「意尽则止」由此诗成为炼句佳话，可对照"画蛇添足"讨论"停在哪里最好"。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、写法主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 20 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
