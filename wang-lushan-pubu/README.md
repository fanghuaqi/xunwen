# 循文入境 · 望庐山瀑布（李白）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，朗读音频本地）。

## 四境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 香炉紫烟 | 日照香炉生紫烟 | 香炉峰顶紫烟柱缓升，晨光斜照 |
| 贰 · 瀑挂前川 | 遥看瀑布挂前川 | 远望白练悬于崖间，河川铺展 |
| 叁 · 飞流直下 | 飞流直下三千尺 | 崖间仰视，飞瀑轰然坠潭，水雾扑面 |
| 肆 · 银河九天 | 疑是银河落九天 | **标志性瞬间**：星河自九天倾泻、沿瀑布轨迹注入水帘；点击画面/按空格重演倾泻 |

## 使用

- `←` `→` / 空格：逐境游览；第四境点击画面引银河入瀑。
- 自动游览 + 自动朗读默认开启，可直接作课堂大屏无人值守展示；控制条可一键关闭。
- 每句含逐字注音（炉 lú、紫 zǐ、尺 chǐ、瀑 pù 等已核对）、释义、展开式注释。

## 音频

`audio/00–05.mp3`（00 标题、01–04 各句、05 全诗），由百度 TTS 生成；
页面在 Edge 下优先使用"在线自然语音"现场朗诵，音频播放失败自动回退浏览器语音。

## 教学

- 小测 5 道题：接龙 ×2、读音（瀑 pù）×1、词义（九天）×1、手法（夸张）×1。
- 情感曲线映射天色：晨光（日照）→ 白昼（遥看）→ 暮壑（飞流）→ 星夜（银河），由天空系统逐境插值。
- 美术赛道：青绿春晓·紫烟山岳变体（强调色 #8fb89a，底色 #0a1410）。

## 开发

- 结构校验：`node <技能目录>/scripts/validate.js index.html`
- 深度冒烟测试（THREE 桩跑全部 build/update/click/自动游览）：`node smoke.test.js`
