# 踏莎行·郴州旅舍 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《踏莎行·郴州旅舍》（宋·秦观）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**烟雨江南**赛道——浓雾是本页主角：黛蓝湿雾漫尽一切，楼台在雾里显而复失，淮海词最凄苦的绝唱被雾月迷蒙裹住。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"点击郴江"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：三道江流绕郴山加速增亮（流向叩问），杜鹃三啼，「为谁流下潇湘去？」题字浮现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：烟雨江南（art-direction 赛道⑥）

| 项 | 取值 |
|---|---|
| 底色 | `#10141a`（黛蓝湿夜） |
| 主色 | `#8f9fc0`（queue 分配强调色：按钮/边框/进度点/题字，**全页无金色**） |
| 文字 | `#e6ecef` |
| 雾 | `#151d26`，fd 0.016–0.020（浓雾是本页主角，仍守赛道上限与主体可读性平衡） |
| 月 | 隐为常；唯境①「月迷津渡」悬一团被雾裹住的低垂淡月（ms 0.5、mhaze 0.85） |
| 粒子母题 | 贴地雾流、大团雾阵、桃色微光（桃源望断）、芦苇摆动（替代金色流萤/火星） |

**有意的设计**：全页只允许一处藕荷 `#d8a7b1`——境①极远处一抹"桃源"桃色微光（永远不可抵达）与境②阶前梅萼；它是"望断无寻处"的那点甜，被浓雾隔在一切之外。

## 教学建议

1. **导入**：从"雾"入手——让学生先看封面浓雾，再读"雾失楼台"，找出画面里"失去轮廓"的东西。
2. **境①意境总纲**：等楼台"显而复失"的一个周期，体会开篇八字如何定下全词"一切景物都失去轮廓"的基调；结合注释讲"月迷津渡""望断"。
3. **境①声景**：杜鹃啼响时再读"杜鹃声里斜阳暮"，讨论杜鹃（子规"不如归去"）与迁客谪居的关系。
4. **境②典故**：看梅枝与素帛讲"驿寄梅花""鱼传尺素"两典，再看石砌层台体会"砌"字——问候为何反而砌高离恨。
5. **境②天问**：点击郴江后读"郴江幸自绕郴山，为谁流下潇湘去"，讨论问江即自问；可补充苏轼绝爱此句、书于扇面并叹"少游已矣，虽万人何赎"的背景。
6. **收束**：末章全词连读，再做 5 题小测（接龙 ×2、读音词义 ×1、本事典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 两境，与 queue.json stages 一致），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 交互境序号 `curIdx===2`；末境挂 `click` + `clicked` 标志 + 1.2s 冷却：首次点击触发交互，再次空格才进终章。
- 每帧写 opacity/intensity 均乘 fadeK；自定义着色器（水）登记 `fogShaders` 同步雾；逐境 draw call 代理 24–38（≤120）、三角面 ≤2.3 万（≤12 万）。
- 校验：`node _pipeline/tools/validate.js tasuoxing-chenzhou/index.html` → **✓ 校验全部通过**。
