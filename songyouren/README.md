# 循文入境 · 送友人（唐 · 李白）

单文件沉浸式诗词课件：四境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 水墨夜思·送别变体：从山水送别地，到孤蓬、浮云、落日，最后落在两匹马的嘶鸣里——不着一个"愁"字。
> 标志性瞬间：浮云游子意，落日故人情——天上浮云与西沉落日的情景互喻。

## 操作

- `← →` / 空格：切境（末境空格 = 触发交互，交互过后再按进终章）
- 自动游览、自动朗读默认开启，可一键关
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置 MP3 → 系统语音
- `audio/00–05.mp3`：题名、四境、全诗（云希·清朗男声，语速 −16%；`tts.json` 多音字替换只影响读音）

## 教学建议

- 对仗教学范本：首联「横/绕」动静相对，颈联「浮云/落日」情景互喻——律诗对仗的两种境界
- 「孤蓬」「班马」两个喻体：蓬是物随风波，马是兽解人情——物皆著"我"之别情
- 全诗无一「愁」字而别意盎然：让学生找一找"情"藏在哪里
- 注音考点：北郭 guō、绕 rào、一为别 wéi、孤蓬 péng、万里征 zhēng、游子 yóu zǐ、萧萧 xiāo xiāo、班马 bān
- 体裁：五言律诗；李白律诗作中的送别名篇
