# 循文入境 · 关雎 —— 沉浸式诗词网页

《诗经·周南·关雎》「循文入境」沉浸式单文件教学网页：诗句逐境推进，三维水泽实景随诗入境，含逐字注音、释义注释、AI 朗读、自动游览、结课小测。

## 使用

- **双击 `index.html` 即可打开**（Three.js r128 走 CDN 三路回退，首次打开需联网；音频为本地文件）。
- `←` `→` 键或空格逐境游览；鼠标移动有视差；控制条可开关自动游览 / 自动朗读 / 注音 / 声音 / 全屏。
- **第五境「钟鼓乐之」为交互境**：点击画面或按空格，编钟齐鸣 + 低鼓，水面涟漪扩散，题字闪烁。
- 右下角「学习小测」共 5 题（接龙 ×2、读音 ×1、词义 ×1、主旨 ×1）。

## 五境设计

| 境 | 诗句 | 情绪 | 场景 |
|---|---|---|---|
| 卷首 | （封面） | 静 | 水泽晨雾、浮荇微光 |
| 一 · 关关雎鸠 | 关关雎鸠，在河之洲。窈窕淑女，君子好逑。 | 悦（起兴） | **标志性瞬间**：河洲上一对雎鸠相向而立，胸前羽色分雌雄，交替伸颈和鸣（WebAudio 合成一降一升两声"关关"，鸣处水面生涟漪），远处水鸟剪影掠过 |
| 二 · 左右流之 | 参差荇菜，左右流之。窈窕淑女，寤寐求之。 | 慕（求） | 荇菜叶群散布水面随流左右漂摇；岸边君子剪影伫立凝望 |
| 三 · 辗转反侧 | 求之不得，寤寐思服。悠哉悠哉，辗转反侧。 | 思（本诗最暗最闷） | 重雾压暗、星月俱隐；河畔卧榻上人影长夜翻来覆去；灰绿雾流缓缓东去即"悠哉悠哉" |
| 四 · 琴瑟友之 | 参差荇菜，左右采之。窈窕淑女，琴瑟友之。 | 近 | 河洲上琴瑟并陈、弦光轻颤、音符升起；岸边人影俯身采荇，荇菜采后稀疏 |
| 五 · 钟鼓乐之 | 参差荇菜，左右芼之。窈窕淑女，钟鼓乐之。 | 乐（交互） | 编钟一架、大鼓一面、观礼人影；荇菜整齐聚拢（芼之待烹）。**点击/空格**：编钟三音+低鼓（WebAudio）、涟漪三叠、题字"钟鼓乐之"闪烁 |

情绪曲线（闻鸟之悦 → 求之之慕 → 辗转之思 → 琴瑟之近 → 钟鼓之乐）由每境天空/雾参数逐境插值实现：境三压至最暗最闷（雾密度 0.012、星月俱隐），末境转明快。

## 美术方案

风格赛道为 **青绿春晓 · 水泽变体**（art-direction.md 赛道④的水色版）：bg `#0c1714`、主色荇绿偏青 `#8fb89a`、辅天青 `#9fc4cf`、文字 `#e9f1ea`、雾 `#0f1d18`（fd 0.007–0.012）。母题是贯穿全诗的**水面（河洲）+ 雾中芦苇/荇菜剪影**；荇菜叶群在境二/四/五以三种状态复用（流→散布漂动、采→人影采撷后稀疏、芼→整齐聚拢）。全篇无晨光金、落花、啼鸟元素，与《春晓》一眼可辨。

## 朗读

配音已按本诗多音字表替换音频读音（不改页面文字）：

|---|---|---|
| 雎（雎鸠） | 居 jū | 雎鸠 jū jiū |
| 参差 | 岑疵 cén cī | 参差 cēn cī（防误读 cān） |
| 荇 | 杏 xìng | 荇菜 xìng cài |
| 好（好逑） | 郝 hǎo | 君子好逑 hǎo qiú |
| 寤（寤寐） | 悟 wù | 寤寐 wù mèi |

## 教学建议

- 课堂大屏无人值守：开启「自动游览 + 自动朗读」即可全程自动放映（约 100 秒）。
- 讲"起兴"手法：先看境一双鸟和鸣，再问学生"水鸟和鸣与君子思慕有何关系"。
- 讲"重章叠句"：对比境二/四/五的荇菜三态（流/采/芼）与诗句复沓。
- 讲使动用法：境五点击后钟鼓齐鸣，正是"钟鼓**乐**之（lè，使她快乐）"。
- 孔子评《关雎》"乐而不淫，哀而不伤"即终章题词，可作结课讨论。
