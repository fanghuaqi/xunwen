# 浣溪沙·游蕲水清泉寺 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《浣溪沙·游蕲水清泉寺》（宋·苏轼）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**青绿春晓·蕲水溪山**变体——山下兰芽浸溪的生机绿、松间沙路的雨后净、门前流水向西的旷达光。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"溪水反向西去"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：溪水反向西去（众水东流此溪独西）、溪面白发意象随水消散、西天渐亮，题字「门前流水尚能西」同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：青绿春晓·蕲水溪山（art-direction 赛道④变体）

| 项 | 取值 |
|---|---|
| 底色 | `#0a1410`（青绿深底） |

| 月 | 暮雨淡月（ms 0.6–0.7，低悬远处，不作主角） |

**有意的设计**：全页唯一的暖色是「西天微光」——境②溪水西流所向的一点暖金（点击后随西流之势渐亮）。它是"逆境中见希望"的色彩注脚；境①暮雨、松林、沙路全部压在青绿色域内，让这一点暖在末境才被读出来。全页最亮的生机色是溪畔**兰芽嫩绿**（`#9fce8f` 系新芽），与净白沙路一暗一亮，撑起「山下兰芽短浸溪，松间沙路净无泥」。

## 教学建议

1. **导入**：讲背景——苏轼 45 岁贬居黄州，大病初愈游清泉寺；然后入境①对照"山下兰芽短浸溪"看溪畔嫩芽。
2. **境①品味**：兰芽之"短"、沙路之"净"、暮雨子规之声，景清而语健；末句"谁道人生无再少？"先让学生带着问题进境②。
3. **境②点击**：先问"中国的河流向哪边流？"再点击画面看溪水**反向西去**——众水东流此溪独西，正是"门前流水尚能西"的词眼所在；白发消散对应"休将白发唱黄鸡"。
4. **典故**：结合注释讲黄鸡典出白居易《醉歌》"黄鸡催晓"，苏轼反用其意——不叹时光，反唱生命可以再来。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
