## 美术方案：烟雨江南 · 长江远眺变体（三月烟花柳绿）

按 `art-direction.md` 赛道⑥取值并作春昼变体，与同赛道《声声慢》（愁雨夜、梧桐）区隔：本页是**白昼春江**——

- 底色 `#10141a`、强调色 `--gold:#a8b8d8`（蓝银）、文字 `#e8eef0`、次要 `#93a6b4`
- 穹顶淡青蓝→暖白雾平线（top `#8fbdd8`–`#a9c9d4` / hor `#dde4d8`–`#e9e9d4`），雾色玉青 `#a9bdb5` 一线，fd 0.0045–0.0088 逐境呼吸（③最澄澈、④回苍茫）
- "月"改**春日暖阳**（②③④可见，①隐）；星近于无（0.03–0.06）；远山黛绿剪影吃雾
- 粒子母题：粉白落英＋柳絮飞花（自写 `makePetal` 着色器：自顶而落随风摆）替代金色流萤
- 情绪曲线：雾重晨别 → 花明春盛 → 碧空极目 → 江天苍茫，怅而不伤

## 教学建议

1. **朗读导入**：自动游览全程约 66 秒，先让学生说"看到了什么"（楼—花—帆—江）。
2. **逐境精读**：结合右侧释义/注释——"西辞"的方位、"烟花"的古今义（小测第 5 题）、"之广陵"的"之"。
3. **多音字考点**：长 cháng（长江）、辞 cí、唯 wéi（页面注音已逐字核对，小测第 2 题）。
4. **互动点睛**：讲到末句请学生点击江面"再送一程"，体会"目送—帆尽—唯余江流"的怅而不伤。
5. 结课"学习小测"（接龙 ×2、读音 ×1、文学常识 ×1、词义 ×1）当堂检测。
