# 登飞来峰 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《登飞来峰》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**大漠金戈**赛道，取「孤峰塔影」变体——赭褐天地间的飞来峰、峰顶七层宝塔、山腰翻涌的浮云，以及末境脚下云海尽头一跃而出的**旭日**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击最高层"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：近前塔檐沉下（身已升至塔顶）、浮云向两侧散开、日轮跃出云海放大，"不畏浮云遮望眼"题字同现
- 末章：全诗回放、学习小测（5 题）

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 `zh-CN-YunjianNeural`，语速 −14%，大漠怀古赛道音色）：

- `00.mp3` 标题（"登飞来峰"）
- `01.mp3` 境壹（飞来山上千寻塔，闻说鸡鸣见日升。）
- `02.mp3` 境贰（不畏浮云遮望眼，自缘身在最高层。）
- `03.mp3` 全篇连读

多音字处理见 `tts.json`：**本诗无多音字险**，故 `sub` 留空（脚本回落内置兜底表，本诗无一条命中，合成文本与页面文字逐字一致）：

- 逐句核过：飞来、千寻 xún、闻说、鸡鸣、见日升（见 jiàn）、不畏（不 bú，去声前变调）、浮云、遮望眼 zhē、自缘 yuán、最高层——无须钉任何替换

页面朗读优先级：Edge 在线自然语音现场逐句朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"为什么古人登高总要写诗？"再入境壹，先看塔有多高、人有多小。
2. **境壹析"千寻"**：寻是长度单位（八尺），千寻极言其高；"闻说"二字要注意——日出是听来的，所以下文必须自己登上去验证。
3. **境贰析哲理**：诗到第三句忽然由景入理："浮云"双关（山间云雾 / 蒙蔽君主的小人），"不畏"是态度，"自缘"是原因。让学生说说"身在最高层"和"站得高看得远"的关系。
4. **点击体会**：点击最高层看云散日升，再追问"如果把遮眼的浮云换成人，这首诗会变成什么？"
5. **知人论世**：王安石写此诗时约三十岁、初入仕途（一说任鄞县知县任满归乡途中），"最高层"是他后来推行新法的自信写照。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音义 ×1、典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 38 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（宝塔、石阶、塔檐、云海）都在 30–80 单位内，fd ≤ 0.0060；**日轮辉光只调 scale、不写 opacity**（首轮 smoke 抓到此处 fadeK 违规，已按铁律改成"只动 scale"）；云海与晨雾同样只动 scale/位置。
- 场景构件（冒烟实测）：卷首 9 mesh / 31 sprite、境壹 12 mesh / 33 sprite、境贰 8 mesh / 40 sprite；draw call 代理值 41 / 46 / 49（≤120），三角面 ≈0.63 / 0.67 / 0.30 万（≤12 万）。
