# 永遇乐·京口北固亭怀古 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《永遇乐·京口北固亭怀古》（宋·辛弃疾）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**大漠金戈**赛道——底色 `#120d08`、雾 `#1a120a` 系、accent `#c9a06a`（取自 queue，用于人物边缘光/旗纹/祠庙轮廓光），禁用艳金；暮色怀古、苍茫悲壮，斜阳—尘霭—战旗—烽烟—神鸦社鼓是全页意象链。稼轩怀古压卷、用典最密的一课：孙权、刘裕、刘义隆、佛狸、廉颇五典连环是教学骨架。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"点击画面"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②运镜：斜阳巷陌之外，铁骑碾尘而过（标志性瞬间——气吞万里如虎）
- 境④轻点画面：三座烽燧错次点燃、烽烟起落（四十三年前的烽火扬州路），「凭谁问——廉颇老矣，尚能饭否」题字悬空渐显，社鼓一记、余音沉沉
- 末章：全诗回放、学习小测（5 题）

`audio/` 内置 6 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunjianNeural，大漠金戈赛道自动选声，语速 -14%）：

- `01–04.mp3` 四片逐境朗读

多音字以诗目录 `tts.json` 同音同调替换（只影响读音，不改页面文字）：永遇乐→永遇悦（乐 yuè）、舞榭→舞谢（榭 xiè）、寄奴曾住→寄奴层住（曾 céng）、封狼居胥→封狼居须（胥 xū）、佛狸祠→毕狸祠（佛 bì）。处 chù、否 fǒu、陌 mò、颇 pō、矣 yǐ 经查为常规读音，未列替。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：辛弃疾写此词时 66 岁、知镇江府、正准备北伐——先问"登亭第一眼，他为什么先说『英雄无觅』？"（引出孙权典）。
2. **境①用典一**：孙仲谋—京口曾是吴都，孙权据江抗曹；「舞榭歌台」残迹对照「千古江山」，讲"江山长在、英雄难觅"。
3. **境②用典二**：寄奴（刘裕小名）—出身寒微、起于巷陌，两度北伐收复长安；"斜阳草树"之荒凉与"金戈铁马"之煊赫对读，体会以盛衬今。
4. **境③用典三+四**：元嘉草草（刘义隆北伐惨败，影射当权韩侂胄）+ 封狼居胥（霍去病筑坛祭天）——"草率"与"壮志"错位，才有"赢得仓皇北顾"的辛辣；再讲"四十三年"（1162 南归至 1205）与"烽火扬州路"（完颜亮南侵）的亲身记忆。
5. **境④用典五**：佛狸祠（拓跋焘行宫，佛读 bì）下"神鸦社鼓"——沦陷区百姓在异族君主祠下迎神赛会，太平是假象，最痛；结拍廉颇典（《史记》"一饭三遗矢"）——以老臣自比，「凭谁问」悬空收束。
6. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释（五典逐条讲清）、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 四境，对句成境），境名逐一对齐；词文与 queue.json 逐字一致。
- 交互境序号 `curIdx===4`（pointerdown + 空格双接线，先交互后进终章，含 1.2s 冷却）；进度点/按键/自动游览末境判断均以 `POEM.length=4` 对齐。
