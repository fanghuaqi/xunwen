# 循文入境 · 夜上受降城闻笛（唐 · 李益）

单文件沉浸式诗词课件：两境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 大漠金戈·霜月变体：沙似雪、月如霜的清寒月夜——全集最"冷"的一页，被一支芦管点着。
> 标志性瞬间：沙似雪——月下白沙如雪、城外月色如霜的空寂边塞全景。

## 教学建议

- 前两句「互文」手法：沙似雪、月如霜互文见义，写尽边塞月夜的清寒空寂
- 「不知何处」的妙处：笛声来路不明，乡愁无处不在
- 「一夜」「尽」：数字与范围的夸张，写乡愁的普遍与深重
- 注音考点：回乐烽 huí lè fēng、似雪 sì xuě、受降城 shòu xiáng、芦管 lú guǎn、征人 zhēng rén、尽 jìn
- 被推为「中唐三绝」之一：以景结情、含蓄不尽——可与「不知何处吹芦管」的「不知」细品
