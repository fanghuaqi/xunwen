# 武陵春·风住尘香花已尽 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《武陵春·风住尘香花已尽》（宋·李清照）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**水墨夜思**赛道——全套冷银水墨色板，写李清照晚年孀居之痛；「载不动许多愁」把愁写出重量，轻舟吃水渐沉是全页的标志性瞬间。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"泛舟载愁"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 末境（贰 · 舴艋载愁）轻点画面：轻舟吃水渐沉、愁雾压舟、愁绪化作满江雾，"载不动许多愁"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 / accent | `#93a8c4`（队列分配强调色；按钮/边框/进度点/题字/边缘光，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#121926` 系，fd 0.0050–0.0060 |
| 月 | 冷银白唯一主角：境①暮色弦月（ms 1.35、高雾霭），境②满月江天（ms 1.95） |
| 星 | 稀疏（亮度 0.20–0.34） |
| 粒子母题 | 最后的落瓣（竖长花瓣形自定义着色器）、尘香微尘、贴水愁雾（自定义"愁雾压舟"下压着色器） |

**有意的设计**：末境"闻说双溪春尚好"保留**一线冷青**（远岸 `#567a67` 雾洗）——它是全页唯一的绿色温，是"也拟泛轻舟"那一丝起意；点击"只恐"跌回后，这线春色被漫起的满江愁雾淹没（spring 光晕随点击渐灭）。除此处外全页冷银，情绪过山车：起意（吃水浅、水面清）→ 跌回（吃水深、愁雾满江）。

- `01–02.mp3` 两境逐境朗读

## 教学建议

1. **导入**：封面设问"愁有重量吗？"再入境①，看落花成尘，讲"物是人非"的背景（晚年孀居、避难金华）。
2. **境①细节**：让学生观察妆台铜镜与"倦梳头"，讨论"女为悦己者容"的反面——梳给谁看；"事事休"与"泪先流"的递进。
3. **境②先不点击**：先读"闻说双溪春尚好，也拟泛轻舟"，看远岸春意与高浮的轻舟——这是"一丝起意"。
4. **点击跌回**：再读"只恐""载不动许多愁"，点击看舟沉、雾起——讨论化虚为实：愁怎么会"载不动"？船越轻越小，愁越重。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1（舴艋 zé měng）、典故 ×1（金华双溪）、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
