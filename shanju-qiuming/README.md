# 山居秋暝 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《山居秋暝》（唐·王维）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**水墨夜思**赛道——全套冷银水墨色板，冷月是唯一主角；accent 取**青灰**（`#a8b8a0`，山色带青），全页无一金色。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"点击清泉"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：月光穿松成柱、泉石流光大亮——"王孙自可留"的缘由显形（五声箫韵余响 +「泉石流光」题字）
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②·青灰变体）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主色 | `#a8b8a0`（accent，按钮/边框/进度点/题字，青灰水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#11191a`～`#121a1b`，fd 0.0050–0.0060 |
| 月 | 冷银白（ms 1.7–2.0），全页唯一主角；星稀（亮度 0.4–0.45） |
| 粒子母题 | 月华微尘、泉上流光、谷间横雾（替代《将进酒》的金色流萤/火星） |
| 青灰层次 | 松冠 `#0d1511`、竹叶 `#101c14`、莲叶 `#17301f`、泉水 `#1a3230`、山岚大气 `#26332f`——同一青灰调的不同明度 |

**有意的设计**：全页严格冷银青灰，唯一点亮"暖"的手段是**亮度**而非色相——境②点击后月光光柱与泉石流光增亮，"山中何所有？明月与清泉"以光显形，正合"随意春芳歇，王孙自可留"的取舍。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -16%，水墨赛道清朗男声）：

- `00.mp3` 题名（诗题自动提取："山居秋暝"）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全诗连读

多音字处理（`tts.json`，sub 非空即完全接管）：「暝」读 míng（同「明」），钉 `山居秋暝→山居秋明`；「浣」读 huàn，钉 `浣女→换女`——均同音同调替换，只影响音频不改页面文字。歇（xiē）、空山之「空」（kōng）、石上流之「石」（shí）经核为默认读音，未钉。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：从诗题读起——"暝"是日暮，秋暝即秋日傍晚；先看封面夜色再入境①。
2. **境①绝唱对**："明月松间照，清泉石上流"上句写色写静、下句写声写动——先看光柱与泉石，再让学生闭眼听朗读，体会"动静相生"；结合注释讲"空山"之"空"是心境的空灵而非无人。
3. **境②以动衬静**：先闻竹喧、再见浣女，先见莲动、后知渔舟——声与人、动与静的先后正是诗人的观察顺序；让学生在画面里找"先闻其声"的证据。
4. **点击与主旨**：点击清泉后问"为什么王孙可留？"——月光与清泉亮起，正是"山中自有可留之物"；对照《楚辞·招隐士》"王孙兮归来，山中兮不可久留"，讲反用典故。
5. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音 ×1、典故 ×1、主旨 ×1）；可补苏轼"味摩诘之诗，诗中有画"一评。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 两境），境名逐一对齐（松月泉声 / 竹喧莲动）；分境拼接与 queue.json 文本逐字一致。
- 交互境序号 `curIdx===2`（pointerdown + 空格双接线；空格首次触发交互、交互后再按才进终章，`clicked` 标志 + 1.2s 冷却门控）。
- 三层构图逐境齐备：`makeRange` 山脊背景 + `makeForeground` 前景框景（坡石/芦苇）+ 中景主体（`makeFigure` 诗人/浣女/渔翁、`makeCrowd` 归途人影、`makeSkiff` 渔舟）；每帧写 opacity/intensity 均乘 fadeK，会每帧写的材质初值=最大值；月光光柱着色器（BEAM_VERT/BEAM_FRAG）显式传 vertexShader/fragmentShader。
- 校验：`node _pipeline/tools/validate.js shanju-qiuming/index.html` → **✓ 校验全部通过**。
- 冒烟：`node shanju-qiuming/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 三境 build/update ×400 帧 → 末境点击门控与 pointerdown → 自动游览至终章 → 键盘全路径 → 小测全流程；逐境 drawCall 代理 14/21/32，三角面 ≤2.7 万，fadeK 合规）。
