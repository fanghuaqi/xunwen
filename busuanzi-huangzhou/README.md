# 卜算子·黄州定慧院寓居作 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《卜算子·黄州定慧院寓居作》「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**宣纸留白**赛道——浅色宣纸底、浓墨疏桐剪影、一弯浅墨缺月、一点浓墨孤鸿，全页笔墨极简、大量留白。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"孤鸿掠枝"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：鸿影俯身掠过寒枝而不肯栖落，随后趋向沙洲寒月，钟声与"拣尽寒枝 不肯栖"题字同现
- 末章：全词回放、学习小测（5 题）

## 美术方案：宣纸留白（art-direction 赛道③）

| 项 | 取值 |
|---|---|
| 底色 | `#e9e2d0`（宣纸） |
| 强调色 | `#3e4a44`（墨青，queue 分配 accent——幽人衣冠、桐叶老绿、按钮/进度点全随之） |
| 文字 | `#23272e`（浓墨） |
| 雾 | `#e6dfcc`，fd 0.0045–0.0068 |
| 月 | 缺月一弯浅墨（mph 0.22 圆缺 + 灰纸调辉光），悬于桐梢上方 |
| 星 | 近无（star 0.03–0.05） |
| 粒子母题 | 淡墨浮尘、纸色雾霭、寒江夜气横流（替代《将进酒》的金色流萤/火星） |
| 浅色必改 | body/err 背景、--gold→墨青、.seg/#jing 暗底投影改 `0 1px 0 rgba(255,255,255,.45)`、封面长调题名缩字号收字距（12 字竖排一屏立得住） |

**有意的设计**：全页只保留三种"墨色"——疏桐是浓墨剪影、缺月是浅墨一弯、孤鸿是飞动的一点浓墨；幽人衣取墨青（accent），是纸面上唯一靠近人物的"活色"，与孤鸿互为镜像：人如鸿，鸿如人。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-YunxiNeural，语速 -18%）：

- `00.mp3` 标题（卜算子·黄州定慧院寓居作）
- `01–02.mp3` 两片逐境朗读
- `03.mp3` 全词连读

多音字以页面拼音为准，`tts.json` 同音同调接管 4 条：卜算子（卜 bǔ→补）、缥缈（piāo miǎo→飘渺）、省（xǐng→醒）、栖（qī→欺）。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：讲「乌台诗案」—苏轼险遭不测、贬居黄州寓居定慧院，再入境①看"缺月挂疏桐"的深夜庭院。
2. **境①词眼**：先让学生在画面里找孤鸿，对照"谁见幽人独往来，缥缈孤鸿影"，点出人与鸿互为镜像——人如鸿、鸿如人。
3. **境②读音**：「省」读 xǐng（知晓、体察），「栖」读 qī，「漏断」是漏壶水断、夜深之极；结合注释辨析。
4. **境②情感**：点击看"掠枝不肯落"，讨论孤鸿为什么拣尽寒枝也不肯栖——孤高自许、不肯附势趋俗，宁可寂寞沙洲。
5. **收束**：末章全词连读，再做 5 题小测（接龙 ×2、读音词义 ×1、黄州贬谪背景 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境，N=queue stages 数），境名逐一对齐；诗文逐字照抄 queue.json（谁见/寂寞沙洲冷从教材通行本）。
- 交互境序号 `curIdx===2`（末境），pointerdown 与空格双接线、clicked 标志 + 1.2s 冷却；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 每境 `makeRange`（淡墨远山）+ `makeForeground`（枯苇/坡石框景）+ `makeFigure`（幽人独立）；drawCall 代理 20–25（≤120），三角面 2.1k–22k（≤12 万）。
- 校验：`validate.js` → ✓ 全部通过；`smoke.test.js` → SMOKE PASS（boot 全流程、逐境 fadeK 合规、三层构图、末境点击门控、自动游览至终章、小测全流程，多次运行稳定）。
- 实拍：`shots.py` 封面 + 两境逐张人工检查（封面题名完整不裁切、末境沙渚墨色不刺目、主体可读）。
