# 桂枝香·金陵怀古 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《桂枝香·金陵怀古》（宋·王安石）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**大漠金戈·怀古变体**（同《山坡羊·潼关怀古》赛道先例）——暮秋金陵的全套暗赭底色，澄江白练是全页唯一亮色，残阳锈赭是唯一的低饱和暖源，禁用艳金。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"点击澄江似练"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境①俯瞰运镜：登临送目，长江如一匹白绢在暮秋天地里铺展（标志性瞬间）
- 境④轻点画面：江面展白绢，六朝残迹（城砖/断柱/残碑）自江心浮沉显形，拨弦余音相和，"六朝旧事随流水"题字同现
- 末章：全诗回放、学习小测（5 题）

| 唯一暖源 | 残阳锈赭（境②落日与霞光、境④歌馆一点暖窗） |

**有意的设计**：全页只允许两处"亮"——境①的白绢（千里澄江似练，词眼所在）与境②的残阳（锈赭而非金）；境④歌馆暖窗是收束时的一点人声余温。其余一切（翠峰、城垣、宫阙虚影、旗影）都压在灰沉的暗赭里，让学生第一眼读出"景如画、眼极冷"的王安石。

多音字以诗目录 `tts.json` 同音同调替换（只影响读音，不改页面文字）：去棹→去照（棹 zhào）、斜矗→斜触（矗 chù）、谩嗟→漫嗟（谩 màn，通"漫"）、遗曲→遗取（曲 qǔ）。簇 cù、似 sì、朝 cháo、衰 shuāi、嗟 jiē 经查无误读风险，未列替。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：先问"六朝金粉的金陵，词人看到的第一个画面是什么？"——不是繁华，是一匹白绢似的江。
2. **境①比喻**：「似练」「如簇」两个比喻一横一纵，先看画面再对字；练是白绢，簇是箭簇，一静一动。
3. **境②设色**：让学生数一数画面里有几种颜色（残阳、归帆、酒旗、彩舟、白鹭、星河），体会"画图难足"为何是总赞。
4. **境③典故**：讲"门外韩擒虎，楼头张丽华"（杜牧《台城曲》）——门内门外一步之隔就是亡国；对照"谩嗟"的"空叹"读出冷眼。
5. **境④收束**：点击展绢、残迹浮沉后再读末句，讨论"商女犹唱"与杜牧《泊秦淮》的互文——历史警钟敲在当下。
6. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
