# 蝶恋花·伫倚危楼风细细 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《蝶恋花·伫倚危楼风细细》（宋·柳永）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**烟雨江南**赛道——黛蓝湿雾 `#90a8c0` 主调（queue 分配强调色），暮景月隐星稀，「残照」以去饱和藕荷作天际微光，**全页禁金**；与《蝶恋花·槛菊愁烟兰泣露》（晏殊·治学第一境，水墨夜思）同族异貌：本页重心在「凭阑人」的身形与春愁天际——楼不必高、愁要看得见。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"衣带渐宽"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：凭阑人衣带松宽垂落、身形渐瘦，春愁自天际铺满、残照被愁云吞去——「衣带渐宽终不悔」题字与磬音琶响同现
- 末章：全词回放、学习小测（5 题）

## 美术方案：烟雨江南（art-direction 赛道⑥）

| 项 | 取值 |
|---|---|
| 底色 | `#10141a`（黛蓝夜暮） |
| 主黛蓝 | `#90a8c0`（accent/按钮/边框/进度点/题字，全页**无一处金色**） |
| 文字 | `#e6ecef` |
| 雾 | `#151c26`～`#161d27`，fd 0.013–0.014（黛蓝湿雾，远山化入「黯黯天际」） |
| 月 | 月隐（ms 0.001、移出视野），星极稀（0.04–0.06）——暮景，残照代月 |
| 残照 | 去饱和藕荷 `#a8848c` 软边横带（glowTex Sprite，additive 雾外着色），随暮色呼吸 |
| 粒子母题 | 细细风缕（低速横流）、草色烟光浮尘、贴地愁雾横带（替代金色流萤/火星） |

**有意的设计**：「黯黯生天际」做成一条压着地平线的暮霭暗带 + 贴地愁雾，随词境逐境加深；「残照里」的藕荷余晖在境②点击后被愁云**吞去大半**（亮度 −55%），而愁雾横带随之**铺满天际**——一消一长，正是「强乐无味」到「终不悔」的情绪曲线。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-XiaoxiaoNeural，语速 -16%，烟雨江南赛道温暖女声）：

- `00.mp3` 题名（诗题自动提取："蝶恋花·伫倚危楼风细细"）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字处理（`tts.json`，sub 非空即完全接管）：「强乐」之「强」读 qiǎng（勉强义，钉为 `强乐→抢乐` 同音同调）；「还无味」之「还」按页面拼音读 huán（仍、还是义，钉为 `还无味→环无味`）；「消得」之「得」读 dé（值得义，钉为 `消得人憔悴→消德人憔悴`）。其余自查：伫 zhù、倚 yǐ、黯 àn、谁 shuí（页面注音口径）、拟 nǐ、憔悴 qiáocuì 均为神经语音默认正确读音，未钉。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"一个人在楼上凭栏久站，他在看什么？"再入境①，对照"无言谁会凭阑意"——满腹心事无人可说的孤寂。
2. **境①意象**：危楼凭阑（久立倚栏）、风细细（春日微风反衬愁绪之绵长）、黯黯生天际（愁绪如暮霭从天边漫起，无形写得有形）、草色烟光残照里（三个意象叠加的苍茫暮景）。
3. **境②动作**：先看横倒的酒杯——"借酒消愁愁更愁"；再点击凭阑人，看衣带渐宽、身形渐瘦，体会"以身体写深情"的笔法。
4. **文学常识**：王国维《人间词话》以此词下片二句为"古今成大事业、大学问者的第二境"——执着追求、虽憔悴而不悔；可与姊妹篇《蝶恋花·槛菊愁烟兰泣露》（第一境·望尽天涯路）对照讲。
5. **收束**：末章全词连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、典故常识 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 两境，N=2 按 queue.json stages 口径），境名逐一对齐（伫倚危楼 / 衣带渐宽）；分境拼接与 queue.json 文本逐字一致。
- 交互境序号 `curIdx===2`（pointerdown + 空格双接线；空格首次触发交互、交互后再按才进终章，`clicked` 标志 + 1.2s 冷却门控）。
- 三层构图逐境齐备：`makeRange` 山脊背景 + `makeForeground` 前景框景（树枝/坡石/芦苇）+ 中景主体（危楼露台/凭阑人 `makeFigure`、案壶杯、`makeCrowd` 远行人影）；每帧写 opacity 均乘 fadeK 且初值=最大值；衣带为独立合批 mesh（腰带环带结 1 + 垂带 1），水面/地面/山脊走引擎雾同步。
