# 循文入境 · 滁州西涧（唐 · 韦应物）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，朗读音频本地）。

## 四境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 幽草涧边 | 独怜幽草涧边生 | 涧水潺潺，两岸幽草随风自青 |
| 贰 · 深树黄鹂 | 上有黄鹂深树鸣 | 浓荫如幄，黄鹂拍翅鸣唱，声纹一圈圈荡开 |
| 叁 · 春潮带雨 | 春潮带雨晚来急 | 暮色雨云压城，潮水一寸寸漫上来 |
| 肆 · 野渡横舟 | 野渡无人舟自横 | **标志性瞬间**：空渡无人，缆舟横在涨水中横摇（点击画面：雨更密、潮更涨、横舟摇晃更明显） |

美术方向：青绿春晓 · 幽涧变体（#8fc4a8 强调色）——清幽自适，末境带一点荒寒。

## 使用

- `← →` 键或空格逐境游览，第四境可点击画面（或按空格）唤"春潮急"
- 顶部小圆点可跳境；控制条可开关自动游览 / 自动朗读 / 注音 / 声音 / 全屏
- 朗读优先 Edge 神经语音现场朗诵，否则回退 `audio/00-05.mp3`（00 标题、01-04 各句、05 全诗）
- 首次打开需联网加载三维引擎

## 教学建议

- 注音已核多音字：涧 jiàn、鹂 lí、横 héng（"舟自横"不读 hèng）
- 小测 5 题覆盖：接龙 ×2、"横"读音、"怜"词义、名句意境理解
- 适用：课堂大屏自动游览展示 + 逐句跟读
