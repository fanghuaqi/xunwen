# 循文入境 · 夏日绝句（宋 · 李清照）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，首次需联网；音频已内置本地 MP3）。

## 内容

- 全诗：生当作人杰，死亦为鬼雄。至今思项羽，不肯过江东。
- 两重意境，随诗句推进：
  1. **人杰鬼雄** —— 乌江断岸，涛声如鼓；「人杰」金光冲天，「鬼雄」幽火沉江。
  2. **乌江夜渡**（标志性瞬间 + 互动）—— 一舟横在渡口而不渡：船头灯笼是全页唯一暖点，霸王持剑背影立于岸石，缆绳紧绷、船身微晃但始终不离岸。**点击画面 / 空格**：江风大作，衣袂猎猎、舟身摇晃更烈、缆绳绷响，题字「不肯过江东」。

## 功能

- 逐字注音（多音字已按教材标注：当 dàng、为 wéi、杰 jié、亦 yì）、释义、注释（含考点）
- AI 朗读（audio/00-03.mp3，百度 TTS 生成；`gen-voice.js` 内含本诗多音字替换表），Edge 下自动优先神经语音现场朗诵
- 自动游览 / 自动朗读开关、全屏、小测 5 题
- 键盘：← → 逐境，空格 下一境/交互，Esc 关闭弹层

## 教学建议

- 先整体自动游览一遍，再逐境提问：①「当作」的「当」为何读 dàng？②「不肯过江东」与项羽乌江自刎的典故关系？③李清照借古讽今的写作意图（南宋偏安）。
- 第二境可请学生上台点击，观察「舟不离岸」如何对应「不肯过」。
