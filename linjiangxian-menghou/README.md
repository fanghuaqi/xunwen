# 临江仙·梦后楼台高锁 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《临江仙·梦后楼台高锁》（宋·晏几道）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版为**水墨夜思**赛道——冷银水墨、冷月为唯一主角，全页无一处金色；微雨、双飞燕、落花是贯穿全页的动态三要素，月光串起两重回忆之境。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在末境为"微雨燕飞"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 末境轻点画面：双燕掠过独立人影、向月而去，落花在庭中渐积，"微雨燕飞"题字同现
- 末章：全词回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#a4b6cc`（本诗分配强调色；按钮/边框/进度点/题字全银蓝水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#131a26` 系，fd 0.0050–0.0065 |
| 月 | 冷银白（ms 1.7–2.1），唯一主角；末境"当时明月"最大最低 |
| 星 | 稀（0.22–0.38），微雨夜星色更淡 |
| 粒子母题 | 微雨丝、落花瓣、微尘、流散残云（替代金色流萤/火星） |

**有意的设计**：标志性瞬间"当时明月在"——旧月犹在、彩云已散，月旁只余几缕残云缓缓流散；案上琵琶弦面泛起一线相思冷光，与旧月同证"月在而云散"。月光位置与色调贯穿境②境③（回忆境），梦后楼台（境①）月更高更远，呼应梦与醒的距离。

## 教学建议

1. **导入**：封面设问"梦醒之后，最清楚的一件事是什么？"再入境①，体会"梦后—酒醒"的双重失落。
2. **境①炼字**：一个"锁"字锁住了什么？（楼台、庭院，也锁住了记忆）"帘幕低垂"为何不言人而言帘？
3. **境②名句**：对照画面讲"人独立"与"燕双飞"的对照——以乐景写哀；谭献评"千古不能有二"。讲"两重心字罗衣"的同心相许。
4. **境③升格**：点击看双燕掠影之后，讨论"当时明月在，曾照彩云归"——月未曾变、人已不在，为什么以月作结最深婉？
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
