# 相见欢·林花谢了春红 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《相见欢·林花谢了春红》（五代·李煜）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**青绿春晓**赛道的暮春风雨变体——全套青绿生机色板，春红（#c98f9f）是全页唯一的暖彩点，「风雨摧花」是只属于这首词的画面。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"风雨摧花"，交互后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：风雨骤起摧花——红瓣辞枝迸落，东流水涨齐岸、雾流东涌，"水长东"题字同现
- 末章：全词回放、学习小测（5 题）

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-XiaoxiaoNeural，语速 -16% 生成）：

- `00.mp3` 题名（自动提取："相见欢·林花谢了春红"）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字以页面注音为准，`tts.json` 钉写 4 条同音同调替换（仅影响读音）：朝（zhāo，"朝来寒雨"）、重（chóng，"几时重"）、长（cháng，"长恨""水长东"）。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：从"如果要你写春天逝去，你会写什么"引入，再对照上片看"谢了"与"太匆匆"如何叠出焦急。
2. **境①互文**：结合注释讲"朝来寒雨晚来风"是互文——朝朝暮暮都有风雨；看画面里雨与风轮替摧花，体会"太匆匆"的节拍。
3. **境②拟人**："胭脂泪"把花上雨珠写成美人和泪，花与人两相怜；讨论"几时重"一问无答的怅惘。
4. **主旨**：点击摧花后看"水长东"——水不理人愁、只管东流，人生长恨绵绵无尽；可介绍李煜亡国之后"以血书者"的词风背景。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故修辞 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
