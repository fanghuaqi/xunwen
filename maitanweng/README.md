# 循文入境 · 卖炭翁（唐 · 白居易）

单文件沉浸式诗词课件：五境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 宣纸留白·苦寒变体：《新乐府》讽喻诗代表作——全集叙事最长的一页，结尾一抹红是全篇唯一重色。
> 标志性瞬间：心忧炭贱愿天寒——衣单却盼天更冷的矛盾心理。

## 教学建议

- 「心忧炭贱愿天寒」：全诗最深刻的心理刻画——矛盾中见辛酸，让学生用自己的话解释这个矛盾
- 对比手法：卖炭翁的困窘 vs 宫使的「翩翩」；千余斤炭 vs 半匹红纱——数量与价值的悬殊就是掠夺
- 「宫市」背景：中唐宫廷派人白手拿货的弊政，此诗是「为民请命」的讽喻诗
- 注音考点：伐薪 fá xīn、鬓 bìn、何所营 yíng、衣裳 yī shang、炭贱 tàn jiàn、辗 niǎn、冰辙 zhé、泥中歇 ní、翩翩 piān piān、两骑 jì、口称敕 chì、叱牛 chì、驱将 jiāng、系 jì、充炭直 zhí（同"值"）
- 体裁：乐府叙事诗（新乐府）；白居易主张「文章合为时而著，歌诗合为事而作」
