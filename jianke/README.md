# 剑客 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《剑客》（唐·贾岛）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**大漠金戈**赛道——但刻意避开战阵/夜射/行军/听笛/白骨的既有边塞构图，写的是一柄剑的**蓄势与亮剑**：境壹=蓄（寒夜剑庐，十年磨剑，霜刃深藏未试），境贰=发（捧剑示君，一朝亮刃）。accent=#c9824a（暗赭鎏金）只落在人物边缘光/剑柄缠丝/剑匣铜箍/窗纸暖光/UI 上，禁艳金；**全页唯一冷色源是「霜刃」**——钢青 0x8a9aaa～0xd8e2ea 只属于剑，暖夜与冷刃对撞出侠气。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"剑出鞘"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：剑匣沿剑身缓缓滑落，霜刃寸寸出鞘，寒光乍现、剑鸣与风声骤起，"今日把示君 谁为不平事"题字同现
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：先讲「推敲」——贾岛骑驴撞韩愈仪仗，为「僧敲月下门」用推用敲斟酌半日；这样一个字抠半天的「苦吟诗人」，写起剑来却是二十年功力一瞬出鞘的快意，两副面孔对读。
2. **境①诗眼**：「十年」与「未曾试」——磨的是剑，也是人；利器已成而锋芒未试，正是「怀才未遇」的先抑。让学生留意画面里剑始终微光内敛、不曾出鞘。
3. **境②点击后**：匣落刃出、寒光乍现的一秒，就是「今日」二字——十年与一朝的对比全在这一击里；讨论「谁为不平事」的自问自答（为，读 wèi，替）：不是炫技，是请战——谁有不平，我替天下出这一剑。
4. **写法**：托物言志——句句写剑（磨剑=苦修、霜刃=才具、示君=求识用），句句写人；可对照「宝剑锋从磨砺出」与「冯谖弹铗而歌」体会寒士以剑自喻的传统。
5. **背景**：贾岛早年为僧、屡试不第；此诗约作于困顿之时，「把示君」从通行本（语料一本作「把似君」），「谁为不平事」一本作「谁有不平事」，意思相承。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、文学常识 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 20 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 交互境序号 `curIdx===2`（pointerdown 与空格双接线，`clicked` 标志 + 1.2s 冷却防连点；空格先交互、再按进终章）。
- fadeK 铁律：所有每帧写 opacity/intensity 的对象（出鞘光带/闪光/冷光/窗光/宿雾）初值=最大且逐帧乘 fadeK；点击前剑身与光带 `visible=false` 硬关（无幻影残影），剑身/剑匣 renderOrder 分层防透底；山脊/地面自定义着色器走引擎 `fogShaders` 雾同步。
- 预算：三境 drawCall 代理 ≈ 19/26/26、三角面 ≈ 0.20/0.59/0.54 万（≤120 / ≤12 万）。
- 校验：`node _pipeline/tools/validate.js jianke/index.html` → **✓ 校验全部通过**；`node jianke/smoke.test.js` → **SMOKE PASS**（真 THREE r128 跑完 boot → 逐境 build/update×400 帧 → fadeK 合规 → 末境点击门控 → 自动游览至终章 → 小测满分）；`node _pipeline/accept.js jianke` → **ACCEPT（2境 · 大漠金戈）**。
