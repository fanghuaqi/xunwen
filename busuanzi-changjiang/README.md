# 卜算子·我住长江头 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《卜算子·我住长江头》（宋·李之仪）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**青绿春晓·大江春晓**变体——宽江是绝对主角：两岸青山夹一水，相思瓣日日东漂，江头江尾两点灯火遥遥相望。

- 末章：全诗回放、学习小测（5 题）

**有意的设计**：「长江头尾两端、共饮一江水」是全词绝招——地理的两端被一条江连成一线。封面与三境全部沿东西向长江构图（西＝江头，东＝江尾），两端的远山让江流没入山影；两岸各立一人遥遥相望。全页最暖的两点是江头、江尾的信标灯（未点时只是两粒微芒），末境点击后随"千里贯通"先后亮起——相思的地理被灯线点亮。水的「日日」循环感由两套系统承担：相思瓣漂到尽头便从头再来的循环回流 + 水面振幅的长周期呼吸（约 30s 一循环）。

## 教学建议

1. **导入**：讲背景——李之仪曾入苏轼幕府，此词相传作于其贬谪之后；先问"两地相隔千里，靠什么相连？"再入境①。
2. **境①品味**：「长江头」「长江尾」对举言相隔之远，「日日」叠用写相思之长；「共饮长江水」是无可奈何中的宽慰——水隔人，水又连人。
3. **境②品味**：两个问句以水之不休喻恨之不已，问而无答恰是深情；看画面里"日夜不休"的急流与被裹挟东去的渡船。
4. **境③点击**：先让学生猜"这条江两头到底有多远"，再轻点画面看镜头沿江千里贯通、头尾两点渐亮——「只愿君心似我心」的盟誓随灯线落到对岸。
5. **典故**：结合小测讲「此水几时休」与汉乐府《上邪》「山无陵，江水为竭，乃敢与君绝」的盟誓口吻一脉相承。
6. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音 ×1、典故 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
