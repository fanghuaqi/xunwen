# 桃花溪 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《桃花溪》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**水墨夜思**赛道，取「桃源问津」变体——野烟迷离中隐约的**飞桥**、溪中的**石矶**与泊在矶西的**渔船**、终日随流水的**桃花**，以及云烟深处若隐若现的**洞口**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击清溪"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：野烟散去（烟片缩到 28%）、一座**飞桥**自烟中现出、130 枚**桃花瓣由顺流改为溯溪而上**（流向 +1→−1 平滑反转）、云烟深处**洞口微现**，"洞在清溪何处边"题字同现
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：封面设问"如果桃花一直往外流，你会顺着水往里找，还是问人？"再入境壹。
2. **境壹析"隐隐"与"隔"**：桥不是不见，是"隔野烟"而隐约——**朦胧**二字就是全诗基调。
3. **境贰析"问"与"不答"**：末句发问而不作答（"洞在清溪何处边"），把答案留给读者；这正是用意——桃源可望不可即。
4. **点解典故**：全诗暗用陶渊明《桃花源记》（渔人、桃花、落英缤纷、山有小口）——「洞」即桃源洞口（第 4 题考点）。
5. **点击体会**：点击清溪看烟散桥现、花瓣逆流而上，问学生："花瓣真的会往上游流吗？诗人为什么要这样写？"（这正是"追寻"的心象。）
6. **知人论世**：张旭以草书闻名（人称"张颠"），此诗清逸含蓄，与其狂草相映成趣。
7. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、词义 ×1、典故 ×1、主旨 ×1）。
8. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 39 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（石矶、渔船、桃树、飞桥）都在 5–40 单位内，fd ≤ 0.0066；全页**无一处手写 opacity**（野烟"散去"只缩 scale、花瓣流向只改 uniform 符号、洞口微光只调 scale）。
- 场景构件（冒烟实测）：卷首 14 mesh / 25 sprite、境壹 19 mesh / 27 sprite、境贰 20 mesh / 29 sprite；draw call 代理值 40 / 47 / 50（≤120），三角面 ≈2.1 / 2.5 / 3.0 万（≤12 万）。
