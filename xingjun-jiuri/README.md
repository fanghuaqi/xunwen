# 行军九日思长安故园 · 大漠金戈（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《行军九日思长安故园》（唐·岑参）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**大漠金戈**赛道——但刻意避开孤城/雪山/金甲/密林夜猎的既有边塞构图，写的是这场**战地重阳的时间线**：境壹=行军暮色（队伍蜿蜒、旌旗风沙、荒丘可登、雁阵南飞、道旁翻倒的空酒壶），境贰=故园悬想（断壁残垣、折戟残旗、硝烟横流，故园菊影傍着战场开）。accent=#b0906a（赭金）只落在人物边缘光/菊心/旌旗杆首/菊影暖光上，禁艳金。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"菊影浮现"，交互过后再按进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：故园菊影自战场硝烟中次第浮现，暖光涨起又徐落、金色花瓣飘落，"遥怜故园菊 应傍战场开"题字同现
- 末章：全诗回放、学习小测（5 题）

**有意的设计**：「应」字是全诗枢纽——长安沦陷、音书断绝，故园什么样只能悬想。画面同理：境贰基态只给战场废墟与一丛暗淡的现实野菊，**点击 = 诗人的悬想**——故园菊影自硝烟中浮现（透明菊影渐显），花开如旧、人事全非。悬想过后暖光徐落、花瓣渐散，想象退场，废墟依旧——「怜」字留在画面外。

## 教学建议

1. **导入**：先讲本事——至德二载（757）前后，长安沦陷于安史叛军之手，岑参随军征戍，行军路上正逢九月初九重阳。佳节与战火撞在同一日，这首二十字的小诗就是那一天的日记。
2. **境①诗眼**：「强」与「无人」——重阳三事（登高、饮酒、赏菊）开头两件就落空；注意「无人送酒来」反用陶渊明典故：陶潜重阳无酒尚有王弘遣白衣送来，行军途中连送酒的人都没有——比陶渊明更孤绝。
3. **境②点击后**：看菊影在硝烟中浮现又退场，讨论「应」字——长安音书断绝，只能悬想；悬想偏偏不肯美化，想象中的菊花就开在战场旁边（顺带钉读音：强 qiǎng、应 yīng、傍 bàng）。
4. **写法**：不写眼前行军之景，掉转笔头写千里之外想象中的景象——悬想（对写/虚写）。可对照王维「遥知兄弟登高处，遍插茱萸少一人」对读：同为重阳，一写兄弟、一写故园的花。
5. **背景**：岑参，边塞诗人代表，两度出塞；此诗是他少数写"后方之思"的边塞诗——金戈铁马之外，见其柔软处。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、手法主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数，全诗 20 字）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；进度点/按键/自动游览末境判断均以 `POEM.length=2` 对齐。
- 交互境序号 `curIdx===2`（pointerdown 与空格双接线，`clicked` 标志 + 1.2s 冷却防连点；空格先交互、再按进终章）。
