# 循文入境 · 石灰吟（明 · 于谦）

双击 `index.html` 即可使用（需联网加载 Three.js 引擎，音频已内置本地 `audio/`）。

## 页面导览

- **三重意境**（随诗句推进）：深山黑岩（千锤万凿出深山）→ 窑火烈焰（烈火焚烧若等闲）→ 清白人间（粉骨碎身浑不怕，要留清白在人间）。
- **色彩叙事**：暗色山岩 → 炽橙窑火 → 极亮雪白，三境三色断崖式转换，呼应"坚贞不屈"的情感曲线。
- **互动**：第二境点击画面窑火更烈（火星迸溅、火光更炽）；第三境点击后白雾散尽、中央清白石灰凝定（全诗互动放在末境）。
- 每句逐字注音（凿 záo、焚 fén、浑 hún 已核），附释义与考点注释；结尾有小测 5 题。
- 朗读优先用 Edge 神经语音现场朗诵，否则播放 `audio/00–04.mp3`（00 标题、01–03 各句、04 全诗）。

## 课堂建议

- 可开"自动游览 + 自动朗读"作大屏无人值守展示（← → 键/空格亦可逐境）。
- 讲到第三境时先提问："清白"只在说石灰吗？——引出一语双关与于谦的生平志向。

## 技术说明

- 单文件网页，Three.js r128（cdnjs → jsdelivr → unpkg 三路回退）。
- 音频由 `gen-voice.js`（百度 TTS 免密钥）生成；如需更自然的诗朗诵音色，配置 `TTS_AZURE_KEY` 后重跑脚本即可。
- 网络不通时页面自动回退浏览器语音，不影响游览。
