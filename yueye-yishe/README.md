# 循文入境 · 月夜忆舍弟（唐 · 杜甫）

单文件沉浸式诗词课件：四境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 水墨夜思·忆弟变体：戍鼓雁声的秋夜，两轮月的对照——他乡之月与记忆里更明的故乡月。
> 标志性瞬间：露从今夜白，月是故乡明——思念让故乡月独明。

## 教学建议

- 「月是故乡明」的主观移情：月亮本无差别，思念让它独明——与「露从今夜白」对仗细品
- 「一雁」的意象：雁行失群喻兄弟离散，首联已埋伏笔
- 结构链：闻雁→见露月→忆弟→无家→寄书不达→战乱未休，层层递进到家国之痛
- 注音考点：戍鼓 shù gǔ、断人行 duàn、一雁 yàn、白露 bái lù、皆分散 jiē、死生 sǐ shēng、寄书 jì shū、长不达 cháng、况乃 kuàng nǎi、休兵 xiū bīng
- 背景：乾元二年秋，史思明叛军南下，杜甫兄弟四散，作于秦州
