# 循文入境 · 逢雪宿芙蓉山主人（刘长卿）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（Three.js 走 CDN，配音在本地 `audio/`）。

## 三境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 暮山白屋 | 日暮苍山远，天寒白屋贫。 | 残阳沉入暮霭，苍山层叠渐远，白屋亮起一点暖窗 |
| 贰 · 柴门犬吠 | 柴门闻犬吠， | 柴门篱笆、犬剪影低吠，声波一圈圈荡开 |
| 叁 · 风雪夜归 | 风雪夜归人。 | **标志性瞬间**：点击画面——犬吠骤起，斗笠归人踏雪而来、身后留一行脚印，柴门推开暖光迎人 |

美术：宣纸留白 · 风雪夜归变体（日暮苍蓝 → 寒夜暖灯；落雪 + 横风 + 暖窗灯火母题）。

## 使用

- `← →` / 空格逐境游览；第三境**轻点画面或按空格**触发犬吠 + 归人归门 + 暖光溢出。
- 控制条：自动游览 / 朗读 / 注音 / 声音开关；结束后附 5 题学习小测。
- 朗读优先 Edge 神经语音现场朗诵，无网时回退 `audio/00-04.mp3`（00 标题、01-03 各境、04 全诗）。

## 课堂建议

1. 先整体自动游览一遍，感受"日暮→天寒→夜归"的光色渐变；
2. 逐境跟读，注意「吠 fèi」「贫 pín」读音；
3. 讨论："夜归人"是谁（主人还是诗人），体会风雪寒夜里"灯火可归"的温暖。
