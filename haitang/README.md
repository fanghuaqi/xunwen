# 海棠 · 夜宴金彩（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《海棠》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**夜宴金彩**赛道，取「夜庭海棠」变体——回廊一侧的夜庭、一树海棠、浮动的香雾与转过回廊的月光；末境点起一支**高烛**，照见海棠的**红妆**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击高烛"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：烛焰腾起、暖光池铺地，海棠花上的红色花光次第显影，"照红妆"题字同现
- 末章：全诗回放、学习小测（5 题）

- 逐句核过：袅袅 niǎo、泛崇光 chóng、空蒙 méng、月转廊 zhuǎn、只恐 zhǐ、花睡去、故烧高烛 zhú、照红妆——无须钉任何替换

## 教学建议

1. **导入**：封面设问"你愿意为看一朵花而熬夜吗？"再入境壹，先读前两句。
2. **境壹析"月转廊"**：月亮转过回廊，说明什么？（时间流逝、诗人已在花下站了很久——为下文的"夜深"埋线。）
3. **境贰析炼字**："只恐"见痴，"故"见情，"烧"（不是"点"）见急切；三个字连读，诗人对花的深情就出来了。
4. **典故与手法**：讲"海棠春睡"（唐明皇以杨贵妃醉态比"海棠睡未足"）；全诗以美人写花——先是"睡去"，再是"红妆"。
5. **点击体会**：点击高烛看花容渐显，让学生说说"这一树花为什么值得点一支高烛"。
6. **知人论世**：此诗作于苏轼贬居黄州时，写花之痴，也是自解——惜花之心，正是对美好事物的珍惜。
7. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、词义 ×1、典故 ×1、主旨 ×1）。
8. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 39 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（海棠、高烛、回廊、诗人）都在 8–24 单位内，fd ≤ 0.0056；**烛焰与光池只调 scale / 由引擎 makeFlame 按 fadeK 驱动**（本页无一处手写 opacity 渐隐），花光点是 Sprite 缩放。
- 场景构件（冒烟实测）：卷首 10 mesh、境壹 10 mesh / 2 points、境贰 14 mesh / 2 points / 20 sprite / 3 light；draw call 代理值 19 / 22 / 36（≤120），三角面 ≈1.1 / 1.3 / 1.0 万（≤12 万）。
- 校验记录：
  - `node _pipeline/tools/validate.js haitang/index.html` → **✓ 校验全部通过**
  - `node haitang/smoke.test.js` → **SMOKE PASS**（连跑 3 次稳定）
  - `node _pipeline/accept.js haitang` → **ACCEPT**（见汇报）
- 实拍抽检（`_pipeline/shots.py`，输出到系统 Temp，逐张 Read 检查）。
