# 扬州慢·淮左名都 · 烟雨江南（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《扬州慢》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。姜夔自度曲，写金兵劫后扬州的**黍离之悲**——本页走烟雨江南赛道的废城变体：黛蓝湿雾里荠麦青青，二十四桥的冷月是全页词眼。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境肆为"冷月无声"触发；末境再按进入终章）
- 控制条：自动游览、自动朗读（默认均开）、注音开关、声音开关、全屏
- 境肆轻点画面（或空格）：月影入波无声荡漾，荠麦青青漫过空城
- 末章：全词回放、学习小测（5 题）

## 美术方案：烟雨江南（art-direction 赛道⑥·废城变体）

| 项 | 取值 |
|---|---|
| 底色 | `#10141a`（黛蓝夜雾，与赛道典型一致） |
| 主色 | `#8f9fc9`（--gold：按钮/边框/进度点/题字） |
| 文字 | 冷白系 |
| 雾 | 湿雾偏浓，废城视野迷蒙 |
| 月 | 冷月唯一主角，末境沉至波心 |
| 荠麦 | 空城里唯一的青绿生命色——「青青」是废墟上仅有的活色 |

**有意的设计**：四境从「名都」到「空城」逐境抽走人气与光——春风十里只剩荠麦、清角吹寒只剩城郭，到末境只剩桥、波、月三样东西；越冷越静，"犹厌言兵"四个字才压得住。

## 教学建议

1. **导入**：先读杜牧「春风十里扬州路」，再入本词——同一座城的两副面孔。
2. **今昔对照**：境壹"名都/荠麦"一墙之隔，让学生找出词中今昔对写的字眼。
3. **拟人**：「废池乔木，犹厌言兵」——厌的是谁？讨论物犹如此、人何以堪。
4. **词眼**：境肆盯着冷月读「二十四桥仍在，波心荡，冷月无声」，数一数这句里有几个名词——以景结情。
5. **天问**：末句「念桥边红药，年年知为谁生」与「泪问红药」对照收束。
6. **收束**：末章全词连读一遍，再做完 5 题小测；课堂大屏可开"自动游览+自动朗读"无人值守循环展示。
