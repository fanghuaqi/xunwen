# 秋浦歌 · 循文入境

> 唐 · 李白　「白发三千丈，缘愁似个长。不知明镜里，何处得秋霜。」
> 单文件沉浸式诗词课堂：双击 `index.html` 即可上课（Three.js 走 CDN，首次打开需联网；配音在本地 `audio/`）。

- **风格赛道**：水墨夜思（shuimo）—— 冷银月为唯一主角，星稀、雾重、微尘与霜晶为粒子母题，UI 去金、窄幅立轴版式
- **强调色**：`#c0c8dd`（银白）｜底色 `#0d1117`｜雾 `#131a26`
- **标志性瞬间**：**三千丈白发如瀑自夜空垂落**，左侧银尺刻度标出「千丈 · 二千丈 · 三千丈」，把看不见的「愁」量成看得见的长度（场景库中无此原型，为本题自创 builder `bHairFall`）
- **交互**：第二境点击画面 / 按空格 **揽镜自照** —— 霜华自镜缘蔓生满镜、镜前白发更白、清磬一声

## 一、境数表（2 境 + 封面 + 终章）

| 序号 | 境名 | 诗句 | 画面与运镜 | 天空基调 |
|---|---|---|---|---|
| 卷首 | 卷首 | — | 秋浦夜水、芦苇剪影、微尘浮起 | 冷银大月低垂，雾薄星稀 |
| 第壹境 | **白发三千** | 白发三千丈，缘愁似个长。 | 发瀑自天垂落（3 层 186 缕），银尺量出三千丈，镜头由低处仰起 | 月为唯一主角（ms 2.0）、星 0.3、fd 0.007 |
| 第贰境 | **明镜秋霜** | 不知明镜里，何处得秋霜。 | 室内青灯一盏、铜镜结霜、镜前白发（可点击），人影对镜而立 | 无天空（ms 0.001、月移地下）、fd 0.02、星 0.08 |

情感曲线：**清冷（卷首）→ 夸张的悲慨（白发三千丈）→ 静默自伤（明镜秋霜）**，雾色由薄转重、月光由亮转隐，正是「愁」逐步内化的过程。

## 三、注音与多音字（逐字核对）

全文 20 字，拼音数组数量与汉字数严格一致（标点不注音）：

| 字 | 读音 | 说明 |
|---|---|---|
| 发（白发） | **fà** | 「头发」义读 fà，不读 fā |
| 似 | **sì** | 似个 = 像这样；非「似的」的 shì |
| 个 | **gè** | 唐宋口语指示代词，「这样、这般」 |
| 长 | **cháng** | 绵长、长；不读 zhǎng |
| 处 | **chù** | 「地方」义读 chù |
| 得 | **dé** | 得到 |
| 其余 | bái sān qiān zhàng / yuán chóu / bù zhī míng jìng lǐ / hé qiū shuāng | 常规读音 |

配音脚本 `gen-voice.local.js` 顶部的 SUB 表按此表改编（`白发→白珐`、`似个长→似个常`），只改音频读音，不改页面文字。

## 四、教学建议

1. **入境先问**：进第壹境前先问「白发怎么可能有三千丈？」——让学生带着夸张的疑问看发瀑垂落，再点开注释里的「三千丈」条目（一丈约三米余，三千丈 ≈ 九千米），体会李白把无形之愁量成有形之长的写法。
2. **量一量**：利用画面左侧的银尺刻度（千丈 / 二千丈 / 三千丈），请学生随镜头仰视，把「夸张」这一修辞落到具体画面上 —— 数字越往上越看不见，正合「愁」无边无际。
3. **对镜一问**：第贰境点「揽镜自照」，问「镜中明明是自己的头发，诗人为什么说『不知』『何处得』？」引导学生体会「故作不识」背后的惊心与自伤 —— 愁到不敢相认。
4. **比较读**：《将进酒》的「高堂明镜悲白发，朝如青丝暮成雪」与本诗同写白发，一豪一冷，可作同题异构的对比阅读。
5. **小测收束**：终章 5 题覆盖画面、读音、出处与手法，可当堂作答；`words` 评语按本诗定制（「已识三千丈之愁」等）。
6. **无人值守**：默认自动游览 + 自动朗读全开，可作课前循环展示或课后自读。

## 六、与《将进酒》的第一眼差异（防同质化三查）

| 维度 | 将进酒（夜宴金彩） | 秋浦歌（水墨夜思） |
|---|---|---|
| 色板 | `#05070d` + 鎏金 `#d4af37` | `#0d1117` + 银白 `#c0c8dd`，全页无金 |
| 母题 | 金色流萤、火星、酒光、三百金杯 | 微尘、霜晶、流云；月是唯一主角，星稀 |
| 版式 | 宽幅、暖色面板 | 窄幅立轴 + 一道银线 + 「秋浦」闲章 |
| 标志瞬间 | 三百金杯盘旋成星河 / 点击碰杯 | 三千丈发瀑垂落 + 银尺刻度 / 点击揽镜生霜 |
