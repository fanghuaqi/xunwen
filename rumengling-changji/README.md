# 如梦令·常记溪亭日暮 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《如梦令·常记溪亭日暮》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版为**青绿春晓·荷塘日暮**变体——全套青绿暮色色板，夕照是全页唯一的低饱和暖点，一滩鸥鹭的白色是画面里最亮的伏笔。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"争渡"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：急桨击水、水花迸溅，一滩鸥鹭冲天而起、盘旋满空，"惊起一滩鸥鹭"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：青绿春晓·荷塘日暮（art-direction 赛道④变体）

| 项 | 取值 |
|---|---|
| 底色 | `#0a1410`（青绿暮塘） |
| 强调色 | `#8fc9b8`（按钮/边框/进度点/题字，取自 queue 分配的 accent） |
| 文字 | `#eef4e6` |
| 雾 | `#0e1d16`，fd 0.0048–0.0060 |
| 夕照 | 低饱和暖光 `#d8b070`（西天一带 + 亭灯一点，**全页唯一暖源**） |
| 月 | 弯月极淡（ms 0.42–0.5，星稀 0.12–0.15） |
| 粒子母题 | 黄绿萤火、粉白荷瓣缓落、暮霭浮尘（替代金色流萤/火星） |
| 主景 | 荷荡（带缺刻圆盘荷叶 + 花苞外翻花瓣，InstancedMesh 合批）、一叶小舟舟中少女、沙洲鸥鹭群 |

**有意的设计**：全页只用一处暖色（夕照+船尾灯），与青绿底形成唯一对比——日暮的温度都酿在这一点点暖光里；白色鸥鹭在青绿暮色中先"伏"在沙洲（境②远处的亮点伏笔），点击后"爆"满天空，声、色、动同时到达顶点。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-XiaoxiaoNeural，语速 -14%，免费无密钥）：

- `00.mp3` 诗题（自动提取："如梦令·常记溪亭日暮"）
- `01.mp3` 上片逐境朗读、`02.mp3` 下片朗读
- `03.mp3` 全词连读

多音字处理（`tts.json`，同音同调替换、只影响读音不改页面文字）：**兴尽 → 幸尽**（兴读 xìng，兴致）；藕 ǒu、滩 tān、鹭 lù 均为本音无险。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入（忆游）**：「常记」二字说明这是一场多年不忘的记忆——什么样的事让人记一辈子？再入境①看画面。
2. **炼字（境①）**：「沉醉」是醉于酒也是醉于景；「误入」不是迷路的慌张，是玩到忘了时间的憨态。让学生找画面里哪里能看出"日暮"（夕照、船尾灯）。
3. **节奏（境②）**：两个「争渡」叠用是全词最响的一拍——先让学生急读两遍，再点击画面看"急桨惊鸟"，体会短促叠句里的慌张与兴奋。
4. **白描**：全词 33 字无一句抒情，只记一事、一景、一瞬，少女的天真烂漫全在事中——与《如梦令·昨夜雨疏风骤》对读（同为易安小令，一惜花、一记游）。
5. **朗读**：跟读音频，注意「兴（xìng）尽」「争渡（zhēng dù）」「鸥鹭（ōu lù）」读音。
6. **收束**：末章全词连读一遍，再做 5 题小测；课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（封面 + 两境），境名逐一对齐；`clamp(i,0,2)`、进度点、末境判断均以 `POEM.length=2` 对齐。
- 交互境序号 `curIdx===2`，pointerdown 与空格双接线（空格先交互、已交互再按进终章）。
- 校验：`node _pipeline/tools/validate.js index.html` → **✓ 校验全部通过**。
