# 溪居即事 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《溪居即事》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**青绿春晓**赛道，取「溪居童趣」变体——溪湾边一座柴门土墙的村居、篱外的垂柳，一只**不系船**被春风吹入钓鱼湾；末境点击去却关，小童急奔柴门、门闩抬起。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击去却关"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：小童从院内急奔到柴门（1.8 秒、位移 4.6 并落脚跳动）、门闩抬起 0.28 并偏转 0.22 弧度、两扇柴扉各转开 1.5 弧度、不系船继续漂入湾深处（移 11 单位并打转），"去却关"题字同现
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：封面设问"如果一只没拴住的船漂到你家门前，你家的孩子会怎么做？"再入境壹。
2. **境壹析"不系"与"吹入"**：一"不系"写船之无人管，一"吹入"写春风之多事；两个词就把"闲"字写出来了。
3. **境贰析"疑是""急向"**：误认（其实是船）＋ 急奔（以为来客）——童心的天真与好客全在这两处。
4. **点解"去却关"**：却＝除去，关＝门闩；"去却关"是**跑去开门**（不是关门）。可让学生动手做"抬门闩—推柴扉"的动作，体会词义（第 4 题考点）。
5. **点击体会**：点击去却关看小童奔门、门闩抬起、船又漂近一分——问："小童开门后会看到什么？他会失望吗？"
6. **写法小结**：全诗不写人而人自现——船「不系」、门「却关」、童「急向」，三个动作串成一幅村居风俗画。
7. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、词义 ×2、主旨 ×1）。
8. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 37 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（柴门、小童、船、柳）都在 6–24 单位内，fd ≤ 0.0062；全页**无一处手写 opacity**（船/童/门/柳/春风全走位置、旋转或 uniform）。
- 场景构件（冒烟实测）：卷首 14 mesh / 2 points、境壹 15 mesh、境贰 17 mesh；draw call 代理值 23 / 24 / 26（≤120），三角面 ≤0.9 万（≤12 万）。
