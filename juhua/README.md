# 菊花 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《菊花》「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本版走**青绿春晓**赛道，取「秋菊绕舍」变体——一丛丛秋菊绕着茅舍（似陶家），篱边看了一遍又一遍、太阳渐渐西斜；末境点击偏爱菊，斜阳更低、菊光次第亮起。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击偏爱菊"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：斜阳更斜更暖（日轮涨 12%、地面长影带转 0.5 弧度）、篱边五丛菊的花光次第点亮（0.45→1.4 倍）、菊丛摇曳加剧，"此花开尽更无花"题字同现
- 末章：全诗回放、学习小测（5 题）

## 教学建议

1. **导入**：封面设问"如果这是今年最后一种花，你会多看它几眼吗？"再入境壹。
2. **境壹析两个"绕"**：菊"绕舍"是花之盛，人"遍绕"是情之痴；"日渐斜"三字写看得忘了时间。
3. **境贰析说理**：先否定"偏爱"（不是我好菊），再给理由（此花开尽更无花）——理由里藏着**惜时**：愈是最后的好景，愈要珍惜；也常被引以喻**晚节可贵**。
4. **点击体会**：点击偏爱菊看斜阳更低、菊光次第亮起，再读末句，体会"最后"二字的重量。
5. **知人论世**："似陶家"用陶渊明"采菊东篱下"的典；元稹与白居易并称"元白"，此诗二十八字全用常语，却有意趣。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、典故 ×1、理趣 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 37 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排诗句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（茅舍、菊丛、篱、斜阳）都在 6–26 单位内，fd ≤ 0.0062；全页**无一处手写 opacity**（日轮/长影/花光/菊丛全走 scale、旋转或位置）。
- 场景构件（冒烟实测）：卷首 22 mesh、境壹 26 mesh、境贰 13 mesh / 29 sprite；draw call 代理值 32 / 36 / 43（≤120），三角面 ≈0.9 / 1.3 / 0.6 万（≤12 万）。
