# 行香子·树绕村庄 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《行香子·树绕村庄》（宋·秦观）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**青绿春晓**赛道——全集里最明亮欢快的页面之一：绿树绕村、春水满塘，桃花红、李花白、菜花黄三色花田是全词彩点，末境莺啼、燕舞、蝶忙三组小动物齐来。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境④为"点亮三色花田"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②入园：红白黄三色花田随词句**次第点亮**（标志性瞬间）
- 境④轻点画面：三色花田再次满开，莺声与"桃花红 · 李花白 · 菜花黄"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：青绿春晓（art-direction 赛道④）

| 项 | 取值 |
|---|---|
| 底色 | `#0a1410`（青绿春夜向晨） |
| 主绿/强调 | `#a0c9b8`（按钮/边框/进度点/题字，queue 分配 accent） |
| 文字 | `#eef4e6` |
| 雾 | `#0e1d16` 系，fd 0.0048–0.0058（逐境微降，天光渐亮） |
| 月 | 弯晓月低悬（ms 0.4–0.6），让位给东天晨曦暖光 |
| 粒子母题 | 粉白花瓣缓落（自定义双 shader 打旋下落）、黄绿萤尘；末境莺/燕/蝶三组活物 |
| 三色系统 | 桃花红 `#d05242` · 李花白 `#e8ecf2` · 菜花黄 `#e6c445`（InstancedMesh 花田，可整体"点亮"） |

**有意的设计**：全页只在"春光"上用高饱和彩点——三色花田未点亮时敛艳（亮度 0.3），点击/入园才满开；其余一切压在青绿底上，让"有桃花红，李花白，菜花黄"成为整卷唯一的色彩爆发。

## 朗读配音

`audio/` 内置 6 个 AI 朗读 MP3（Edge 神经语音 zh-CN-XiaoxiaoNeural，语速 -14%，免费无密钥）：

- `00.mp3` 标题（行香子·树绕村庄）
- `01–04.mp3` 四境逐境朗读
- `05.mp3` 全词连读

多音字以页面注音为准，`tts.json` 同音同调替换 8 条：陂塘 bēi（杯）、飏 yáng（扬）、徜徉 cháng yáng（尝羊）、豪兴/乘兴 xìng（姓）、莺儿/燕儿/蝶儿 ér（额）。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"春天有哪些颜色？"再入境①，对照"树绕村庄，水满陂塘"看树与水的布局。
2. **境②彩点**：让学生盯住三色花田次第点亮，数一数"桃花红、李花白、菜花黄"三个主谓短语——不着一个形容字，颜色自己会说话。
3. **境③叠字**："远远""隐隐"对读，体会淡墨远村；看青旗翻飏理解"飏"字之活。
4. **境④收束**：点击点亮三色花田后读末句，讨论"人徜徉"与"蝶儿忙"的闲忙相映；可介绍秦观"苏门四学士"的生平底色，反衬此词的难得轻快。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音 ×1、名物 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数=汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放。
- `STAGES = POEM + 1`（卷首 + 四境），境名逐一对齐；词文与 queue.json 逐字一致（语料未收，按统编教材通行本登记）。
- 交互境序号 `curIdx===4`，带 clicked 标志 + 1.4s 冷却；进度点/按键/自动游览末境判断均以 `POEM.length=4` 对齐。
- 每境 makeRange（多峰山脊）+ makeForeground（坡石/芦苇/树枝框景）+ makeFigure（乘兴漫步人）三层构图；draw call 代理 ≤50、三角面 ≤2.2 万，雾密度主体可读预算内。
- 校验：`validate.js` 全绿；`smoke.test.js`（真 r128 引擎）SMOKE PASS——fadeK 合规、末境交互门控、自动游览全生命周期、小测全流程；`accept.js` ACCEPT。
