# 涉江采芙蓉 · 宣纸留白（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《涉江采芙蓉》（汉·古诗十九首）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本页为**宣纸留白**赛道——但刻意避开已有宣纸页的构图（终南望余雪=雪线山体+城头望雪、十五从军征=荒村坟园+破败庭院、登乐游原=夕阳驱车、幸蜀宫=行宫宫苑），写的是这首游子诗的**江渚采芳·回望长路**：浅纸为天、浓墨作剪影、大量留白，一江浅水贯穿（卷首俯瞰→境壹入丛→境贰执芳→境叁回望→境肆临暮），核心是**江上采芳+回望长路的转身构图**。accent=#4a5a4e（青灰竹叶色，queue 分配强调色）只落在采莲人袍色衣领、UI、末境青灰雾流与暮光转冷上，全页近零饱和；芙蓉花用极淡的藕色，是全页唯一一点花意。

**有意的设计**：四境是一条"采芳而无可赠"的情感线——①涉江入丛（兴致勃勃渡水采芳，乐景起笔）→ ②执芳自问（花在手上、人在天边，「采之欲遗谁」一问问空了欢喜）→ ③转身回望（标志性瞬间：望见的不是家而是路，长路漫浩浩，旧乡只剩一道烟痕）→ ④临暮还顾（点击还顾：故乡淡现又远去——望乡而终不可归，「忧伤以终老」）。长路上的极小行人剪影即"所思在远道"的虚写：花要送的人在路的另一头，两头都回不去。

## 教学建议

1. **导入**：先问学生——如果你采到一枝最美的花，第一个想送给谁？如果他/她在千里之外呢？——这首诗的全部故事，就从"花在手上、人在天边"开始。
2. **境壹看点**：江水、兰泽、芙蓉、芳草，全是洁净芳洁之物；「多」字写足兰泽繁盛，也暗中蓄起一份欢喜——采芳是为了赠人。以乐景起笔，是跌落的起点。
3. **境贰诗眼**：「遗 wèi」是赠。自问自答，一句话把欢喜问成了空。可让学生注意长路上那些极小的行人剪影——所思的人就在某条路上，花却送不到。
4. **境叁看点（标志性瞬间）**：让学生在画面里找"家"——找不到的；望见的是路。「还 huán 顾」是一个转身的动作：身在江渚采芳，心却早已顺着来路回去了。「浩浩」本写水势，移来写长路，路与愁一同浩浩而去。
5. **境④点击后**：故乡剪影淡现又远去——看得到，回不去。追问：为什么是"淡现又远去"而不是"越望越近"？——空间的远，也是归期的渺茫。
6. **主旨**：「同心」与「离居」四个字硬生生对撞：心越近，人越远。收束不呼号、不泣诉，只淡淡说「忧伤以终老」——把一时的相思说成一生的底色，语浅而情深，正是《古诗十九首》「深衷浅貌，短语长情」的绝唱处。
7. **诵读**：五言二三节拍（涉江/采芙/蓉，兰泽/多芳/草），语速宜缓；「采之欲遗谁」的自问宜轻，「长路漫浩浩」宜拖长渐弱——望不到头的路，声音也要望不到头。
8. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示；末境留 3 秒给学生自己点击，看故乡淡现又远去的一刻。

## 小测设计（5 题）

接龙×2（起句接下句、第三境句接第四境句）→ 读音词义×1（遗 wèi 赠送／浩浩 hào hào 考点钉子）→ 文学常识×1（《古诗十九首》东汉文人五言诗代表、最早见于萧统《文选》、采芳赠远上承楚辞香草传统）→ 名句理解/主旨×1（"同心而离居，忧伤以终老"以一生的忧伤写绵长无尽的思念，语浅情深）。
