# 谒金门·风乍起 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《谒金门·风乍起》「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本版走**青绿春晓**赛道，取「春池杏影」变体——一池被春风吹皱的池水、一对缓游的鸳鸯、临水的一树红杏、刻着斗鸭的阑干与斜坠的碧玉搔头；全页的题眼只有一件事：**风乍起，吹皱一池春水**。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境贰为"点击池水，涟漪再起"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境贰轻点画面：池水涟漪层层皱开，枝头喜鹊振翅上飞，"举头闻鹊喜"题字同现
- 末章：全诗回放、学习小测（5 题）

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 `zh-CN-XiaoxiaoNeural`，语速 −14%，与 Azure 付费"诗朗诵"同一套神经语音）：

- `00.mp3` 标题（"谒金门·风乍起"）
- `01.mp3` 境壹（风乍起，吹皱一池春水。闲引鸳鸯香径里，手挼红杏蕊。）
- `02.mp3` 境贰（斗鸭阑干独倚，碧玉搔头斜坠。终日望君君不至，举头闻鹊喜。）
- `03.mp3` 全篇连读

多音字处理见 `tts.json`（**sub 非空即完全接管**，不再叠加脚本内置兜底表）：

- `斗鸭` → `豆鸭`（dòu yā 同音同调，钉住"斗"的 dòu 音，避免被读成 dǒu）
- 「手挼红杏蕊」的 `挼`（ruó）**未做替换**：现代汉语里没有更常见、且同音同调的替代字（`捼` 同样生僻，替换反而更糟），故按"宁缺勿滥"保留原字，读音以页面注音 ruó 为准
- 其余逐句核过：乍 zhà / 皱 zhòu / 鸳鸯 yuān yāng / 蕊 ruǐ / 阑干 lán gān / 玉 yù / 搔 sāo / 斜 xié / 坠 zhuì / 鹊 què，均为神经语音的常见读音，无需干预

页面朗读优先级：Edge 在线自然语音现场逐句朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"风看得见吗？"再入境壹，让学生先看池面再看词句——风本无形，词人用一个"皱"字让它现了形。
2. **境壹炼字**：重读"吹皱一池春水"，讲"皱"字之妙（把水面写成有褶皱的绸缎）；顺势讲冯延巳与南唐中主李璟"吹皱一池春水，干卿何事"的词坛本事。
3. **景中之情**：点出"鸳鸯成双"与她"独自逗引"的反衬——春景越明媚，人的百无聊赖越明显；"挼（ruó）"是随手揉搓，正是无心的动作。
4. **境贰动作**：让学生跟着做"独倚"与"举头"两个动作，再读"终日望君君不至"，体会等待被拉到最长的那一刻。
5. **末句一转**：点击池水看涟漪再起、喜鹊上飞，讨论"闻鹊喜"为什么是全词的转机——民间以鹊声为喜兆，无望里忽然有了一点希望。
6. **收束**：末章全诗连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、典故本事 ×1、主旨 ×1）。
7. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示（2 境约 38 秒走完）。

## 结构与校验

- 单文件 `index.html`：竖排词句 + 逐字注音（拼音数 = 汉字数）、释义/注释、境名/意境题句、5 题小测、终章回放；封面与终章均有"返回诗集目录"链接。
- `STAGES = POEM + 1`（封面 + 贰境），境名逐一对齐；`showEnding` 以 `state!=='stage'` 守卫，交互境序号 `curIdx===2`（pointerdown 与空格双接线，空格先交互、交互过后再按才进终章，含 1.2s 冷却）。
- 雾预算：主体（池水/阑干/人物）都在 15–30 单位内，fd ≤ 0.0058，实测主体遮蔽率远低于 0.35 上限；自定义着色器（水面 `makeWater`、涟漪、远山）全部登记 `fogShaders` 同步雾参数，穹顶/星/月 `fog:false`。
- 场景构件（冒烟实测）：卷首 15 mesh、境壹 24 mesh / 1 points / 7 sprite、境贰 23 mesh / 1 points / 8 sprite；draw call 代理值 24 / 32 / 32（≤120），三角面 ≈2.8 / 3.2 / 2.7 万（≤12 万）。
