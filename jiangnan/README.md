# 循文入境 · 江南（汉乐府）

单文件沉浸式诗词课件：双击 `index.html` 即可运行（Three.js 走 CDN，音频本地）。

## 使用

- **入境**：封面点「入 境」；`← →` 方向键 / 空格逐境游览，也可点顶部进度点跳境。
- **自动游览**：控制条「自动游览」打开后无人值守自动走完全部 4 境并进入终章（适合课堂大屏）。
- **朗读**：进入新境自动朗读；Edge 浏览器下优先用"在线自然语音"现场逐句朗诵，其他浏览器回退内置 `audio/*.mp3`。
- **互动**：第四境「鱼戏南北」**点击画面 / 按空格**，撒下一群鱼向东南西北四向穿梭戏莲（标志性瞬间"鱼戏四向"）。
- **注音 / 声音 / 全屏**：控制条可随时开关。

## 四境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 莲叶田田 | 江南可采莲，莲叶何田田。 | 镜水之上莲叶层层铺满，莲花点缀 |
| 贰 · 鱼戏叶间 | 鱼戏莲叶间。 | 鱼群绕着莲叶穿行，尾尾带涟漪 |
| 叁 · 鱼戏东西 | 鱼戏莲叶东，鱼戏莲叶西。 | 两路鱼群东西对穿莲叶 |
| 肆 · 鱼戏南北 | 鱼戏莲叶南，鱼戏莲叶北。 | 南北对穿 + 点击撒鱼四向戏莲 |

## 文件

```
index.html        主页面（单文件）

gen-voice.js      配音再生成脚本（SUB 表：乐府→悦府，保 yuè fǔ 读音）
smoke.test.js     深度冒烟测试（node smoke.test.js，19 项）
```

## 教学建议

- 先整体自动游览一遍，再逐境提问："鱼都游到了哪几个方向？"体会民歌复沓回环的趣味。
- 注意「间 jiān / 戏 xì」的读音；「田田」「何」为常考词义。
- 网络不通时页面自动回退浏览器语音；重新生成配音：`node gen-voice.js index.html "江南" "汉，乐府"`。
