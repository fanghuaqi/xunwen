# 点绛唇·蹴罢秋千 · 青绿春晓（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《点绛唇·蹴罢秋千》（宋·李清照）「循文入境」教学网页：诗句推进到哪一句，三维实景就走到哪一重意境。本篇为**青绿春晓·易安春园**变体——春日后园的青绿晨光、露浓花瘦的花树、倚门回首嗅梅的少女剪影。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"回首嗅梅"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：少女和羞跑向门边（跑）→ 倚门回身（回首）→ 把青梅举到鼻尖（嗅梅），秋千余荡重启、梅香微光浮起，题字「却把青梅嗅」同现；可反复点击重演三段动作
- 末章：全诗回放、学习小测（5 题）

## 美术方案：青绿春晓·易安春园（art-direction 赛道④变体）

| 项 | 取值 |
|---|---|
| 底色 | `#0a1410`（青绿深底） |
| 主绿 | `#b0cf9f`（按钮/边框/进度点/题字，分配强调色） |
| 文字 | `#eef4e6`，次要 `#8aa892` |
| 雾 | `#0e1d16` 系，fd 0.0050–0.0058 |
| 月 | 晨昏淡月（下弦 ms 0.36–0.50，低悬远山，不作主角） |
| 星 | 极稀（0.06–0.10，春晓星隐） |
| 粒子母题 | 粉白落花瓣（慢落）、黄绿萤火、花冠露光、梅香微光（替代《将进酒》的金色流萤/火星） |

**有意的设计**：全页唯一的暖色是东天晨曦的一抹暖金（平行光 `#d8c88a` 系 + 封面晨曦光晕）——它是"春晓"的温度；园中景物全部压在青绿色域内。境①最亮的生机色是枝头**粉白瘦花**与花冠**露光**（「露浓花瘦」），境②的点睛色是门边**青梅**的嫩果绿（「却把青梅嗅」）——两境各有一处"最亮"，随词句推进换位。

## 朗读配音

`audio/` 内置 4 个 AI 朗读 MP3（Edge 神经语音 zh-CN-XiaoxiaoNeural，语速 −14%，青绿赛道自动选声）：

- `00.mp3` 标题（点绛唇·蹴罢秋千）
- `01–02.mp3` 两境逐境朗读
- `03.mp3` 全词连读

多音字以页面拼音为准，`tts.json` 同音同调替换：蹴 cù（借「促」）、刬 chǎn（借「产」）、薄 bó（借「博」）、和羞 hé（借「河羞」）；「溜 liū」无可靠同音同调常用字，由神经语音按 liū 直读。页面朗读优先级：Edge 在线自然语音现场朗诵 → 内置 MP3 → 系统语音兜底。

## 教学建议

1. **导入**：封面设问"荡完秋千的那一瞬，少女会做什么？"再入境①，对照"慵整纤纤手"看画面里举到鬟边的双手。
2. **境①以花喻人**：让学生找"露浓花瘦"在画面里的对应——花冠露光与清瘦花枝，讨论"花瘦"怎样暗写少女身影；"薄汗轻衣透"由少女微亮的衣缘边缘光带出。
3. **境②动作戏**：先读词句再点击画面，让学生给三段动作配音（跑—回首—嗅梅），体会"袜刬金钗溜"的匆忙与"却把青梅嗅"的机灵；可追问"她真的在想梅子吗？"
4. **知人论世**：简介早期李清照（易安居士少女时代）与周煇《清波杂志》所记本事，对比后期词风的沉郁。
5. **收束**：末章全词连读一遍，再做 5 题小测（接龙 ×2、读音 ×1、名句理解 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
