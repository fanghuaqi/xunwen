# 浣溪沙·谁念西风独自凉 · 水墨夜思（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《浣溪沙·谁念西风独自凉》（清·纳兰性德）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。纳兰悼亡词的压卷之作，本版为**水墨夜思**赛道——全套冷银水墨色板，冷灰残阳与萧萧黄叶是现实底色，疏窗内的一线茶色暖光是全页唯一的暖点：回忆越暖，现实越冷，即是「当时只道是寻常」的钝痛。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②先触发"茶香书影闪回"，再按才进终章）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：窗内夫妻对影凝现（赌书泼茶的闺房之乐）、残阳满窗暖忆漫上，"当时只道是寻常"题字同现
- 末章：全诗回放、学习小测（5 题）

## 美术方案：水墨夜思（art-direction 赛道②）

| 项 | 取值 |
|---|---|
| 底色 | `#0d1117`（墨夜） |
| 主银 | `#b0bcc9`（按钮/边框/进度点/题字，全部冷银水墨调，**无一处金色**） |
| 文字 | `#dfe6f0` |
| 雾 | `#121926` 系，fd 0.0050–0.0060 |
| 日 | 残阳冷灰（`#d9dee6` 日轮 + 银灰辉光，limbTex 临边昏暗），低垂山脊；月藏（ms 0.001 移出视野）——本词主角是"残阳"不是月 |
| 星 | 稀疏（亮度 0.20–0.30） |
| 粒子母题 | 萧萧黄叶（灰黄低饱和下落）、西风横流、微尘、霜晶微闪、茶香烟缕（替代《将进酒》的金色流萤/火星） |

**有意的设计**：全页唯一暖点是境②疏窗内的**茶色暖忆**（窗纸暖光 `#b08e80`、暖点光、地面光池，低饱和不违水墨禁金）——点击前窗内影"伏而未现"（寻常到被忽略），点击"泼茶香"后夫妻对影**凝现**、暖忆漫上窗纸、残阳满窗：窗内是暖忆书影，窗外是冷灰残阳，**一窗两界**，即是"当时只道是寻常"。李清照赵明诚赌书泼茶之典（见《金石录后序》注释），写的正是自家与卢氏的闺房之乐。

## 教学建议

1. **导入**：设问——秋凉人人受过，为什么纳兰的"凉"格外痛？再入境①，找画面里"独自"二字的位置。
2. **境①写景**：让学生数一数画面里的凉意来源（西风、黄叶、闭窗、残阳），结合注释讲卢氏其人，理解"谁念"问的是"再无知冷知热的人"。
3. **境②用典**：先看注释里李清照《金石录后序》"赌书泼茶"的原典，再点击画面看闪回，讨论纳兰为什么借李赵夫妇写自家闺房之乐。
4. **结句钝痛**：点击后对比窗内暖忆与窗外冷灰，讨论"当时只道是寻常"为什么不着一个"悲"字而痛到极处——最深的悼念，是悔恨当初把幸福当成了寻常。
5. **收束**：末章全诗连读一遍，再做 5 题小测（接龙 ×2、读音词义 ×1、典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
