# 循文入境 · 白雪歌送武判官归京（唐 · 岑参）

单文件沉浸式诗词课件：六境随诗句推进，逐字注音、释义注释、AI 朗读（Edge 神经语音）、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

> 全集唯一**浅色（宣纸留白）雪景**页面：宣纸底、灰调远山、深色锚点（红旗/辕门/人影）压住画面。

## 六境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 风卷白草 | 北风卷地白草折，胡天八月即飞雪 | 八月胡天飞雪，白草折伏 |
| 贰 · 梨花千树 | 忽如一夜春风来，千树万树梨花开 | 标志性瞬间：满树积雪绽成白梨花（**点击枝头**次第绽开） |
| 叁 · 苦寒难着 | 散入珠帘湿罗幕……都护铁衣冷难着 | 狐裘不暖、角弓不得控、铁衣难着 |
| 肆 · 冰天饯别 | 瀚海阑干百丈冰……胡琴琵琶与羌笛 | 百丈冰原上中军帐置酒饯别 |
| 伍 · 暮雪辕门 | 纷纷暮雪下辕门，风掣红旗冻不翻 | **全诗唯一重色**：一杆冻僵、不再翻卷的红旗 |

## 操作

- `← →` / 空格：切境（交互境空格 = 触发交互）；自动游览、自动朗读默认可开
- 朗读优先级：Edge 神经语音现场朗诵 → `audio/` 内置 MP3 → 系统语音
- `audio/00–07.mp3`：题名、六境、全诗（Edge 神经语音·云希；`tts.json` 多音字替换只影响读音）

## 教学建议

- "忽如一夜春风来，千树万树梨花开"：以春景写冬雪的浪漫想象，咏雪千古名句
- "风掣红旗冻不翻"：细节的功夫——别人的旗都在飘，这一面冻住了
- "山回路转不见君，雪上空留马行处"：言有尽而意无穷，可与"孤帆远影碧空尽"对读
- 注音考点：白草折 zhé、锦衾薄 bó、冷难着 zhuó、都护 dū hù、风掣 chè、辕门 yuán
- 异文说明：语料库古本作"狐裘不煖""愁云黪淡"，本页从现行教材本作"不暖""惨淡"
- 结构：咏雪（奇寒）→ 饯别 → 送别 → 余味，送别诗的完整叙事链
