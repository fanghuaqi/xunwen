# 菩萨蛮·小山重叠金明灭 · 夜宴金彩·闺阁晨妆（循文入境沉浸式诗词课件）

以 Three.js 打造的单文件《菩萨蛮·小山重叠金明灭》（唐·温庭筠）「循文入境」教学网页：词句推进到哪一句，三维实景就走到哪一重意境。本篇为**夜宴金彩·闺阁晨妆变体**赛道——底色沿用夜宴基线 `#05070d`，但把"豪饮之金"换成"梳妆之金"：金箔屏山、铜镜、烛焰、香篆、金线绣鹧鸪，是一间晓色未明的闺阁，不是一场宴席。

## 打开方式

双击 `index.html` 即可（需联网加载 Three.js CDN；音频本地播放）。推荐 Chrome / Edge 全屏演示。

- `←` `→` 键 / 空格：逐境推进（空格在境②为"镜中花面重影交映"）
- 控制条：自动游览、自动朗读、注音开关、声音开关、全屏
- 境②轻点画面：前后两镜镜面同时生辉、镜中花面重影交映出一道光桥，衣上金鹧鸪金线随之生亮（五声琶音 +「花面交相映」题字）
- 末章：全词回放、学习小测（5 题）

## 美术方案：夜宴金彩·闺阁晨妆（art-direction 赛道①变体）

| 项 | 取值 |
|---|---|
| 底色 | `#05070d`（夜宴基线，style-audit 硬校验） |
| 主金 | `#d4b050`（queue 分配强调色；按钮/边框/进度点/题字/金箔/金线全跟此色） |
| 文字 | `#e8dcc0` |
| 雾 | `#150f0a` 暖褐，fd 0.0052–0.0090（室内感） |
| 月 | 隐月（两处词境 ms 0.001 且月沉地下），仅卷首残月低垂；星稀（0.05–0.3） |
| 粒子母题 | 金尘浮粒（烛光浮埃）、香篆一缕（香炉起烟）、焰心火星——不用流萤/酒光 |
| 暖源 | 妆台双烛（点光 1.76/1.9 + 焰体）、窗外晓色、楼窗一点金——全页仅闺阁暖金一种色温 |

**有意的设计**：与《将进酒》的"三百金杯"宴饮金区别开——本篇的金全部长在"妆"上：屏山上金箔明灭（`emissiveIntensity` 随烛焰双频呼吸，即"金明灭"的字面视觉化）、铜镜高反光（shininess 96）、罗襦上一对金线鹧鸪。点击前后镜时才让镜中花面重影交映成桥，是全页唯一的爆发性高光。

## 教学建议

1. **导入**：封面设问"'小山'是什么山？"再入境①，对照画面看屏山金箔随烛光明灭——介绍"小山"的屏山说（一说眉妆、发髻）。
2. **境①炼字**：抓住"懒""迟"二字——妆容未成而意兴阑珊，让学生体会"以慵懒写幽怨"的侧面笔法；"鬓云欲度香腮雪"是云与雪的比喻叠映。
3. **境②动作**：让学生想象"前后镜"如何照见簪花——两镜相照、花面重重交叠，理解"交相映"的妙处；点击画面强化这个瞬间。
4. **结句反衬**：看罗襦上"双双金鹧鸪"——衣上成双与人影独立相对照，讨论"乐景写哀"。
5. **收束**：末章全词连读一遍，再做完 5 题小测（接龙 ×2、读音词义 ×1、名物典故 ×1、主旨 ×1）。
6. 课堂大屏可开"自动游览 + 自动朗读"无人值守循环展示。
7. 可补背景：温庭筠被称为"花间鼻祖"，此词为《花间集》开卷第一首。
