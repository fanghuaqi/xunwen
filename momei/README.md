# 循文入境 · 墨梅（元 · 王冕）

单文件沉浸式诗词课件：双击 `index.html` 即可打开（首次需联网加载 Three.js）。

## 页面特色

- **赛道**：宣纸留白 · 洗砚池墨梅变体 —— 页面本身即一张宣纸，墨梅以水墨笔触在画中"晕开"。
- **三境**：① 洗砚池头（半池墨色、砚台墨锭、树影初描）→ ② 淡墨花开（整棵梅树被墨笔逐枝"画"出，花朵自一粒墨点层层洇开）→ ③ 清气乾坤（清气化作墨香流雾弥散全屏）。
- **互动**：第三境点击画面 / 空格 —— 墨梅晕染重生：整树重画、花朵次第重绽、清气弥散。
- **配套**：逐字注音（砚 yàn、痕 hén、乾 qián、坤 kūn）、释义注释、AI 朗读（audio/00–04.mp3，00 标题、01–03 各句、04 全诗）、自动游览、结课小测 5 题。

## 教学建议

1. 先整体自动游览一遍，让学生"看画猜诗"。
2. 第二境停留观察"墨点晕开花瓣"的过程，对应"朵朵花开淡墨痕"的"痕"字。
3. 借第三境"清气"讨论双关：既是梅香，也是人格气节；结合注释中王冕生平与"不要人夸好颜色"体会托物言志。
4. 小测覆盖接龙、"乾"字读音、洗砚池典故与主旨，可作课堂检测。

## 说明

- 声音开关、注音开关、自动游览均可一键切换；无音频时自动回退浏览器语音。
