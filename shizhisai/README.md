# 循文入境 · 使至塞上（唐 · 王维）

单文件沉浸式诗词课件：四境随诗句推进，逐字注音、释义注释、AI 朗读、自动游览、结课小测。
双击 `index.html` 即可打开（Three.js 走 CDN，音频本地；首次打开需联网）。

## 四境

| 境 | 诗句 | 画面 |
|---|---|---|
| 壹 · 单车问边 | 单车欲问边，属国过居延 | 单车孤骑出汉塞，身后是渐远的关隘与苍茫地平线 |
| 贰 · 征蓬归雁 | 征蓬出汉塞，归雁入胡天 | 蓬草随风出塞、归雁没入胡天，两重飘零同框 |
| 叁 · 孤烟落日 | 大漠孤烟直，长河落日圆 | 标志性瞬间：一根笔直孤烟直上，一轮正圆落日压着横贯长河——横与竖的几何对位 |
| 肆 · 萧关燕然 | 萧关逢候骑，都护在燕然 | 萧关烽燧次第点亮，烽火链一路传向燕然（**点击画面**点燃，题字「都护在燕然」） |

## 教学建议

- 注音考点：单车 `dān`、属国 `shǔ`、候骑 `hòu jì`、都护 `dū hù`、燕然 `yān rán`、长河 `cháng`
- 名句赏析："大漠孤烟直，长河落日圆"——以"直""圆"两字写尽塞外苍茫，被称为"千古壮观"（王国维《人间词话》）；画面中孤烟竖直、落日正圆，可与诗句对读
- 用典："燕然"用窦宪破匈奴、勒石燕然山典故，写唐军声威
- 情感线索：以"征蓬""归雁"自比（开元二十五年出使河西），由漂泊孤独到听闻前线捷报的开阔
- 可作课堂大屏无人值守展示：默认已开启"自动游览 + 自动朗读"，全程自走
